## 5 交互流程

### 5.1 单点登录

```
访问 /admin/dashboard（未登录）
  → 重定向 /admin/login → 点击"企业 SSO 登录"
  → 跳转 IdP → 认证成功回调 → 令牌换发 → 回到原页面
  首次登录（无账号，自动开通开启）→ 展示"完善信息"引导页
  MFA 用户 → 二次验证 → 通过后进入
```

### 5.2 待办审批

```
工作台"我的待办"→ 点击任务 → 审批详情（含单据摘要 + 审批轨迹）
  → 选择动作（同意/驳回/加签/转办）→ 填写意见 → 二次确认
  → 提交（幂等）→ Toast 成功 → 返回待办列表（已处理移除）
  并发冲突 → 提示"任务已被处理"并刷新
```

### 5.3 租户开通

```
管理端 → 租户列表 → 新建 → 4 步向导 → 提交
  → 进入审批（合规审核）→ 进度可查 → 审批通过 → 展示开通结果（编码/管理员/初始化状态）
  驳回 → 通知发起人（含意见）→ 修改重提
```

### 5.4 开放应用上架

```
开发者门户 → 创建应用 → 填写用途/scope/回调 → 提交审核
  → 平台运维初审 → 安全管理员复审 → 通过
  → 生成 AppKey/AppSecret（仅显示一次）→ 引导下载 SDK/调试
```

### 5.5 AI 问答

```
/携带 输入问题 → 护栏检测（输入）→ 检索（权限过滤）
  → 流式生成（SSE delta）→ 展示引用（citation）→ 完成（done）
  → 用户反馈（👍/👎）→ 降级提示（degraded 时展示"当前为降级模式"）
```

## 6 响应式

### 6.1 断点

| 断点 | 宽度 | 布局 |
|---|---|---|
| XL | ≥ 1440px | 完整布局（管理端三栏） |
| LG | 1200–1439px | 完整布局（次要列隐藏） |
| MD | 992–1199px | 侧栏可折叠；表格横向滚动 |
| SM | 768–991px | 用户端顶部导航；管理端侧栏抽屉化 |
| XS | < 768px | 单列；移动端优先；最小可点击区 44×44px |

### 6.2 响应式规则

- 管理端在 MD 及以下侧栏折叠为图标/抽屉；表格列按优先级隐藏（`priority` 列）；
- 用户端 SM 及以下卡片单列堆叠；快捷入口横向滚动；
- 图表容器宽高自适应（ResizeObserver）；
- 移动端手势：下拉刷新、左滑操作（消息/待办）。

## 7 状态规范

| 状态 | 处理 |
|---|---|
| 加载（首次） | 骨架屏（Skeleton），避免整页白屏 |
| 加载（局部/分页） | 区域 Loading 遮罩 |
| 空态 | `FlEmpty` + 引导文案 + 主操作按钮（如"新建租户"） |
| 错误（网络/服务） | 错误卡片 + 重试按钮 + 错误码（可复制 requestId） |
| 无权限（403） | "无访问权限"页 + 申请权限入口 |
| 未认证（401） | 跳转登录（携 redirect） |
| 成功反馈 | Toast（轻）/ Message（中） |
| 危险操作确认 | 二次确认弹窗（需输入名称/验证码的高危操作） |
| 降级状态 | 顶部横幅提示"当前为降级模式/数据可能滞后" |

**一致性要求**：所有列表页必备"加载/空/错误/无权限"四态；所有写操作必备成功/失败反馈。

## 8 可访问性

| 项 | 要求 |
|---|---|
| 对比度 | 文本与背景对比度 ≥ 4.5:1（大字 ≥ 3:1） |
| 键盘导航 | 全功能可键盘操作；`Tab` 顺序合理；`Esc` 关闭弹窗 |
| 焦点样式 | 显式 focus ring（2px 主色描边），不可移除 |
| 语义化 | 使用语义标签/ARIA 属性；表单控件关联 label |
| 表单校验 | 错误信息与控件关联（`aria-describedby`），并聚焦首个错误 |
| 动效 | 尊重 `prefers-reduced-motion`，禁用非必要动画 |
| 颜色非唯一信息载体 | 状态需同时有图标/文字（不仅靠颜色） |
| 国际化 | 文案外置（i18n），默认 `zh-CN`，预留 `en-US`；数字/日期本地化格式化 |

## 1 通用约定

（完整约定引用 FL-HUB-STD-001 第 5 章，本节补充平台特有约定。）

- 协议 HTTPS（TLS 1.2+，推荐 1.3）；内部服务间 mTLS；数据格式 `application/json; charset=UTF-8`；文件 `multipart/form-data`。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1）、`size`（默认 20，最大 200）；响应 `data = { records, total, page, size }`。
- 统一响应体：

```json
{
  "code": "0",
  "message": "success",
  "data": {},
  "requestId": "b1f2c3d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- 请求头：`Authorization`、`X-Tenant-Id`、`X-Client-Type`（ADMIN/PORTAL）、`X-Request-Id`、`Idempotency-Key`、`Accept-Language`。
- 错误码结构 `{域2}{模块2}{序号3}`，平台域前缀 `00`：

## 2 鉴权与端别

| 项 | 说明 |
|---|---|
| 鉴权（双端） | OAuth2.1/OIDC，JWT（RS256）；`Authorization: Bearer {access_token}` |
| 鉴权（服务间） | mTLS + 服务令牌；`X-Caller-Product`、`X-On-Behalf-Of`（用户代理） |
| 端别 | `X-Client-Type`：`ADMIN`/`PORTAL`；须与令牌 `client_type` 一致，否则 `0000002` |
| 租户 | `X-Tenant-Id` 必填，须与令牌一致 |
| 权限 | 功能权限码 + 数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）+ 字段权限 |
| 幂等 | 写操作支持 `Idempotency-Key`（24h）；审批/计量/结算强制 |
| 追踪 | `X-Request-Id`、`X-Trace-Id` |

**端别归属**：`/api/hub/v1/admin/**` 仅 ADMIN；其余业务路径仅 PORTAL；`/internal/**` 仅服务间（mTLS）；`/.well-known/**`、`/api/hub/v1/sso/**` 免业务鉴权（协议端点）。

## 4 逐接口定义

> 以下每条包含：方法/路径、端别与权限、请求参数、响应示例、错误码、幂等与限流。公共请求头不再重复。

### 4.1 SSO / OIDC

#### HUB-API-101 OIDC 发现文档
- `GET /.well-known/openid-configuration`｜公开
- 响应：`data={"issuer":"https://hub.fenglincloud.com","authorization_endpoint":"/api/hub/v1/sso/authorize","token_endpoint":"/api/hub/v1/sso/token","jwks_uri":"/.well-known/jwks.json","response_types_supported":["code"],"code_challenge_methods_supported":["S256"],"scopes_supported":["openid","profile","tenant","offline_access"]}`

#### HUB-API-102 JWKS 公钥
- `GET /.well-known/jwks.json`｜公开
- 响应：`data={"keys":[{"kty":"RSA","kid":"hub-2026-01","use":"sig","alg":"RS256","n":"...","e":"AQAB"}]}`

#### HUB-API-103 授权端点
- `GET /api/hub/v1/sso/authorize?client_id=&redirect_uri=&response_type=code&code_challenge=&code_challenge_method=S256&state=&scope=openid+profile`｜公开
- 行为：302 重定向登录页或回调 `redirect_uri?code=xxx&state=xxx`。
- 错误码：`0000003`（参数非法）、`0001004`（SSO 配置错误）。

#### HUB-API-104 令牌端点
- `POST /api/hub/v1/sso/token`｜公开｜强制幂等｜200 QPS
- 请求体（授权码模式）：

| 参数 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `grant_type` | string | 是 | `authorization_code`/`client_credentials`/`refresh_token` |
| `code` | string | 条件 | 授权码模式必填 |
| `code_verifier` | string | 条件 | PKCE |
| `client_id` | string | 是 | 客户端 ID |
| `client_type` | string | 是 | `ADMIN`/`PORTAL` |
| `redirect_uri` | string | 条件 | 授权码模式必填 |

- 响应：`data={"access_token":"eyJ...","token_type":"Bearer","expires_in":7200,"refresh_token":"...","id_token":"...","scope":"openid profile"}`（`id_token` 与 `access_token` 为 RS256 JWT）。
- 错误码：`0001001`（凭据错误）、`0001002`（账号锁定）、`0001003`（需 MFA）。

#### HUB-API-105 令牌刷新
- `POST /api/hub/v1/sso/token:refresh`｜公开｜强制幂等｜200 QPS
- 请求体：`{ "grant_type":"refresh_token","refresh_token":"...","client_id":"..." }`
- 响应：同 104（refresh_token 轮换，旧 token 失效）。
- 错误码：`0000001`（refresh 失效）。

#### HUB-API-106 令牌撤销
- `POST /api/hub/v1/sso/token:revoke`｜双端｜强制幂等｜200 QPS
- 请求体：`{ "token":"...","token_type_hint":"access_token" }`
- 响应：`data={"revoked":true}`；撤销写入黑名单（Redis）。

#### HUB-API-107 单点登出 SLO
- `POST /api/hub/v1/sso/logout`｜双端｜支持幂等｜200 QPS
- 请求体：`{ "id_token_hint":"...","all_sessions":true }`
- 响应：`data={"updated":[{"clientId":"crm","status":"LOGGED_OUT"},{"clientId":"collab","status":"LOGGED_OUT"}]}`
- 说明：`all_sessions=true` 登出全部产品会话；并发会话踢出。

#### HUB-API-108 用户信息端点
- `GET /api/hub/v1/sso/userinfo`｜双端｜500 QPS
- 响应：`data={"sub":"20031","name":"张丰麟","employeeNo":"FL0001","tenantId":10001,"tenantCode":"T000001","clientType":"PORTAL","permissions":["crm:lead:view","biz:message:view"]}`

#### HUB-API-109 SSO 配置管理
- `PUT /api/hub/v1/admin/sso/configs/{protocol}`｜ADMIN｜`tenant:auth:sso:manage`｜强制幂等｜50 QPS
- 路径 `protocol`：`OIDC`/`SAML2`/`WECOM`/`FEISHU`/`DINGTALK`
- 请求体：`{ "clientId":"...","clientSecret":"***","issuer":"...","ssoUrl":"...","attributeMapping":{"employeeNo":"employee_id","name":"name"},"autoProvision":true,"status":"ENABLED" }`
- 响应：`data={"protocol":"OIDC","status":"ENABLED","secretFingerprint":"a1b2c3"}`（密钥仅回显指纹）。

#### HUB-API-110 SSO 配置测试
- `POST /api/hub/v1/admin/sso/configs/{protocol}:test`｜ADMIN｜支持幂等｜20 QPS
- 响应：`data={"reachable":true,"latencyMs":120,"attributeResolved":{"employeeNo":"FL0001"}}`
- 错误码：`0001004`。

#### HUB-API-201 租户开通

| 参数 | 类型 | 必填 | 约束 |

| `name` | string | 是 | ≤128 |

## 6 开放 API 与事件

### 6.1 开放 API 规范

- 前缀 `/openapi/{domain}/v1`，经 `fenglin-openapi-service` 统一鉴权；
- 签名：`signature = HMAC-SHA256(AppSecret, method + path + timestamp + nonce + bodyHash)`；
- 请求头：`X-App-Key`、`X-Timestamp`（秒，偏差 ≤ 5min）、`X-Nonce`、`X-Signature`；
- 配额：应用 + 接口维度；超限 `0000006`；签名失败 `0009002`。
- 可供开放的平台资源示例：

| 资源 | 方法 | 路径 |
|---|---|---|
| 组织同步 | GET | `/openapi/hub/v1/orgs` |
| 用户同步 | GET | `/openapi/hub/v1/users` |
| 待办推送 | POST | `/openapi/hub/v1/workflow/tasks:push` |
| 消息发送 | POST | `/openapi/hub/v1/messages` |
| 审计查询 | GET | `/openapi/hub/v1/audit/logs` |
| 指标查询 | GET | `/openapi/hub/v1/metrics/{code}/data` |

### 6.2 平台事件（Kafka Topic）

| 事件 | Topic | 触发 | 载荷要点 |
|---|---|---|---|
| 租户开通 | `hub.tenant.provisioned` | 开通成功 | `tenantId, code, package` |
| 用户创建 | `hub.user.created` | 用户新增 | `userId, employeeNo, orgId` |
| 用户离职 | `hub.user.resigned` | 离职 | `userId, resignedAt` |
| 权限变更 | `hub.authz.changed` | 角色/权限变更 | `subjectType, subjectId, changedAt` |
| 流程完成 | `hub.workflow.completed` | 流程结束 | `instanceId, businessKey, result` |
| 审批待办 | `hub.workflow.task_created` | 任务生成 | `taskId, assigneeId, nodeKey` |
| 消息发送 | `hub.message.sent` | 消息发送 | `messageId, channel, receiverId` |
| 文件就绪 | `hub.file.available` | 文件可用 | `fileId, md5, objectKey` |
| 审计告警 | `hub.audit.alert` | 高危操作 | `logNo, eventType, operatorId` |
| 计量阈值 | `hub.metering.threshold` | 用量达阈值 | `metricCode, used, quota` |
| AI 用量 | `hub.ai.usage` | AI 调用计量 | `hostProduct, capability, tokenIn, tokenOut` |

### 6.3 Webhook 投递

- 基于 Kafka 的 Webhook 回调，签名验签（HMAC-SHA256）；
- 重试：指数退避，最多 6 次；
- 幂等：事件 `eventId` 去重；
- 失败入死信并告警。

## 7 版本与兼容

1. 版本采用 URL 段（`/v1`）；重大不兼容变更升 `v2`，旧版本保留 ≥ 12 个月。
2. 字段新增向后兼容；字段废弃先标记 `deprecated` 并给迁移期 ≥ 6 个月，变更公告经开发者门户发布。
3. 流式接口（SSE）事件类型（`delta`/`citation`/`done`/`error`）为兼容契约，新增事件不影响旧客户端。
4. 能力嵌入契约（`/internal/**`）变更须同步 8 大业务域产品并回归；云智双模式切换不改变契约。
5. 错误码一经发布不复用；新增错误码须登记本文件与错误码中心。

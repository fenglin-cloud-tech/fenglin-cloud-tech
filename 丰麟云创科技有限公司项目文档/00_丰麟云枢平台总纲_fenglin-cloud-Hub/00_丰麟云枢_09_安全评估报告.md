## 1 评估范围

### 1.1 评估对象

丰麟云枢平台 13 个中台服务、8 大业务域集成面、管理端（`/admin/**`）与用户端（`/app/**`）、开放平台与开发者门户、数据存储与中间件。

### 1.2 评估层次（五层）

| 层 | 范围 |
|---|---|
| 边界层 | 接入 SLB/WAF、Ingress、网关、开放网关、网络分区 |
| 主机/容器层 | K8s 集群、容器镜像、宿主机、镜像仓库 |
| 应用层 | 13 中台服务 + 8 业务域服务、SSO/IAM、开放 API、低代码运行时、AI 护栏 |
| 数据层 | PostgreSQL、Redis、ES、Kafka、MinIO、KMS、备份 |
| 管理层 | 安全制度、三员分立、人员、建设、运维、应急预案 |

### 1.3 评估方法

资产识别 → 威胁建模（STRIDE）→ 控制矩阵对照（等保三级）→ 渗透测试与配置核查 → 风险定级 → 加固 → 复测。

## 3 威胁建模（STRIDE）

| 威胁类 | 说明 | 典型威胁 | 平台措施 |
|---|---|---|---|
| **S**poofing 仿冒 | 冒充身份 | 令牌伪造、SSO 仿冒、开放 API 冒充 | JWT RS256 签名 + JWKS 校验、PKCE、HMAC 签名 + nonce 防重放、mTLS |
| **T**ampering 篡改 | 数据/代码篡改 | 篡改令牌内容、篡改审计、篡改请求 | 签名校验、审计哈希链 + WORM、TLS 完整性、请求签名 |
| **R**epudiation 抵赖 | 否认操作 | 否认审批/导出/越权 | 全链路审计（含 IP、操作人、前后值）、数字签名审计、留存 |
| **I**nformation Disclosure 信息泄露 | 数据泄露 | 越权读取、PII 明文、日志泄露 | RLS + 数据权限、字段脱敏、AES-256-GCM、日志脱敏、签名 URL |
| **D**enial of Service 拒绝服务 | 资源耗尽 | 洪水攻击、配额击穿、慢查询 | WAF + Sentinel 限流熔断、配额隔离、慢查询治理、HPA |
| **E**levation of Privilege 提权 | 越权提权 | 水平/垂直越权、跨租户、沙箱逃逸 | 最小权限、端别校验、租户边界默认拒绝、低代码沙箱白名单 |

### 3.1 关键威胁场景与验证

| 场景 | 威胁 | 验证结果 |
|---|---|---|
| 跨租户访问 | I/E | 篡改 `X-Tenant-Id`/资源 ID 均被拒绝；RLS 阻断直查（TC-093） |
| 端别提权 | E | PORTAL 令牌访问管理端接口返回 403（TC-007） |
| 开放 API 重放 | S | timestamp/nonce 校验阻断（TC-060） |
| 审计篡改 | T/R | 哈希链校验发现篡改（TC-051） |
| 提示注入 | T/I | AI 护栏拦截（TC-081） |
| 低代码沙箱逃逸 | E | 白名单函数 + 超时限制，逃逸用例 0 成功（TC-076） |
| PII 明文暴露 | I | 数据库列加密 + 展示脱敏，核查通过 |

## 5 加固措施

### 5.1 边界层

- WAF 规则（OWASP Top10）、CC 防护；IDS/IPS 联动；仅开放 443/内网必要端口；
- 网络分区（DMZ/应用区/数据区），数据区禁止公网；
- 开放网关独立限流与风控策略。

### 5.2 主机/容器层

- 容器以非 root 运行、只读根文件系统、最小 Capability；
- 镜像来源可信 + 镜像扫描（无高危）+ 镜像签名校验；
- HIDS + 主机基线核查（CIS）+ 定期补丁。

### 5.3 应用层

- 统一 OAuth2.1/OIDC + MFA；端别强校验；越权默认拒绝；
- 输入校验与输出编码（防 XSS/SQLi）；CSRF Token；接口幂等；
- 低代码运行时沙箱；AI 输入输出护栏；
- 密钥/凭据不落日志；错误响应统一（不泄露堆栈）。

### 5.4 数据层

- TLS1.3/mTLS；PII AES-256-GCM + 哈希列；TDE；备份加密；
- KMS 密钥分层，数据密钥 ≤90 天轮换，支持重加密；
- 数据库最小权限账号（应用只读写必要对象）、Redis ACL、ES 认证、Kafka SASL。

### 5.5 管理层

- 三员分立与最小权限；堡垒机运维 + 全量会话审计；
- 安全制度体系（策略/制度/规程/表单）；应急预案与演练；
- 人员安全（背景审查、保密协议、离岗回收）。

### 5.6 密钥管理（KMS）

```
根密钥（HSM 保护，年度轮换）
  └─ 域密钥（按域隔离，180 天轮换）
       └─ 数据密钥（字段/文件加密，≤90 天轮换，支持重加密）
```

- 密钥操作（创建/轮换/撤销）全部审计，高危告警；
- 密钥不出 KMS 硬件边界（应用仅获取加解密结果）。

## 6 合规结论

| 项 | 结论 |
|---|---|
| 等保三级 | 控制项逐项满足，建议测评结论：**符合（第三级）** |
| 传输加密 | 客户端↔网关 TLS1.3、内部 mTLS，符合 |
| 存储加密 | PII AES-256-GCM + TDE，符合 |

| 高危漏洞 | 0（已全部修复并复测） |

**总体结论**：丰麟云枢平台安全设计满足等保三级与平台基线要求，具备上线条件（在高危漏洞清零前提下）。

## 7 残余风险

| 编号 | 残余风险 | 等级 | 说明 | 持续措施 |
|---|---|---|---|---|
| RR-01 | 外部大模型服务的可用性与合规性 | 中 | 依赖第三方模型 | 多模型路由 + 私有化模型选项 + 合同约束 |
| RR-02 | 内部人员滥用权限 | 低 | 制度性风险 | 三员分立 + 强审计 + 季度复核 |
| RR-03 | 供应链新披露漏洞 | 中 | 时间窗口 | SCA 持续监控 + 快速补丁流程 |
| RR-04 | DDoS 极端流量 | 低 | 超出常规防护 | 云清洗 + 弹性扩容 + 限流 |
| RR-05 | 零日漏洞 | 低 | 不可预见 | 纵深防御 + 最小暴露面 + 快速响应 |
| RR-06 | 客户端环境安全（终端失窃） | 低 | 用户侧 | 会话超时 + 设备管理 + 强制 MFA（敏感角色） |

> 残余风险均在可接受范围内，且已制定持续监控与应急响应措施。

## 1 管理员角色与登录

### 1.1 管理员角色矩阵

| 角色 | 权限域 | 职责 |
|---|---|---|
| 平台超级管理员 | `platform:*` | 平台最高权限（运维专用、强审计） |
| 平台运维 | `platform:ops:*` | 租户/套餐/监控/灰度/开放平台运营 |
| 平台安全管理员 | `platform:sec:*` | 密钥、三员分立、审计复核 |
| 审计管理员 | `platform:audit:*` | 审计检索、合规报告（三员分立） |
| 租户管理员 | `tenant:*` | 本租户组织/用户/角色/权限/参数 |

> 三员分立：**系统管理员**（配置运行）、**安全管理员**（密钥与安全策略）、**审计管理员**（审计复核）相互制约，不可兼任。请遵循最小权限原则分配权限。

### 1.2 登录管理端

1. 访问 `https://hub.fenglincloud.com/admin`；
2. 使用企业 SSO 或账号登录；平台超管/安全管理员**强制 MFA**；
3. 登录后进入运营管理首页 `/admin/dashboard`。

> 管理端（`/admin/**`）用于配置类操作；用户端（`/app/**`）用于业务操作，请勿混用。

### 1.3 端别与权限提示

- 若提示 **403（无权限）**，说明当前角色不具备该功能权限；
- 若提示**端别不匹配**，说明用错了端（如用用户端令牌访问管理端）。

## 2 租户治理

### 2.1 开通租户（平台运维）

路径：`运营管理 → 租户管理 → 新建`

1. **基本信息**：租户名称、社会信用代码、联系人、行业；
2. **套餐与席位**：选择套餐、席位数、试用期；
3. **隔离策略**：`SHARED`（SaaS 共享库）/`ISOLATED`（私有化独立库）/`HYBRID`（混合）；
4. **确认提交**：进入审批流（合规审核）；
5. 审批通过后自动初始化：默认组织、管理员账号、基础角色、字典/参数、配额与许可。

> 开通成功后系统生成租户编码（`T{6位}`），请记录并告知客户。

### 2.2 租户状态管理

| 动作 | 说明 |
|---|---|
| 暂停（SUSPEND） | 欠费/违规时暂停，用户无法登录业务功能 |
| 恢复（RESUME） | 恢复为 ACTIVE |
| 注销（CLOSE） | 冷静期 30 天后经审批物理擦除（剩余信息保护） |

> 状态变更全部落审计；注销为高危操作，需二次确认与审批。

### 2.3 查看租户详情

`租户管理 → 点击租户`：查看信息、订阅、用量、配额、许可、操作审计。

## 3 套餐、订阅与计费

### 3.1 套餐管理

路径：`运营管理 → 套餐管理`

- 定义套餐（基础/专业/旗舰/私有化）：计费方式（席位/按量/包周期）、价格、含席位、包含产品与能力项；
- 套餐上下架；修改套餐不影响已订阅租户的历史账期。

### 3.2 订阅管理

- **新订/续订**：选择套餐与周期；
- **升配**：即时生效，按比例补差；
- **降配**：下周期生效；
- **退订**：按合同规则处理。

### 3.3 计量与出账

路径：`运营管理 → 计量与配额 / 订阅与账单`

- 计量维度：席位、API 调用量、AI Token、存储量、流程实例数等；
- 日汇总 + 月出账（T+1）；账单支持导出、对账、开票关联；
- 配额预警（≥80%）与超限（100%）通知；
- 对账误差阈值 ≤ 0.01%，异常自动告警。

> 席位不足将拦截新增用户（错误码 `0000101`）；私有化许可过期将限制登录（`0000102`）。

## 4 组织与岗位管理

### 4.1 组织树

路径：`租户管理 → 组织管理`

1. 新建组织（编码层级点分，如 `1.2.3`），设置上级、类型（公司/部门/团队）、负责人；
2. 支持拖拽调整层级；
3. **删除限制**：存在子组织或用户时不可删除（`0003001`）。

### 4.2 岗位管理

- 维护岗位（编码、名称、职级、归属组织）；
- 用户可关联主岗与兼岗（仅一个主岗）。

### 4.3 建议

- 组织编码遵循企业人力体系，避免频繁调整；
- 负责人设置用于审批人解析（上级主管）。

## 5 用户管理

### 5.1 新增用户

路径：`租户管理 → 用户管理 → 新建`

1. 填写姓名、登录名、手机、邮箱、主部门、主岗位、初始角色；
2. 工号可自动生成（`{公司码}{4位}`）；
3. 手机/邮箱**加密存储**，列表展示为脱敏值。

### 5.2 批量导入

1. 下载模板，填写后上传（Excel/CSV）；
2. 可选**草稿校验**（先校验再提交）；
3. 系统返回成功/失败明细（含失败行原因）。

### 5.3 用户生命周期

| 操作 | 说明 |
|---|---|
| 变更 | 修改部门/岗位/联系方式（记录审计） |
| 停用/启用 | 临时禁用登录 |
| 离职 | 停用账号 + 踢出会话 + 权限回收 + 待办转交（可选），自动归档 |

> 离职联动作业由调度任务定时执行，可在"账号复核"中核查。

### 5.4 账号复核

路径：`运营管理 → 账号复核`

- 按季度生成复核任务，逐账号确认保留或回收权限；
- 复核结果留痕，异常权限自动回收并通知。

## 6 角色与权限管理

### 6.1 角色管理

路径：`租户管理 → 角色管理`

- 内置角色（平台超管/运维/租户管理员/业务管理员/业务用户/只读）不可删除；
- 支持角色继承（子角色继承父角色权限）；
- 删除被引用的角色将被拒绝（`0003002`）。

### 6.2 功能权限

- 权限码规则：`{域}:{模块}:{操作}`（如 `crm:lead:export`）；
- 在权限树中为角色勾选菜单/按钮/接口权限；
- **敏感权限**（导出、跨租户、密钥相关）变更需审批。

### 6.3 数据权限

- 五档范围：本人 / 本部门 / 本部门及下级 / 指定部门 / 全部；
- 支持为角色/用户/部门配置；多角色取并集；
- 服务端强制行级过滤，不依赖前端。

### 6.4 字段权限

- 对敏感字段配置 `HIDDEN`（隐藏）/`MASK`（脱敏）/`READ`/`WRITE`；
- 按角色/用户/资源维度配置字段访问矩阵。

### 6.5 授权建议

1. 优先用角色授权，避免直接给用户授权；
2. 敏感权限走审批并设置有效期（临时授权）；
3. 定期（季度）复核权限，及时回收。

## 8 流程与表单配置

### 8.1 流程定义

路径：`租户管理 → 流程定义`

1. 新建/编辑 BPMN 流程（可视化设计或导入 XML）；
2. 配置审批节点（候选人/角色/上级主管/发起人自选）、条件分支（金额/部门/等级）；
3. 发布并版本化（新实例走最新版本，运行中实例保持原版本）。

### 8.2 表单配置

- 可关联低代码表单（动态表单），表单数据随流程持久化；

### 8.3 流程监控

路径：`租户管理 → 流程监控`

- 查看实例轨迹、节点耗时、超时预警；
- 超时任务自动催办与升级（可配置）。

## 9 产品矩阵与集成管理

### 9.1 产品矩阵总览

路径：`运营管理 → 产品矩阵`

- 查看 8 大产品（云销/云协/云才/云财/云研/云服/云法/云智）的订阅状态、用量、健康度、版本；
- 26 个业务模块与产品映射维护（支撑导航与权限配置）。

### 9.2 单点登录集成

路径：`租户管理 → SSO 配置`

1. 选择协议（OIDC/SAML2/企微/飞书/钉钉）；
2. 填写客户端信息、属性映射、自动开通策略；
3. 点击"测试"验证连通与属性解析（`0001004` 表示配置错误）；
4. 启用后用户可通过企业身份登录。

### 9.3 跨域与事件

- 跨域工单/审批流转由工作流 + 事件总线承载；
- 事件 Topic 命名 `{domain}.{entity}.{action}`；
- 云智双模式：云智可作为独立产品，也可作为能力嵌入其余 7 产品（授权与计量统一）。

### 9.4 统一监控

- 平台统一监控 8 大产品健康度、依赖拓扑、SLA 看板。

## 10 开放平台管理

路径：`运营管理 → 开放平台`

### 10.1 应用管理

1. 查看/创建开放应用（ISV/内部/客户）；
2. 配置授权范围（scope）与回调地址（白名单）；
3. 应用上架需审核：运维初审 → 安全管理员复审（数据范围最小化、回调白名单、加密要求）。

### 10.2 密钥管理

- 生成/轮换 AppKey/AppSecret；**AppSecret 仅生成时回显一次**，之后仅显示指纹；
- 泄漏时立即轮换（支持宽限期设置）并撤销全部令牌。

### 10.3 配额与限流

- 按应用 + 接口维度配置 QPS 与日调用量配额；
- 超限返回 `0000006`；配额预警通知开发者；
- 异常调用风控（短时封禁）。

### 10.4 调用统计

- 查看应用调用量、错误率、Top 接口；
- 调用日志纳入审计与计量。

## 11 监控与审计

### 11.1 运营监控

路径：`运营管理 → 监控`

- 平台/租户 SLA、QPS、响应时间、错误率、配额使用、待办积压、产品健康度；
- 异常告警推送至责任人。

### 11.2 审计检索

路径：`运营管理 → 审计检索`（审计管理员）

- 多维检索（操作人/租户/对象/时间/类别/结果）；
- 覆盖登录、鉴权、数据变更、配置变更、导出、密钥变更、跨租户访问；
- **导出行为本身落审计**，导出带水印。

### 11.3 审计防篡改

- 审计日志采用**哈希链 + WORM**，不可修改/删除；
- 定期执行**链校验**（`审计中心 → 链校验`），异常立即告警（P0）；
- 留存 ≥ 6 个月（建议 12 个月），到期归档。

### 11.4 告警配置

- 配置高危操作告警规则（越权、批量导出、密钥变更、跨租户）；
- 告警通道：P0/P1 电话+短信+IM；P2 IM+邮件；P3 站内信。

### 11.5 合规报告

- 生成周期性合规审计报告（等保留痕），支持导出。

## 12 备份与运维协作

### 12.1 备份策略（与运维协作）

| 对象 | 频率 | 保留 |
|---|---|---|
| PostgreSQL | 每日全备 + WAL 增量 | 30 天（异地 90 天） |
| Redis | 每小时 RDB | 7 天 |
| Elasticsearch | 每日快照 | 14 天 |
| MinIO | 跨集群复制 | 30 天 |

- 备份加密；每月抽样恢复验证；季度完整演练。

### 12.2 常见运维操作

| 操作 | 说明 |
|---|---|
| 配置变更 | 通过管理端配置（外置 Nacos），热更新，留审计 |
| 灰度发布 | 由平台运维经网关灰度规则执行，按租户/用户/比例 |
| 回滚 | 应用镜像回滚 ≤ 5min；配置回滚 ≤ 1min |
| 索引重建 | 管理端触发 + 审批，蓝绿切换 |

### 12.3 应急联系

- 平台故障/安全事件请立即联系平台运维与安全管理员；
- 数据安全事件：隔离 → 冻结会话 → 取证（审计）→ 上报。

## 13 常见问题

| 问题 | 处理 |
|---|---|
| 新用户无法登录 | 检查账号状态、角色是否含登录权限、SSO 是否启用 |
| 用户看不到某应用 | 检查产品订阅状态与角色权限 |
| 用户看不到数据 | 检查数据权限范围配置 |
| 敏感字段显示脱敏 | 字段权限为 MASK，按需调整授权 |
| 席位不足无法加人 | 升级套餐或释放闲置席位（配额 `0000101`） |
| 许可过期 | 私有化续签 License（`0000102`） |
| 删除角色/组织失败 | 存在引用/子节点，先解绑（`0003001`/`0003002`） |
| 开放应用审核不通过 | 查看驳回意见，完善 scope/回调/安全措施后重提 |
| 审计导出失败 | 检查导出权限与限流（导出 5 QPS），大数据量改异步 |
| 端别不匹配 403 | 确认使用正确的端（管理端/用户端） |

### 13.1 安全操作规范

1. 平台超管/安全管理员必须开启 MFA；
2. 高危操作（租户注销、密钥轮换、权限回收、数据擦除）需二次确认与审批；
3. 遵循三员分立与最小权限；离岗及时回收权限；
4. 定期检查审计告警与账号复核结果。

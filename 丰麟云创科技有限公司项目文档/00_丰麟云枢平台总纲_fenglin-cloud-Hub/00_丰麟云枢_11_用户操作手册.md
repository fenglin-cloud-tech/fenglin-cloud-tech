## 1 快速开始

### 1.1 访问地址

| 端 | 地址 | 适用 |
|---|---|---|
| 用户端（PC） | `https://hub.fenglincloud.com/app` | 日常办公 |
| 用户端（移动） | 手机浏览器访问同一地址（自适应） | 移动办公、审批 |
| 开发者门户 | `https://open.fenglincloud.com` | 开放 API 对接 |

> 提示：`/app/**` 为**用户端**，用于日常业务操作；`/admin/**` 为**管理端**，由租户管理员使用，您通常无需访问。

### 1.2 三步上手

1. **登录**：使用企业统一身份（SSO）或账号口令登录；
2. **看工作台**：在"我的工作台"查看待办、消息与快捷入口；
3. **干活**：从待办或常用应用进入具体业务功能。

### 1.3 推荐浏览器

Chrome/Edge 最近两个大版本，或 Safari 15+。

## 2 登录与账号

### 2.1 登录方式

| 方式 | 说明 |
|---|---|
| 企业统一登录（SSO） | 点击"企业登录"，跳转企业身份（企微/飞书/钉钉/OIDC），无需另记密码 |
| 账号口令 | 输入登录名与密码 |
| 二次验证（MFA） | 若已开启，需输入动态验证码（TOTP/短信） |

**登录步骤**：
1. 打开 `https://hub.fenglincloud.com/app`；
2. 选择"企业登录"或输入账号口令；
3. 如提示 MFA，输入验证码；
4. 登录成功后进入"我的工作台"。

### 2.2 忘记密码

1. 登录页点击"忘记密码"；
2. 通过绑定手机/邮箱验证身份；
3. 设置新密码（≥ 12 位，含大小写、数字、符号）；
4. 使用新密码登录。

### 2.3 账号安全提示

- 密码 90 天需要更新一次；连续输错 5 次账号将锁定 15 分钟；
- 空闲 30 分钟会自动退出，请及时保存工作；
- 在新设备/异地登录会收到提醒消息。

## 3 我的工作台

工作台是您进入平台的第一屏，包含：

| 区域 | 内容 |
|---|---|
| 问候区 | 您的姓名、待办数量、未读消息数 |
| 我的待办 | 需要您处理的审批/任务（点击"处理"直接办理） |
| 消息 | 最近的系统通知与提醒 |
| 快捷入口 | 发起审批、上传文件、AI 助手、报表看板、全局搜索 |
| 常用应用 | 您有权限使用的产品入口（云销/云协/云才/云财/云研/云服/云法/云智） |

> 若看不到某个应用，可能是您的账号暂无该应用权限，或企业尚未开通该产品。

## 4 统一待办与审批

### 4.1 查看待办

1. 顶部菜单点击"待办"，或工作台点击"我的待办"；
2. 可按**产品/类型/紧急程度**筛选；
3. 列表展示：标题、发起人、当前节点、截止时间。

### 4.2 处理审批

1. 点击待办进入详情，查看**单据摘要**与**审批轨迹**；
2. 选择操作：

| 操作 | 说明 |
|---|---|
| 同意 | 通过当前节点 |
| 驳回 | 退回发起人，需填写意见 |
| 加签 | 增加审批人后继续 |
| 转办 | 转交给他人处理 |
| 委托 | 设置代理人代处理 |

3. 填写审批意见 → 提交；
4. 提交成功后有提示，任务从待办列表移除。

> 若提示"任务已被处理"，说明他人已先处理，请刷新列表。

### 4.3 我发起的

- "我发起的"可查看自己提交的流程进度；
- 首节点前可**撤回**；撤回后流程终止，可修改后重新提交。

### 4.4 移动端审批

- 手机浏览器打开用户端即可审批，操作与 PC 一致；
- 支持下拉刷新与左滑快捷操作。

## 5 消息中心

### 5.1 查看消息

- 顶部"消息"图标显示未读数；点击进入消息中心；
- 支持按**通道/类别/未读**筛选；点击消息跳转相关业务。

### 5.2 标记与处理

- 点击消息即标记已读；支持"全部已读"；
- 消息可通过站内信、邮件、短信、企业 IM、实时推送（在线）等多种方式送达。

### 5.3 订阅偏好

路径：`我的设置 → 消息偏好`

- 可配置各类消息的**接收通道**；
- 可设置**免打扰时段**（如 22:00–08:00）。
- 注意：**安全类强制消息**不可关闭，将始终送达。

## 6 文件中心

### 6.1 上传文件

1. 进入"我的文件" → 点击"上传"；
2. 支持拖拽、批量上传、大文件分片与断点续传；
3. 若文件已存在（MD5 命中），将**秒传**。

### 6.2 下载与预览

- 点击文件可**在线预览**（Office/PDF/图片/音视频）；
- 下载通过**有时效的链接**，有效期约 15 分钟；过期请重新获取；
- 预览/下载可能带**动态水印**（含您的姓名与时间），请勿外传涉密文件。

### 6.3 版本管理

- 文件支持多版本，可查看历史版本并**回滚**；
- 上传同名文件会生成新版本。

### 6.4 注意事项

- 仅允许上传白名单类型（常见办公/图片/音视频），不支持可执行文件；
- 上传后会进行**病毒扫描**，扫描通过才可使用；
- 企业存储空间有限，请及时清理不需要的文件。

## 7 全局搜索

### 7.1 使用

1. 顶部搜索框，或按快捷键 **Ctrl + K**；
2. 输入关键词，选择范围（全部/指定产品）；
3. 结果按产品**分组展示**，可点击直达。

### 7.2 说明

- 搜索结果**自动按您的权限过滤**，您只能搜到有权限查看的内容；
- 支持**语义搜索**（按意思搜索，不要求关键词完全一致）。

## 8 报表看板

### 8.1 查看

- 进入"报表看板"，选择您关注的看板；
- 图表支持筛选（时间/部门等）、下钻与联动。

### 8.2 导出

- 支持导出 Excel/PDF/PNG；
- 导出文件带**水印**，且导出操作会被记录（审计）；
- 大数据量导出为**异步任务**，可在任务列表下载。

## 9 AI 助手

### 9.1 使用

1. 进入"AI 助手"，选择"知识范围"（如制度知识库）；
2. 输入问题，AI 基于企业资料回答，并展示**引用来源**；
3. 可点击引用查看原文。

### 9.2 反馈

- 对回答点赞/点踩，帮助改进；
- 若顶部提示"当前为降级模式"，说明智能能力暂时受限（如模型不可用），系统会返回检索结果。

### 9.3 注意

- AI 回答仅供参考，重要决策请核对**引用原文**；
- 请勿输入个人敏感信息或机密内容。

## 10 低代码应用

- 企业自建的表单/页面应用会展示在"常用应用"或对应菜单；
- 使用方式与其他应用一致：填写表单 → 提交 → 进入审批（如配置）；
- 提交后可在"我发起的"查看后续进度。

## 11 个人设置

| 设置项 | 路径 | 说明 |
|---|---|---|
| 我的资料 | 设置 → 我的资料 | 查看姓名/工号/部门/岗位/角色（只读，如需变更请联系管理员） |
| 安全设置 | 设置 → 安全设置 | 修改密码、开启/关闭 MFA、管理登录设备 |
| 消息偏好 | 设置 → 消息偏好 | 通道与免打扰 |
| 我的操作记录 | 设置 → 我的操作记录 | 查看本人操作审计（只读） |

### 11.1 管理设备

- 可查看当前登录的设备/会话，**强制下线**可疑设备；
- 建议在公共设备使用后主动退出。

## 12 常见问题

| 问题 | 处理 |
|---|---|
| 无法登录 | 确认账号状态；检查是否锁定；联系管理员重置密码 |
| 看不到某个应用 | 可能无权限或未开通，请联系管理员 |
| 待办点进去提示"已被处理" | 他人已处理，刷新列表 |
| 文件无法下载 | 链接过期请重新获取；确认是否有下载权限 |
| 搜索不到内容 | 可能无权限或索引尚未同步，稍后重试 |
| AI 回答不准确 | 核对引用原文；可切换知识范围 |
| 页面显示 403 | 无访问权限，请向管理员申请 |
| 会话频繁退出 | 空闲 30 分钟自动退出为正常策略 |
| 收不到消息通知 | 检查消息偏好与免打扰设置；安全消息不可关闭 |

### 12.1 获取帮助

- 页面右下角"帮助"入口；
- 联系本企业管理员；
- 服务热线与邮箱以企业公告为准。

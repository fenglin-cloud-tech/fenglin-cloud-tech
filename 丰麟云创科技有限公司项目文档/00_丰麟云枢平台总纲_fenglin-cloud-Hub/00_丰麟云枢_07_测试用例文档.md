## 1 测试范围与策略

### 1.1 测试范围

覆盖丰麟云枢平台 12 大能力域：统一门户与 SSO、租户治理与计费、IAM/4A、工作流引擎、消息中心、文件中心、审计中心、搜索中心、开放平台、报表/指标中心、低代码引擎、AI 中台，以及 8 大产品矩阵集成。

### 1.2 测试类型

| 类型 | 说明 | 工具 |
|---|---|---|
| 功能测试 | 用例覆盖 FR，含正向/反向/边界 | 手工 + Playwright |
| 接口测试 | 契约、鉴权、幂等、错误码、限流 | Postman/newman、自研契约测试 |
| 权限与越权测试 | 功能/数据/字段/租户边界 | 自研越权扫描（含 RLS 注入用例） |
| 并发与一致性测试 | 工作流并发、配额扣减、计量幂等 | JMeter/Gatling |
| 安全测试 | 注入、越权、防篡改、传输/存储加密 | OWASP ZAP、自研校验 |
| 兼容性测试 | 浏览器/移动端/分辨率 | BrowserStack |
| 性能测试 | 见 FL-HUB-PERF-008 | JMeter/Gatling |
| 容灾测试 | 双活切换、备份恢复 | 演练脚本 |

### 1.3 测试策略

- **左移**：契约测试与越权用例纳入 CI，每次合并执行；
- **环境**：dev/test/uat 分级；性能测试独立环境；数据脱敏；
- **准入**：单测覆盖率 ≥ 70%，静态扫描无阻断项；
- **出口**：P0/P1 缺陷清零，P2 ≤ 5 且不影响验收。

## 3 用例详情

> 以下为 P0 与关键用例详情；其余用例按同结构维护于测试管理平台。

### TC-001 SSO 授权码+PKCE 全流程登录

- **前置**：租户 `T000001` 已配置 SSO（OIDC）；用户 `FL0001` 已开通。
- **步骤**：
  1. 访问 `/admin/dashboard`（未登录）→ 期望 302 至 `/api/hub/v1/sso/authorize`；
  2. 携 `client_id`、`code_challenge`（S256）、`state` 提交；
  3. 完成 IdP 认证回调 `GET /sso/callback?code=xxx&state=xxx`；
  4. 调 `POST /sso/token`（含 `code_verifier`）；
  5. 携 `access_token` 请求 `/sso/userinfo`。
- **预期**：返回 `code=0`，`access_token` 为 RS256 JWT 且 `client_type=ADMIN`；`userinfo` 含租户与权限；`state` 校验通过；审计记录 `LOGIN` 事件。
- **异常**：`code` 复用 → 拒绝并记录安全事件；`code_verifier` 不匹配 → `0000001`。

### TC-007 端别串位拦截

- **前置**：获取 PORTAL 端令牌。
- **步骤**：以 PORTAL 令牌请求 `/api/hub/v1/admin/users`，`X-Client-Type: PORTAL`。
- **预期**：返回 `0000002`（403）；审计记录越权尝试（`risk_level=MEDIUM`）。

### TC-010 租户开通全流程

- **步骤**：
  1. 平台运维提交开通（含套餐/席位/隔离策略）→ 期望返回 `processInstanceId`（状态 `TRIAL`）；
  2. 安全管理员审批通过；
  3. 查询租户详情。
- **预期**：租户编码 `T000001`；默认组织/管理员/角色/字典初始化完成；配额按套餐分配；审计记录开通。
- **异常**：初始化任一步失败 → 整体回滚，流程 `ERROR` 并告警。

### TC-014 计量幂等去重

- **步骤**：同一 `(tenantId, metricCode, sourceId)` 并发上报 10 次。
- **预期**：仅落 1 条计量明细；重复上报返回首次结果；对账数量一致。

### TC-024 数据权限五档

- **步骤**：以 `data_scope` 分别为 SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL 的用户查询同一列表（构造 3 部门共 30 条数据）。
- **预期**：SELF=本人 5 条；DEPT=本部门 10 条；DEPT_AND_CHILD=本部门及下级 20 条；CUSTOM=指定部门合计；ALL=30 条。

### TC-025 数据权限行级 SQL 拦截

- **步骤**：构造跨部门查询参数尝试越权（手工传 `orgId`）。
- **预期**：服务端强制注入 `data_scope` 条件，越权数据不可见；不依赖前端过滤。

### TC-035 工作流并发审批同一任务

- **步骤**：两名用户同时提交同一 `taskId` 的 `APPROVE`（各带不同 `Idempotency-Key`）。
- **预期**：仅一次成功；另一返回 `0004002`（任务已被处理）；流程状态一致，无重复流转。

### TC-051 审计防篡改：哈希链校验

- **步骤**：
  1. 正常分区执行 `POST /audit/chain:verify`；
  2. 直接修改数据库某条审计日志 `detail` 字段后再次校验。
- **预期**：步骤 1 返回 `valid=true`；步骤 2 返回 `0007001` 且 `brokenAt` 指向被篡改记录；告警触发。

### TC-060 开放 API 签名校验

- **步骤**：以正确签名、错误签名、篡改 `timestamp`（>5min）、重复 `nonce` 分别请求。
- **预期**：正确 → 200；错误 → `0009002`（401）；过期 → `0009002`；重放 → 拒绝并记录。

### TC-061 开放 API 配额限流

- **步骤**：配置 QPS=50、日调用=1000；以 100 QPS 持续请求 30s；构造第 1001 次调用。
- **预期**：超出 QPS 返回 `0000006`（429）；日调用超限返回 `0000006`；配额预警（80%）通知开发者；调用日志完整。

### TC-083 能力未授权调用拦截（embedded）

- **步骤**：宿主产品 `collab` 未经授权调用 `/internal/v1/ai/capability`（能力 `RAG`）。
- **预期**：返回 `0000002` 语义（能力未授权）；计量不产生；审计记录。

### TC-093 租户隔离越权全量扫描

- **步骤**：
  1. 以租户 A 令牌遍历全部列表/详情/导出接口，篡改 `X-Tenant-Id`/路径 ID 指向租户 B 资源；
  2. RLS 注入用例：直接以租户 A 会话执行跨租户 SQL（绕过应用层）。
- **预期**：所有越权请求被拒绝（`0000002`/404 不暴露存在性）；RLS 阻断跨租户直查；全部越权尝试落审计并告警；扫描覆盖率 100%。

### TC-086 embedded 计量归集

- **步骤**：宿主产品 `crm` 调用 RAG 100 次（记录 token 用量）；对照 AI 计量与租户计量。
- **预期**：计量归集至 `crm`；双向对账误差 ≤ 0.01%；重复上报幂等。

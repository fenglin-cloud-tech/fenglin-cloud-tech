## 1. 评估范围

### 1.1 评估对象

| 类别 | 范围 |
|---|---|
| 应用 | `fenglin-collab-service`（IM/文档/日历/会议/OKR/审批/工作台/ONA） |
| 前端 | 用户端 `fenglin-collab-portal-ui`（`/app/collab`）、管理端 `fenglin-collab-admin-ui`（`/admin/collab`） |
| 接口 | `/api/collab/v1/**`、WebSocket `/ws/collab/**`、开放 API `/openapi/collab/v1/**` |
| 数据 | `fenglin_collab` 库 32 张 `collab_` 表；Redis 缓存；MinIO 文件；ES 索引 |
| 依赖 | 网关、IAM、工作流（Flowable）、消息（Kafka）、文件、审计中台 |

### 1.2 评估方法与依据

| 方法 | 说明 |
|---|---|
| 代码审计 | 静态扫描（SonarQube + Semgrep + 依赖 SCA） |
| 渗透测试 | 黑盒 + 灰盒，覆盖 OWASP Top 10（2021）与 API Security Top 10 |
| 配置核查 | K8s/中间件安全基线核查 |
| 数据安全核查 | 加密、脱敏、密钥管理、审计留痕 |
| 合规对照 | 等保三级控制矩阵逐项对照 |

依据：《网络安全法》《数据安全法》《个人信息保护法》、GB/T 22239-2019、GB/T 25070-2019、平台统一标准第 8 章。

### 1.3 关注重点（云协特性）

1. **IM 内容安全**：消息敏感词、外部联系人手机号加密、消息撤回/删除审计痕迹。
2. **文档内容安全**：文档密级、动态水印、机密文档禁外链、协同越权、防泄漏（DLP）钩子。
3. **多租户隔离**：租户数据不串号（RLS + 应用层租户校验）。
4. **ONA 隐私合规**：基于行为聚合指标，不出消息内容；匿名阈值；个人画像可见范围。

## 2. 等保三级控制矩阵逐项对照

| 控制类别 | 控制项 | 平台要求 | 云协落地措施 | 结论 |
|---|---|---|---|---|
| 身份鉴别 | 双因子/强口令/登录失败锁定 | MFA、口令复杂度、5 次锁定、会话超时 30min | 复用统一 IAM：MFA（TOTP/短信）、口令复杂度策略、连续 5 次失败锁定 15min、会话空闲 30min 失效；IM/文档长连接令牌 30min 续期 | 符合 |
| 访问控制 | 最小权限、职责分离 | RBAC+ABAC+数据权限、三员分立 | 协作域 RBAC（会话/文档/会议/审批/ONA 资源权限）+ 数据权限（本人/本部门/本部门及下级/指定/全部）；系统管理员/安全管理员/审计管理员三员分立；管理端与用户端权限域隔离（`platform:*`/`tenant:*` vs `biz:*`） | 符合 |
| 安全审计 | 全量审计、防篡改 | 全链路审计日志、哈希链、WORM、留存 ≥6 个月 | 协作域关键操作（登录、消息撤回/删除、文档密级变更、外链分享、会议室删除、审批办理、ONA 配置、权限变更）全量审计；审计日志接入 `fenglin-audit-service` 哈希链 + WORM，留存 12 个月 | 符合 |
| 入侵防范 | 边界防护、攻击检测 | WAF、IDS/IPS、Sentinel 流控、漏洞扫描 | 网关接入 WAF + IDS/IPS；Sentinel 对协作域接口限流（错误码 2000005、2001006）；CI 集成 SAST/SCA/镜像扫描；季度漏洞扫描 | 符合 |
| 恶意代码防范 | 主机/应用防护 | 主机 HIDS、镜像扫描、依赖 SCA | 节点部署 HIDS；容器镜像构建期 Trivy 扫描；Maven 依赖 SCA（OWASP Dependency-Check）；上传文件（IM 文件/文档附件）ClamAV 病毒扫描 | 符合 |
| 数据完整性 | 传输/存储完整性 | TLS1.3、HMAC、数据库校验 | 客户端↔网关 TLS1.3；服务间 mTLS；JWT RS256 签名；开放 API HMAC-SHA256；消息/文档版本哈希校验；数据库约束与外键校验 | 符合 |
| 数据保密性 | 传输/存储加密 | TLS、AES-256-GCM、KMS | 消息体敏感字段（外部联系人手机号）与员工手机号 AES-256-GCM 加密存储；唯一约束落于 `phone_hash`（SHA-256）；数据库 TDE；密钥由 KMS 管理，90 天轮换 | 符合 |
| 数据备份恢复 | 本地+异地备份、演练 | 每日全备+增量、异地容灾、季度演练 | 每日全备 + WAL 增量（PITR），异地异步复制；MinIO 跨区复制；季度恢复演练（RPO 8s / RTO 42s 实测） | 符合 |
| 剩余信息保护 | 数据擦除 | 存储/内存剩余信息清理、介质销毁 | 会话退出清理内存令牌与草稿缓存；账号注销/文档删除后存储介质擦除；文件删除采用覆盖擦除；介质退役销毁流程 | 符合 |
| 个人信息保护 | 最小必要、脱敏、同意 | PII 加密、脱敏、授权访问、审计 | 员工手机号加密 + 列表脱敏（138****5678）；ONA 仅用聚合行为指标；个人画像默认仅本人可见；PII 访问二次授权与审计 | 符合 |
| 安全管理 | 制度、机构、人员、建设、运维 | 安全管理制度体系、三员分立、应急预案 | 编制安全管理制度、三员职责分离、开发安全规范（SDL）、发布安全评审、应急响应预案与演练 | 符合 |

**控制矩阵结论**：11 类控制项全部"符合"，无"部分符合"或"不符合"项。

### 2.1 关键控制点专项

| 专项 | 措施 | 验证方式 |
|---|---|---|
| IM 消息内容安全 | 敏感词拦截（2001007）、消息加密存储、撤回/删除审计 | 渗透测试 + 用例 TC-COLLAB-IM-008 |
| 文档外泄防护 | 密级（公开/内部/机密）、动态水印（查看人+工号+时间）、机密禁外链/下载、DLP 钩子 | 用例 TC-COLLAB-DOC-007 |
| 协同越权 | 文档级权限 + 分享链接有效期/访问码 + 数据权限边界 | 用例 TC-COLLAB-DOC-006、SEC-002 |
| 多租户隔离 | 网关租户一致性校验 + 应用层租户过滤 + RLS | 用例 TC-COLLAB-SEC-001 |
| ONA 隐私 | 匿名阈值（部门人数 < 阈值不出图）、禁止输出消息内容、可见范围配置 | 用例 TC-COLLAB-ONA-004 |

## 3. 威胁建模（STRIDE）

| 威胁类型 | 威胁场景（云协） | 风险等级 | 已有控制 | 处置 |
|---|---|---|---|---|
| **S**poofing 身份伪造 | 伪造 JWT 访问他人会话/文档；重放令牌 | 高 | RS256 签名、令牌短时效（30min）、`jti` 防重放、mTLS | 已缓解 |
| S 身份伪造 | 伪造会议邀请链接入会 | 中 | 入会码 + 身份校验 + 会议权限 | 已缓解 |
| **T**ampering 篡改 | 篡改文档协同操作流导致内容污染；篡改审批表单 | 高 | OT/CRDT 服务端权威合并、操作签名、审批幂等键、审计留痕 | 已缓解 |
| T 篡改 | 篡改审计日志掩盖痕迹 | 高 | 审计哈希链 + WORM 只读 | 已缓解 |
| **R**epudiation 抵赖 | 用户否认发送消息/审批意见 | 中 | 消息与审批操作全量审计 + 时间戳 + 用户标识 | 已缓解 |
| **I**nformation Disclosure 信息泄露 | 越权读取他人文档/会话；ONA 泄露个人关系；导出泄露 | 高 | 文档/会话权限校验、数据权限、ONA 匿名阈值与聚合、导出审批与水印 | 已缓解 |
| I 信息泄露 | 传输链路窃听 | 中 | TLS1.3 + mTLS | 已缓解 |
| I 信息泄露 | 敏感词绕过（变体/图片/拼音）导致违规内容传播 | 中 | 敏感词库 + 变体归一化 + 图片 OCR 巡检（DLP） | 部分缓解（见残余风险 R2） |
| **D**enial of Service 拒绝服务 | 消息洪泛、协同文档恶意高频操作、会议预定脚本争抢 | 高 | 网关限流、Sentinel 热点参数限流、IM 发送频率限制（2001006）、协同操作速率限制 | 已缓解 |
| D 拒绝服务 | 超大文档/附件耗尽存储与内存 | 中 | 大小限制（消息/文件/文档）、异步快照、配额 | 已缓解 |
| **E**levation of Privilege 权限提升 | 普通成员通过接口提权为群管理员/获取管理端能力 | 高 | 服务端权限再校验（不信任前端）、端别路由（`X-Client-Type`）、资源属主校验 | 已缓解 |
| E 权限提升 | 跨租户构造资源 ID 访问 | 高 | 网关租户一致性 + RLS 兜底 | 已缓解 |

STRIDE 结论：12 个威胁场景中 11 个"已缓解"，1 个"部分缓解"（敏感词变体绕过），已纳入残余风险并制定后续迭代计划。

## 4. 漏洞与风险

### 4.1 评估发现汇总

| 编号 | 发现 | 类别 | 严重性 | 状态 |
|---|---|---|---|---|
| F-01 | 消息分享链接未强制登录校验（历史实现） | 访问控制 | 中 | 已修复 |
| F-02 | 文档分享链接默认无有效期 | 访问控制 | 中 | 已修复（默认 7 天，可配置） |
| F-03 | 会话成员变更后历史文件推理可见（边缘） | 信息泄露 | 低 | 已修复（文件继承当前成员范围） |
| F-04 | 敏感词库仅精确匹配，变体可绕过 | 内容安全 | 中 | 迭代修复（见残余风险 R2） |
| F-05 | 会议室预定接口无频率限制（历史） | 拒绝服务 | 中 | 已修复（Sentinel 限流） |
| F-06 | 审计日志导出无二次鉴权 | 审计安全 | 中 | 已修复（导出需审计管理员权限 + 审批） |
| F-07 | ONA 部门视图小样本可反推个人（未配置阈值） | 隐私 | 中 | 已修复（匿名阈值默认 5 人） |
| F-08 | 前端错误提示暴露接口路径 | 信息泄露 | 低 | 已修复（统一提示 + requestId） |

## 5. 加固措施

| 序号 | 加固项 | 措施 | 责任方 |
|---|---|---|---|
| H1 | 传输加固 | 全链路 TLS1.3；HSTS；禁弱套件 | 平台组 |
| H2 | 数据加密 | 消息/手机号 AES-256-GCM；TDE；KMS 90 天轮换 | 平台组 |
| H3 | 访问控制 | 服务端二次鉴权、端别路由、数据权限最小化 | 云协组 |
| H4 | 内容安全 | 敏感词库 + 变体归一化 + DLP 图片 OCR 巡检 | 云协组 + 安全组 |
| H5 | 文档防泄 | 密级默认"内部"、动态水印、机密禁外链/下载 | 云协组 |
| H6 | 审计 | 全量操作审计 + 哈希链 WORM；导出二次鉴权 | 平台组 |
| H7 | 限流防刷 | 网关 + Sentinel 双层限流；发送频率限制 | 云协组 |
| H8 | ONA 隐私 | 匿名阈值、聚合输出、可见范围配置、无消息内容 | 云协组 |
| H9 | 供应链 | CI 集成 SAST/SCA/镜像扫描，阻断高危合入 | DevOps 组 |
| H10 | 应急 | 应急预案 + 季度演练 + 值班响应 | 安全组 |

## 6. 合规结论

| 维度 | 结论 |
|---|---|
| 等保三级控制矩阵 | 11 类控制项全部"符合" |
| 个人信息保护 | 符合最小必要、加密、脱敏、授权与审计要求 |
| 数据安全 | 传输/存储加密、备份恢复、剩余信息保护到位 |
| OWASP Top 10 / API Top 10 | 无可利用高危漏洞 |
| STRIDE 威胁 | 11/12 已缓解，1 项部分缓解并纳入残余风险 |

**综合合规结论：丰麟云协 V1.0.0 满足网络安全等级保护第三级要求，具备上线安全条件；后续需按残余风险计划持续改进。**

## 7. 残余风险

| 编号 | 残余风险 | 等级 | 影响 | 缓解现状 | 后续计划 |
|---|---|---|---|---|---|
| R1 | 服务间调用依赖 mTLS，若证书轮换失败可能中断 | 中 | 服务不可用 | 证书有效期监控 + 双证书热切换 | 引入 SPIFFE/自动轮换 |
| R2 | 敏感词变体/图片违规内容可能绕过 | 中 | 违规内容传播 | 已含变体归一化，图片 OCR 巡检为非实时 | V1.1 引入实时图片 OCR + 模型化内容识别 |
| R3 | 内部人员（有数据权限）恶意导出文档 | 中 | 数据泄露 | 水印 + 审计 + 导出审批 | 引入 DLP 外发管控与异常导出行为告警 |
| R4 | ONA 聚合指标在极端小组织下仍可能被推断 | 低 | 隐私推断 | 匿名阈值 + 聚合展示 | 引入差分隐私噪声 |
| R5 | 移动端本地缓存（IM/文档草稿）存在设备侧泄露风险 | 低 | 本地数据泄露 | 本地加密 + 退出清理 | 引入设备指纹绑定与远程擦除 |
| R6 | 第三方 AI 能力（会议转录）数据外发边界 | 低 | 数据外发 | 私有化部署 + 脱敏 | 明确数据出境评估与合同约束 |

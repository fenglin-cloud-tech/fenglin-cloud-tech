## 1. 通用约定

- 协议：HTTPS（TLS 1.2+，推荐 1.3）；服务间 mTLS。
- 风格：RESTful + 资源化；动作型接口 `POST /{resource}/{action}`。
- 版本：URL 版本段 `/api/collab/v1`。
- 数据格式：`application/json; charset=UTF-8`；文件上传 `multipart/form-data`。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1 开始，默认 1）、`size`（默认 20，最大 200）。
- 幂等：写操作支持 `Idempotency-Key`；审批、会议室预定、消息发送、日程创建强制幂等。
- 追踪：`X-Request-Id`（网关生成）、`X-Trace-Id`（SkyWalking）。

### 1.1 请求头

| 名称 | 必填 | 说明 |
|---|---|---|
| `Authorization` | 是 | `Bearer {access_token}`（JWT RS256） |
| `X-Tenant-Id` | 是 | 租户标识 |
| `X-Client-Type` | 是 | `ADMIN` / `PORTAL` |
| `X-Request-Id` | 否 | 幂等/追踪 |
| `Accept-Language` | 否 | `zh-CN` / `en-US` |
| `Idempotency-Key` | 否 | 写操作幂等键（24h） |

### 1.2 统一响应体

```json
{
  "code": "0",
  "message": "success",
  "data": {},
  "requestId": "b1f2c3d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

分页 `data` 结构：`{ "records": [], "total": 0, "page": 1, "size": 20 }`。

## 2. 鉴权与端别

- 令牌：OAuth2.1/OIDC 签发 JWT（RS256），承载 `sub`、`tenantId`、`roles`、`permissions`、`clientType`。
- 端别：`X-Client-Type` 与路径前缀双重约束。
  - `/admin/collab/**` 需 `ADMIN` 且具备 `tenant:collab:*` 或 `platform:*`。
  - `/app/collab/**` 需 `PORTAL` 且具备 `biz:collab:*`。
- 数据权限：网关与业务层按 `data_scope`（本人/本部门/本部门及下级/指定部门/全部）注入过滤条件。
- 租户边界：任何跨租户访问默认拒绝（除平台运营端，强审计）。
- WebSocket：握手阶段校验 JWT 与租户一致性。

  "message": "success",
  "data": {

    "memberCount": 4,

#### API-IM-006 发送消息

| 项 | 内容 |
|---|---|

错误码：`2001007`（敏感词）、`2001006`（限流）、`2001011`（非成员）、`2001010`。

#### API-IM-007 拉取消息

`GET /api/collab/v1/im/conversations/{convId}/messages?cursor={seq}&size=50&direction=BACKWARD`
响应 `data.records`：消息数组（`messageId,seq,senderId,msgType,summary,fileId,cardPayload,revoked,sentAt`）。
说明：`cursor` 为 `seq`，支持向前/向后翻页；撤回消息返回 `revoked=true` 与占位摘要。错误码：`2001010`、`2001011`。

#### API-IM-008 撤回消息

`POST /api/collab/v1/im/messages/{messageId}/revoke`
请求：`{ "reason": "发送错误" }`；仅发送人（≤24h）或群主可撤回。
响应：`{ "code":"0","data":{"messageId":8800123456790,"revoked":true,"revokedAt":"..."} }`
错误码：`2000004`（超时或已撤回）、`2000002`。
审计：撤回动作写审计（保留原文）。

#### API-IM-009 标记已读

`POST /api/collab/v1/im/messages/{messageId}/read`
响应：`{ "code":"0","data":{"conversationId":"...","unreadCount":0} }`；幂等。

#### API-IM-010 表情回复

`POST /api/collab/v1/im/messages/{messageId}/reactions`，请求 `{ "emoji":"👍" }`；重复返回已存在。错误码：`2000004`。

#### API-IM-011 消息搜索

`GET /api/collab/v1/im/messages/search?keyword=评审&convId=&senderId=&msgType=&startTime=&endTime=&page=1&size=20`
响应 `data`：命中消息列表（含高亮 `highlight` 字段）。错误码：`2000001`。

#### API-IM-050 敏感词策略配置（ADMIN）

响应：`{ "code":"0","data":{"policyId":501,"wordCount":2,"action":"BLOCK"} }`；幂等。端别 ADMIN，权限 `tenant:collab:im:sensitive:manage`。

`GET /api/collab/v1/admin/im/audit/conversations?deptId=&startTime=&endTime=&page=1&size=20`（受 `data_scope` 约束，全量审计）。

## 5. 开放 API

### 5.1 开放网关

- 前缀：`/openapi/collab/v1`（经 `fenglin-openapi-service`）。
- 鉴权：AppKey/AppSecret + HMAC-SHA256 签名（`X-Ca-Key`、`X-Ca-Signature`、`X-Ca-Timestamp`、`X-Ca-Nonce`）；或 OAuth2.1 授权码模式。
- 配额：默认 100 QPS/应用，超限返回 `0000006`。
- 沙箱：提供沙箱租户与 Mock 数据。

### 5.2 可开放资源

| 资源 | 路径 | 方法 | 说明 |
|---|---|---|---|
| 会话只读 | `/openapi/collab/v1/conversations` | GET | 授权范围内会话元数据 |
| 消息发送（受限） | `/openapi/collab/v1/messages` | POST | 应用机器人消息 |
| 文档只读 | `/openapi/collab/v1/documents/{id}` | GET | 授权文档元数据 |
| 日程只读 | `/openapi/collab/v1/events` | GET | 授权日历日程 |
| 会议只读 | `/openapi/collab/v1/meetings/{id}` | GET | 会议元数据、纪要摘要 |
| 审批发起 | `/openapi/collab/v1/approvals` | POST | 按授权模板发起 |
| ONA 部门级只读 | `/openapi/collab/v1/ona/dept-network` | GET | 部门级聚合（需单独授权） |

提供 Java / JS / Python SDK，封装签名、重试、幂等。

## 6. 事件与 Webhook

### 6.1 事件清单

| 事件 Key | 触发时机 | 载荷要点 |
|---|---|---|
| `collab.message.sent` | 消息发送成功 | messageId、conversationId、senderId、msgType |
| `collab.message.revoked` | 消息撤回 | messageId、operatorId |
| `collab.document.updated` | 文档保存/版本生成 | docId、version、editorId |
| `collab.document.permission.changed` | 文档权限变更 | docId、subject、permission |
| `collab.event.created` | 日程创建 | eventId、calendarId、startAt |
| `collab.meeting.created` | 会议创建 | meetingId、roomId、startAt |
| `collab.meeting.minutes.published` | 纪要发布 | minutesId、meetingId |
| `collab.approval.completed` | 审批完成 | instanceId、result、finishedAt |
| `collab.okr.aligned` | OKR 对齐 | childObjectiveId、parentObjectiveId |
| `collab.ona.snapshot.generated` | ONA 快照生成 | snapshotId、periodKey、density |

### 6.2 回调机制

- 传输：Kafka → Webhook HTTP POST。
- 签名：`X-Fenglin-Signature = HMAC-SHA256(body, appSecret)`，接收方须验签。
- 重试：指数退避 3 次（10s/60s/300s）；成功响应须 2xx。
- 幂等：事件含 `eventId`，接收方须幂等处理；乱序容忍（按 `occurredAt` 排序）。
- 死信：重试耗尽入死信队列，支持手动重放。

### 6.3 WebSocket 实时通道

| 项 | 内容 |
|---|---|
| 路径 | `/ws/collab/v1` |
| 鉴权 | 握手 `Authorization` + `X-Tenant-Id`，校验 JWT 与租户 |
| 心跳 | 客户端每 30s 发送 `ping`，服务端 `pong`；90s 无心跳断开 |
| 消息帧 | `{ "type":"MSG", "payload":{...} }`；类型含 `MSG`/`READ`/`PRESENCE`/`DOC_OP`/`MEETING`/`NOTICE` |
| 重连 | 客户端按 `lastCursor`（seq）补齐；服务端返回 `RESUME_ACK` |
| 协同 | 文档房间 `JOIN_DOC`/`DOC_OP`/`LEAVE_DOC`；服务端广播排除来源 |
| 安全 | 帧级权限校验；越权订阅返回 `ERROR: 2000002` |

## 7. 版本与兼容

- 版本策略：URL 版本段；重大不兼容变更升 `/v2`；旧版本至少保留 12 个月。
- 兼容承诺：新增字段向后兼容；枚举值仅新增不删除；错误码不复用。
- 废弃流程：废弃接口提前 6 个月公告（开放平台"变更公告"），响应头 `Sunset` 标注下线时间。
- 契约：以 OpenAPI 3.1（`openapi.yaml`）为准，接口变更须同步更新契约并过契约测试。

## 1. 管理端总览

### 1.1 登录与权限域

管理端地址：`https://collab.fenglincloud.com/admin/collab`。系统管理员使用具备 `platform:*` / `tenant:*` 权限域的账号登录，与用户端（`biz:*`）权限域隔离。

> 安全约束：三员分立（系统管理员 / 安全管理员 / 审计管理员）职责分离；管理端操作全部审计留痕。

### 1.2 导航结构

| 一级菜单 | 二级功能 | 路由 |
|---|---|---|
| 运营概览 | 协作运营概览 | `/admin/collab/overview` |
| IM 治理 | 会话治理、敏感词库 | `/admin/collab/im/*` |
| 文档治理 | 文档治理、密级与水印 | `/admin/collab/docs/*` |
| 日历资源 | 公共日历、节假日 | `/admin/collab/calendar/resources` |
| 会议管理 | 会议室管理、会议统计 | `/admin/collab/meeting/*` |
| OKR 管理 | 周期管理、组织目标 | `/admin/collab/okr/*` |
| 审批管理 | 模板管理、流程配置、统计 | `/admin/collab/approval/*` |
| 工作台配置 | 组件与模板 | `/admin/collab/workbench/config` |
| ONA 配置 | 分析配置、组织洞察 | `/admin/collab/ona/*` |
| 通知模板 | 站内信/邮件/IM 模板 | `/admin/collab/notification/templates` |
| 协作审计 | 审计日志 | `/admin/collab/audit` |

### 1.3 运营概览

`[截图：A-OV-协作运营概览]`

## 2. 租户 / 组织 / 用户 / 角色

> 本节基础能力由丰麟云枢中台 `fenglin-tenant-service`、`fenglin-iam-service` 提供，云协管理端复用并叠加协作域配置。

### 2.1 租户管理

| 操作 | 路径 | 说明 |
|---|---|---|
| 租户开通 | 中台租户管理 | 分配租户 ID、套餐、配额 |
| 协作能力开关 | 云协管理端 → 租户配置 | 启用/停用 IM、文档、会议、ONA 等子能力 |
| 配额管理 | 中台租户管理 | 文档存储、消息留存、ONA 分析窗口 |

租户隔离策略：所有协作数据带 `tenant_id`，网关校验令牌与 `X-Tenant-Id` 一致性，数据库启用 RLS 兜底。

### 2.2 组织管理

- 组织架构（部门树）由中台同步；云协以下列维度使用组织数据：
  - 文档/审批/ONA 的数据权限范围（本部门/本部门及下级）。
  - ONA 部门协作网络视图。
  - 会议室归属（楼宇/楼层）。

### 2.3 用户管理

| 操作 | 说明 |
|---|---|
| 用户同步 | 由中台 IAM / 企业目录（LDAP/AD/HR）同步 |
| 协作状态 | 启用/停用协作账号（停用后无法登录用户端） |
| PII 处理 | 员工手机号加密存储（AES-256-GCM），列表脱敏显示 `138****5678` |
| 账号解锁 | 因登录失败锁定（15 分钟）可手动解锁 |

### 2.4 角色管理

云协内置角色（可复制扩展）：

| 角色 | 权限域 | 说明 |
|---|---|---|
| 平台协作管理员 | `platform:collab:*` | 全局治理（敏感词、密级策略、ONA 配置） |
| 租户协作管理员 | `tenant:collab:*` | 租户内协作治理 |
| 会议室管理员 | `tenant:collab:meeting:manage` | 会议室资源与设备维护 |
| 审批流程管理员 | `tenant:collab:approval:manage` | 审批模板与流程配置 |
| 审计管理员 | `tenant:collab:audit:read` | 审计查询与导出 |
| 普通员工 | `biz:collab:*` | 用户端日常协作 |

角色分配遵循最小权限原则；角色变更审计留痕。

## 3. 权限与数据权限配置

### 3.1 功能权限（RBAC）

- 权限项按"功能点"粒度配置（如 `collab:doc:share-external`、`collab:meeting:room:delete`）。
- 管理端操作权限与用户端业务权限严格分离。

### 3.2 数据权限

数据可见范围五级：

| 级别 | 说明 |
|---|---|
| 本人 | 仅本人创建/参与的数据 |
| 本部门 | 本部门范围 |
| 本部门及下级 | 本部门及所有下级部门 |
| 指定部门 | 指定若干部门 |
| 全部 | 租户内全部（仅管理员） |

适用范围：审批实例、文档治理、会议统计、ONA 洞察。跨租户默认拒绝。

### 3.3 敏感操作二次确认

| 操作 | 二次确认方式 |
|---|---|
| 删除会议室/文档密级变更 | 二次弹窗 + 操作留痕 |
| 审计日志导出 | 需审计管理员权限 + 审批 |
| 停用协作能力 | 二次确认 + 影响面提示 |

## 4. 参数与字典

### 4.1 协作参数（管理端配置，对应应用配置）

| 参数 | 默认 | 说明 |
|---|---|---|
| IM 单条消息最大长度 | 8000 字符 | 超限返回 2000001 |
| IM 发送频率上限 | 20 条/秒 | 超限返回 2001006 |
| 消息撤回窗口 | 24 小时 | — |
| 单文档协同人数上限 | 50 人 | 超限拒绝新会话 |
| 会议室开放时段 | 08:00–22:00 | 可配置 |
| 审批任务超时 | 48 小时 | 超时告警/自动催办 |
| ONA 数据窗口 | 90 天 | 可配置 |
| ONA 匿名阈值 | 5 人 | 部门人数 < 阈值不出图 |
| 审计留存 | 12 个月 | 强制 ≥ 6 个月 |

### 4.2 字典维护

| 字典 | 用途 |
|---|---|
| 文档密级 | 公开 / 内部 / 机密 |
| 审批模板分类 | 行政 / 财务 / 人事 / 采购 / 用印 |
| 会议类型 | 例会 / 评审 / 培训 / 客户 |
| OKR 周期类型 | 季度 / 半年 / 年度 |
| 通知渠道 | 站内信 / 邮件 / IM 卡片 / 短信 |

字典支持增删改，变更即时生效并记录变更历史。

### 4.3 敏感词库

路径：`/admin/collab/im/sensitive`。

- 支持关键词、正则、变体归一化。
- 命中策略：拦截 / 替换 / 仅告警；命中记录入审计。
- 支持按业务场景启用不同词库。

## 5. 流程与审批配置

### 5.1 审批模板管理

路径：`/admin/collab/approval/templates`。

1. 新建模板：设置模板名称、分类、图标、可见范围。
2. 设计表单：拖拽字段（文本/数字/日期/金额/附件/成员选择器等），支持必填与校验。
3. 绑定流程：选择或新建 Flowable 流程。
4. 发布：设置版本与生效范围。

### 5.2 审批流程配置

路径：`/admin/collab/approval/processes`（Flowable BPMN 2.0 设计器）。

| 能力 | 说明 |
|---|---|
| 节点类型 | 审批、抄送、条件分支、并行/会签/或签 |
| 审批人 | 指定人 / 角色 / 上级 / 部门负责人 / 表单变量 |
| 条件分支 | 基于表单字段（如金额 > 10000 走财务复核） |
| 超时策略 | 超时自动催办 / 自动通过 / 自动转办 |
| 代理与授权 | 支持出差期间设置审批代理（限定期限、可审计） |

`[截图：A-APR-审批流程配置]`

### 5.3 审批统计

- 指标：审批量、平均处理时长、超时率、驳回率、及时率。
- 支持下钻到模板/部门/处理人；支持导出。

## 6. 集成与开放平台

### 6.1 中台能力集成

| 能力 | 中台服务 | 用途 |
|---|---|---|
| 身份/权限 | `fenglin-iam-service` | 登录、角色、数据权限 |
| 工作流 | `fenglin-workflow-service` | 审批流程引擎 |
| 消息 | `fenglin-message-service` | 站内信/邮件/IM 推送、WebSocket |
| 文件 | `fenglin-file-service` | 文件存储、预览、水印、DLP 钩子 |
| 审计 | `fenglin-audit-service` | 审计日志哈希链/WORM |
| 搜索 | `fenglin-search-service` | 消息/文档检索 |
| AI | `fenglin-ai-service` | 会议转录、纪要摘要 |

### 6.2 开放 API

- 开放网关前缀：`/openapi/collab/v1`。
- 应用管理：注册应用、AppKey/AppSecret（HMAC-SHA256 签名）、OAuth2.1 授权。
- 配额与限流：按应用/接口配置 QPS，超限返回 `0000006`。
- 事件订阅：基于 Kafka 的 Webhook 回调（重试 + 验签 + 幂等）。
- 可开放资源：会话、消息（发送）、文档（创建/读取）、日程、会议室（查询/预定）、审批（发起/查询）、OKR（读取）。
- 沙箱：开发者门户提供在线调试。

### 6.3 第三方渠道

支持将协作通知转发至企业微信 / 飞书 / 钉钉（消息转发策略由管理端配置）。

## 7. 监控与审计

### 7.1 协作审计日志

路径：`/admin/collab/audit`。

- 审计范围：登录、消息撤回/删除、敏感词命中、文档密级变更/外链分享、会议室删除、审批办理、ONA 配置、权限变更、审计导出。
- 审计要素：操作人、时间、IP、对象、操作类型、前后值、`requestId`。
- 防篡改：哈希链 + WORM；留存 12 个月。
- 查询与导出：支持多条件检索；导出需审计管理员权限 + 审批。

`[截图：A-AUD-协作审计日志]`

### 7.2 监控对接

管理端可查看（或跳转平台监控）：服务健康、错误率、P95/P99、Kafka lag、慢查询、告警。详见《部署运维手册》第 7 章。

### 7.3 告警配置

- 业务告警：消息发送失败率、协同同步率、会议室超定、审批超时。
- 告警通道：值班电话 + 企微/飞书 + 邮件。

## 8. 备份与安全运维

### 8.1 备份

| 对象 | 策略 | 保留 |
|---|---|---|
| 协作库（`fenglin_collab`） | 每日全备 + WAL 增量（PITR） | 全备 30 天 / WAL 7 天 |
| 文件（MinIO） | 版本化 + 跨区复制 | 按桶生命周期 |
| 审计日志 | WORM | 12 个月 |
| 配置（Nacos） | 版本化快照 | 全量 |

### 8.2 安全运维

| 项目 | 要求 |
|---|---|
| 密钥轮换 | 数据库/接口密钥 ≤ 90 天 |
| 权限审计 | 每季度复核角色与数据权限 |
| 漏洞扫描 | 每季度 + 上线前 |
| 账号治理 | 离职账号及时停用；长期未登录账号清理 |
| 密级策略 | 机密文档禁外链/下载；动态水印强制开启 |
| PII 保护 | 手机号等加密存储 + 脱敏展示 + 访问审计 |

## 9. 故障处理

| 故障现象 | 可能原因 | 处理步骤 |
|---|---|---|
| 用户无法登录 | 账号锁定 / 协作能力停用 / IAM 异常 | 检查锁定状态 → 解锁；检查租户协作开关；检查 IAM |
| 消息发送失败 | Kafka 异常 / 限流命中 / 敏感词 | 检查 Kafka 与 WS 网关；核对限流与敏感词 |
| 文档无法协同 | WS 连接异常 / 文档超限 / 权限不足 | 检查 WS 网关；核对协同人数与权限 |
| 会议室无法预定 | 时段占用 / 开放时段外 / 权限不足 | 核对占用与开放时段；检查会议室管理员权限 |
| 审批流程卡住 | 流程节点配置错误 / 引擎异常 | 检查 BPMN 配置；Flowable 补偿/重试 |
| 审批无法办理 | 非处理人 / 未设置代理 | 核对处理人；设置审批代理 |
| ONA 无数据 | 样本不足 / 未开启采集 / 匿名阈值 | 核对数据窗口与隐私开关；降低阈值需评估隐私 |
| 审计日志缺失 | 审计服务异常 / 留存策略误配 | 检查审计中台；核对留存配置 |
| 管理端 403 | 权限域不符 / 端别错误 | 核对角色权限与 `X-Client-Type` |

故障升级路径：一线运维 → 云协产品组值班 → 平台架构组；重大故障启动应急响应预案（见《部署运维手册》第 9 章）。

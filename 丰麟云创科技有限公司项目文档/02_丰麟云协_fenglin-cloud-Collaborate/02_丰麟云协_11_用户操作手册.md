## 1. 快速开始

### 1.1 产品简介

丰麟云协是丰麟云枢平台的协作与办公产品（域B），面向企业员工提供**即时通讯（IM）、协同文档、日历、会议与会议室、OKR 协同、审批、工作台**七大协同能力，并基于协作行为提供 **ONA 组织协作网络洞察**。它帮助你把"沟通—协作—目标—决策"串联在一个入口完成。

### 1.2 三分钟上手

1. **登录**：浏览器打开 `https://collab.fenglincloud.com/app/collab`，使用企业账号登录（首次登录需完成双因子验证）。
2. **看工作台**：进入首页"我的工作台"，查看今天的待办、日程、消息与 OKR。
3. **发消息**：点击左侧"消息"，选择同事开始对话。
4. **建文档**：点击"文档"→"新建"，邀请同事一起协作。
5. **约会议**：点击"会议"→"预定会议室"，选择时间与会议室。

### 1.3 浏览器与设备要求

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome 118+ / Edge 118+ / Firefox 119+ / Safari 16+ |
| 移动端 | Android 12+ / iOS 16+ 浏览器，支持添加到主屏（PWA） |
| 网络 | 建议 ≥ 2Mbps；IM 与文档协同需保持长连接 |
| 屏幕 | 最小 360px 宽；推荐 1366px 以上 |

### 1.4 界面总览

| 区域 | 说明 |
|---|---|
| 顶部导航 | 工作台 / 消息 / 文档 / 日历 / 会议 / OKR / 审批；右侧为搜索、通知、头像 |
| 内容区 | 当前功能页面 |
| 快捷入口 | 工作台上的常用操作（发起审批、预定会议室、新建文档、发起会议） |

## 2. 登录与导航

### 2.1 登录

1. 打开用户端地址，进入登录页。
2. 输入企业账号（工号/邮箱）与密码。
3. 首次登录或异地登录时，输入**双因子验证码**（手机短信/身份验证器）。
4. 登录成功后默认进入"我的工作台"。

> 提示：连续 5 次密码错误，账号将被锁定 15 分钟；如忘记密码，点击"忘记密码"通过企业邮箱重置。

### 2.2 导航

- **顶部导航切换**：点击任一标签切换功能模块。
- **工作台卡片钻取**：点击卡片右上角"›"进入对应模块。
- **全局搜索**：顶部放大镜，可搜索联系人、消息、文档、日程、审批。
- **通知中心**：顶部铃铛，按分类（协作/审批/会议/系统）查看，支持标记已读与免打扰时段设置。
- **移动端**：底部 Tab 导航；列表进入详情为两级页面。

### 2.3 个人设置

点击头像 → "个人设置"，可设置：

| 设置项 | 说明 |
|---|---|
| 头像与昵称 | 展示于消息、文档、会议 |
| 在线状态 | 在线 / 忙碌 / 离线 |
| 通知免打扰 | 设置免打扰时段与渠道 |
| 日历偏好 | 默认视图、时区、工作日 |
| 隐私 | 是否参与 ONA 协作网络分析 |

## 3. 分模块操作指引

> 各模块"截图位"以 `[截图：模块-页面]` 标注，UI 详见《UI/UX 设计规范》。

### 3.1 消息（IM）

**进入**：顶部"消息"。

**发起会话**

1. 点击会话列表左上角"＋ 发起会话"。
2. 选择联系人（支持多选创建群聊，群成员上限 2000 人）。
3. 输入消息发送。

`[截图：IM-消息中心]`

**发送消息**

- 支持文本、表情、图片、文件、语音条、@提及、引用回复。
- 点击消息右键/长按可"引用""转发""撤回（24 小时内）"。
- 消息发送失败时气泡显示"重试"，点击可重发（不会重复发送）。

**群管理**（群主/管理员）

- 群设置中可修改群名、群公告、添加/移除成员、设置免打扰与置顶。
- 可在群内查看"已读人数"。

**常用操作**

| 操作 | 方法 |
|---|---|
| 搜索消息 | 会话内点击搜索，按关键词/发送人/时间/类型检索 |
| 置顶会话 | 会话右键 → 置顶 |
| 免打扰 | 会话右键 → 免打扰 |
| 收藏消息 | 消息右键 → 收藏 |
| 文件转文档 | 文件消息右键 → 转为协同文档 |

> 注意：消息内容受敏感词策略管控，命中敏感词将无法发送并提示原因。

### 3.2 协同文档

**进入**：顶部"文档"。

**新建文档**

1. 点击"新建"，选择"空白"或从模板库选择模板。
2. 输入标题，进入编辑器。

`[截图：DOC-文档编辑]`

**多人协作**

- 顶部显示当前在线协作者头像（最多 5 个），编辑区显示他人光标与姓名。
- 支持同一文档 ≥ 50 人同时编辑，实时同步、无冲突合并。
- 冲突无法自动合并时会提示"内容已被他人修改"并定位，请确认后继续。

**权限与分享**

1. 点击右上角"分享"。
2. 选择成员或部门，设置权限：可阅读 / 可评论 / 可编辑 / 可管理。
3. 可生成分享链接（设置有效期与访问码）。

> 注意：机密文档禁止外链分享与下载；所有文档页面含动态水印（查看人姓名 + 工号 + 时间）。

**版本与评论**

- 右侧面板可查看"评论""版本""协作者"。
- 版本历史支持对比与一键回滚；评论支持 @提及与解决/重开。

### 3.3 日历

**进入**：顶部"日历"。

**创建日程**

1. 点击日期格或"＋ 新建日程"。
2. 填写标题、时间、地点、参与人、重复规则、提醒。
3. 如需会议室，勾选"预定会议室"（自动联动会议模块）。

`[截图：CAL-我的日历]`

**查看与使用**

| 操作 | 方法 |
|---|---|
| 切换视图 | 月/周/日视图切换 |
| 忙闲查询 | 创建日程时查看参与人忙闲，系统推荐最优时段 |
| 提醒 | 到期通过站内信/IM 提醒 |
| 订阅日历 | 订阅团队共享日历、公共日历（假期/公司事件） |

### 3.4 会议与会议室

**进入**：顶部"会议"。

**预定会议室**

1. 点击"预定会议室"，选择日期、楼宇、容纳人数。
2. 在时间轴上点击"空白格"发起预定。
3. 填写会议主题、时间、参会人、是否需要纪要/循环。
4. 提交后时间格变为"占用"。

`[截图：MEET-会议室预定]`

> 若提交时提示"该时段已被占用"，说明他人刚刚预定成功，请选择系统推荐的相邻时段或其他可用会议室。

**会议与纪要**

- "我的会议"查看会议列表与详情（议程、参会人、纪要）。
- 会议纪要支持结构化（议题/结论/行动项），行动项可一键转为待办或日程并指派责任人。

### 3.5 OKR 协同

**进入**：顶部"OKR"。

**制定与更新**

1. "我的 OKR"中创建目标（O）与关键结果（KR）。
2. 更新 KR 进度（0–100%）与信心指数（高/中/低）。
3. 状态自动计算：进展正常（绿）/有风险（黄）/偏离（红）。

`[截图：OKR-我的 OKR]`

**对齐视图**

- "OKR 对齐视图"展示上下对齐与横向对齐关系，可追溯，禁止循环对齐。
- 目标可关联文档、会议、审批，形成"目标—协作"闭环。

### 3.6 审批

**进入**：顶部"审批"。

**发起审批**

1. 点击"发起审批"，选择模板（如采购申请、请假申请、用印申请）。
2. 填写表单并上传附件，提交。

`[截图：APR-发起审批]`

**办理审批**

1. 在"待办"中打开审批详情。
2. 查看表单信息与流程进度。
3. 点击"同意"或"驳回"（驳回需填写意见），支持转办/加签。

`[截图：APR-审批办理]`

> 只有当前节点处理人可办理；非处理人操作会被拦截。

### 3.7 工作台

**进入**：登录后首页。

- 卡片展示：待我审批、我的日程、消息未读、我的 OKR、团队动态。
- 快捷入口：发起审批、预定会议室、新建文档、发起会议。
- 支持拖拽调整卡片与隐藏；管理端配置的默认模板可被个人个性化覆盖。

### 3.8 协作网络（ONA）

**进入**：顶部"OKR/更多"→"协作网络"。

- **个人协作网络**：以你为中心展示与同事的协作关系（消息/文档/会议共现），连接强度按频次着色。
- **团队协作洞察**：查看团队连接度、协作孤岛预警（需权限）。
- 数据仅基于聚合行为指标，不展示消息内容；未开启隐私授权的成员不参与。

`[截图：ONA-协作网络]`

> 若提示"数据不足，暂无法生成协作网络"，说明你的近期协作记录较少。

## 4. 常见任务场景

### 场景一：安排一场跨部门评审会

1. "日历"→新建日程，填写主题与时间，添加参与人（可查看忙闲）。
2. 勾选"预定会议室"，选择可用会议室（系统自动联动会议）。
3. 保存后，参与人收到邀请；会议创建成功。
4. 会议结束后在"会议详情"填写纪要，勾选"行动项"指派责任人。

### 场景二：与同事协作撰写方案

1. "文档"→新建文档（或从模板），邀请同事（可编辑权限）。
2. 多人实时协作编辑，使用评论 @同事讨论。
3. 定稿后点击"分享"生成链接（设有效期）或导出。
4. 如需评审，关联到相关 OKR 或发起审批。

### 场景三：提交并跟进一笔采购申请

1. "审批"→发起审批→选择"采购申请"模板。
2. 填写金额、事由，上传报价单，提交。
3. 在"我发起"中查看进度；被驳回时按意见修改后重新提交。
4. 审批结果通过 IM 卡片与工作台待办通知你。

### 场景四：更新季度 OKR 进展

1. "OKR"→我的 OKR，选择本季度目标。
2. 更新各 KR 进度与信心指数，填写说明。
3. 上级对齐视图实时同步；如状态变为"偏离"，及时调整计划。

### 场景五：在群里分享一份文件并转成文档

1. 在会话中发送文件。
2. 文件消息右键→"转为协同文档"，生成共享链接。
3. 文件/文档继承会话成员可见范围；邀请协作编辑。

## 5. 常见问题 FAQ

| 问题 | 原因与解决办法 |
|---|---|
| 登录提示账号被锁定 | 连续 5 次密码错误，等待 15 分钟或联系管理员解锁 |
| 消息发送失败 | 检查网络；确认未命中敏感词；点击气泡"重试"重发 |
| 消息延迟/收不到 | 检查是否离线；重新进入会话触发同步；确认未被免打扰 |
| 文档显示"无权限" | 联系文档所有者或管理员申请权限 |
| 文档提示"内容已被他人修改" | 你与他人同时编辑冲突段落，确认提示内容后继续 |
| 无法分享机密文档链接 | 机密文档禁止外链分享与下载（管理端策略） |
| 预定会议室提示占用 | 该时段刚被他人预定，请选择相邻时段或其他会议室 |
| 审批无法办理 | 你可能不是当前节点处理人；如已出差请设置审批代理 |
| OKR 状态为"偏离" | 进度偏低或信心不足，请更新计划或说明 |
| 协作网络显示"数据不足" | 近期协作记录较少（< 5 条），无法生成 |
| 移动端体验受限 | 建议添加到主屏（PWA）；复杂配置建议使用桌面端 |
| 退出后本地草稿丢失 | 退出会清理本地缓存的草稿，请先保存 |

## 6. 快捷键

> 适用于桌面端（Chrome/Edge/Firefox/Safari）。

### 6.1 全局

| 快捷键 | 功能 |
|---|---|
| `Ctrl/⌘ + K` | 打开全局搜索 |
| `Ctrl/⌘ + /` | 显示快捷键帮助 |
| `Ctrl/⌘ + ,` | 打开个人设置 |
| `Esc` | 关闭当前弹窗/抽屉 |

### 6.2 消息（IM）

| 快捷键 | 功能 |
|---|---|
| `Enter` | 发送消息 |
| `Shift + Enter` | 消息内换行 |
| `↑` | 编辑上一条已发送消息（可撤回） |
| `@` | 唤起成员提及 |
| `Ctrl/⌘ + F` | 会话内搜索 |
| `Esc` | 关闭表情/附件面板 |

### 6.3 文档

| 快捷键 | 功能 |
|---|---|
| `Ctrl/⌘ + B / I / U` | 加粗 / 斜体 / 下划线 |
| `Ctrl/⌘ + S` | 立即保存（自动保存已开启） |
| `Ctrl/⌘ + Z / Shift + Z` | 撤销 / 重做 |
| `Ctrl/⌘ + Alt + M` | 插入评论 |
| `Ctrl/⌘ + /` | 显示文档快捷键 |

### 6.4 日历与会议

| 快捷键 | 功能 |
|---|---|
| `C` | 新建日程 |
| `T` | 跳转到今天 |
| `M / W / D` | 切换月 / 周 / 日视图 |

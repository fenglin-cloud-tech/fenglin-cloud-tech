## 1. 设计令牌

### 1.1 色彩令牌

丰麟云协全端共用丰麟云枢统一定义的设计令牌（Design Token）。令牌以 CSS 变量形式落地于 `fenglin-collab-ui/src/styles/tokens.scss`，禁止在业务组件中硬编码色值。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fl-color-primary` | `#1F5EFF` | 主色（丰麟蓝）：按钮、选中态、链接、品牌标识 |
| `--fl-color-primary-hover` | `#3D78FF` | 主色悬停 |
| `--fl-color-primary-active` | `#1A4FD8` | 主色按下 |
| `--fl-color-primary-light` | `#E8EFFF` | 主色浅底（选中行、标签底色） |
| `--fl-color-success` | `#16A34A` | 成功：已通过、在线、已完成 |
| `--fl-color-warning` | `#F59E0B` | 警告：待处理、即将到期 |
| `--fl-color-danger` | `#DC2626` | 危险：驳回、删除、占用冲突 |
| `--fl-color-info` | `#64748B` | 信息：中性提示、次要说明 |
| `--fl-color-text-primary` | `#1E293B` | 主文本 |
| `--fl-color-text-secondary` | `#64748B` | 次文本 |
| `--fl-color-text-disabled` | `#94A3B8` | 禁用文本 |
| `--fl-color-bg` | `#F5F7FA` | 页面背景 |
| `--fl-color-surface` | `#FFFFFF` | 卡片/容器背景 |
| `--fl-color-border` | `#E2E8F0` | 边框/分割线 |
| `--fl-color-online` | `#16A34A` | IM 在线态圆点 |
| `--fl-color-busy` | `#F59E0B` | IM 忙碌态圆点 |
| `--fl-color-offline` | `#94A3B8` | IM 离线态圆点 |

业务语义色（云协专属，扩展自基础令牌）：

### 1.4 图标与插图

- 图标库：管理端统一使用 Element Plus Icons；用户端使用自研 Portal Icons（线性 1.5px 描边，24×24 基准，与 Element Plus 视觉对齐）。
- 插图：空态、引导、错误页使用品牌插图（主色 + 中性灰），详见 `assets/illustrations/`，命名 `empty-chat.svg`、`empty-doc.svg`、`empty-meeting.svg`、`error-500.svg`。
- IM 表情：内置 128 组品牌表情（`collab-emoji-*`），支持快捷输入 `:` 触发。

## 5. 交互流程

### 5.1 IM 发送消息

```
用户输入文字
   └─► 本地即时渲染"发送中"气泡
         └─► 调用 POST /api/collab/v1/im/messages（Idempotency-Key）
               ├─ 成功 ─► 气泡置为已发送 ─► WebSocket 广播 ─► 他人实时接收
               └─ 失败 ─► 气泡显示"重试"按钮 ─► 点击重发（同幂等键）
```

### 5.2 文档协同编辑

```
打开文档 ─► 建立 WebSocket（/ws/collab/doc/{id}）
   ├─► 拉取最新快照 ─► 渲染
   ├─► 本地编辑 ─► OT 变换 ─► 增量提交 ─► 服务端合并 ─► 广播他人
   ├─► 收到远端变更 ─► 变换本地未提交操作 ─► 应用
   └─► 冲突无法自动合并 ─► 提示"内容已被他人修改"并定位（错误码 2002004）
```

### 5.3 会议室预定（含并发冲突）

```
选择时间格 ─► 填写预定信息 ─► 提交
   └─► POST /meeting/rooms/{id}/bookings（Idempotency-Key）
         ├─ 成功 ─► 时间轴刷新为"占用" ─► Toast"预定成功"
         └─ 冲突（2006005 会议室占用）─► 弹窗提示"该时段已被占用"
               └─► 提供"相邻时段"与"其他可用会议室"替代建议
```

### 5.4 审批办理

```
审批中心待办 ─► 打开详情 ─► 查看表单与流程 ─► 填写意见
   ├─ 同意 ─► 流程推进至下一节点 ─► Toast"已同意"
   ├─ 驳回 ─► 意见必填 ─► 流程退回发起人
   ├─ 转办/加签 ─► 选择人员 ─► 节点更新
   └─ 非处理人操作 ─► 拦截（2007003 非审批处理人）
```

### 5.5 OKR 更新与对齐

```
我的 OKR ─► 更新 KR 进展（进度 + 信心指数 + 说明）
   └─► PATCH /okr/key-results/{id}
         └─► 上级目标对齐视图实时刷新 ─► 状态色随进度/信心自动计算
               （进度≥70 且信心高=正常；信心中=有风险；信心低或进度<50=偏离）
```

### 6.1 断点定义

| 断点 | 宽度 | 目标设备 | 布局策略 |
|---|---|---|---|
| XL | ≥1440px | 桌面大屏 | 内容区最大宽 1440px 居中，工作台 4 列卡片 |
| LG | 1200–1439px | 标准桌面 | 内容区自适应，工作台 3 列卡片 |

| SM | 768–991px | 平板竖屏 | 侧栏抽屉化，表格横向滚动 |

- 最小可点击区：44×44px（移动端）。

### 6.3 栅格

## 7. 状态规范

每个数据视图必须实现以下状态，缺一不可：

| 状态 | 表现 | 规范 |
|---|---|---|
| 加载中 | 骨架屏（Skeleton） | 列表/卡片用骨架；按钮用 loading 态；禁止空白闪烁 |
| 空态 | 品牌插图 + 文案 + 主操作 | 如"还没有会话，发起第一个会话吧" |
| 错误态 | 插图 + 错误说明 + 重试按钮 | 展示错误码与 `requestId`，便于运维定位 |
| 无权限 | 锁形插图 + 说明 | 提示申请权限入口（链接至管理端配置） |
| 成功反馈 | Toast / Message | 顶部或角落，2.5s 自动消失 |
| 失败反馈 | Toast（danger） | 展示可读原因，不暴露堆栈 |
| 断网/离线 | 顶部横幅"网络异常，正在重连" | IM/文档提供本地缓存与重连机制 |
| 部分加载 | 分页/懒加载占位 | 列表滚动到底自动加载下一页 |

状态文案示例：

| 场景 | 空态文案 | 错误文案 |
|---|---|---|
| 消息中心 | 还没有会话，点击"发起会话"开始沟通 | 消息加载失败，请重试（错误码 2001001） |
| 文档列表 | 暂无文档，创建或从模板开始 | 文档加载失败，请检查网络（2002001） |
| 会议室 | 该楼宇暂无可用会议室 | 会议室信息加载失败（2006001） |
| 审批中心 | 暂无待办，休息一下 | 审批数据加载失败（2007001） |
| OKR | 本周期还没有目标 | OKR 数据加载失败（2005001） |
| ONA | 数据不足，暂无法生成协作网络 | ONA 样本不足（2009001） |

## 8. 可访问性

### 8.1 对比度与色彩

- 文本与背景对比度 ≥ 4.5:1；大号文本（≥18px 或 14px 加粗）≥ 3:1。
- 禁止仅以颜色传达信息，状态须辅以图标或文字（如会议室占用=红色 + "占用"文字）。

### 8.2 键盘与焦点

- 全部交互元素可通过 Tab 到达，Tab 顺序符合视觉顺序。
- 焦点样式：2px 主色描边 + 2px 偏移，禁止 `outline:none` 且不提供替代。
- 快捷键：见《用户操作手册》第 6 章；支持 `Esc` 关闭弹窗/抽屉。

### 8.3 语义化与辅助技术

- 使用语义标签（`nav`/`main`/`header`/`button`），表单控件关联 `label`。
- 图标按钮提供 `aria-label`；动态消息区域使用 `aria-live="polite"`。
- 支持屏幕阅读器对消息列表、审批流程的朗读。

### 8.4 国际化

- 全部文案外置（i18n），默认 `zh-CN`，预留 `en-US`。
- 日期/时间/数字按 `Accept-Language` 本地化；时间显示用户本地时区（存储 UTC）。

### 8.5 无鼠标/触屏兼容

- 支持触屏手势：IM 长按引用/撤回、左滑删除；日历双指缩放切换视图。
- 双击/双指缩放禁用页面缩放限制，允许用户放大（最大 200% 不破版）。

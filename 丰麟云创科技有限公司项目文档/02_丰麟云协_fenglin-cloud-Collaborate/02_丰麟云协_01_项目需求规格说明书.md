## 1. 引言

### 1.1 编写目的

本文档定义丰麟云协（Fenglin Cloud Collaborate）的完整需求基准，作为架构设计、数据库设计、模块详细设计、接口开发、测试验收与交付评审的统一依据。读者对象为产品经理、架构师、研发工程师、测试工程师、实施交付与安全合规人员。

### 1.2 项目范围

| 项目 | 内容 |
|---|---|
| 产品中文名 | 丰麟云协 |
| 产品英文名 | Fenglin Cloud Collaborate |
| 业务域 | 域B：协作与办公 |
| 产品定位 | 智能协作与组织网络平台 |
| 品牌口号 | 让协作有温度，让组织有网络 |
| 域名 | `collab.fenglincloud.com` |
| API 前缀 | `/api/collab/v1` |
| 命名空间 | `fenglin-collab` |
| 服务名 | `fenglin-collab-service` |
| Java 包名 | `com.fenglin.collab` |
| 数据库 | `fenglin_collab`（表前缀 `collab_`） |
| 前端路由 | `/app/collab`（用户端）、`/admin/collab`（管理端） |
| 错误码域前缀 | `20`（如 `2000001`） |
| 交付形态 | SaaS 多租户 + 管理端/用户端分离 + 私有化混合部署 |

本产品**覆盖 2 个业务模块**：

- **B1 内部协作与办公**：借鉴飞书设计理念，包含即时通讯（IM）、在线文档、日历、会议、OKR 协同、审批、工作台七大能力族。
- **B2 会议效率与协同网络分析（ONA）**：参考阔知·组织网络分析，包含会议效率度量与组织网络分析（Organization Network Analysis）能力族。

本项目**不包含**：视频会议的底层音视频编解码引擎自研（复用中台 `fenglin-message-service` 与第三方 RTC 网关）、企业级知识检索与 AI 问答（归属云智 H1/H2，通过云智能力嵌入模式调用）。

## 2. 产品概述

### 2.1 产品定位

丰麟云协面向中大型企业（含丰麟云创自身 3400 人规模集团），以"协作有温度、组织有网络"为设计主张，构建"沟通—协作—会议—目标—流程—度量"的一体化数字协作空间，并通过 ONA 将显性的协作行为沉淀为可度量的组织网络资产，支撑组织效能诊断、跨部门协同优化与关键人识别。

### 2.2 用户角色

| 角色 | 端 | 说明 | 权限域 |
|---|---|---|---|
| 平台超级管理员 | 管理端 | 平台级最高权限，运维专用，强审计 | `platform:*` |
| 平台运维 | 管理端 | 租户/套餐/监控/灰度 | `platform:*` |
| 租户管理员 | 管理端 | 本租户协作域配置、组织、角色、权限 | `tenant:collab:*` |
| 协作业务管理员 | 管理端 | 审批模板、会议室、文档策略、ONA 度量口径配置 | `tenant:collab:*` |
| 部门协作管理员 | 管理端 | 本部门会话/日历/会议室/OKR 管理 | `tenant:collab:dept` |
| 业务用户 | 用户端 | 员工日常沟通、文档、日历、会议、OKR、审批 | `biz:collab:*` |
| 只读/访客 | 用户端 | 受限查看（如会议室空闲、公共日历） | `biz:collab:read` |

### 2.3 双端能力归位

| 能力 | 管理端（ADMIN） | 用户端（PORTAL） |
|---|---|---|
| IM | 会话审计、敏感词策略、群组治理 | 收发消息、建群、文件共享 |
| 文档 | 文档策略、模板库、密级与水印规则 | 创建/协同编辑/评论/分享 |
| 日历 | 公共日历、假期规则、日程审计 | 个人/团队日程、预约、忙闲查询 |
| 会议 | 会议室资源、会议策略、纪要归档规则 | 发起会议、预定会议室、查看纪要 |
| OKR | OKR 周期、对齐规则、度量口径 | 制定目标、对齐、更新进度 |
| 审批 | 模板与流程设计、审批授权、代办配置 | 发起审批、审批处理、查看进度 |
| 工作台 | 组件上架、租户级布局模板 | 个性化工作台、待办聚合 |
| ONA | 度量模型、指标口径、快照策略、隐私边界 | 查看本人协作画像、部门网络视图（受权限） |

## 3. 业务需求

需求编号规则：`FR-B{模块}-{三位序号}`。优先级：P0（必须）/P1（重要）/P2（期望）。

### 3.1 B1 内部协作与办公

#### 3.1.1 IM 即时通讯

| 编号 | 需求名称 | 需求描述 | 优先级 |
|---|---|---|---|
| FR-B1-001 | 会话创建与管理 | 支持单聊、群聊（≤2000 人）、话题群三种会话形态；支持会话置顶、免打扰、归档、退出、解散；群主可管理群公告与成员。 | P0 |
| FR-B1-002 | 消息收发与类型 | 支持文本、富文本、图片、文件、语音条、视频、卡片（审批/日程/文档）、@提及；消息支持引用回复、转发、撤回（24h 内）。 | P0 |
| FR-B1-003 | 消息已读与回执 | 单聊与群聊支持已读/未读状态；群聊支持"已读人数"查看（仅群主/管理员）；支持消息免打扰下的红点策略。 | P0 |
| FR-B1-004 | 消息搜索与定位 | 支持按关键词、发送人、时间范围、消息类型检索会话内消息；命中消息可在会话内跳转定位。 | P1 |
| FR-B1-005 | 表情回复与快捷互动 | 消息支持表情回复（Reaction）、快捷回复；支持收藏消息至个人收藏夹。 | P2 |
| FR-B1-006 | 会话内文件与文档协同 | 会话内可直接发送/接收文件，支持将文件一键转为协同文档并生成共享链接；文件继承会话成员可见范围。 | P1 |
| FR-B1-007 | 消息安全与合规 | 消息体敏感字段（如外部联系人手机号）加密存储；支持敏感词拦截策略（管理端配置）；消息撤回/删除留审计痕迹。 | P0 |
| FR-B1-008 | 消息推送与多端同步 | 支持 Web、移动端（PWA）多端在线同步；离线消息可靠投递（至少一次 + 客户端去重）；支持外部渠道（企微/飞书/钉钉）消息转发。 | P0 |

#### 3.1.2 协同文档

|---|---|---|---|

| FR-B1-011 | 文档权限与分享 | 支持文档级权限（可阅读/可评论/可编辑/可管理）；支持按成员、按部门授权；支持分享链接（可设有效期与访问码）；权限继承组织与租户边界。 | P0 |
| FR-B1-012 | 评论与批注 | 支持行内评论、@提及、评论解决/重开；变更历史可对比；支持订阅文档变更通知。 | P1 |
| FR-B1-013 | 文档密级与水印 | 支持文档密级（公开/内部/机密）与动态水印（含查看人姓名+工号+时间）；机密文档禁止外链分享与下载（管理端策略）。 | P0 |

| FR-B1-015 | 文档嵌入与引用 | 文档可嵌入日程、审批实例、OKR、会议纪要卡片；支持双向链接（Backlink）。 | P2 |

### 3.2 B2 会议效率与协同网络分析（ONA）

| 编号 | 需求名称 | 需求描述 | 优先级 |
|---|---|---|---|
| FR-B2-001 | 会议效率度量模型 | 基于会议时长、参会人数、有效发言、决策达成率、会后行动项完成率构建会议效率评分模型，口径可在管理端配置。 | P0 |
| FR-B2-002 | 会议成本核算 | 按参会人时薪系数×时长×人数估算会议人力成本；支持部门/团队维度汇总。 | P1 |
| FR-B2-003 | 会议健康度预警 | 对"高频低效会议""无议程会议""超员会议"进行识别与预警，推送改进建议。 | P1 |
| FR-B2-004 | 协作关系图谱构建 | 基于 IM 会话、文档协作、会议共现、审批流转、OKR 对齐等行为构建组织协作关系图谱（节点=员工/部门，边=协作强度）。 | P0 |
| FR-B2-005 | ONA 核心指标计算 | 计算网络密度、度中心度、中介中心度、接近中心度、结构洞、集群系数、跨部门连接度等指标。 | P0 |
| FR-B2-006 | 关键人识别与断点分析 | 识别高中心度关键连接人（Key Connector）与协作断点（Broker/Silo）；输出组织孤岛与潜在瓶颈。 | P0 |
| FR-B2-007 | 部门协作网络视图 | 提供部门级协作网络可视化（桑基图/力导向图/矩阵热力图），支持下钻到个人（受数据权限）。 | P1 |
| FR-B2-008 | ONA 快照与趋势 | 按周期（周/月/季）生成 ONA 快照，支持网络指标趋势对比与异动检测。 | P1 |
| FR-B2-009 | 组织效能洞察报告 | 生成周期性组织协作洞察报告（自动 PDF/在线），覆盖协作活跃度、跨部门协同、会议效率、风险提示。 | P2 |
| FR-B2-010 | ONA 隐私与合规边界 | ONA 分析仅基于聚合与结构化行为指标，禁止输出消息内容；个人画像默认仅本人可见；管理端配置可见范围与匿名阈值（部门人数 < 阈值不出图）。 | P0 |

## 6. 接口需求

### 6.1 接口总则

- 遵循 FL-HUB-STD-001 第 5 章；API 前缀 `/api/collab/v1`。
- 统一响应体、错误码域前缀 `20`。
- 强制请求头 `Authorization`、`X-Tenant-Id`、`X-Client-Type`（`ADMIN`/`PORTAL`）。
- 写操作支持 `Idempotency-Key`；审批、会议室预定、红包类强幂等。

### 6.2 接口域规划（详见《接口文档》）

| 域 | 前缀 | 代表接口 |
|---|---|---|
| IM | `/api/collab/v1/im/**` | 会话、消息、已读、反应 |
| 文档 | `/api/collab/v1/docs/**` | 文档 CRUD、协同、评论、版本 |
| 日历 | `/api/collab/v1/calendars/**`、`/events/**` | 日历、日程、忙闲 |
| 会议 | `/api/collab/v1/meetings/**`、`/meeting-rooms/**` | 会议、会议室、纪要 |
| OKR | `/api/collab/v1/okr/**` | 目标、KR、对齐、进展 |
| 审批 | `/api/collab/v1/approvals/**` | 模板、实例、任务 |
| 工作台 | `/api/collab/v1/workbench/**` | 组件、布局、待办 |
| ONA | `/api/collab/v1/ona/**` | 图谱、指标、快照 |
| 实时 | `/ws/collab/v1` | WebSocket 消息与协同信令 |
| 开放 | `/openapi/collab/v1/**` | 开放 API 与事件订阅 |

### 6.3 实时通信需求

- WebSocket 通道承担：IM 消息推送、已读回执、在线状态、文档协同操作广播、会议状态、通知推送。
- 连接鉴权：握手阶段校验 JWT 与租户一致性；心跳 30s；断线重连补齐消息（基于游标）。

### 6.4 事件与 Webhook

| 事件 | 触发 | 载荷要点 |

| `collab.document.updated` | 文档保存 | docId、version、editorId |
| `collab.meeting.created` | 会议创建 | meetingId、roomId、startTime |
| `collab.approval.completed` | 审批完成 | instanceId、result |
| `collab.ona.snapshot.generated` | ONA 快照生成 | snapshotId、period |

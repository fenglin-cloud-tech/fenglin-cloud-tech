## 1. 管理端总览

管理端访问地址：`https://finance.fenglincloud.com/admin/finance`，采用左侧菜单 + 顶部面包屑 + 信息密集型布局（Element Plus），权限域 `platform:*`、`tenant:*`。

| 一级菜单 | 二级能力 |
|---|---|
| 财务运营 | 运营总览、待办审批、监控 |
| 总账核算 | 账套、会计期间、科目、凭证工作台、账簿与报表 |
| 往来与资金 | 应收应付、收付款、核销、发票、银企对账 |
| 费用与预算 | 报销审批、预算管理 |
| 项目交付 | 项目管理、成本归集、人力费率、盈利分析 |
| 资产管理 | 资产类别、台账、折旧、处置、盘点、IT 资产 |
| ESG 与双碳 | 排放因子、碳核算、双碳目标、ESG 报告 |
| 系统设置 | 权限与规则、审批流、集成、参数与字典 |

管理端专有能力：**配置、授权、审核、报表定义、租户治理**（用户端不提供）。

## 2. 租户 / 组织 / 用户 / 角色

### 2.1 租户管理（平台运维）

- 租户开通、套餐与配额（用户数、存储、接口调用量）。
- 隔离策略：SaaS 共享库 + `tenant_id` + RLS；高合规客户可选独立库。
- 查看租户用量与配额告警；配额不足返回 `0000101`。

### 2.2 账套与组织

- 账套（多法人主体）创建：编码、本位币、会计年度起始月、会计准则（CAS/小企业）。
- 组织/部门来自平台组织主数据（IAM/云才），支持按部门配置数据权限与资产归属。

### 2.3 用户与角色

- 用户来源统一 IAM；支持离职联动（回收权限、资产回收提醒）。
- 角色基线（继承平台）：

| 角色 | 端 | 说明 |
|---|---|---|
| 平台超级管理员 | 管理端 | 平台级最高权限（运维专用、强审计） |
| 平台运维 | 管理端 | 租户/套餐/监控/灰度 |
| 租户管理员 | 管理端 | 本租户配置、组织、角色、权限 |
| 财务管理员 | 管理端 | 账套/科目/预算/报表定义、审批 |
| 财务主管/会计 | 管理端 | 凭证审核/过账、报表出具 |
| 出纳 | 管理端 | 收付款、银行对账 |
| 资产管理员 | 管理端 | 资产全生命周期 |
| ESG 负责人 | 管理端 | 因子/核算/目标/报告 |
| 业务用户（员工/PM） | 用户端 | 报销/工时/资产/碳填报 |

## 3. 权限与数据权限配置

### 3.1 功能权限

- 权限码规则 `{域}:{模块}:{操作}`，如 `tenant:finance:voucher:post`、`biz:finance:expense:apply`。
- 按角色分配权限码；菜单/按钮/接口三级一致。
- 三权分离：制单、审核、过账分别授权，禁止同一角色同时持制单与审核。

### 3.2 数据权限

| 数据范围 | 适用 |
|---|---|
| 本人 | 员工（我的报销/我的工时） |
| 本部门 | 部门资产负责人 |
| 本部门及下级 | 部门审批人 |
| 指定部门 | 跨部门财务 |
| 全部 | 财务主管/管理员 |

配置方式：角色绑定 `data_scope`，叠加 RLS 与 SQL 拦截器；字段权限控制敏感字段（银行卡号/身份证）隐藏或脱敏。

### 3.3 端别配置

- 后端依据令牌 `client_type`（`ADMIN`/`PORTAL`）执行路由与鉴权；越端调用返回 `0000002`。
- 管理员可为用户端用户分配 `biz:*` 权限，为管理端用户分配 `tenant:*`/`platform:*` 权限。

## 4. 参数与字典

| 类别 | 参数示例 | 说明 |
|---|---|---|
| 币种与汇率 | 本位币、汇率录入（日/月/期末） | 多币种折算 |
| 会计科目模板 | 内置企业会计准则科目 | 一键初始化科目 |
| 凭证模板 | 业务类型→借贷科目映射 | 业财一体规则 |
| 预算控制 | 强控/弱控、预警阈值（80/90/100%） | 预算策略 |
| 折旧政策 | 方法、年限、残值率 | 资产类别默认 |
| 坏账政策 | 账龄分段计提比例 | 应收 |
| 幂等参数 | TTL=24h | 幂等键有效期 |
| 金额精度 | 4 位小数（固定） | 不可更改 |
| 排放因子 | 来源、版本、区域 | 碳核算 |
| 碳核算标准 | GHG Protocol / ISO 14064 | 口径 |
| 数据字典 | 状态、类型枚举 | 统一维护 |

参数变更均留审计；金额精度为**强制固定值**，管理员不可修改。

## 5. 流程与审批配置

管理端通过平台 `fenglin-workflow-service`（Flowable 7，BPMN 2.0）配置以下流程：

| 流程 Key | 场景 | 关键节点 |
|---|---|---|
| `fin-d1-voucher-approval` | 凭证审批 | 提交→（>50万）第二审核→过账→哈希链 |
| `fin-d1-expense-claim` | 费用报销 | 提交（预算占用）→主管→（>1万）部门负责人→财务→付款 |
| `fin-d1-period-close` | 期末结账 | 发起→校验→损益结转→快照 |
| `fin-d2-project-approval` | 项目立项 | 提交→部门→（>100万）经营会审→财务 |
| `fin-d2-timesheet-approval` | 工时审批 | 提交→PM→计入成本 |
| `fin-d2-project-settlement` | 项目结算 | 发起→部门→财务→生成应收/开票 |
| `fin-d3-asset-disposal` | 资产处置 | 发起→资产部门→（>50万）财务经理→处置 |
| `fin-d3-asset-stocktaking` | 资产盘点 | 发起→执行→复核→盘盈亏审批→账务 |
| `fin-d4-carbon-verification` | 碳数据核证 | 填报→校验→复核→核算 |
| `fin-d4-esg-report` | ESG 报告 | 创建→汇总→复核→发布冻结 |

配置要点：金额阈值、审批层级、会签/或签、超时提醒（消息推送）、代理人设置。

## 6. 集成与开放平台

### 6.1 内部集成

| 来源 | 集成内容 | 方式 |
|---|---|---|
| 云销 | 合同、回款 | Kafka 事件 |
| 云法 | 合同、签章 | 开放 API/事件 |
| 云才/枢 | 员工、组织、主数据 | 开放 API |
| 中台 | IAM、租户、工作流、消息、文件、审计、报表 | 内部契约 |

### 6.2 业务事件

| 事件 | 说明 |
|---|---|
| `finance.voucher.posted` | 凭证过账 |
| `finance.receivable.created` | 应收生成 |
| `finance.expense.approved` | 报销审批 |
| `finance.project.settled` | 项目结算 |
| `finance.depreciation.completed` | 折旧完成 |
| `finance.carbon.calculated` | 碳核算完成 |
| `finance.budget.overrun` | 预算超支 |

### 6.3 开放平台

- 开发者门户：应用注册、AppKey/AppSecret、API 目录、沙箱调试、SDK。
- 前缀 `/openapi/finance/v1`；HMAC-SHA256 签名 + OAuth2.1。
- 配额按应用/接口 QPS，超限返回 `0000006`；Webhook 支持签名验签 + 重试 + 幂等。

## 7. 监控与审计

### 7.1 监控

- 财务运营总览看板：收入/成本、应收账龄、现金余额、待办。
- 系统监控：QPS/RT/错误率、结账与折旧任务、队列延迟、DB 慢查询（详见部署运维手册 §7）。

### 7.2 审计

- 全链路操作审计（谁、何时、何操作、何结果），留存 ≥6 个月（审计日志 12 个月）。
- 凭证审计链：`GET /vouchers/{id}/audit-trail` 查看 CREATE→…→POSTED 链，校验哈希连续性。
- 结账快照与哈希链防篡改；WORM 存储。
- 审计查询入口：系统设置 → 审计日志；支持按人/时间/操作/单据检索与导出。

### 7.3 关键合规巡检（管理员视角）

| 巡检项 | 频率 |
|---|---|
| 凭证哈希链校验 | 每日 |
| 未过账凭证/异常凭证 | 每日 |
| 预算超支与到期应付 | 每日 |
| 权限复核（离职/闲置） | 每月 |
| 审计日志留存与完整性 | 每月 |
| 折旧/结账批次成功 | 每月 |

## 8. 备份与安全运维

- 备份：每日全备 + 增量 + 异地；季度恢复演练（详见部署运维手册 §8）。
- 安全：TLS1.3、mTLS、PII 加密、KMS 轮换 ≤90 天、等保三级控制项（详见安全评估报告）。
- 生产禁手工改库；变更走工单审批并留痕。
- 三员分立：系统管理员/安全管理员/审计员职责隔离；平台超管跨租户查询强审计。

## 9. 故障处理

| 现象 | 排查 | 处理 |
|---|---|---|
| 凭证无法过账 | 检查状态、权限、期间是否封账 | 状态/权限/期间修正后重试 |
| 结账失败 | 查看校验清单（未过账/试算/折旧/核销） | 按清单处理→断点续跑 |
| 折旧批次失败 | 查看批次日志、费率/凭证模板 | 修复后幂等重跑 |
| 对账差额≠0 | 检查未达账项与流水重复 | 补录/去重后重对 |
| 报销卡在审批 | 检查审批人缺失/离职 | 指派代理人或改派 |
| 碳核算报未复核 | 检查活动状态 | 复核通过后核算 |
| 报表数据异常 | 检查期间/科目/过滤 | 修正后重算 |
| 接口 403 越权 | 检查端别与权限码 | 调整权限分配 |
| 接口 429 限流 | 检查调用量 | 调整配额/扩容 |
| 登录失败锁定 | 检查失败次数 | 等待解锁或管理员重置 |

故障上报与升级：一级（业务阻塞）立即上报并启动应急；二级（局部异常）4 小时内处理；所有故障记录归档并复盘。

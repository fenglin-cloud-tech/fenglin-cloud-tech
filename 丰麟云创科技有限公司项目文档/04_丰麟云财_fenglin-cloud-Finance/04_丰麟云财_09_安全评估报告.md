### 2.1 财务数据专项控制（强化项）

| 控制点 | 措施 | 验证 |
|---|---|---|
| 凭证不可篡改 | 过账后写 `fin_voucher_audit_log` 哈希链（`record_hash` + `prev_hash` + HMAC 签名）；同步 WORM | 篡改任一节点，链式校验失败；已通过校验 |
| 防重复记账 | 金额/库存/审批类写操作强制 `Idempotency-Key`（24h）；`fin_idempotency_record` 表 | 重复提交仅 1 条记录 |
| 结账不可逆篡改 | `fin_period_close_snapshot` 记录结账快照 + 哈希链；封账后禁止记账 | 封账后记账被拒 |
| 金额精度 | 全字段 `numeric(20,4)`；接口字符串传输；禁止浮点；静态扫描 | 精度用例全通过 |
| 职责分离 | 制单人≠审核人；过账独立权限；三员分立 | 自审被拒用例通过 |
| 审计留存 | 凭证/审计日志 ≥12 个月；操作审计 ≥6 个月 | 保留策略核查 |

## 3. 威胁建模（STRIDE）

| 类别 | 威胁场景 | 现有控制 | 风险等级 | 处置 |
|---|---|---|---|---|
| **S**poofing 仿冒 | 伪造令牌调用财务接口 | JWT RS256 + 网关校验 + `X-Tenant-Id` 一致性 + mTLS | 中 | 已缓解 |
| **T**ampering 篡改 | 篡改已过账凭证/折旧明细 | 哈希链 + WORM + 乐观锁 + 审计 | 中 | 已缓解 |
| **R**epudiation 抵赖 | 否认发起过某付款 | 全链路审计 + 操作人快照 + 时间戳 | 低 | 已缓解 |
| **I**nformation Disclosure 信息泄露 | PII/银行账号泄露 | AES-256-GCM + 脱敏 + 字段权限 + TDE | 中 | 已缓解 |
| **D**enial of Service 拒绝服务 | 报表/结账接口被打爆 | Sentinel 限流熔断 + WAF + HPA + 异步化 | 中 | 已缓解 |
| **E**levation of Privilege 提权 | 用户端越权访问管理端接口 | `client_type` 端别校验 + 权限码 + 数据权限 | 中 | 已缓解 |

### 3.1 关键攻击路径与阻断

```
攻击者 → 伪造令牌 → 网关校验失败(401) ✗
攻击者 → 用户端令牌调管理端接口 → 端别白名单拦截(403) ✗
内部人员 → 篡改已过账凭证 → 哈希链不匹配 + 数据库只读约束 ✗
内部人员 → 重复提交付款 → 幂等键命中，返回首次结果 ✗
外部 → 高频刷报表接口 → Sentinel 限流(429) ✗
```

## 4. 漏洞与风险

| 编号 | 漏洞/风险 | 等级 | 状态 |
|---|---|---|---|
| V-01 | 报表导出接口存在同步阻塞，可能被用于慢速 DoS | 中 | 已修复（改异步 + 限流） |
| V-02 | 早期银行流水导入未做文件类型白名单 | 中 | 已修复（类型/大小/病毒扫描） |
| V-03 | 部分查询接口缺少 `size` 上限校验 | 低 | 已修复（≤200） |
| V-04 | 依赖库存在 2 个中危 CVE | 中 | 已升级 |
| V-05 | 附件下载缺少水印与防扩散钩子 | 低 | 已接入文件服务水印 |
| V-06 | 错误信息在异常时可能回显堆栈 | 低 | 已统一异常处理，屏蔽堆栈 |

渗透测试结果：未发现高危漏洞；中危 4 项（均已修复并复测通过）；低危 2 项（已修复）。

## 5. 加固措施

| 类别 | 措施 |
|---|---|
| 传输 | 强制 TLS1.3，禁用弱套件；内部 mTLS |
| 存储 | PII AES-256-GCM + `{field}_hash`；DB TDE；备份加密 |
| 密钥 | KMS 托管 + ≤90 天轮换 + 历史密钥保留 |
| 认证 | MFA + SSO + 会话超时 + 失败锁定 + 令牌短有效期 |
| 授权 | 权限码三级 + 数据权限 + 字段权限 + 端别隔离 |
| 审计 | 全链路审计 + 哈希链 + WORM + 12 个月留存 |
| 应用 | 输入校验 + 参数化 SQL（MyBatis-Plus）+ 输出编码 + CSP |
| 依赖 | SCA 扫描 + 镜像扫描 + 及时升级 |
| 运维 | 最小权限账号 + 堡垒机 + 变更审计 + 生产禁手工改库 |
| 财务专项 | 幂等强制 + 金额精度 + 职责分离 + 结账快照 + 冲销留痕 |

## 6. 合规结论

**综合结论：丰麟云财通过等保三级安全评估，满足上线安全要求。**

## 7. 残余风险

| 编号 | 残余风险 | 说明 | 缓解与监控 |
|---|---|---|---|
| RR-01 | 内部高权限账号（平台超管 BYPASSRLS）滥用 | 跨租户查询能力 | 强制审计 + 双人复核 + 定期权限复核 |
| RR-02 | 结账 `force` 强制结账被误用 | 绕过部分校验 | 仅平台超管 + 二次确认 + 告警 |
| RR-03 | 第三方（银企直联/CMDB）接口不可用 | 影响对账/同步 | 降级 + 补偿重试 + 监控告警 |
| RR-04 | 零日漏洞 | 未知威胁 | 持续 SCA + WAF 规则更新 + 应急响应 |
| RR-05 | 密钥轮换期短暂不可用 | 轮换窗口 | 双密钥并行 + 灰度轮换 |

残余风险整体处于**可接受**水平，纳入常态化监控与季报复审。

## 1. 通用约定

- 协议：HTTPS（TLS 1.2+，推荐 1.3）；内部服务间 mTLS。
- 前缀：`/api/finance/v1`（开放 API 为 `/openapi/finance/v1`）。
- 数据格式：`application/json; charset=UTF-8`；文件上传 `multipart/form-data`。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1）、`size`（默认 20，最大 200）。
- 追踪：`X-Request-Id`、`X-Trace-Id`。
- 统一响应体：

```json
{ "code": "0", "message": "success", "data": {}, "requestId": "b1f2c3d4-...", "timestamp": "2026-10-19T08:00:00.000+08:00" }
```

- 分页响应 `data` 结构：`{ "records": [], "total": 0, "page": 1, "size": 20 }`。
- **金额约定**：所有金额字段为 `decimal`（数据库 `numeric(20,4)`），JSON 中以**字符串**传输（避免前端精度丢失），并伴生 `currencyCode`（ISO-4217）。示例：`"amount": "1234567.8900", "currencyCode": "CNY"`。

### 1.1 幂等约定

- 写操作支持请求头 `Idempotency-Key`（24h 有效）。
- **强制幂等**接口：凭证、收付款、报销付款、折旧、盘点结果、项目结算、碳核算。
- 同键重复请求：返回首次结果（业务 `code=0`），不重复执行；并发同键返回 `0000005`。

### 1.2 限流约定

- 默认按租户+接口维度限流，超限返回 HTTP 429 + `0000006`。
- 各接口限流阈值见定义表。

## 2. 鉴权与端别

| 请求头 | 必填 | 说明 |
|---|---|---|
| `Authorization` | 是 | `Bearer {access_token}`（JWT RS256） |
| `X-Tenant-Id` | 是 | 租户标识（与令牌一致，不一致拒绝） |
| `X-Client-Type` | 是 | `ADMIN` / `PORTAL`，须与令牌 `client_type` 一致 |
| `X-Request-Id` | 否 | 追踪/幂等参考 |
| `Idempotency-Key` | 否 | 写操作幂等键 |
| `Accept-Language` | 否 | `zh-CN` / `en-US` |

端别规则：接口标注端别，网关按 `client_type` 白名单放行；越端调用返回 `0000002`（403）。功能权限以权限码校验，数据权限按 `data_scope` 叠加。

## 4. 逐接口定义（D1）

### I-01 查询会计科目树

| 项 | 值 |
|---|---|
| 方法/路径 | `GET /api/finance/v1/accounting-subjects` |
| 端别 | ADMIN |
| 鉴权 | 是，权限码 `tenant:finance:subject:view` |
| 限流 | 100 QPS/租户 |
| 幂等 | 只读 |

请求参数（query）：`ledgerId`(long,必填)、`keyword`(string,选填)、`category`(string,选填)、`status`(string,选填)。

响应：

```json
{ "code":"0","message":"success","data":{ "records":[
  {"subjectCode":"1001","subjectName":"库存现金","parentId":0,"subjectLevel":1,"category":"ASSET","balanceDirection":"DEBIT","isLeaf":true,"auxiliaryTypes":[]}
], "total":1,"page":1,"size":20 },"requestId":"...","timestamp":"2026-10-19T08:00:00.000+08:00" }
```

错误码：`0000001`、`0000002`、`4001001`。

### I-02 新增会计科目

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/finance/v1/accounting-subjects` |
| 端别 | ADMIN ；鉴权 `tenant:finance:subject:manage` ；幂等 是（`Idempotency-Key`）；限流 20 QPS/租户 |

请求体：

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| ledgerId | long | 是 | 账套 |
| subjectCode | string | 是 | ≤32，租户内唯一 |
| subjectName | string | 是 | ≤128 |
| parentId | long | 否 | 0 为顶级 |
| category | string | 是 | ASSET/LIABILITY/EQUITY/COST/PROFIT_LOSS |
| balanceDirection | string | 是 | DEBIT/CREDIT |
| auxiliaryTypes | array | 否 | 枚举：dept/project/customer/supplier/employee/asset/cashflow |

错误码：`0000003`、`4001002`（科目编码重复）、`4001006`（父科目不可用）。

### I-03 查询会计期间

`GET /api/finance/v1/accounting-periods` — ADMIN；`tenant:finance:period:view`；query：`ledgerId`(必填)、`year`。返回期间列表含 `periodCode`、`status`。错误码：`0000001`、`0000002`。

### I-04 期末结账

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/finance/v1/accounting-periods/{id}/close` |
| 端别 | ADMIN ；鉴权 `tenant:finance:period:close` ；**幂等 是**（强制） ；限流 2 QPS/租户 ；端别 高权限 |

请求体：`{ "force": false, "remark": "2026-01 月结" }`。

校验：期间内凭证全部过账、试算平衡、折旧已计提、往来已核销；`force=true` 仅平台超管可用且强审计。

响应：`{ "periodCode":"2026-01","status":"CLOSED","closedAt":"...","snapshotHash":"a1b2..." }`

错误码：`4001007`（试算不平衡）、`4001008`（存在未过账凭证）、`4000005`（并发结账）。

### I-05 反结账

`POST /api/finance/v1/accounting-periods/{id}/reopen` — ADMIN；`tenant:finance:period:reopen`；幂等 是；限流 2 QPS。请求体 `{ "reason":"..." }`。错误码：`4001004`（已封账需审批）、`4001009`。

### I-06 创建凭证

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/finance/v1/vouchers` |
| 端别 | ADMIN ；鉴权 `tenant:finance:voucher:create` ；**幂等 是（强制）** ；限流 50 QPS/租户 |

请求体：

```json
{
  "ledgerId": 1001, "voucherWord": "记", "voucherDate": "2026-10-15",
  "periodCode": "2026-10", "summary": "项目结算确认收入",
  "currencyCode": "CNY",
  "entries": [
    { "lineNo":1, "summary":"应收-A客户", "subjectCode":"1122", "direction":"DEBIT",  "amount":"113200.0000", "exchangeRate":"1.00000000" },
    { "lineNo":2, "summary":"主营收入",   "subjectCode":"6001", "direction":"CREDIT", "amount":"106792.4528", "exchangeRate":"1.00000000" },
    { "lineNo":3, "summary":"销项税额",   "subjectCode":"2221", "direction":"CREDIT", "amount":"6407.5472",  "exchangeRate":"1.00000000" }
  ]
}
```

校验：分录 ≥2；借贷合计相等（容差 0，`numeric(20,4)`）；金额 > 0；期间未封账。
响应：`{ "id": 900001, "voucherNo":"记-2026-10-0001", "status":"DRAFT", "totalDebit":"113200.0000", "totalCredit":"113200.0000" }`
错误码：`4000003`（借贷不平衡）、`4001004`（期间已封账）、`4000005`。

### I-07 查询凭证

`GET /api/finance/v1/vouchers` — ADMIN；`tenant:finance:voucher:view`；query：`ledgerId`(必填)、`periodCode`、`status`、`voucherNo`、`subjectCode`、`amountMin`、`amountMax`、分页。金额以字符串返回。错误码：`0000001`、`0000002`。

### I-08 凭证详情

`GET /api/finance/v1/vouchers/{id}` — ADMIN；返回凭证头 + 分录 + 附件数 + 来源。错误码：`4000002`（凭证不存在）。

### I-09 修改凭证

`PUT /api/finance/v1/vouchers/{id}` — ADMIN；`tenant:finance:voucher:create`；幂等 是；仅 `DRAFT`/`REJECTED` 可改，`version` 乐观锁。错误码：`4000004`（已过账不可修改）、`0000005`。

### I-10 提交凭证

`POST /api/finance/v1/vouchers/{id}/submit` — ADMIN；`tenant:finance:voucher:create`；幂等 是；置 `SUBMITTED` 并启动 `fin-d1-voucher-approval`。错误码：`4000005`、`4001004`。

### I-11 审核凭证

| 项 | 值 |
|---|---|
| 方法/路径 | `POST /api/finance/v1/vouchers/{id}/audit` |
| 端别 | ADMIN ；鉴权 `tenant:finance:voucher:audit` ；**幂等 是** ；限流 50 QPS |

## 8. 开放 API

- 前缀：`/openapi/finance/v1`，由 `fenglin-openapi-service` 统一管理。
- 认证：AppKey/AppSecret + HMAC-SHA256 签名（`X-Ca-Key`、`X-Ca-Signature`、`X-Ca-Timestamp`），或 OAuth2.1 授权码。
- 配额：按应用/接口维度配置 QPS，超限返回 `0000006`。
- 开放资源（只读为主 + 受限写）：

| 资源 | 方法 | 路径 | 说明 |
|---|---|---|---|
| 凭证 | GET | `/openapi/finance/v1/vouchers` | 查询已过账凭证 |
| 应收 | GET | `/openapi/finance/v1/receivables` | 查询应收 |
| 项目成本 | GET | `/openapi/finance/v1/projects/{id}/cost-summary` | 项目成本汇总 |
| 资产台账 | GET | `/openapi/finance/v1/asset-cards` | 资产台账 |
| 碳排放 | GET | `/openapi/finance/v1/carbon-emissions` | 碳排结果 |
| 报销 | POST | `/openapi/finance/v1/expense-claims` | 代录报销（受限，需白名单） |

- SDK：Java / JS / Python；沙箱环境 `sandbox-finance.fenglincloud.com`。

## 9. 事件与 Webhook

### 9.1 事件主题（Kafka）

| 事件 | Topic | 触发时机 | 载荷要点 |
|---|---|---|---|
| 凭证已过账 | `finance.voucher.posted` | 凭证过账后 | voucherId, voucherNo, periodCode, totalDebit, totalCredit, chainHash |
| 应收已生成 | `finance.receivable.created` | 结算/销售生成应收 | arNo, customerId, amount, currencyCode |
| 报销已审批 | `finance.expense.approved` | 报销终审通过 | claimNo, applicantId, totalAmount |
| 项目已结算 | `finance.project.settled` | 项目结算审批通过 | projectNo, settlementNo, amount |
| 折旧已完成 | `finance.depreciation.completed` | 批量折旧完成 | periodCode, assetCount, totalDepreciation |
| 碳核算已完成 | `finance.carbon.calculated` | 碳核算批次完成 | periodCode, scope, emissionTotal |
| 预算已超支 | `finance.budget.overrun` | 预算触达阈值 | budgetId, alertLevel |

### 9.2 Webhook 约定

- 订阅方配置回调 URL，事件以 JSON POST 推送。
- 签名：请求头 `X-Fin-Signature` = HMAC-SHA256(body, secret)。
- 重试：指数退避 5 次（1s/5s/30s/5m/30m）；幂等：请求头 `X-Fin-Event-Id`（消费方按此去重）。
- 验签失败返回 401 并计入失败统计。

## 11. 版本与兼容

- 版本以 URL 段 `/v1` 标识；不兼容变更升 `/v2`，旧版本至少保留 12 个月。
- 兼容性变更（新增可选字段/新接口）在 `v1` 内平滑发布，并在本文件与变更公告登记。
- 废弃流程：标注 `Deprecated` → 双写过渡 ≥ 3 个月 → 下线公告 ≥ 30 天。

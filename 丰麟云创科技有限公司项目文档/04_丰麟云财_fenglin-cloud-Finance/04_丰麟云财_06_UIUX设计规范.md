|---|---|---|
| `--fl-color-primary` | `#1F5EFF` | 主色（丰麟蓝） |
| `--fl-color-primary-hover` | `#3D78FF` | 主色悬停 |
| `--fl-color-success` | `#16A34A` | 成功 |
| `--fl-color-warning` | `#F59E0B` | 警告 |
| `--fl-color-danger` | `#DC2626` | 危险 |
| `--fl-color-info` | `#64748B` | 信息 |
| `--fl-color-text-primary` | `#1E293B` | 主文本 |
| `--fl-color-text-secondary` | `#64748B` | 次文本 |
| `--fl-color-bg` | `#F5F7FA` | 页面背景 |
| `--fl-color-surface` | `#FFFFFF` | 卡片/容器 |
| `--fl-color-border` | `#E2E8F0` | 边框/分割线 |

### 1.2 财务场景扩展令牌（在基线令牌之上派生，不改变基线）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fin-color-debit` | `#1F5EFF` | 借方金额 / 借方列 |
| `--fin-color-credit` | `#DC2626` | 贷方金额 / 贷方列 |
| `--fin-color-positive` | `#16A34A` | 余额/利润正数 |
| `--fin-color-negative` | `#DC2626` | 余额/利润负数 |
| `--fin-color-locked` | `#94A3B8` | 已锁定/已过账（只读态） |
| `--fin-amount-font` | `"Roboto Mono","SFMono-Regular",monospace` | 金额等宽字体（对齐小数） |

### 1.3 字体与排版

| 令牌 | 值 |
|---|---|
| `--fl-font-family` | `"PingFang SC","Microsoft YaHei",-apple-system,"Segoe UI",Roboto,sans-serif` |
| `--fl-font-size-xs/sm/base/lg/xl` | `12/13/14/16/20px` |
| 金额字号 | 表格内 `13px`（sm）；汇总/合计 `16px`（lg）加粗 |
| 数字对齐 | 金额列**右对齐**，千分位分组，保留 2 位展示（底层 4 位） |

### 1.4 圆角 / 间距 / 阴影

| 令牌 | 值 |
|---|---|
| `--fl-radius-sm/md/lg` | `4/8/12px` |
| `--fl-space-xs/sm/md/lg/xl` | `4/8/16/24/32px` |
| `--fl-shadow-sm/md` | `0 1px 2px rgba(0,0,0,.05)` / `0 4px 16px rgba(0,0,0,.08)` |

### 1.5 金额与币种展示规范（强制）

- 金额展示格式：`¥1,234,567.89 CNY`（符号 + 千分位 + 保留 2 位 + 币种代码）。
- 多币种并列时显示原币与本位币两列（原币在上，本位币次行小字）。
- 借贷分色：借方主色、贷方红色；红字冲销以负号 + `--fin-color-danger` 呈现。
- 精度提示：录入框限制 4 位小数，展示截取 2 位；不允许科学计数法。
- 只读态（已过账/已锁定）使用 `--fin-color-locked` 背景，字段不可编辑并显示锁图标。

## 5. 交互流程

### 5.1 凭证制单流程

```
新建凭证 → 选期间/币种 → 增删分录行 → 填写金额(实时校验平衡)
 → 存草稿(自动) → 提交审批 → 流转审核/过账 → 状态标签更新 → 只读锁定
```

### 5.2 报销流程（用户端→管理端）

```
填报(P-03) → 提交 → [审批中] → 主管/财务审批(管理端 A-09) → 通过 → 打款 → [已付款]
                └─ 驳回 → 消息通知 → 修改重提
```

### 5.3 资产盘点流程

```
管理端发起(A-20) → 生成任务 → 用户端扫码盘点(P-09) → 提交结果
 → 管理端复核差异 → 盘盈盘亏审批 → 生成凭证 → 盘点报告
```

### 5.4 碳核算流程

```
用户端填报(P-11) → 提交 → 管理端复核(A-23) → 触发核算 → 结果展示(可追溯因子版本) → 目标进度更新
```

交互通用要求：所有提交类操作均二次确认；金额类操作展示影响预览；长任务（结账/折旧/核算）显示进度与异步结果通知。

## 6. 响应式

| 断点 | 管理端 | 用户端 |
|---|---|---|
| ≥1440 | 三栏（菜单+内容+侧栏） | 卡片三列 |
| 1200 | 二栏 | 卡片两列 |
| 992 | 菜单收起为图标 | 卡片两列 |
| 768 | 抽屉式菜单 | 卡片单列 |
| <768 | 移动端表格横滑、操作收进底部栏 | 卡片单列、底部 Tab 导航 |

- 移动端最小可点击区 44×44px。
- 复杂表格在小屏提供"卡片化"降级视图与横向滚动。
- 金额列在窄屏保留右对齐与完整数字（可横向滚动）。

## 7. 状态规范

| 状态 | 表现 |
|---|---|
| 加载 | 骨架屏（列表/卡片）；按钮 loading；表格 shimmer |
| 空态 | 插画 + 文案 + 主操作按钮（如"暂无凭证，新建凭证"） |
| 错误 | 错误面板 + 错误码 + 重试按钮；表单字段级错误提示 |
| 无权限 | 403 占位页 + 申请权限入口 |
| 成功反馈 | Message/Toast（如"凭证已过账"）；关键操作结果对话框 |
| 只读/锁定 | 字段灰化 + 锁图标 + tooltip 说明（如"已过账不可修改"） |
| 长任务 | 进度条 + 可关闭后台运行 + 完成后站内信通知 |

## 8. 可访问性

- 对比度 ≥ 4.5:1（正文）；借/贷分色不单独依赖颜色，辅以"借/贷"文字标识。
- 支持键盘导航与可见焦点样式；表单支持 Tab 顺序与回车提交。
- 图标按钮提供 `aria-label`；表格提供表头语义。
- 金额等数字提供屏幕阅读友好文本（如 `aria-label="借方一百一十三万二千元"`）。
- 国际化：文案外置 i18n，默认 `zh-CN`，预留 `en-US`；金额/日期本地化。

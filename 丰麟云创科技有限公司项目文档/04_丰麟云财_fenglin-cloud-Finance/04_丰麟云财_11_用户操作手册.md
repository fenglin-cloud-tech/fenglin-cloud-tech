## 1. 快速开始

丰麟云财用户端（员工工作台）访问地址：`https://finance.fenglincloud.com/app/finance`。

用户端聚焦"日常业务操作、协同、查询、填报"，包含：

| 能力 | 入口 | 谁用 |
|---|---|---|
| 费用报销 | 我的报销 | 全体员工 |
| 预算查询 | 预算查询 | 全体员工 |
| 项目交付 | 我的项目 | 项目经理、项目成员 |
| 工时填报 | 工时填报 | 项目成员 |
| 资产借用/盘点 | 我的资产 | 资产使用人 |
| 碳/ESG 填报 | 碳活动填报 / 我的 ESG 数据 | 责任人、ESG 专员 |

> 提示：管理端（配置/审批/报表出具）由财务与管理员使用，入口为 `/admin/finance`，不在本手册范围（详见《系统管理员手册》）。

## 2. 登录与导航（用户端）

### 2.1 登录

1. 打开 `https://finance.fenglincloud.com/app/finance`，自动跳转统一登录（SSO）。
2. 支持：企业微信/飞书/钉钉扫码、账号密码 + 短信验证码（MFA）。
3. 首次登录需修改初始密码；连续 5 次失败账号锁定，30 分钟后自动解锁或联系管理员。

### 2.2 导航结构

```
顶部导航：首页 | 待办 | 消息 | 我的
左侧/工作台宫格快捷入口：
  ├ 我的报销    ├ 工时填报    ├ 我的项目
  ├ 预算查询    ├ 我的资产    ├ 碳/ESG 填报
```

- **工作台首页**：待办卡（待审批、待补材料、借用到期）、快捷入口宫格、我的数据卡（本月已报金额/工时/名下资产）。
- 移动端（PWA）：底部 Tab 导航，卡片单列。

### 2.3 通用操作约定

- 金额展示：`¥1,234,567.89 CNY`，右对齐，保留 2 位（内部精度 4 位）。
- 提交类操作均二次确认；重要提交显示影响预览。
- 每个列表支持筛选、排序、分页；空态提供主操作按钮。

## 3. 分模块操作指引

> 截图位以下方 `[截图：…]` 标注，实施时替换为真实界面截图（本手册配套图册）。

### 3.1 费用报销

[截图：我的报销列表页]

**新建报销单**

1. 进入「我的报销」→ 点击「新建报销」。
2. 填写基本信息：报销类型（差旅/办公/招待/物料/其他）、部门、关联项目（可选）。
3. 添加费用明细（可多条）：费用日期、费用类别、金额、发票（上传）。
4. 系统实时显示合计金额与**预算可用余额**；若超出预算将提示无法提交。
5. 点击「提交审批」，进入审批流程；可在列表查看进度（审批中/已通过/已驳回/已付款）。

**要点**

- 金额录入支持 4 位小数，展示保留 2 位。
- 发票可拍照上传，系统自动关联验真。
- 草稿自动保存；驳回后可直接修改重提。

### 3.2 预算查询

[截图：预算查询页]

1. 进入「预算查询」，选择年度与维度（部门/项目/科目）。
2. 查看预算总额、已占用、已执行、可用余额（环形图 + 数字）。
3. 报销/工时提交前可先查询可用余额，避免超支。

### 3.3 我的项目（项目交付）

[截图：我的项目列表与详情]

1. 项目经理：进入「我的项目」→「新建立项申请」，填写客户、合同号、金额、周期、预算等，提交后由管理端审批。
2. 立项通过后：可维护里程碑、项目成员，查看成本概览与进度。
3. 项目成员：查看参与项目、里程碑进度与个人工时。

**项目结算申请（项目经理）**

1. 项目详情 →「结算申请」→ 选择阶段（STAGE）或终验（FINAL）。
2. 填写结算金额、税率、完工进度，提交审批。
3. 审批通过后生成应收并联动开票与财务凭证。

### 3.4 工时填报

[截图：工时周视图]

1. 进入「工时填报」，按周填写每日工时（可关联项目与里程碑/任务）。
2. 单日工时不得超过 24 小时；填写说明后可保存。
3. 提交后由项目经理审批；审批通过后计入项目成本。

### 3.5 我的资产 / 资产借用

[截图：我的资产与扫码页]

1. 进入「我的资产」查看名下资产（含二维码、保修/借用到期提醒）。
2. 借用：选择可借用 IT 资产 → 填写预计归还日期与用途 → 提交。
3. 报修：对资产发起维修工单并跟踪状态。
4. 扫码：使用手机扫码可快速查看资产详情。

### 3.6 扫码盘点

[截图：扫码盘点页]

1. 收到盘点任务后进入「扫码盘点」。
2. 逐项扫描资产二维码/RFID，确认账面信息与实盘（部门/地点/责任人）。
3. 对差异项选择结果（正常/盘盈/盘亏/位置变动）并备注。
4. 提交盘点结果，交由管理端复核。

### 3.7 碳活动填报（ESG 与双碳）

[截图：碳活动填报页]

1. 进入「碳活动填报」，选择组织、设施、范围（范围一/二/三）与活动类型（电力/天然气/燃料/差旅/物流等）。
2. 填写活动数据量与单位（系统提供单位换算提示）。
3. 选择排放因子（默认最新有效版本），标记数据质量（高/中/低）并上传证据附件。
4. 提交后由 ESG 负责人复核；复核通过且锁定后不可修改（需解锁审批）。

### 3.8 我的 ESG 数据

[截图：我的 ESG 数据页]

1. 查看本人负责的 E/S/G 指标与目标值、实际值。
2. 按报告年度维护指标数据并提交复核。

## 4. 常见任务场景

| 场景 | 操作路径 |
|---|---|
| 出差回来报销差旅费 | 我的报销 → 新建报销 → 上传发票 → 提交 → 等待审批/打款 |
| 查询本部门预算余额 | 预算查询 → 选部门 → 查看可用余额 |
| 项目经理提交立项 | 我的项目 → 新建立项申请 → 提交审批 |
| 提交本周工时 | 工时填报 → 填周视图 → 提交 → PM 审批 |
| 提交项目阶段结算 | 我的项目 → 项目详情 → 结算申请 → 提交 |
| 借用笔记本电脑 | 我的资产 → 借用 → 填归还日期 → 提交 |
| 参与季度资产盘点 | 我的资产 → 扫码盘点 → 逐项确认 → 提交 |

## 5. FAQ

**Q1：报销提交后发现金额填错怎么办？**
A：若仍在审批中，撤回后修改重提；若已通过但未打款，联系财务驳回后修改。已打款需走调整流程。

**Q2：为什么提交报销时提示"预算不足"？**
A：本部门/项目预算采用强控。请查询预算余额，或联系预算管理员调整。

**Q3：工时填错了可以改吗？**
A：审批前可编辑；审批通过后需申请撤销/调整，由 PM 处理。

**Q4：资产借用到期未还会怎样？**
A：系统会发送到期提醒（消息+待办），超期将通知你的主管并影响后续借用。

**Q5：碳数据提交后还能改吗？**
A：复核通过并锁定后不可直接修改，需发起解锁申请，由 ESG 负责人审批。

**Q6：金额为什么显示两位小数，实际是几位？**
A：展示保留 2 位，系统内部精确到 4 位小数，保证核算精度。

**Q7：发票上传失败/识别不出怎么办？**
A：检查文件格式（支持 JPG/PNG/PDF）；仍失败可先手工填写金额，事后再补发票。

**Q8：登录密码忘记/账号被锁？**
A：点击"忘记密码"通过短信/邮箱重置；被锁 30 分钟后自动解锁，或联系管理员。

**Q9：我看不到某个菜单？**
A：菜单按权限显示。若无所需权限，请联系管理员或提交权限申请。

**Q10：移动端和电脑端数据同步吗？**
A：同步，均为同一系统，移动端为响应式 PWA。

## 6. 快捷键

| 快捷键 | 功能 |
|---|---|
| `Alt + 1` | 跳转工作台首页 |
| `Alt + 2` | 跳转我的报销 |
| `Alt + 3` | 跳转工时填报 |
| `Alt + 4` | 跳转我的资产 |
| `Ctrl + Enter` | 提交当前表单（需二次确认） |
| `Ctrl + S` | 保存草稿 |
| `Esc` | 关闭弹窗/取消编辑 |
| `/` | 聚焦列表搜索框 |

> 说明：快捷键在表单焦点内不触发；移动端不适用。

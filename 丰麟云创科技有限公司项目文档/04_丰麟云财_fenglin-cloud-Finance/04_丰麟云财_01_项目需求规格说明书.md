## 1. 引言

### 1.1 编写目的

本文档定义丰麟云财（Fenglin Cloud Finance）产品的功能与非功能需求，是架构设计、数据库设计、接口设计、UI/UX 设计、测试与验收的统一依据。读者对象为产品经理、架构师、研发工程师、测试工程师、实施顾问、运维工程师与质量评审人员。

### 1.2 产品范围

丰麟云财是丰麟云枢平台"域D：财务与经营"业务域产品，定位为**业财一体与经营核算平台**，品牌口号"**业财一体，经营可视，资产可控，双碳可量**"。产品覆盖 4 个核心模块：

| 模块码 | 模块名 | 参考标杆 | 一句话定位 |
|---|---|---|---|
| D1 | 财务与业财一体 | 用友 YonSuite | 从业务单据到会计凭证、报表的全链路业财融合与经营核算 |
| D2 | 项目交付与成本核算 | 代码时空 | 项目全生命周期交付管理与精细化成本核算 |
| D3 | 固定资产与 IT 资产追踪 | UCloud 优刻得资产管理系统 | 资产全生命周期与 IT 资产台账的可视可控 |
| D4 | ESG 与双碳管理 | 碳阻迹 | 组织碳盘查、双碳目标与 ESG 披露的可量化管理 |

本产品**不含**以下范围（由其它产品承接）：合同与电子签章（丰麟云法 G1）、人力资源薪酬计算（丰麟云才 C1）、统一身份与租户治理（丰麟云枢中台）。

## 2. 产品概述

### 2.1 产品定位与价值

丰麟云财以"业财一体"为主线，打通业务单据（项目、采购、报销、资产、碳活动）与财务核算（凭证、账簿、报表），实现：

- **经营可视**：经营看板、多维度利润分析、现金流预测；
- **资产可控**：固定资产与 IT 资产全生命周期可视、折旧自动、盘点闭环；
- **双碳可量**：碳排放可核算、双碳目标可跟踪、ESG 可披露；
- **合规可信**：财务凭证不可篡改、金额精确、操作全审计、等保三级。

### 2.2 目标用户与角色

| 角色 | 端 | 职责 |
|---|---|---|
| 平台超级管理员 | 管理端 | 平台级最高权限（运维专用、强审计） |
| 平台运维 | 管理端 | 租户/套餐/监控/灰度 |
| 租户管理员 | 管理端 | 本租户财务配置、组织、角色、权限 |
| 财务管理员（业务管理员） | 管理端 | 账套/科目/预算/报表定义、审批、期末结账 |
| 财务主管/会计 | 管理端 | 凭证审核、过账、报表出具、资产管理 |
| 项目经理 | 用户端 | 项目立项申请、工时审批、成本查看 |
| 项目成员/员工 | 用户端 | 工时填报、费用报销、资产领用、碳数据填报 |
| 资产管理员 | 用户端/管理端 | 资产建档、盘点执行、IT 台账维护 |

## 6. 接口需求

- 全部业务接口遵循 `/api/finance/v1` 前缀与统一响应体（`code/message/data/requestId/timestamp`）。
- 写操作支持 `Idempotency-Key`；金额/库存/审批类操作强制幂等。
- 请求头必含 `Authorization`、`X-Tenant-Id`、`X-Client-Type`（`ADMIN`/`PORTAL`）。
- 核心接口 ≥ 40 个（详见 FL-FIN-API-001），错误码采用 40 域前缀。
- 开放 API：`/openapi/finance/v1/**`，HMAC-SHA256 签名 + OAuth2.1；事件经 Kafka + Webhook 推送。

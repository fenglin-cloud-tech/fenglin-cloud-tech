## 1. 快速开始

### 1.1 概述

丰麟云研是研发效能与度量平台，帮助团队完成"需求 → 迭代 → 任务 → 缺陷 → 测试 → 代码 → 构建 → 发布"的全流程在线化管理，并以度量洞察持续改进效能。本手册面向用户端使用者：产品经理、研发主管、开发、测试、运维/发布工程师、效能分析师。

### 1.2 访问与准备

| 项 | 说明 |
|---|---|
| 访问地址 | `https://devops.fenglincloud.com/app/devops` |
| 浏览器 | Chrome/Edge/Firefox/Safari 最近两个大版本 |
| 账号 | 由租户管理员开通，使用平台统一账号登录 |
| 前置 | 已加入至少一个"产品"，否则首页提示"暂无可见产品" |

### 1.3 五分钟上手

1. 登录后进入**我的工作台**，查看"我的待办 / 我的任务 / 我的缺陷"。
2. 进入**需求**页签，创建或领取需求。
3. 在**迭代与看板**中把需求拉入当前迭代，并拖拽推进状态。
4. 在**任务**中拆分执行项并登记工时；在**缺陷**中提交与回归问题。
5. 在**我的效能**中查看个人贡献度与交付效率，在**团队大盘**查看团队指标。

## 3. 分模块操作指引

### 3.1 我的工作台

- **我的待办**：需我处理的需求评审、缺陷、测试执行、发布审批。
- **我的任务/缺陷**：按优先级与截止时间排序，逾期标红。
- **快捷入口**：常用页面与"新建"。
- **我的效能**：个人贡献度、交付效率、质量指标卡片。

> 图示位：`【截图位 3-1 我的工作台】`、`【截图位 3-2 我的效能卡片】`

### 3.2 产品规划（Roadmap）

1. 选择产品与时间范围（季度/发布）。
2. 在时间轴上拖动需求调整计划排期，或按版本分组查看。
3. 点击空白处快速新建需求并定位到对应时间段。

> 图示位：`【截图位 3-3 产品路线图】`

### 3.3 需求管理

**创建需求**：需求 → 新建 → 填写标题、类型（业务/用户/技术）、优先级（P0–P3）、负责人、预估工时、验收标准 → 保存。

**维护需求**：详情页可编辑描述与验收标准、添加父子/关联/阻塞关系、上传附件、查看提交时间线。

**需求评审**：点击"提交评审"并指定评审人 → 评审人通过/驳回 → 通过后需求可拉入迭代。

**批量操作**：列表勾选多条，批量调整优先级/负责人/迭代。

> 图示位：`【截图位 3-4 需求详情】`

> 规则提示：需求必须归属一个产品与类型；父需求与子需求不能跨产品；非法状态流转会被系统拒绝并提示"状态冲突"。

### 3.4 迭代与看板

**迭代规划**：迭代与看板 → 新建迭代（名称、起止日期、容量）→ 将需求拉入迭代；超出容量会提示"超载"，但不阻断。

**看板操作**：
- Scrum/Kanban 切换；列可自定义；
- 拖拽卡片切换状态；Kanban 列设置 WIP 限制，超限以红色提示；
- 按负责人/优先级设泳道；
- 大迭代支持分列懒加载与虚拟滚动，滚动流畅。

**燃尽图**：迭代详情查看燃尽趋势，需求移出会修正燃尽快照。

> 图示位：`【截图位 3-5 迭代看板】`、`【截图位 3-6 燃尽图】`

### 3.5 任务与工时

1. 任务 → 新建：关联需求/缺陷、设负责人、优先级、截止日期、预估工时。
2. 子任务：在父任务下拆分，父任务进度按子任务汇总。
3. 登记工时：任务/缺陷详情 → 登记工时（日期、工时、说明），自动汇总为实际工时。

> 图示位：`【截图位 3-7 任务详情与工时登记】`

### 3.6 缺陷管理

1. 缺陷 → 新建：标题、复现步骤、严重级（阻塞/严重/一般/轻微）、优先级、环境、关联需求、附件截图。
2. 状态流转：`new → confirmed → fixing → fixed → closed`；关闭后如需处理，使用"重新打开"。
3. 回归：修复后由测试验证并关闭；验证失败可重新打开并记录原因。

> 图示位：`【截图位 3-8 缺陷详情】`

> 规则提示：「阻塞」级缺陷会自动标记为迭代阻断项；直接由"已关闭"改回"待处理"会被系统拒绝，请走"重新打开"。

### 3.7 测试

| 步骤 | 操作 |
|---|---|
| 用例 | 测试 → 用例 → 新建/克隆：前置条件、步骤、所属分组；可提交用例评审 |
| 计划 | 测试 → 计划 → 新建：选择迭代/版本、分配用例与执行人 |
| 执行 | 打开计划 → 逐条记录结果（通过/失败/阻塞），失败可**一键生成缺陷**并自动回填用例与构建版本 |

> 图示位：`【截图位 3-9 测试执行】`

### 3.8 代码

- 代码 → 选择仓库 → 分支/标签/提交列表；提交详情显示作者、行数变化。
- 提交/合并请求与工作项自动关联：提交信息含 `#需求编号` 或 `#缺陷编号` 即自动关联（如 `feat #DEV-RQ202610000005`）。
- 需求/缺陷详情页可查看关联提交时间线。

> 图示位：`【截图位 3-10 提交与关联】`

> 说明：代码浏览为**只读**，平台不对第三方仓库回写代码内容。

### 3.9 流水线与构建

1. 流水线 → 选择流水线 → "触发构建"（可选参数）。
2. 构建列表查看状态（排队/运行/成功/失败）与日志摘要。
3. 构建详情查看制品版本并与提交/发布关联。

> 图示位：`【截图位 3-11 流水线与构建】`

### 3.10 发布与部署

1. 发布 → 新建发布单：版本号、环境、关联构建/需求。
2. 提交审批：进入发布审批流（审批人处理）。
3. 审批通过后执行部署（生产环境需 MFA 二次确认）；部署记录留痕。
4. 如需回滚：在部署记录选择"回滚"，填写原因与操作人。

> 图示位：`【截图位 3-12 发布单与部署记录】`

> 规则提示：审批通过前不允许生产部署；回滚必须记录原因。

### 3.11 度量洞察

| 页面 | 内容 |
|---|---|
| 效能洞察大盘 | 贡献度/交付/质量/DORA 多指标聚合，可按产品/团队/迭代/时间下钻 |
| 团队/个人画像 | 多指标加权评分与雷达图 |
| 趋势与对比 | 时间趋势、团队/迭代横向对比、同比环比 |
| 报表与订阅 | 导出 Excel/CSV/PDF，配置周期订阅推送 |

> 图示位：`【截图位 3-13 洞察大盘】`、`【截图位 3-14 效能画像】`

> 数据可见范围：团队负责人见本部门及下级，个人见本人，管理员见全部。

## 4. 常见任务场景

### 场景 A：一个需求的完整闭环（PM → 开发 → 测试 → 发布）

1. PM 在**需求**创建需求并填写验收标准 → 提交评审 → 评审通过。
2. 主管在**迭代**中把需求拉入当前迭代，并在**看板**分配给开发。
3. 开发在**任务**中拆分并执行，提交代码时写 `#需求编号`；关联提交自动出现在需求时间线。
4. 开发触发**流水线**构建 → 创建**发布单**并提交审批。
5. 测试在**测试计划**中执行用例，失败用例一键生成**缺陷**。
6. 缺陷修复并回归关闭 → 发布审批通过 → 执行**部署**。
7. 在**度量洞察**查看该需求交付周期与团队 DORA 指标变化。

### 场景 B：迭代规划与燃尽跟踪

1. 新建迭代，设置成员可用工时形成容量。
2. 从需求池拉入需求，观察是否超载。
3. 每日在看板推进状态，查看燃尽图是否偏离理想线。
4. 迭代结束查看回顾数据与交付效率。

### 场景 C：缺陷质量改进

1. 从**质量度量**查看缺陷密度、逃逸率、重开率、修复时长。
2. 定位高缺陷模块与根因分类。
3. 在迭代中安排质量改进项，跟踪指标趋势。

### 场景 D：效能复盘

1. 打开**团队大盘**，对比本迭代与上迭代 DORA 与交付效率。
2. 下钻到具体团队/个人画像。
3. 导出报表并订阅周报。

## 5. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 找不到某个产品 | 联系产品负责人/管理员将你加入产品成员并配置可见范围 |
| 需求无法拉入迭代 | 需求需先通过评审（状态=已评审） |
| 提示"状态冲突" | 当前状态不允许该流转，请按合法路径操作（如缺陷需"重新打开"） |
| 看板拖拽无反应 | 无该产品编辑权限，或状态列不允许该目标状态 |
| 提交未自动关联 | 提交信息未包含 `#编号` 关键字，或在"提交"页手动关联 |
| 无法执行生产部署 | 发布审批未通过，或需完成 MFA 二次确认 |
| 大盘数据为空 | 数据按周期聚合，检查统计周期与可见范围；离线聚合每日 01:00 执行 |
| 指标与预期不一致 | 查看指标口径说明与版本，必要时联系效能分析师 |
| 导出失败 | 数据权限或数据量超限，缩小范围后重试 |
| 收不到通知 | 检查通知偏好设置与订阅配置 |

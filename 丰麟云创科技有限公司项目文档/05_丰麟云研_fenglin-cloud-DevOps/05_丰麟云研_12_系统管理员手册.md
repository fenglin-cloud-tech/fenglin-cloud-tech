## 1. 管理端总览

### 1.1 定位

管理端 `/admin/devops` 承载**配置、授权、审核、报表定义**类能力，与用户端 `/app/devops`（业务操作、协同、查询、填报）严格分离。管理端令牌声明 `client_type=ADMIN`，权限域为 `platform:*` 与 `tenant:*`；管理端接口不向用户端令牌开放，反之亦然。

### 1.2 管理端角色

| 角色 | 权限域 | 职责 |
|---|---|---|
| 平台超级管理员 | `platform:*` | 平台级最高权限（运维专用、强审计） |
| 平台运维 | `platform:*` | 租户、套餐、监控、灰度 |
| 租户管理员 | `tenant:*` | 本租户研发配置、组织、角色、权限、成员 |
| 研发管理员（业务管理员） | `tenant:devops:*` | 产品/流程/字段/集成/度量口径配置、审批 |

### 1.3 管理端功能地图

| 模块 | 路由 | 主要功能 |
|---|---|---|
| 研发概览 | `/admin/devops/overview` | 租户级研发总览、跨团队对比 |
| 产品配置 | `/admin/devops/product` | 产品/产品线、成员与可见范围 |
| 方案配置 | `/admin/devops/scheme` | 需求状态方案、字段方案、缺陷严重级 |
| 看板配置 | `/admin/devops/board-config` | 看板列、WIP 限制 |
| 发布配置 | `/admin/devops/release-config` | 发布审批流、发布窗口、环境 |
| 集成配置 | `/admin/devops/integration` | 代码库、流水线、Webhook 与凭据 |
| 度量配置 | `/admin/devops/metric` | 指标口径、权重、目标、预警、口径版本 |
| 报表与订阅 | `/admin/devops/report` | 报表定义、订阅管理 |
| 监控与审计 | `/admin/devops/audit` | 操作审计、系统监控、集成健康 |

## 2. 租户、组织、用户与角色

### 2.1 租户管理（平台运维）

- 租户创建/开通、套餐与配额（用户数、产品数、仓库数、Webhook 速率）。
- 租户隔离：所有 `devops_*` 表含 `tenant_id` 并启用 PostgreSQL RLS，跨租户访问默认拒绝。
- 租户级开关：功能开关、集成开关、度量模块开关。

### 2.2 组织与用户

- 组织（部门）与用户由中台 IAM 统一管理；管理端可查询与分配研发相关角色。
- 用户停用后其研发数据保留，但不可再操作。

### 2.3 角色与成员

| 配置 | 说明 |
|---|---|
| 产品成员 | 在产品中分配 `owner/admin/developer/tester/reporter` |
| 数据范围 | `self/dept/dept_sub/dept_list/all` |
| 租户角色 | 研发管理员、租户管理员由 IAM 分配 |

## 3. 权限与数据权限配置

### 3.1 功能权限

- 权限码格式 `{域}:{模块}:{操作}`，管理端使用 `tenant:devops:*`，如：
  - `tenant:devops:product:manage`、`tenant:devops:repo:manage`、`tenant:devops:metric:config`、`tenant:devops:release:approve_config`。
- 通过角色-权限矩阵分配；遵循最小权限与职责分离（研发管理员与发布审批人分离）。

### 3.2 数据权限

| 范围 | 含义 |
|---|---|
| `self` | 仅本人 |
| `dept` | 本部门 |
| `dept_sub` | 本部门及下级 |
| `dept_list` | 指定部门 |
| `all` | 租户内全部 |

- 数据权限与产品可见范围（private/public）叠加生效；度量数据可见范围遵循同一规则。
- 跨租户一律拒绝，返回 `5000002`（无权限）。

### 3.3 端别与网关策略

- 网关按令牌 `client_type` 与路由前缀校验端别；
- 管理端接口（`/admin/devops` 对应后端 `tenant:*`/`platform:*`）拒绝 PORTAL 令牌；
- 生产部署与发布审批在权限基础上强制 MFA 二次确认。

### 4.2 字典与枚举

| 字典 | 取值 |
|---|---|

## 5. 流程与审批配置

### 5.1 状态机配置

- **需求状态方案**：自定义状态（名称/类别/颜色/排序），绑定到产品；配置合法流转规则。
- **缺陷状态与严重级**：配置状态集合与严重级字典。
- 非法流转由应用层强制校验，返回 `5000005`（状态冲突）/`5000201`（工作项状态非法流转）。

### 5.2 审批工作流（BPMN）

| 工作流 | 用途 | 关键配置 |
|---|---|---|
| `devops-requirement-review` | 需求评审 | 评审人范围、通过阈值 |
| `devops-defect-flow` | 缺陷流转审批（可选） | 触发条件、审批人 |
| `devops-release-approval` | 发布审批 | 审批层级、双人复核、MFA 要求、发布窗口 |

- 工作流由中台 `fenglin-workflow-service`（Flowable 7，BPMN 2.0）编排。
- 发布审批通过前系统拒绝生产部署，返回 `5000205`。

> 图示位：`【截图位 5-1 发布审批流程配置】`

### 5.3 发布窗口与环境

- 配置允许发布的时间窗口（如工作日 10:00–18:00）；
- 配置环境（dev/test/staging/prod）与部署策略（滚动/蓝绿）；
- 生产环境强制 MFA + 双人复核。

## 6. 集成与开放平台

### 6.1 代码库集成

1. 集成配置 → 代码库 → 新增：选择类型（GitLab/GitHub）、地址、访问令牌、默认分支。
2. 令牌以 **AES-256-GCM** 加密落库，创建时**仅返回一次明文**，后续展示脱敏。
3. 保存后触发同步分支/提交/标签；也可手动同步。

> 安全提示：平台对仓库仅具**只读**权限，不回写代码内容；状态回写仅限白名单动作。

### 6.2 流水线集成

- 接入 Jenkins/GitLab CI：配置地址、凭据、项目/流水线标识。
- 支持手动触发与 Webhook 回调更新构建状态。

### 6.3 Webhook 配置与联调

| 来源 | 回调地址 | 验签方式 |
|---|---|---|
| GitLab | `/api/devops/v1/integration/gitlab/webhook` | Secret Token + HMAC |
| GitHub | `/api/devops/v1/integration/github/webhook` | HMAC-SHA256 |
| Jenkins | `/api/devops/v1/integration/jenkins/webhook` | Token + HMAC |
| SonarQube | `/api/devops/v1/integration/sonarqube/webhook` | Token |

- 验签失败返回 `5000204`；重放由幂等键去重；失败重试（指数退避 ≤5 次）后进死信队列。
- 提供"测试回调"按钮联调，展示最近事件与处理结果。

> 图示位：`【截图位 6-1 集成配置与 Webhook 联调】`

### 6.4 开放平台

- 前缀 `/openapi/devops/v1`；应用注册、AppKey/AppSecret HMAC-SHA256 签名、OAuth2.1、按 QPS 配额限流。
- 开放事件经 Kafka Webhook 回调订阅方。

### 6.5 度量口径配置

- 指标口径：定义公式、单位、数据源映射；
- 权重与目标值：用于画像评分与预警；
- 口径版本管理：变更留版本，可回滚；离线聚合按版本计算快照。

## 7. 监控与审计

### 7.1 系统监控

| 维度 | 关注指标 |
|---|---|
| 服务 | QPS、响应 P95/P99、错误率、Pod 状态 |
| 数据库 | 连接数、慢查询、复制延迟、锁等待 |
| 消息 | Kafka lag、分区均衡 |
| 集成 | 第三方回调成功率、令牌有效性、死信数量 |
| 度量 | 聚合任务时长、快照完整性、预警触发 |

### 7.2 审计

- 全量操作审计（谁/何时/何对象/何操作/结果）；发布、部署、凭据、权限操作写**哈希链 + WORM**。
- 审计留存 ≥ 6 个月（建议 12 个月）；支持按租户、用户、对象、时间检索与导出。
- 审计写入失败即时告警。

> 图示位：`【截图位 7-1 操作审计查询】`

### 7.3 告警分级

P0（不可用/数据错乱/越权）电话+群；P1（核心劣化/积压）群+工单；P2（非核心/容量）群；P3 邮件/日报。详见 FL-DEVOPS-OPS-001 §7。

## 8. 备份与安全运维

### 8.1 备份恢复

| 对象 | 策略 |
|---|---|
| PostgreSQL | 每日全备 + WAL 归档，PITR；保留全备 30 天 |
| Redis | AOF + RDB |
| MinIO | 版本管理 + 跨机房复制 |
| 配置 | Nacos 每日导出快照 |
| 审计 | WORM 双副本 |

RPO ≤ 5min、RTO ≤ 30min；季度恢复演练。详见 FL-DEVOPS-OPS-001 §8。

### 8.2 凭据与密钥

- 集成令牌/Secret 由 KMS 托管，轮换周期 ≤ 90 天；
- 支持一键重置凭证；重置后需重新联调；
- 凭据操作全程审计；展示统一脱敏。

### 8.3 安全运维要点

- 端别隔离、最小权限、职责分离、三员分立；
- 生产部署/发布强制 MFA + 双人复核；
- 依赖 SCA 与镜像扫描纳入发布门禁；
- 数据导出受数据权限控制并留审计（详见 FL-DEVOPS-SEC-001）。

## 9. 故障处理

| 故障 | 定位方向 | 处置 |
|---|---|---|
| 用户无法访问某产品 | 产品成员/可见范围/数据权限 | 校验并修正成员与范围配置 |
| 状态流转被拒 | 状态机配置/当前状态 | 核对合法流转路径或调整方案配置 |
| Webhook 未生效 | 回调地址/Secret/验签/限流 | 用"测试回调"联调，校验 Secret 与网络白名单 |
| 集成同步中断 | 令牌失效/网络/第三方变更 | 重置令牌、检查出站白名单与第三方 API 版本 |
| 发布无法部署 | 审批状态/发布窗口/MFA | 检查审批是否通过、是否在窗口内、MFA 是否完成 |
| 度量指标异常 | 口径版本/数据质量/聚合任务 | 冻结口径、校验数据质量、触发重算（幂等覆盖） |
| 大盘查询慢 | 缓存/索引/只读副本 | 刷新缓存、检查慢查询与索引 |
| 审计缺失 | 审计服务/WORM 写入 | 检查审计服务连通与 WORM 存储状态 |
| 性能劣化 | 连接池/GC/Kafka lag/DB | 参照 FL-DEVOPS-PERF-001 调优项处置 |
| 安全告警 | 越权/异常登录/洪泛 | 封禁账号或令牌、取证审计、上报安全组 |

> 应急流程与联系角色见 FL-DEVOPS-OPS-001 §9；重大故障 15min 内升级，3 个工作日内完成复盘闭环。

## 1. 设计原则

| 编号 | 原则 |
|---|---|
| P-01 | 多租户共享库共享模式：每张业务表含 `tenant_id`，启用 PostgreSQL RLS 行级安全 |
| P-02 | 主键统一 `bigint` 雪花 ID；对外暴露使用 `uuid` 映射列 `biz_uuid`（不直接暴露自增） |
| P-03 | 全表公共字段：`id`、`tenant_id`、审计四字段（`created_by`/`created_at`/`updated_by`/`updated_at`）、`deleted`、`version` |
| P-04 | 逻辑删除 `deleted smallint`（0 正常 / 1 删除），查询默认过滤 |
| P-05 | 乐观锁 `version int`，更新语句 `WHERE id=? AND version=?` |
| P-06 | 数值规范：工时 `numeric(10,2)`（小时）；比率/百分比 `numeric(9,6)`；代码行数 `int`；评分 `numeric(6,2)` |
| P-07 | 所有 DDL/DML 通过 Flyway 脚本，命名 `V{版本}__{描述}.sql`，禁止手工改库 |
| P-08 | 集成令牌/密钥字段 AES-256-GCM 加密 + `{field}_hash`（SHA-256+租户盐）用于检索；禁止明文唯一索引 |
| P-09 | 时间统一 `timestamptz` 存 UTC；统计窗口按租户时区换算 |
| P-10 | 高频写入表（提交、Webhook 事件）按 `created_at` 月分区，滚动归档 |

## 2. 逻辑模型（ER）

```
图例：  ──1:N──▶ 表示一对多 | ══1:1══ 表示一对一 | ◀··N:M··▶ 表示多对多

[devops_product 产品]
   │1:N
   ├──▶ [devops_product_member 产品成员]
   ├──▶ [devops_requirement 需求] ──N:1──▶ [devops_requirement_status 需求状态]
   │        │1:N
   │        ├──▶ [devops_requirement_relation 需求关联]（父子/阻塞/克隆）
   │        └──▶ [devops_task 任务] ──1:N──▶ [devops_task_worklog 工时日志]
   ├──▶ [devops_sprint 迭代] ──1:N──▶ [devops_sprint_member 迭代成员]
   │        └── ◀··N:M··▶ [devops_requirement]（拉入迭代）
   ├──▶ [devops_board 看板] ──1:N──▶ [devops_board_column 看板列]
   ├──▶ [devops_defect 缺陷]
   ├──▶ [devops_test_case 测试用例] ──1:N──▶ [devops_test_plan 测试计划]
   │                                              └──1:N──▶ [devops_test_execution 测试执行]
   │                                                              └──1:N──▶ [devops_test_execution_item 明细]
   ├──▶ [devops_repo 代码库] ──1:N──▶ [devops_commit 代码提交] ──1:N──▶ [devops_commit_link 提交映射]
   │                                                                        └──N:1──▶ 需求/任务/缺陷
   ├──▶ [devops_pipeline 流水线] ──1:N──▶ [devops_pipeline_run 运行] ──1:N──▶ [devops_build 构建]
   └──▶ [devops_release 发布] ──1:N──▶ [devops_deployment 部署记录]

[devops_webhook_event Webhook事件]（分区表，多态来源 vcs/ci/quality）

[devops_metric_config 度量配置] ── 定义 ──▶ [devops_metric_snapshot 效能指标快照]
[devops_metric_snapshot] ◀── 汇总 ── [devops_contribution 代码贡献度]
[devops_dora_metric DORA指标] ◀── 汇总 ── [devops_deployment] / [devops_release]
[devops_insight_dashboard 洞察大盘] ── 引用 ── [devops_metric_snapshot]
[devops_metric_alert 效能预警] ── 基于 ── [devops_metric_snapshot]

[devops_attachment 附件]（多态：biz_type + biz_id）
[devops_idempotency_record 幂等记录]（幂等键）
```

## 6. 约束与 RLS

### 6.1 外键与业务约束

| 表 | 约束 | 说明 |
|---|---|---|
| `devops_requirement` | 父需求与子需求同产品 | 应用层校验 |
| `devops_task` | `requirement_id` / `defect_id` 至少关联其一（任务可独立） | 应用层校验 |
| `devops_board_column` | `wip_limit > 0` 或空 | CHECK |
| `devops_task_worklog` | `hours > 0 AND hours <= 24` | CHECK |
| `devops_release` | `window_end > window_start` | CHECK |
| `devops_metric_snapshot` | `denominator >= 0` | CHECK |
| 全表 | `deleted IN (0,1)` | CHECK |

### 6.2 RLS 策略

```sql
-- 每张 devops_* 业务表统一启用 RLS
ALTER TABLE devops_requirement ENABLE ROW LEVEL SECURITY;

CREATE POLICY p_requirement_tenant ON devops_requirement
  USING (
    tenant_id = current_setting('app.tenant_id')::bigint
    OR current_setting('app.is_platform_admin', true) = 'true'
  );

-- 平台运营端跨租户访问需显式设置 app.is_platform_admin=true，并强制审计
```

- 应用连接初始化时通过 `SET app.tenant_id = ?` 注入租户上下文。
- 跨租户查询仅限 `platform:*` 权限，由 `fenglin-audit-service` 强制记录。

| 表 | 字段 | 类型 | 加密方式 | 检索列 |

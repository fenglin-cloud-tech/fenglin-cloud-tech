## 1 测试范围与策略

### 1.1 测试范围

| 维度 | 范围 |
|---|---|
| 功能 | A1 销售管理、A2 客户成功与续费、A3 情绪与 NPS、A4 PRM、A5 舆情与竞品 |
| 接口 | `/api/crm/v1` 全部接口（清单见 FL-CRM-API-005，共 71 个，逐接口定义 45 个），含开放 API `/openapi/crm/v1` 与事件 Webhook |
| 权限 | 功能权限码、数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）、字段权限（脱敏/隐藏）、端别（ADMIN/PORTAL）与租户边界 |
| 异常 | 参数校验、状态冲突、并发、幂等、依赖降级、超时、限流 |
| 兼容 | 浏览器与终端（响应式断点）、双端一致性 |
| 性能/可靠性/安全 | 见 FL-CRM-PERF-008、FL-CRM-SEC-009 专项报告 |

### 1.2 测试策略

| 层级 | 方法 | 覆盖目标 |
|---|---|---|
| 单元测试 | JUnit5 + Mockito | Service 业务规则覆盖率 ≥ 70% |
| 接口测试 | Postman/Newman + REST Assured | 覆盖全部已定义接口的正常/异常/边界 |
| 集成测试 | Testcontainers（PostgreSQL/Redis/Kafka）+ 契约测试 | 跨模块事件、Seata 事务、RLS/幂等 |
| 端到端（E2E） | Playwright | 双端关键业务主流程 |
| 性能测试 | JMeter/Gatling（详见 PERF-008） | 3400 人在线、峰值 ≥ 1200 QPS |
| 安全测试 | 扫描 + 渗透（详见 SEC-009） | 等保三级控制项、OWASP Top10 |

### 1.3 用例编号规则

`TC-{模块或类型}-{3位序号}`；模块：A1/A2/A3/A4/A5/CFG（配置）/SEC（安全）/PERF（性能）/REL（可靠性）/COMPAT（兼容）。编号与 FL-CRM-SRS-001 第 9 章 RTM 覆盖用例一致。

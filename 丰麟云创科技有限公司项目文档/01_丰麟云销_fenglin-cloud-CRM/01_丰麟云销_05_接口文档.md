## 1 通用约定

（完整约定引用 FL-HUB-STD-001 第 5 章，本品补充如下。）

- 协议 HTTPS（TLS 1.2+，推荐 1.3）；数据格式 `application/json; charset=UTF-8`。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1 开始）、`size`（默认 20，最大 200）；响应 `data = { records, total, page, size }`。
- 统一响应体：

```json
{
  "code": "0",
  "message": "success",
  "data": {},
  "requestId": "b1f2c3d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- 请求头：`Authorization`、`X-Tenant-Id`、`X-Client-Type`（ADMIN/PORTAL）、`X-Request-Id`、`Idempotency-Key`、`Accept-Language`。
- 错误码结构 `{域2}{模块2}{序号3}`，域前缀 `10`：

| 错误码 | HTTP | 含义 |
|---|---|---|
| `0000001` | 401 | 未认证或令牌失效（平台通用） |
| `0000002` | 403 | 无权限（功能或数据） |
| `0000003` | 400 | 参数校验失败 |
| `0000004` | 404 | 资源不存在 |
| `0000005` | 409 | 状态冲突（并发/重复提交） |
| `0000006` | 429 | 触发限流 |
| `1000001` | 400 | 云销通用参数错误 |
| `1000002` | 403 | 云销功能无权限 |
| `1001001` | 409 | 线索重复 |
| `1001002` | 400 | 线索状态不允许该操作 |
| `1001003` | 400 | 必填项缺失 |
| `1002001` | 400 | 商机阶段准入不满足 |
| `1002002` | 409 | 商机状态冲突 |
| `1003001` | 400 | 报价折扣超限未审批 |
| `1004001` | 409 | 续费单重复 |
| `1005001` | 400 | 健康度权重配置非 100% |
| `1006001` | 409 | NPS 问卷重复投放 |
| `1007001` | 403 | 伙伴未激活 |
| `1007002` | 403 | 伙伴数据越权 |
| `1007003` | 409 | 报备冲突 |
| `1008001` | 400 | 佣金重复结算 |

- 限流：默认按租户+接口 QPS 限流（读取 200 QPS、写入 50 QPS、导出 5 QPS），超限返回 `0000006`。

## 2 鉴权与端别

| 项 | 说明 |
|---|---|
| 鉴权 | OAuth2.1/OIDC，JWT（RS256）；`Authorization: Bearer {access_token}` |
| 端别 | `X-Client-Type`：`ADMIN`（管理端）/`PORTAL`（用户端）；须与令牌 `client_type` 一致，否则 `0000002` |
| 租户 | `X-Tenant-Id` 必填，须与令牌 `tenant_id` 一致 |
| 权限 | 功能权限码校验（如 `crm:lead:create`）；数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）行级过滤 |
| 幂等 | 写操作支持 `Idempotency-Key`（24h 有效）；金额/审批/结算类强制 |
| 追踪 | `X-Request-Id`（贯穿全链路）、`X-Trace-Id`（SkyWalking） |

**端别归属原则**：`/api/crm/v1/admin/**` 仅 `ADMIN` 可访问；其余 `/api/crm/v1/**` 仅 `PORTAL` 可访问（内部接口 `/internal/**` 仅服务间 mTLS 调用）。

## 4 逐接口定义

> 说明：所有接口均须携带第 2 章请求头；`data` 为统一响应体中的数据体。`PII` 字段返回时默认脱敏。

### CRM-API-001 创建线索

- **方法/路径**：`POST /api/crm/v1/leads`；**端别**：PORTAL；**鉴权**：`crm:lead:create`；**幂等**：支持（`Idempotency-Key`，`tenant_id` 维度）。
- **请求体**：

| 参数 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `name` | string | 是 | 1–128 | 线索名称/企业名 |
| `contactName` | string | 否 | ≤64 | 联系人 |
| `mobile` | string | 是 | 11 位手机号 | 手机号（加密存储） |
| `email` | string | 否 | 邮箱格式 | 邮箱 |
| `industry` | string | 否 | ≤64 | 行业 |
| `regionCode` | string | 否 | ≤16 | 区域 |
| `source` | string | 是 | 枚举 | 见数据字典 |
| `ownerId` | long | 否 | — | 指定归属（为空则走分配规则） |

- **响应示例**：

```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": 1789012345678901234,
    "uuid": "3f2a1b4c-5d6e-7f8a-9b0c-1d2e3f4a5b6c",
    "leadNo": "CRM202610000123",
    "name": "星河科技有限公司",
    "mobile": "138****8888",
    "status": "NEW",
    "ownerId": 10086,
    "createdAt": "2026-10-19T08:00:00.000+08:00"
  },
  "requestId": "b1f2c3d4-...",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- **错误码**：`0000003`（参数）、`1001001`（手机号重复）、`1000002`（无权限）。
- **幂等**：相同 `Idempotency-Key` 24h 内返回首次结果。

### CRM-API-002 批量导入线索

- **方法/路径**：`POST /api/crm/v1/leads/import`；**端别**：PORTAL；**鉴权**：`crm:lead:import`；**幂等**：支持。
- **请求**：`multipart/form-data`，字段 `file`（xlsx/csv，≤20MB）、`duplicateStrategy`（SKIP/UPDATE，默认 SKIP）。
- **响应**：`{ "taskId": "...", "total": 1200, "success": 1180, "failed": 20, "errorFileId": "..." }`（异步生成导入报告）。
- **错误码**：`1001001`（重复行）、`0000006`（超出导入 QPS）。

### CRM-API-003 线索查重

- **方法/路径**：`POST /api/crm/v1/leads/check-duplicate`；**端别**：PORTAL；**鉴权**：`crm:lead:view`。
- **请求体**：`{ "mobile": "13800008888", "name": "星河科技", "email": "a@x.com" }`
- **响应**：`{ "exactMatch": [ { "id":..., "leadNo":"CRM202610000123" } ], "fuzzyMatches": [ ... ] }`
- **说明**：`mobile` 先哈希后精确匹配；`name/email` 模糊匹配（pg_trgm/ES）。

### CRM-API-004 线索转化

- **方法/路径**：`POST /api/crm/v1/leads/{id}/convert`；**端别**：PORTAL；**鉴权**：`crm:lead:transfer`；**幂等**：强制。
- **请求体**：`{ "createCustomer": true, "createContact": true, "createOpportunity": true, "opportunityName": "...", "amount": 200000, "stage": "S1" }`
- **响应**：`{ "leadId":..., "customerId":..., "contactId":..., "opportunityId":..., "opportunityNo":"CRM202610000124" }`
- **错误码**：`1001002`（线索状态不允许转化）、`0000005`（并发冲突）。

### CRM-API-005 线索详情

- **方法/路径**：`GET /api/crm/v1/leads/{id}`；**端别**：PORTAL；**鉴权**：`crm:lead:view`。
- **响应**：返回线索主档 + `activities`（近期活动）+ `opportunities`（关联商机）+ `tags`；手机号脱敏，需 `crm:lead:pii:view` 且审计后才返回明文。

### CRM-API-006 线索分配

- **方法/路径**：`POST /api/crm/v1/leads/{id}/assign`；**端别**：PORTAL；**鉴权**：`crm:lead:assign`。
- **请求体**：`{ "ownerId": 10086, "reason": "区域匹配" }`
- **规则**：`ownerId` 为空时按分配规则（轮询/负载/指定）执行；目标为离职账号则回退部门池。

### CRM-API-007 线索回收至公海

- **请求体**：`{ "poolId": 1, "reason": "30天无活动" }`

### CRM-API-008 领取公海线索

- **请求体**：`{ "leadIds": [1789012345678901234], "poolId": 1 }`
- **错误码**：`1001002`（已被领取）、`0000002`（超出领取上限）。

## 5 开放 API

### 5.1 通用

- 前缀：`/openapi/crm/v1`，经 `fenglin-openapi-service` 统一接入。
- 鉴权：OAuth2.1 授权码模式签发令牌 + 应用级 AppKey/AppSecret（HMAC-SHA256 签名，签名头 `X-FL-Signature`、`X-FL-Timestamp`、`X-FL-App-Key`）。
- 配额：按应用/接口维度 QPS（默认 20），超限返回 `0000006`。
- 沙箱：`/openapi/crm/v1/sandbox/**`，与生产隔离，配额独立。

### 5.2 对外开放资源

| 方法 | 路径 | 说明 | 权限范围 |
|---|---|---|---|
| POST | `/openapi/crm/v1/leads` | 创建线索 | `crm.lead.write` |
| GET | `/openapi/crm/v1/leads/{id}` | 查询线索 | `crm.lead.read` |
| GET | `/openapi/crm/v1/customers` | 查询客户 | `crm.customer.read` |
| GET | `/openapi/crm/v1/opportunities` | 查询商机 | `crm.opportunity.read` |
| POST | `/openapi/crm/v1/partner/deals` | 伙伴报备 | `crm.partner.deal.write` |
| GET | `/openapi/crm/v1/opinions` | 查询舆情 | `crm.opinion.read` |

### 5.3 签名示例

```
StringToSign = HTTPMethod + "\n" + CanonicalURI + "\n" + CanonicalQuery + "\n"
             + "X-FL-App-Key:" + appKey + "\n" + "X-FL-Timestamp:" + ts + "\n"
X-FL-Signature = Base64(HMAC-SHA256(appSecret, StringToSign))
```

时间戳容差 ±300s；签名失败返回 `0000001`。

### 6.2 Webhook 投递规范

```json
POST {subscriber_callback_url}
Headers:
  X-FL-Event: crm.lead.converted
  X-FL-Event-Id: evt_20261019000001
  X-FL-Timestamp: 1760774400
  X-FL-Signature: Base64(HMAC-SHA256(secret, eventId + "." + timestamp + "." + body))
Body:
{
  "event": "crm.lead.converted",
  "eventId": "evt_20261019000001",
  "tenantId": "T000001",
  "occurredAt": "2026-10-19T08:00:00.000+08:00",
  "data": { "leadId": 1789012345678901234, "customerId": 20001, "opportunityId": 30001 }
}
```

- **重试**：投递失败按指数退避重试，最多 6 次（间隔 10s/30s/2m/10m/1h/6h）。
- **幂等**：消费方按 `eventId` 去重。
- **验签**：`HMAC-SHA256(secret, eventId + "." + timestamp + "." + body)`；时间戳容差 ±300s。
- **订阅**：通过 `fenglin-openapi-service` 开发者门户配置订阅与回调地址。

## 7 版本与兼容

1. 版本以 URL 段体现（`/v1`）；重大不兼容变更升 `/v2`，旧版本保留 ≥ 12 个月。
2. 兼容性策略：新增字段为向后兼容；字段语义变更或删除视为不兼容。
3. 废弃流程：先标记 `Deprecated`（OpenAPI `deprecated: true`）并在变更公告中通知，≥ 6 个月后下线。
4. 新增枚举值消费方需容错；错误码只增不改语义。
5. OpenAPI 3.1 契约（`openapi.yaml`）随服务发布，作为接口契约唯一来源。

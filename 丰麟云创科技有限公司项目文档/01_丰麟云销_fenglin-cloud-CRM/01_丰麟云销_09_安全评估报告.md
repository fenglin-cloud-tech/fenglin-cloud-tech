## 2 等保三级控制矩阵逐项对照

> 结论列：✔ 满足；△ 部分满足（见加固）；✘ 不满足。

### 2.1 安全物理环境 / 安全通信网络

| 控制项 | 三级要求 | 云销实现 | 结论 |
|---|---|---|---|
| 通信传输保密性 | 采用密码技术保证通信过程数据保密性 | 客户端↔网关 TLS 1.2+（推荐 1.3）；微服务间 mTLS；证书由 KMS 签发与轮换 | ✔ |
| 通信传输完整性 | 保证通信过程数据完整性 | TLS 记录层完整性校验；关键回调 HMAC-SHA256 签名 | ✔ |
| 网络架构 | 划分安全区域、边界防护 | K8s NetworkPolicy 隔离命名空间；网关统一入口；内部接口仅服务间 mTLS 可达 | ✔ |
| 网络访问控制 | 按最小权限控制网络访问 | 数据库/中间件仅应用网段可达；管理端口禁用公网 | ✔ |

### 2.2 安全区域边界

| 控制项 | 三级要求 | 云销实现 | 结论 |
|---|---|---|---|
| 边界防护 | 非授权设备不得接入 | WAF + 网关白名单 + K8s 网络策略 | ✔ |
| 访问控制 | 在边界对源/目的/端口控制 | 网关路由与端别策略（ADMIN/PORTAL 前缀强制）；Sentinel 按租户+接口限流 | ✔ |
| 入侵防范 | 检测并阻断已知攻击 | IDS/IPS + WAF 规则（SQLi/XSS/命令注入）；依赖 SCA 阻断高危组件 | ✔ |
| 恶意代码防范 | 边界恶意代码检测 | 上传文件病毒扫描 + 类型/大小白名单 | ✔ |
| 安全审计 | 边界审计与告警 | 网关访问日志 + 异常流量告警（Prometheus Alertmanager） | ✔ |

### 2.3 安全计算环境

| 控制项 | 三级要求 | 云销实现 | 结论 |
|---|---|---|---|
| 身份鉴别-唯一标识 | 用户标识唯一 | 中台 IAM 统一账号（员工工号唯一） | ✔ |
| 身份鉴别-复杂度与周期 | 口令复杂度、定期更换 | 口令复杂度策略 + 90 天到期提醒 | ✔ |
| 身份鉴别-MFA | 双因子鉴别（重要操作） | 登录 MFA；管理端高风险操作（跨租户/佣金支付/批量导出）二次验证 | ✔ |
| 身份鉴别-失败锁定 | 登录失败处理 | 连续 5 次失败锁定 15 分钟；会话空闲 30min 超时 | ✔ |
| 访问控制-最小权限 | 授予最小权限 | RBAC 功能权限码 + 数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）+ 字段权限 | ✔ |
| 访问控制-职责分离 | 关键操作分离 | 审批链多角色分离（申请人≠审批人）；三员分立（系统管理/审计管理/安全管理） | ✔ |
| 访问控制-默认拒绝 | 默认拒绝未授权访问 | 无权限码默认拒绝；跨租户默认拒绝（RLS）；`0000002` 返回 | ✔ |
| 安全审计-全覆盖 | 覆盖重要用户与操作 | 全链路审计（登录、权限变更、业务关键操作、PII 查看、导出、审批） | ✔ |
| 安全审计-防篡改 | 审计记录防未授权删改 | 审计写 `fenglin-audit-service`（哈希链 + WORM）；应用侧无删除接口 | ✔ |
| 安全审计-留存 | 留存 ≥ 6 个月 | 操作审计留存 12 个月，安全日志 ≥ 6 个月 | ✔ |
| 入侵防范-最小安装 | 仅安装必要组件 | 基础镜像最小化 + 无多余端口/服务 | ✔ |
| 入侵防范-漏洞修补 | 及时修补漏洞 | 镜像扫描 + 依赖 SCA + 发布流水线阻断高危 | ✔ |
| 恶意代码-主机防护 | 主机恶意代码防范 | HIDS + 容器镜像扫描 + 运行时防护 | ✔ |
| 可信验证 | 关键设备/程序可信验证 | 镜像签名校验（cosign）+ ArgoCD 校验基线 | △（私有化环境需开启可信根） |
| 数据完整性 | 传输/存储完整性 | TLS、HMAC、数据库约束与校验（金额/编号一致性校验） | ✔ |
| 数据保密性 | 传输/存储加密 | PII AES-256-GCM；数据库 TDE；密钥 KMS 管理、轮换 ≤90 天 | ✔ |
| 数据备份恢复 | 本地/异地备份与演练 | 每日全备 + 增量、异地容灾、季度演练（RPO 2.4min/RTO 18min） | ✔ |
| 剩余信息保护 | 存储/内存剩余信息清除 | 逻辑删除 + 物理清理任务；日志脱敏；介质销毁流程 | △（内存级清零依赖运行时，见加固） |
| 个人信息保护 | 最小必要、脱敏、授权、审计 | 手机号加密存储 + `mobile_hash` 检索；展示脱敏；明文查看需 `crm:lead:pii:view` 并审计 | ✔ |

## 3 威胁建模（STRIDE）

| 威胁类别 | 场景 | 资产 | 攻击面 | 缓解措施 | 残余等级 |
|---|---|---|---|---|---|
| **S**poofing 身份伪造 | 伪造令牌访问接口；伙伴伪造为厂商销售 | 全部接口 | 网关、JWT | JWT RS256 签名校验；`X-Client-Type` 与令牌 `client_type` 一致校验；`X-Tenant-Id` 与令牌一致；MFA；伙伴账号独立身份且 `is_partner=true` | 低 |
| **S**poofing | Webhook 伪造回调 | 事件订阅 | 开放 API | HMAC-SHA256 签名校验 + 时间戳防重放 + 幂等键 | 低 |
| **T**ampering 篡改 | 篡改报价折扣/佣金金额 | 报价、佣金 | 业务接口 | 服务端重算与校验；金额字段服务端权威；审批版本校验；审计留痕；幂等键防重放 | 低 |
| **T**ampering | 篡改审计日志 | 审计 | 审计库 | 哈希链 + WORM；应用仅追加；异常篡改告警 | 低 |
| **R**epudiation 抵赖 | 否认提交报备/审批 | 报备、审批 | 业务操作 | 操作人标识 + 时间戳 + 客户端信息审计；审批意见不可删改 | 低 |
| **I**nformation Disclosure 信息泄漏 | 越权读取其他租户/部门/伙伴数据 | 客户/线索/PII | 数据查询 | RLS 行级安全；数据权限 SQL 拦截；伙伴数据 `partner_id` 强隔离（`1007002`）；字段权限脱敏；跨租户默认拒绝 | 低 |
| **I**nformation Disclosure | PII 明文泄漏 | 手机号 | 数据库/接口/导出 | AES-256-GCM 存储；展示脱敏；导出脱敏或需审批；日志脱敏；明文查看审计 | 低 |
| **I**nformation Disclosure | 附件越权下载 | 附件 | 文件服务 | 附件鉴权（对象级权限）+ 短时签名 URL + 水印 | 低 |
| **D**enial of Service 拒绝服务 | 高频请求打满 | 服务/DB | 全部接口 | 网关限流（读 200/写 50/导出 5 QPS）；Sentinel 熔断降级；导入/导出异步化；HPA 弹性扩容 | 中（见残余风险 R-04） |
| **D**enial of Service | 大文件/深分页拖垮 | ES/DB | 检索/列表 | 文件大小白名单；限制 `size` ≤200；ES `search_after`；查询超时熔断 | 低 |
| **E**levation of Privilege 权限提升 | 普通用户调用管理端配置接口 | 配置接口 | ADMIN 前缀 | 端别强校验；权限码校验；管理端接口仅 ADMIN 令牌可达 | 低 |
| **E**levation of Privilege | 伙伴用户提升为厂商角色 | 伙伴门户 | 角色服务 | 伙伴身份不可通过自助修改角色；角色变更仅管理端且审计 | 低 |

## 4 漏洞与风险

### 4.1 扫描与渗透结果汇总

| 测试项 | 范围 | 结果 |
|---|---|---|
| SAST（SonarQube） | 后端 + 前端 | 阻断级 0；严重 0；一般 6（已修复 6） |

## 5 加固措施

| 类别 | 加固项 | 措施 |
|---|---|---|
| 传输 | 全链路加密 | 强制 TLS 1.2+（推荐 1.3）；HSTS；内部 mTLS；禁用弱套件 |
| 存储 | 加密与密钥 | PII AES-256-GCM + TDE；KMS 托管密钥、轮换 ≤90 天；`{field}_hash` 唯一性替代明文索引 |
| 访问 | 最小权限 | RBAC+ABAC+数据权限+字段权限；跨租户默认拒绝；伙伴数据强隔离 |
| 认证 | 强认证 | MFA；5 次失败锁定；会话 30min 超时；令牌短期有效 + 刷新令牌轮换 |
| 审计 | 不可篡改与留存 | 哈希链 + WORM；留存 12 个月；PII 查看/导出/跨租户强制审计 |
| 输入输出 | 校验与编码 | 参数白名单校验；统一异常码；输出编码防 XSS；文件类型/大小白名单 + 病毒扫描 |
| 依赖 | 供应链安全 | 镜像签名校验 + SCA + 镜像扫描；无高危依赖进入发布 |
| 运行时 | 防护与隔离 | HIDS + 容器最小权限（非 root、只读根文件系统）+ NetworkPolicy |
| 剩余信息 | 清理 | 逻辑删除 + 定时物理清理；日志与缓存脱敏；介质销毁流程 |
| 合规 | 个人信息保护 | 最小必要采集；告知同意；脱敏展示；授权访问；可审计；支持删除请求（逻辑删除+清理） |

## 6 合规结论

1. 对照 GB/T 22239-2019 三级基本要求与 FL-HUB-STD-001 第 8 章控制矩阵，丰麟云销 **11 类控制域核心项全部满足，2 项部分满足**（可信验证、剩余信息保护的内存级清零），已列入加固计划；
2. OWASP Top 10（2021）逐项测试未发现高危可 exploitable 漏洞；中低危发现项已全部修复；
3. 越权（水平/垂直）、PII 泄漏、注入、并发滥用等专项测试全部通过；
4. 容灾演练 RPO 2.4min、RTO 18min，备份恢复有效；
5. **合规结论：达到网络安全等级保护三级要求，可提交测评**；无高危漏洞遗留（与 AC-12 一致）。

## 7 残余风险

| 编号 | 残余风险 | 等级 | 说明 | 缓解与跟踪 |
|---|---|---|---|---|
| R-01 | 可信验证依赖部署环境可信根 | 低 | 私有化客户若未开启可信根，镜像签名校验降级 | 私有化交付清单中强制开启；交付验收项 |
| R-02 | 内存级剩余信息保护依赖运行时 | 低 | JVM/容器内存清零非应用可控 | 启用容器内存隔离与运行时防护；登记为平台级残余 |
| R-03 | 开放 API 密钥托管风险 | 低 | AppSecret 泄漏可导致越权调用 | KMS 托管 + 定期轮换 + 调用审计 + 配额限流 |
| R-04 | 分布式拒绝服务（大规模 DDoS） | 中 | 应用层限流无法抵御流量型 DDoS | 依赖云厂商 DDoS 高防 + WAF 清洗；保留弹性扩容；演练应急 |
| R-05 | 第三方 AI 情感识别结果偏差 | 低 | 模型误判影响预警准确性 | 置信度 <0.6 人工复核；人工修正回流校准；可降级关键词规则 |
| R-06 | 舆情采集合规边界 | 低 | 外部数据源使用需持续合规 | 遵守法律法规与 robots；来源可信度评分；敏感内容转合规工单 |
| R-07 | 数据库预留表未启用 | 低 | 8 张预留表当前无数据，无直接风险 | 后续启用前纳入安全评审与权限配置 |

> 残余风险均登记至安全风险台账，按季度复核；R-04 纳入年度应急演练。

## 1 设计令牌

### 1.1 色彩令牌（继承规范 9.1，强制）

| 令牌 | 值 | 云销用途 |
|---|---|---|
| `--fl-color-primary` | `#1F5EFF` | 主色（丰麟蓝）：主按钮、选中态、关键数据高亮 |
| `--fl-color-primary-hover` | `#3D78FF` | 主色悬停 |
| `--fl-color-success` | `#16A34A` | 健康、赢单、已续费、推荐者 |
| `--fl-color-warning` | `#F59E0B` | 关注、待跟进、被动者、一般预警 |
| `--fl-color-danger` | `#DC2626` | 危急、流失、输单、贬损者、P0 预警 |
| `--fl-color-info` | `#64748B` | 信息、未启用、归档 |
| `--fl-color-text-primary` | `#1E293B` | 主文本 |
| `--fl-color-text-secondary` | `#64748B` | 次文本 |
| `--fl-color-bg` | `#F5F7FA` | 页面背景 |
| `--fl-color-surface` | `#FFFFFF` | 卡片/容器 |
| `--fl-color-border` | `#E2E8F0` | 边框/分割线 |

### 1.2 业务语义色（云销扩展，基于上表令牌）

| 语义场景 | 令牌组合 | 示例 |
|---|---|---|
| 线索状态 | NEW=info / FOLLOWING=primary / CONVERTED=success / INVALID=info / NURTURING=warning | 线索列表状态标签 |
| 商机阶段 | S1–S4=primary 梯度（20/40/60/80% 透明度）/ WON=success / LOST=danger | 商机看板列头 |
| 健康度等级 | HEALTHY=success / WATCH=warning / RISK=danger / CRITICAL=danger（深） | 健康度徽标 |
| NPS 分层 | 推荐者=success / 被动者=warning / 贬损者=danger | NPS 分布条 |
| 情绪极性 | 正=success / 中=info / 负=danger | 情绪列表 |
| 续费倒计时 | T-90/60=info / T-30/15=warning / T-7=danger | 续费台账角标 |
| 预警等级 | P0=danger / P1=warning / P2=info / P3=info（浅） | 预警卡片 |
| 伙伴等级 | 金牌（#C8A24A 金）/ 银牌（#94A3B8 银）/ 认证=primary / 注册=info | 伙伴徽章 |
| 佣金状态 | PENDING=info / APPROVED=primary / PAID=success / REVERSED=danger | 佣金状态标签 |

> 金色/银色为业务扩充色，仅用于伙伴等级徽章与图表图例，不作为交互控件主色使用。

### 1.3 字体与排版

| 令牌 | 值 |
|---|---|
| `--fl-font-family` | `"PingFang SC","Microsoft YaHei",-apple-system,"Segoe UI",Roboto,sans-serif` |
| `--fl-font-size-xs/sm/base/lg/xl` | `12/13/14/16/20px` |
| `--fl-radius-sm/md/lg` | `4/8/12px` |
| `--fl-space-xs/sm/md/lg/xl` | `4/8/16/24/32px` |
| `--fl-shadow-sm/md` | `0 1px 2px rgba(0,0,0,.05)` / `0 4px 16px rgba(0,0,0,.08)` |

金额数字统一使用等宽数字 `font-variant-numeric: tabular-nums`，金额千分位、两位小数、币种前缀。占比/指标变化使用 `+/-` 与语义色。

### 1.4 双端令牌应用差异

| 维度 | 管理端（`/admin/crm`） | 用户端（`/app/crm`） |
|---|---|---|
| 表格尺寸 | `size=small`（紧凑，行高 36px） | `size=default`（舒适，行高 44px） |
| 主色使用 | 中性为主，主色用于关键数据/操作 | 主色为主导，辅以场景化插画 |
| 圆角倾向 | `--fl-radius-sm/md` | `--fl-radius-md/lg` |
| 卡片阴影 | `--fl-shadow-sm` | `--fl-shadow-md` |
| 表单标签位置 | 右对齐（顶对齐用于筛选区） | 顶对齐 |
| 页面标题 | 面包屑 + 页面标题 | 顶部导航 + 大标题 |

### 4.1 通用组件（双端共用，基于同一 Token）

| 组件 | 说明 |
|---|---|
| `FlButton` | 主/次/危险/文字按钮，含 `loading`、`disabled` 态 |

## 5 交互流程

### 5.1 线索录入与查重（用户端，A1）

```
我的线索 → [新建线索] → 抽屉表单
 → 填写企业名/手机号/来源（手机号实时校验 11 位）
 → 失焦触发查重（CRM-API-003）
     ├ 命中精确重复 → 弹出 LeadDuplicateDialog（显示重复记录，可跳转/合并，返回 1001001）
     └ 命中疑似 → 顶部温和提示，可继续提交
 → 提交成功 → Toast"线索已创建" → 按分配规则分配 → 5 秒内被分配人收到通知
```

### 5.2 线索转化（用户端，A1）

```
线索详情 → [转化为客户] → 校验（必填：企业名、手机号）
 → 选择/新建客户、生成主要联系人、可选同时创建商机（填金额/阶段/预计成交日）
 → 确认 → 事务提交（客户+联系人+商机）→ 保留来源链路 → 线索状态置 CONVERTED
 → 并发冲突返回 1000005，提示刷新后重试
```

### 5.3 商机阶段推进（用户端，A1）

```
商机看板 → 拖拽卡片至下一阶段
 → 后端校验准入准则（CRM-API-022）
     ├ 不满足（如 S3 缺预计金额/成交日/关键决策人）→ 弹出 StageGateDrawer 补全，返回 1002001
     └ 满足 → 更新阶段 + 写 crm_opportunity_stage_log
 → 进入 S4 前若无报价单 → 阻断并引导创建报价单
 → 推进成功 → 看板与漏斗刷新；WON 触发 crm.opportunity.won 事件（通知 A2/A4）
```

### 5.4 报价折扣审批（用户端，A1）

```
报价单编辑 → 计算综合折扣
 → [提交审批]（强制 Idempotency-Key）
     ├ 折扣 ≤ 20% → 自动通过 → 状态 APPROVED
     ├ 20% < 折扣 ≤ 35% → crmQuotationApproval：销售经理审批
     └ 折扣 > 35% 或金额 > 100 万 → 销售经理 → 财务复核 → 总经理审批
 → 审批意见与版本校验（版本不一致拒绝，提示重新提交）
 → 通过 → 发布 crm.quotation.approved → 可转合同
```

### 5.5 续费提醒与审批（用户端，A2）

```
客户成功工作台 → 续费台账
 → 系统按 T-90/60/30/15/7 自动生成提醒（站内信/邮件）
 → CSM [提交审批] → crmRenewalApproval（主管→财务；S 级追加总监）
 → 通过 → SIGNED → 触发服务合同与 A1 合同更新
 → 客户明确不续 → 转 CHURNED（必填流失原因）→ 触发赢回任务
```

### 5.6 情绪预警处置（用户端，A3）

```
情绪实时监测台 → 负面事件达阈值 → 生成预警（P0/P1）
 → 站内信+邮件+Webhook 触达责任人（≤5 分钟）
 → [认领] → ACK → 填写处置措施 → PROCESSING → [解决] → CLOSED
 → 超时未解决 → ESCALATED 升级至主管
 → 贬损者（NPS 0–6）自动生成 VoC 条目并指派 CSM 回访
```

### 5.7 伙伴报备与裁决（用户端/管理端，A4）

```
伙伴门户 → [报备商机] → 填写客户/金额/预计成交
 → 查重与保护期校验（CRM-API-062）
     ├ 无冲突 → 自动通过（或渠道经理审批）→ APPROVED → 生成 A1 关联商机
     └ 冲突 → CONFLICT → 管理端「冲突裁决台」裁决（保护期+优先级）
             └ 通过 → APPROVED；驳回 → REJECTED（伙伴可申诉）
 → 保护期到期未成交 → EXPIRED（自动释放）
```

### 5.8 舆情预警处置（用户端，A5）

```
舆情看板/检索 → 负面命中阈值 → 生成预警
 → 推送市场/品牌/关联销售（P0 立即，P1 汇总）
 → [认领] → 处置（记录动作与结果）→ CLOSED
 → 舆情命中已有客户 → 自动关联并提醒对应 CSM/销售
```

## 7 状态规范

| 状态 | 规范 |
|---|---|
| 加载 | 骨架屏（表格/卡片/看板/树），禁止空白闪烁；长列表首屏 ≤ 1s（内网） |
| 空态 | 插画 + 引导按钮（如"暂无线索，立即新建"），区分"无数据"与"无权限" |
| 错误 | 错误插图 + 错误码 + 重试按钮；场景化提示（如 `1001001` 线索重复给出重复记录入口） |
| 无权限 | 403 插画 + 申请权限指引；跨端访问提示"请切换至管理端/用户端" |
| 成功 | Toast（3s 自动消失，`role="status"`） |
| 关键操作确认 | 二次确认（删除、转合同、流失、佣金支付、批量回收、跨租户查看） |
| 部分成功 | 批量导入展示成功/失败行数与原因，可下载错误报告 |
| 长时任务 | 进度条 + 后台执行提示（导出、健康度重算、报告生成），完成后消息通知 |
| 实时态 | 情绪/舆情预警红点与角标；连接断开降级为轮询并提示 |
| 审批中 | 单据锁定编辑，展示审批流程图与当前节点，支持催办 |

## 8 可访问性

| 项 | 要求 |
|---|---|
| 对比度 | 正文文本与背景 ≥ 4.5:1，大字（≥18px 或 14px 加粗）≥ 3:1 |
| 键盘导航 | 全功能键盘可达；Tab 顺序合理；表格支持方向键；看板卡片支持键盘推进 |
| 焦点样式 | 明显焦点环（`--fl-color-primary`），不依赖颜色单一维度 |
| 语义化 | 正确使用 `label`、`aria-*`；图标按钮带 `aria-label`；图表提供数据表替代 |
| 动态提示 | Toast/错误使用 `role="status"`/`role="alert"`；预警播报 `aria-live` |
| 缩放 | 支持 200% 缩放不破版 |
| 动效 | 尊重 `prefers-reduced-motion`，可关闭过渡动画 |
| 国际化 | 文案外置 i18n，默认 `zh-CN`，预留 `en-US`；日期/数字/金额本地化 |
| 表单 | 必填项明确标注（`*` + `aria-required`），错误信息与字段关联并聚焦首个错误 |
| 色彩语义 | 状态不仅靠颜色区分，同时使用图标/文字（如健康度同时显示等级文字） |

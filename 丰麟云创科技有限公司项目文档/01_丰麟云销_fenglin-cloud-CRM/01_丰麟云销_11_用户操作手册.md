## 1 快速开始

### 1.1 三步上手

1. **登录**：访问 `https://crm.fenglincloud.com/app/crm`，使用企业账号登录（支持 SSO / 企微 / 飞书 / 钉钉扫码），首次登录完成 MFA 绑定。
2. **认识工作台**：进入「我的工作台」，查看今日待办、我的目标、续费倒计时、待处理预警。
3. **完成第一个动作**：点击右上角「＋ 快捷新建」，创建一条线索或记录一次跟进。

### 1.2 运行环境

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome/Edge ≥ 110、Safari ≥ 16、Firefox ≥ 110 |
| 屏幕 | 支持 1440/1200/992/768 断点；移动端最小点击区 44×44px |
| 网络 | 建议 4G 及以上；页面首屏内网 ≤1s、4G ≤2s |
| 移动端 | 支持 PWA 安装与消息推送 |

### 1.3 角色与可见范围

| 角色 | 主要可见范围 |
|---|---|
| 销售代表 | 本人负责的线索、客户、商机、活动（SELF） |
| 销售经理 | 本部门及下级（DEPT_AND_CHILD），含审批与团队报表 |
| 销售总监 | 本租户全部（ALL），含目标与全量报表 |
| CSM | 本人负责客户的成功计划、健康度、续费、流失预警 |
| 客户成功主管 | 本部门及下级，含续费审批与续费报表 |
| 渠道经理 / 渠道总监 | 伙伴、报备、佣金、冲突裁决（本部门/全租户） |
| 市场分析专员 | 舆情、竞品、市场洞察报告 |
| 伙伴用户 | 仅本伙伴自身的报备、佣金、协议、赋能内容 |
| 只读用户 | 授权范围内的查看权限，无写操作 |

## 2 登录与导航（用户端）

### 2.1 登录

1. 打开用户端地址 → 选择登录方式（账号密码 / 企业 SSO / 扫码）；
2. 输入企业账号与口令（口令需满足复杂度策略）；
3. 首次登录或异地登录需完成 MFA 二次验证；
4. 连续 5 次失败将锁定 15 分钟；空闲 30 分钟会话自动超时，需重新登录。

### 2.3 通用操作约定

- **新建**：多数列表页右上角提供「＋ 新建」；
- **筛选**：筛选区条件可折叠、可保存为常用视图；
- **批量**：列表首列勾选后出现批量操作条（分配、回收、导出等）；
- **导出**：导出为异步任务，完成后在消息中心下载；
- **字段脱敏**：手机号默认显示 `138****8888`，查看明文需相应权限且记录审计；
- **二次确认**：删除、转化、流失、提交审批等关键操作需确认。

## 3 分模块操作指引

### 3.1 A1 销售管理

#### 3.1.1 线索录入

1. 进入「销售 → 我的线索」，点击「＋ 新建线索」；
2. 填写企业名（必填）、联系人、手机号（必填）、邮箱、行业、区域、来源；
3. 手机号失焦时系统自动查重；若命中重复，弹出提示并展示重复记录，可**跳转查看**或**合并**；疑似重复仅提示，不阻断；
4. 未指定归属时，系统按「指定 → 区域/行业匹配 → 负载均衡 → 轮询」规则自动分配，被分配人 5 秒内收到通知。

【截图位：线索新建抽屉与查重提示】

#### 3.1.2 线索跟进与转化

1. 打开线索详情，点击「记录活动」选择类型（电话/邮件/拜访/微信），填写内容与下次跟进时间；
2. 线索状态流转：**新建 → 跟进中 → 已转化 / 无效 / 培育**；
3. 点击「转化为客户」：可同时创建客户、主要联系人与商机（填写预估金额、阶段、预计成交日），提交后保留来源链路；
4. 转化成功后线索置「已转化」，可在客户详情查看关联商机。

#### 3.1.3 公海池

1. 进入「销售 → 公海池」，可按行业/区域筛选；
2. 「领取」：受每日领取上限（默认 50 条）限制，超限会提示；
3. 线索超过配置天数（默认 30 天）无活动且无关联商机时，自动回收至公海（回收规则由管理员配置）。

#### 3.1.4 客户与联系人

1. 「销售 → 客户列表」查看客户，支持按分级（A/B/C/D）、行业、区域、负责人筛选；
2. 打开「客户 360° 视图」，可查看商机、合同、联系人、活动、情绪/NPS、舆情等聚合信息；
3. 在「联系人」页签维护多联系人，设置角色（决策人/影响人/使用人）与影响力，查看关系图谱。

【截图位：客户 360° 视图聚合页】

#### 3.1.5 商机与阶段推进

1. 进入「销售 → 商机看板」，卡片按阶段（S1–S4）分列展示；
2. 拖拽卡片推进阶段；系统校验准入准则：
   - 进入 S3 需填写**预计金额、预计成交日期、关键决策人**；
   - 进入 S4 需存在**已审批或待审批的报价单**；
   - 不满足时弹出必填项抽屉，补全后可继续；
3. 输单（LOST）必须填写输单原因；
4. 看板列头展示阶段加权预测（`金额 × 赢率 × 阶段系数`）。

【截图位：商机看板与阶段准入抽屉】

#### 3.1.6 报价与折扣审批

1. 在商机或独立入口点击「新建报价单」，添加产品行（数量、单价、折扣、税率），系统自动试算；
2. 综合折扣 ≤ 20% 时提交后自动通过；
3. 折扣 > 20% 触发审批：20%–35% 由销售经理审批；> 35% 增加财务复核与总经理审批；金额 > 100 万增加总经理审批；
4. 审批通过后可「转合同」；审批驳回可修改后重新提交（审批中的报价单不可编辑）。

【截图位：报价单编辑与审批时间线】

#### 3.1.7 活动、目标与业绩

- 「活动与日历」：记录并统计有效拜访、通话时长、邮件数，与日程打通；
- 「我的目标」：查看周期目标（签约额/回款额/商机数）与完成率；
- 「销售业绩」：查看团队/个人完成率、排名与销售漏斗。

### 3.2 A2 客户成功与续费管理

#### 3.2.1 客户成功台与健康度

1. 进入「客户成功 → 客户成功台」，查看在服客户、成功计划进度、健康度分布；
2. 「健康度看板」：按客户/客户群/CSM 维度查看健康度分数与等级（**≥80 健康 / 60–79 关注 / 40–59 风险 / <40 危急**）；
3. 点击任一客户可下钻查看**因子明细**（使用活跃度 30%、工单 15%、情绪 20%、NPS 15%、回款 10%、关键人 5%、深度 5%），权重由管理员配置。

【截图位：健康度看板与因子明细】

#### 3.2.2 成功计划

1. 成交客户自动/手动创建成功计划；
2. 维护里程碑（上线、首值、月活、扩展）的负责人与达成状态；
3. 全部里程碑完成计划置「已完成」。

#### 3.2.3 续费台账与审批

1. 进入「客户成功 → 续费台账」，按到期区间、状态、负责人筛选；
2. 系统按 **T-90/60/30/15/7 天**分级提醒（站内信+邮件），倒计时按级别着色（蓝/黄/红）；
3. 点击「提交审批」发起续费审批（主管 → 财务；S 级战略客户追加总监）；驳回可修改后重新提交；
4. 状态流转：**待跟进 → 报价 → 审批中 → 已签约 → 已完成**；客户明确不续则转「已流失」并**必须填写流失原因**。

#### 3.2.4 流失预警与增购

- 「流失预警」：健康度低于阈值或连续负向事件自动生成预警与赢回任务，处置后关闭；
- 「增购推荐」：基于未使用模块与相似客户生成建议，可一键转商机。

### 3.3 A3 客户情绪与 NPS

#### 3.3.1 NPS 看板与投放

1. 「体验 → NPS 看板」：查看 NPS 趋势、分布、开放题词云（可按客户群/产品线/CSM 维度）；
2. 「问卷投放」：选择问卷与投放渠道（邮件/短信/站内/企微/飞书），按客户分层或触点事件触发；
3. 频次控制：同一客户 30 天内同类问卷最多 1 次；黑名单客户不投放。

#### 3.3.2 情绪监测与预警处置

1. 「情绪监测台」：查看多源情绪记录（工单/会话/评价/邮件/社媒）的极性、情绪标签与置信度；
2. 负面事件达阈值生成预警（P0/P1）并指派责任人，**触达 ≤ 5 分钟**（站内信/邮件/Webhook）；
3. 处置流程：**认领 → 已确认 → 处置中 → 已解决**；超时未解决自动升级至主管；
4. 置信度 < 0.6 的结果标记「待人工复核」，可人工修正情绪标签。

【截图位：情绪监测台与预警处置面板】

#### 3.3.3 客户之声（VoC）

1. 「客户之声工作台」汇集 NPS 开放题、情绪记录与投诉；
2. 分类归档并指派责任人，按 SLA 处置（P0 24h / P1 72h / P2 7 天 / P3 30 天），超时升级；
3. 贬损者（NPS 0–6）自动生成 VoC 条目并指派 CSM 回访；关闭时记录处理结果。

### 3.4 A4 合作伙伴/渠道生态（PRM）

#### 3.4.1 伙伴门户（伙伴用户）

1. 登录用户端进入「渠道 → 伙伴门户首页」，查看本月报备、通过率、待结佣金、保护期客户；
2. 「报备提交」：填写客户、金额、预计成交日期后提交；系统校验保护期与查重；
3. 「我的报备」：查看状态（已提交/已通过/冲突/已驳回/已过期）与保护期截止日；
4. 「我的佣金」：查看佣金单号、金额与状态（待结算/已审批/已支付）；金额不可编辑；
5. 「培训认证」：报名课程、参加认证考试、下载物料；认证状态与等级挂钩。

【截图位：伙伴门户首页与报备提交】

#### 3.4.2 渠道经理操作（厂商侧）

- 报备审批/裁决：在「渠道 → 报备列表」处理待审报备；冲突报备按保护期与优先级裁决；
- 佣金结算：发起佣金计算与结算，跟踪结算链路（待结算 → 已审批 → 已支付）；
- 伙伴绩效：查看伙伴贡献排行与趋势（报备数、成交额、佣金、认证）。

> 伙伴数据严格隔离：伙伴用户仅可见本伙伴数据；越权访问将被拒绝。

### 3.5 A5 舆情与竞品监测

#### 3.5.1 舆情看板与检索

1. 「舆情 → 舆情看板」：按热度、情感、来源、时间、关键词查看多维看板；
2. 「舆情检索」：输入关键词全文检索（支持品牌词/产品词/负面词），可按来源与情感过滤。

#### 3.5.2 负面预警处置

1. 负面舆情达阈值生成预警并派单，P0 立即推送、P1 汇总推送；
2. 处置流程：**认领 → 处置中 → 已关闭**，记录处置动作与结果；
3. 舆情命中已有客户时自动关联并提醒对应 CSM/销售。

#### 3.5.3 竞品与市场洞察

1. 「竞品档案」：维护竞品产品、定价、动态、优劣势，查看情报时间轴；
2. 「竞品对比」：生成多维对比矩阵（功能/价格/服务/口碑），可导出对比报告；
3. 「市场洞察报告」：查看周期报告（趋势、声量份额 SOV、热点事件），支持定时推送。

## 4 常见任务场景

### 4.1 从线索到合同（销售代表）

```
新建线索 → 查重 → 记录活动 → 转化为客户+商机 → 推进阶段(补齐准入项)
 → 生成报价单 → 提交折扣审批 → 审批通过 → 转合同 → 成交(WON)
```

### 4.2 续费保卫（CSM）

```
续费台账查看 T-90/60/30/15/7 提醒 → 提前触达客户 → 健康度与情绪核查
 → 提交续费报价与审批 → 签约 → 若流失则填原因并启动赢回
```

### 4.3 负面体验应急处置（CSM/客户体验专员）

```
情绪监测台收到 P0 预警 → 5 分钟内认领 → 联系客户 → 记录处置措施
 → 解决并关闭 → 若为贬损者 → 转 VoC 回访 → 沉淀改进项
```

### 4.4 渠道报备与佣金（伙伴/渠道经理）

```
伙伴提交报备 → 系统查重与保护期校验 → (无冲突)审批通过 / (冲突)裁决
 → 生成关联商机 → 成交(WON) → 计算佣金(可复算) → 总监审批 → 财务对账 → 支付
```

### 4.5 市场竞争研判（市场分析专员）

```
配置监测关键词 → 采集舆情 → 看板分析情感与热度 → 处置负面预警
 → 维护竞品情报 → 生成对比矩阵 → 输出周期洞察报告并推送
```

## 5 FAQ

| 问题 | 解答 |
|---|---|
| 登录提示「未认证或令牌失效」怎么办？ | 会话空闲 30 分钟会自动超时，请重新登录；若仍失败请联系管理员核对账号状态。 |
| 为什么手机号显示为 `138****8888`？ | PII 字段默认脱敏展示；查看明文需相应权限且会记录审计。 |
| 新建线索提示「线索重复」？ | 系统按手机号查重命中已有线索。请在提示中查看重复记录，选择跳转或合并。 |
| 商机无法推进到下一阶段？ | 可能未满足阶段准入准则（如 S3 需填预计金额/成交日/关键决策人，S4 需有报价单）。请按弹窗补全。 |
| 报价提交后为什么进入审批？ | 综合折扣 > 20% 会触发审批；> 35% 或金额 > 100 万会增加审批节点。 |
| 为什么收不到续费提醒？ | 提醒按 T-90/60/30/15/7 天分级触达，请检查通知渠道绑定；如仍未收到请联系管理员。 |
| NPS 问卷收不到或被限制投放？ | 同一客户 30 天内同类问卷最多 1 次；投诉客户会进入 90 天黑名单。 |
| 伙伴看不到某个报备？ | 伙伴数据按 `partner_id` 隔离，仅可见本伙伴数据；越权访问会被拒绝。 |
| 预警为什么没有第一时间通知我？ | 预警按等级与责任人派单；若预警未达阈值或不满足触发条件则不推送；请核对责任人与通知渠道。 |
| 导出的文件在哪里下载？ | 导出为异步任务，完成后在「消息中心」下载；导出文件带水印与审计编号。 |
| 移动端可以使用全部功能吗？ | 支持响应式与 PWA；小屏下看板转为纵向列表，复杂配置类操作建议在桌面端进行。 |
| 忘记密码怎么办？ | 通过企业 SSO 重置或联系管理员重置；连续 5 次失败将锁定 15 分钟。 |

| 快捷键 | 功能 | 生效范围 |

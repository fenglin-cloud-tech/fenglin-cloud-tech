## 1 设计原则

| 编号 | 原则 |
|---|---|
| P1 | 所有业务表含 `id`、`tenant_id`、审计四字段、`deleted`、`version` |
| P2 | 主键 `bigint`（雪花 ID）；对外暴露资源编号用业务编码（如 `emp_no`、`req_no`） |
| P3 | 多租户逻辑隔离：`tenant_id` + RLS 行级安全策略 |
| P4 | 逻辑删除 `deleted`（0 正常 / 1 删除），并发控制 `version` 乐观锁 |
| P5 | PII（手机号、身份证号）AES-256-GCM 加密为 `*_enc`，并保存 `*_hash`（SHA-256+租户盐）用于唯一约束/检索 |
| P6 | 禁止在明文列建唯一索引 |
| P7 | 时间统一 `timestamptz`（UTC）；金额 `numeric(18,2)` |
| P8 | 全部 DDL 通过 Flyway 提交，禁止手工改库 |
| P9 | 枚举字段使用 `varchar` + 注释（避免 PG enum 变更困难），校验在应用层 |
| P10 | 组织树采用物化路径 `path`（点分层级）+ 邻接 `parent_id` 双写 |

### 1.1 公共字段定义（下文各表"公共字段"引用本表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | `bigint` | PK | 雪花 ID |
| `tenant_id` | `bigint` | NOT NULL | 租户 ID |
| `created_by` | `bigint` | NOT NULL | 创建人 |
| `created_at` | `timestamptz` | NOT NULL DEFAULT now() | 创建时间(UTC) |
| `updated_by` | `bigint` | NULL | 更新人 |
| `updated_at` | `timestamptz` | NULL | 更新时间(UTC) |
| `deleted` | `smallint` | NOT NULL DEFAULT 0 | 0 正常 / 1 删除 |
| `version` | `int` | NOT NULL DEFAULT 0 | 乐观锁 |

## 6 约束与 RLS

### 6.1 主键与唯一约束

- 主键：所有表 `PRIMARY KEY (id)`。
- 唯一约束：均以 `(tenant_id, 业务键)` 组合，避免跨租户冲突。
- 外键：采用逻辑外键（应用层保证），不在数据库层建立跨表 FK（便于分片与归档），关键引用列建索引。

### 6.2 RLS 行级安全策略

```sql
-- 每个业务表启用 RLS
ALTER TABLE talent_employee ENABLE ROW LEVEL SECURITY;

CREATE POLICY p_emp_tenant ON talent_employee
  USING (tenant_id = current_setting('app.tenant_id')::bigint);

-- 平台运营端跨租户（仅 platform:* 权限）
CREATE POLICY p_emp_platform ON talent_employee
  USING (current_setting('app.is_platform', true) = 'true');
```

- 应用连接在执行 SQL 前通过 `SET LOCAL app.tenant_id = {tenantId}` 注入租户上下文。
- `fenglin-talent-service` 以普通角色连接，禁止 `BYPASSRLS`；平台级跨租户查询使用独立受审计角色。
- 所有业务表统一启用 RLS，策略命名 `p_{表简称}_tenant`。

### 6.3 乐观锁

MyBatis-Plus `@Version` 作用于 `version` 字段；更新语句 `WHERE id = ? AND version = ?`，失败返回错误码 `0000005`（状态冲突）。

### 7.1 加密字段清单

### 7.2 密钥体系

```
KMS CMK（每租户一份，≤90 天轮换）
   └─ 加密得到 DEK → 存 talent_tenant_key.dek_cipher
         └─ 业务读写时解密 DEK 用于 AES-256-GCM
   └─ 租户盐 tenant_salt（密文存储）参与 hash
```

### 7.3 透明加解密实现

```java
// com.fenglin.talent.common.crypto
@MappedTypes(String.class)
public class AesGcmTypeHandler extends BaseTypeHandler<String> {
    // 写入：AES-256-GCM 加密 → *_enc 列
    // 读取：解密（受字段权限约束，越权返回脱敏）
}
```

- 业务代码仅操作明文 Java 字段，`*_enc` / `*_hash` 由 TypeHandler 自动维护。
- 归档/擦除：删除租户时销毁 DEK，使密文不可解（剩余信息保护）。
- 展示脱敏：手机号 `138****8888`，身份证 `110***********1234`。

### 7.4 检索策略

| 场景 | 方式 |
|---|---|
| 手机号/身份证号精确检索 | `WHERE phone_hash = SHA256(?, salt)` |
| 姓名模糊检索 | ES 倒排（不含 PII 明文） |
| 唯一性约束 | `*_hash` 唯一索引 |

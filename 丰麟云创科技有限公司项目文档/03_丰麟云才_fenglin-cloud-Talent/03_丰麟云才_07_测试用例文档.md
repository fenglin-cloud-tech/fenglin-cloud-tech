## 3 用例详情

> 表单：前置条件 / 测试步骤 / 预期结果 / 关联需求。

### 3.1 C1 人力资源

**TC-C1-002 组织移动级联重算 path**
- 前置：存在 总公司 > 研发部 > 平台组（path `/1/5/12/`）。
- 步骤：1) 调 `POST /orgs/{平台组id}/move`，`targetParentId=市场部`；2) 查询研发部与市场部子树。
- 预期：平台组 `parentId=市场部`，`path` 变为 `/1/8/12/`，`level` 正确；研发部子树不再含平台组。
- 关联：FR-C1-001 / BR-C1-001。

**TC-C1-003 组织移动形成环被拒**
- 前置：总公司 > 研发部。
- 步骤：将"总公司"移动到"研发部"之下。
- 预期：返回 `3001005`，组织树不变。
- 关联：EX-C1-001。

**TC-C1-010 新增员工**
- 前置：组织/岗位/职级已存在；管理端账号具备 `talent:admin:employee:create`。
- 步骤：调 `POST /employees`，`phone=13800138000`、`idCard=110101199001011234`。
- 预期：返回 `{id, empNo, empStatus:"PENDING"}`；库中 `phone_enc`/`id_card_enc` 为密文，`phone_hash`/`id_card_hash` 已写；响应无明文 PII。
- 关联：FR-C1-002 / FR-C1-003 / API-012。

**TC-C1-013 批量导入员工（部分失败）**
- 前置：准备含 1 条重复手机号的 xlsx。
- 步骤：`POST /employees/import`（`dryRun=false`）。
- 预期：`{total:N, success:N-1, failed:1, errors:[{row, reason:"3001001"}]}`；成功行落库，失败行不落库。
- 关联：API-014。

**TC-C1-042 招聘需求审批流**
- 前置：招聘需求处于 `DRAFT`，编制的余额充足。
- 步骤：1) `POST /recruit/requisitions/{id}/submit`；2) 工作流依次通过部门负责人、HRD、HR；3) 回调业务。
- 预期：状态 `DRAFT→APPROVING→RECRUITING`；发布事件 `talent.recruit.approved`；驳回分支回退 `DRAFT`。
- 关联：API-042 / MOD-C1-05。

**TC-C1-090 异动生效（快照）**
- 前置：员工现组织=A、岗位=P5、职级=P5。
- 步骤：`POST /transfers`（after: 组织=B、职级=P6）→ 审批通过 → `POST /transfers/{id}/effective`。
- 预期：`before_json`/`after_json` 正确；员工主数据更新为 B/P6；事件 `talent.employee.transferred` 发布。
- 关联：API-091 / BR-C1-009。

**TC-C1-101 离职联动 IAM 停用账号**
- 前置：员工在职，IAM 账号启用。
- 步骤：`POST /resignations` → 上级确认 → HR 审批（`approved=true`）。
- 预期：员工 `emp_status=RESIGNED`；IAM 账号 30s 内停用；事件 `talent.employee.resigned`。
- 关联：API-101 / BR-C1-010。

### 3.4 C4 敬业度与离职预测

**TC-C4-021 答题与提交（匿名不存标识）**
- 前置：问卷 `anonymous=true`。
- 步骤：员工 `POST /engagement/surveys/{id}/submit`。
- 预期：`talent_survey_response` 中 `employee_hash` 为 NULL，仅存 `dept_id` + 维度得分；接口/导出均无法反推个人。
- 关联：API-271 / BR-C4-001 / NFR-S-007。

**TC-C4-030 敬业度分析与 eNPS 计算**
- 前置：3120 份答卷，其中推荐者 1500、中立者 1200、贬损者 420。
- 步骤：`GET /engagement/surveys/{id}/analysis`。
- 预期：`enps = (48.08% − 13.46%)×100 ≈ +34.6`（按实际取整规则）；维度得分为加权平均；趋势数组正确。
- 关联：API-280 / BR-C4-004。

**TC-C4-031 样本不足部门结果隐藏**
- 前置：某部门答卷数=3（阈值 5）。
- 步骤：`GET /engagement/surveys/{id}/analysis?orgId=该部门`。
- 预期：返回 `3004005`（样本不足），`orgBreakdown` 不含该部门。
- 关联：API-280 / BR-C4-002。

**TC-C4-050 离职风险评分批处理**
- 前置：3400 名在职员工及特征就绪。
- 步骤：`POST /attrition/score/trigger`（`async=true`）。
- 预期：5min 内完成；`talent_attrition_risk` 每员工一条最新评分；`risk_level` 按阈值分级；不包含已离职员工。
- 关联：API-291 / NFR-P-008。

**TC-C4-051 高风险预警推送（数据权限）**
- 前置：某员工 `risk_score=82`（HIGH），归属于研发部。
- 步骤：批处理完成；直线经理（data_scope=本部门）与 HR 登录查看。
- 预期：直线经理仅见本部门高风险；HR 见全部；事件 `talent.attrition.alert` 推送；无数据权限者不可见且不可导出。
- 关联：API-290 / BR-C4-007。

### 3.5 C5 创新与 OKR

**TC-C5-021 目标加权进度计算**
- 前置：目标含 KR1(权重 60, 进度 100%)、KR2(权重 40, 进度 50%)。
- 步骤：查询目标详情。
- 预期：`progress = 60%×100 + 40%×50 = 80%`。
- 关联：API-311 / BR-C5-005。

**TC-C5-031 对齐形成环被拒**
- 前置：目标 A 对齐 B，B 对齐 C。
- 步骤：`POST /okr/alignments`（child=C, parent=A）。
- 预期：返回 `3005005`，不建立对齐。
- 关联：API-330 / EX-C5-001。

**TC-C5-070 提案评审（≥3 评审人）**
- 前置：提案处于 `REVIEWING`，已分配 3 名评审人。
- 步骤：3 名评审人分别 `POST /innovation/proposals/{id}/reviews`（得分 8/7/9）。
- 预期：汇总加权得分 8.0；达阈值后可立项；评审人不足 3 人时阻塞立项。
- 关联：API-360 / BR-C5-008。

**TC-C5-071 提案投票与自我投票拦截**

- 预期：E 投票返回 `3005015`；他人投票成功 `votes+1`；重复投票返回 `0000005`。
- 关联：API-361 / BR-C5-009。

### 3.6 安全与权限

**TC-SEC-001 员工手机号加密落库验证**
- 前置：测试库可直连。
- 步骤：新增员工后 `SELECT phone_enc, phone_hash FROM talent_employee WHERE emp_no='FL9999'`。
- 预期：`phone_enc` 非明文（GCM 密文含 nonce+tag）；`phone_hash` 为 64 位十六进制；不存在明文 `phone` 列。
- 关联：NFR-S-002 / BR-C1-004。

**TC-SEC-002 phone_hash 唯一约束与检索**
- 前置：已存在手机号 13800138000。
- 步骤：1) 再次新增同手机号员工；2) 以手机号精确检索员工。
- 预期：1) 唯一约束冲突返回 `3001001`；2) 检索命中（走 `phone_hash`），不触发全表解密。
- 关联：NFR-S-003 / BR-C1-004。

**TC-SEC-005 租户边界（跨租户访问拒绝）**
- 前置：账号属租户 T000001。
- 步骤：携 `X-Tenant-Id: T000002` 请求员工列表。
- 预期：网关校验令牌与租户不一致，返回 `0000002`/`403`；RLS 双重拦截。
- 关联：NFR-S-005 / 规范 6.1。

**TC-SEC-006 双端越端访问拒绝**
- 前置：用户端令牌（`client_type=PORTAL`）。
- 步骤：访问 `GET /api/talent/v1/employees`（ADMIN 权限码）。
- 预期：返回 `0000002`/`403`，提示越端。
- 关联：规范 1.3 / ARCH 7.2。

**TC-SEC-008 匿名问卷防反推**
- 前置：匿名问卷存在。
- 步骤：以答题时间、维度得分、组合筛选尝试关联到个人（含导出、分析接口）。
- 预期：任何接口/导出均无个人标识；样本 <5 部门隐藏；审计记录可疑查询并告警。
- 关联：NFR-S-007 / BR-C4-001。

### 3.7 接口与兼容

**TC-API-002 幂等键 24h 生效**
- 前置：写接口携带 `Idempotency-Key: K1`。
- 步骤：24h 内以 K1 重复提交相同请求；24h 后再次提交。
- 预期：24h 内返回首次结果（不重复写入）；24h 后作为新请求处理。
- 关联：规范 5.1 / 各写接口。

**TC-API-004 限流返回 0000006**
- 前置：接口限流 50 QPS。
- 步骤：以 100 QPS 持续请求 10s。
- 预期：超限请求返回 HTTP 429 / `0000006`；未影响正常租户。
- 关联：规范 5.4 / 10.1。

**TC-CMP-001 响应式断点渲染**
- 步骤：在 1440/1200/992/768/<768 宽度下渲染管理端与用户端。
- 预期：布局按第 6 章规则适配；移动端最小可点击区 44×44px；表格转卡片无溢出。
- 关联：NFR-C-001 / UIUX 6。

## 1 通用约定

- 协议：HTTPS（TLS 1.2+）；服务间 mTLS。
- 路径：`/api/talent/v1/{资源}`；动作型 `POST /api/talent/v1/{资源}/{动作}`。
- 数据格式：`application/json; charset=UTF-8`；文件上传 `multipart/form-data`。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1 起）、`size`（默认 20，最大 200）。
- 统一响应体：

```json
{
  "code": "0",
  "message": "success",
  "data": {},
  "requestId": "b1f2c3d4-...",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- 分页 `data`：`{ "records": [], "total": 0, "page": 1, "size": 20 }`。
- 错误码结构 `{域30}{模块2位}{序号3位}`；通用错误码见规范 5.4。

### 1.1 云才错误码（域 30）

| 错误码 | HTTP | 含义 |
|---|---|---|
| `3001001` | 409 | 手机号/身份证号已存在（哈希唯一冲突） |
| `3001005` | 400 | 组织移动形成环 |
| `3001006` | 409 | 组织下存在在职员工/下级/在招需求，不可撤销 |
| `3001020` | 409 | 超出编制余额 |
| `3001090` | 400 | 异动生效日非法 |
| `3002005` | 409 | 班次已满（返回候补位次） |
| `3002006` | 400 | 报名已截止 |
| `3003005` | 403 | 试用期员工不可申请活水 |
| `3003006` | 409 | 存在进行中的活水申请 |
| `3004005` | 403 | 部门样本不足，结果不可见 |
| `3005005` | 400 | OKR 对齐形成环 |
| `3005006` | 400 | 跨周期对齐禁止 |
| `3005015` | 403 | 提案人不可自我投票 |

## 2 鉴权与端别

| 请求头 | 必填 | 说明 |
|---|---|---|
| `Authorization` | 是 | `Bearer {access_token}`（JWT RS256） |
| `X-Tenant-Id` | 是 | 租户标识 |
| `X-Client-Type` | 是 | `ADMIN` / `PORTAL` |
| `X-Request-Id` | 否 | 追踪 ID |
| `Idempotency-Key` | 否 | 写操作幂等键（24h） |

- 端别（End）列：`ADMIN` 管理端、`PORTAL` 用户端、`BOTH` 双端。
- 权限码格式 `{域}:{模块}:{操作}`，如 `talent:admin:employee:create`（管理端）、`biz:talent:profile:edit`（用户端）。
- 越端访问返回 `403` / `0000002`。

## 4 逐接口定义

> 每个接口包含：方法/路径、端别、鉴权、限流、幂等、参数、响应、错误码。响应省略统一外层（只列 `data`）。

### API-001 组织树

| 项 | 内容 |
|---|---|
| 方法/路径 | `GET /api/talent/v1/orgs/tree` |
| 端别 | BOTH |
| 权限 | `talent:org:tree` |
| 限流 | 50 QPS/租户 |
| 幂等 | 读接口 |
| 查询参数 | `rootId`(可选)、`depth`(可选，默认全量)、`includeDisabled`(bool) |
| 响应 | `data`: `[{id, orgCode, orgName, parentId, level, orgType, leaderId, children:[]}]` |
| 错误码 | `0000001`、`0000002` |

### API-002 组织详情

`GET /api/talent/v1/orgs/{id}` · BOTH · `talent:org:view` · 读。
响应 `data`：`{id, orgCode, orgName, parentId, path, level, orgType, leader:{id,name}, employeeCount, status}`。
错误码：`0000004`（不存在）。

### API-003 新建组织

| 项 | 内容 |
|---|---|
| 方法/路径 | `POST /api/talent/v1/orgs` |
| 端别 | ADMIN · `talent:admin:org:create` · 限流 20 QPS · 幂等：`Idempotency-Key` |
| 请求体 | `{parentId, orgCode, orgName, orgType, leaderId, sortNo}` |
| 响应 | `data`: `{id, orgCode, path, level}` |
| 错误码 | `3001005`（编码/结构非法）、`0000003`、`0000005` |

### API-004 更新组织

`PUT /api/talent/v1/orgs/{id}` · ADMIN · `talent:admin:org:update` · 幂等 `version` 乐观锁。
请求体：`{orgName, leaderId, sortNo, status, version}`；响应 `data`：`{id, updatedAt}`。
错误码：`0000004`、`0000005`。

### API-005 移动组织

`POST /api/talent/v1/orgs/{id}/move` · ADMIN · `talent:admin:org:move`。
请求体：`{targetParentId}`；响应 `data`：`{id, path, level}`。
错误码：`3001005`（形成环）、`0000005`。
说明：移动后级联重算子树 `path` 与 `level`。

### API-006 撤销组织

`DELETE /api/talent/v1/orgs/{id}` · ADMIN · `talent:admin:org:delete`。
响应 `data`：`{id, status:"DISABLED"}`。
错误码：`3001006`（存在在职员工/下级/在招需求）。

### API-010 员工列表

| 项 | 内容 |
|---|---|
| 方法/路径 | `GET /api/talent/v1/employees` |
| 端别 | ADMIN · `talent:admin:employee:list` · 限流 100 QPS |
| 查询参数 | `orgId`、`includeSubOrg`(bool)、`empStatus`、`keyword`（姓名/工号）、`page`、`size` |
| 响应 | `data.records`: `[{id, empNo, name, org:{id,name}, position, grade, empStatus, hireDate, maskedPhone}]` |
| 错误码 | `0000002`、`0000003` |
| 说明 | 数据权限：仅返回 `data_scope` 范围内员工；`maskedPhone` 已脱敏 |

### API-011 员工详情

`GET /api/talent/v1/employees/{id}` · BOTH · `talent:employee:view`。
响应 `data`：`{id, empNo, name, gender, birthDate, maskedPhone, maskedIdCard, email, org, position, grade, manager, employmentType, hireDate, formalDate, empStatus, workLocation}`。
字段权限：无 `talent:employee:pii:view` 时 PII 仅返回脱敏。
错误码：`0000002`、`0000004`。

### API-012 新增员工（PII 加密）

| 项 | 内容 |
|---|---|
| 方法/路径 | `POST /api/talent/v1/employees` |
| 端别 | ADMIN · `talent:admin:employee:create` · 幂等：`Idempotency-Key` 必填 |
| 请求体 | `{empNo, name, gender, birthDate, phone, idCard, email, orgId, positionId, gradeId, managerId, employmentType, hireDate, workLocation}` |
| 响应 | `data`: `{id, empNo, empStatus:"PENDING"}` |
| 错误码 | `3001001`（手机号/身份证重复）、`0000003`、`0000005` |
| 说明 | `phone`/`idCard` 明文入参，服务端 AES-256-GCM 加密为 `phone_enc`/`id_card_enc`，并计算 `phone_hash`/`id_card_hash`；响应不返回明文 |

## 6 事件与 Webhook

### 6.1 事件清单

| 事件 | Topic | Payload 摘要 |
|---|---|---|
| 招聘需求已批准 | `talent.recruit.approved` | `{requisitionId, reqNo, orgId, headcount}` |
| Offer 已接受 | `talent.offer.accepted` | `{offerId, candidateId, positionId, expectJoinDate}` |
| 员工已入职 | `talent.employee.onboarded` | `{employeeId, empNo, orgId, hireDate}` |
| 员工已异动 | `talent.employee.transferred` | `{employeeId, transferType, before, after, effectiveDate}` |
| 员工已离职 | `talent.employee.resigned` | `{employeeId, empNo, lastWorkDate, reasonCategory}` |
| 活水申请已批准 | `talent.flow.approved` | `{applicationId, employeeId, demandId, applyType}` |
| 问卷已关闭 | `talent.survey.closed` | `{surveyId, surveyNo, responseCount}` |
| 风险预警生成 | `talent.attrition.alert` | `{employeeId, riskScore, riskLevel, factors}` |
| OKR 已对齐 | `talent.okr.aligned` | `{childObjectiveId, parentObjectiveId, alignType}` |
| 提案已立项 | `talent.innovation.incubated` | `{proposalId, proposalNo, proposerId}` |

### 6.2 Webhook 投递

- 订阅方式：`POST /openapi/talent/v1/subscriptions` 登记回调 URL 与事件类型。
- 签名：请求头 `X-FL-Signature = HMAC-SHA256(body + timestamp, appSecret)`；接收方须验签。
- 重试：指数退避，最多 6 次（1s/5s/30s/2min/10min/30min），仍失败进死信队列。
- 幂等：请求头 `X-FL-Event-Id`，接收方须按事件 ID 去重。
- 投递约束：至少一次（at-least-once），要求消费方幂等。

## 7 版本与兼容

### 7.1 版本策略

- URL 版本段 `/v1`；不兼容变更升 `/v2`，旧版本至少保留 12 个月。
- 兼容变更（新增可选字段、新增接口）不升版本，通过变更公告周知。

### 7.2 弃用策略

- 弃用前 6 个月公告；响应头 `Sunset` 标注下线时间；提供迁移指引。

## 1 设计令牌

### 1.1 色彩令牌（继承规范 9.1，强制）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fl-color-primary` | `#1F5EFF` | 主色（丰麟蓝） |
| `--fl-color-primary-hover` | `#3D78FF` | 主色悬停 |
| `--fl-color-success` | `#16A34A` | 成功（如"已转正""目标达成"） |
| `--fl-color-warning` | `#F59E0B` | 警告（如"中风险""信心指数低"） |
| `--fl-color-danger` | `#DC2626` | 危险（如"高风险""离职") |
| `--fl-color-info` | `#64748B` | 信息 |
| `--fl-color-text-primary` | `#1E293B` | 主文本 |
| `--fl-color-text-secondary` | `#64748B` | 次文本 |
| `--fl-color-bg` | `#F5F7FA` | 页面背景 |
| `--fl-color-surface` | `#FFFFFF` | 卡片/容器 |
| `--fl-color-border` | `#E2E8F0` | 边框/分割线 |

### 1.2 业务语义色（云才扩展，基于令牌）

| 语义 | 令牌组合 | 示例场景 |
|---|---|---|
| 敬业度维度 | 主色渐变（蓝→青） | 维度得分雷达/柱状 |
| eNPS 推荐者 | `--fl-color-success` | 9–10 分 |
| eNPS 中立者 | `--fl-color-warning` | 7–8 分 |
| eNPS 贬损者 | `--fl-color-danger` | 0–6 分 |
| 离职风险高/中/低 | danger / warning / success | 风险清单标签 |
| OKR 信心高/中/低 | success / warning / info | 目标卡片角标 |
| 状态-已完成 | `--fl-color-success` | 学习完成、目标达成 |

### 1.3 字体与排版

| 令牌 | 值 |
|---|---|
| `--fl-font-family` | `"PingFang SC","Microsoft YaHei",-apple-system,"Segoe UI",Roboto,sans-serif` |
| `--fl-font-size-xs/sm/base/lg/xl` | `12/13/14/16/20px` |
| `--fl-radius-sm/md/lg` | `4/8/12px` |
| `--fl-space-xs/sm/md/lg/xl` | `4/8/16/24/32px` |
| `--fl-shadow-sm/md` | `0 1px 2px rgba(0,0,0,.05)` / `0 4px 16px rgba(0,0,0,.08)` |

### 1.4 双端令牌应用差异

| 维度 | 管理端 | 用户端 |
|---|---|---|
| 表格尺寸 | `size=small`（紧凑） | `size=default`（舒适） |
| 主色使用 | 中性为主，主色强调数据 | 主色为主，场景化插画 |
| 圆角倾向 | `--fl-radius-sm/md` | `--fl-radius-md/lg` |
| 卡片阴影 | `--fl-shadow-sm` | `--fl-shadow-md` |

## 5 交互流程

### 5.1 员工新增（管理端）

```
点击[+新增员工] → 抽屉表单
 → 填写工号/姓名/组织/岗位/职级/PII
 → 校验：工号唯一、PII 哈希查重（3001001）、薪资带宽（Offer 场景）
 → 提交 → Toast 成功 → 列表刷新
```

### 5.2 活水投递（用户端）

```
活水市场 → 选择需求 → [投递] → 弹窗填写申请理由
 → 校验（试用期 3003005 / 进行中申请 3003006）
 → 提交 → Toast"已提交，等待现部门确认" → 我的活水申请可见 PENDING
```

### 5.3 问卷答题（用户端）

```
我的问卷 → 进入答题（匿名提示条）
 → 逐题作答（支持暂存草稿）
 → 提交 → 二次确认（一次性提交不可修改）
 → Toast"感谢参与" → 页面置为已完成
```

### 5.4 OKR 对齐（用户端）

```
我的 OKR → 新建目标 → 选择上级目标（同周期）
 → [建立对齐] → 上级负责人确认
 → 对齐成功后目标卡片显示上级链路
```

### 5.5 面试评价（用户端）

```
我的面试 → 选择待评价 → 打分 + 评价 + 结果
 → 提交 → 状态置"已完成" → 招聘看板同步
```

## 6 响应式规则

| 断点 | 布局 |
|---|---|
| ≥ 1440px | 管理端：左树(280) + 内容；用户端：4 列卡片 |
| 1200–1439px | 管理端：左树(240) + 内容；用户端：3 列卡片 |
| 992–1199px | 管理端：左菜单可折叠；用户端：2 列卡片 |
| 768–991px | 管理端：抽屉式菜单；用户端：2 列；表格横向滚动 |
| < 768px | 单列；底部 Tab 导航；表格转卡片列表；最小可点击区 44×44px |

移动端（PWA）：支持安装、离线缓存静态资源、扫码签到（线下培训）。

## 7 状态规范

| 状态 | 规范 |
|---|---|
| 加载 | 骨架屏（表格/卡片/树），禁止空白闪烁 |
| 空态 | 插画 + 引导按钮（如"暂无候选人，去新增"） |
| 错误 | 错误插图 + 错误码 + 重试按钮；PII 错误明确提示 `3001001` |
| 无权限 | 403 插画 + 申请权限指引；越端访问提示"请切换端" |
| 成功 | Toast（3s 自动消失）；关键操作（离职/立项）二次确认 |
| 部分成功 | 批量导入展示成功/失败行数与原因 |
| 长时任务 | 进度条 + 后台执行提示（导出、评分） |

## 8 可访问性

| 项 | 要求 |
|---|---|
| 对比度 | 文本与背景 ≥ 4.5:1（正文），大字 ≥ 3:1 |
| 键盘导航 | 全键盘可达，Tab 顺序合理；表格支持方向键 |
| 焦点样式 | 明显焦点环（主色 `--fl-color-primary`） |
| 语义化 | 正确使用 label、aria-*；图标按钮带 `aria-label` |
| 动态提示 | Toast/错误使用 `role="status"`/`alert` |
| 缩放 | 支持 200% 缩放不破版 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 国际化 | 文案外置 i18n，默认 `zh-CN`，预留 `en-US`；日期/数字本地化 |
| 表单 | 必填项明确标注，错误信息与字段关联 |

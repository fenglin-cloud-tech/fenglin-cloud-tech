## 1 快速开始

### 1.1 你可以在用户端做什么

| 模块 | 你能做的事 |
|---|---|
| C1 人力资源 | 查看/维护个人档案、查看面试任务、提交离职申请 |
| C2 培训与知识 | 报名培训、在线学习、参加考试、查看证书、检索知识库 |
| C3 技能与活水 | 维护个人技能、浏览活水市场、投递内部岗位、跟踪申请 |
| C4 敬业度 | 参与敬业度问卷、脉冲调研 |
| C5 创新与 OKR | 制定个人 OKR、更新进度、提交创新提案、参与投票 |

### 1.2 三步上手

1. 用企业账号（SSO/账号密码）登录 `https://talent.fenglincloud.com/app/talent`。
2. 进入「我的工作台」，查看待办（面试、问卷、学习、OKR）。
3. 点击卡片进入对应功能，完成日常操作。

> 提示：管理端地址为 `https://talent.fenglincloud.com/admin/talent`，仅面向 HR、管理员。普通员工请使用用户端。

## 2 登录与导航（用户端）

### 2.1 登录

| 方式 | 说明 |
|---|---|
| 企业 SSO | 点击「企业登录」，跳转统一身份认证（企微/飞书/钉钉/AD） |
| 账号密码 | 输入账号、密码，首次登录建议修改初始密码 |
| 移动端 | 手机浏览器/PWA 打开同一地址，可「添加到主屏幕」 |

> 连续 5 次密码错误将锁定 10 分钟。忘记密码请联系系统管理员重置。

### 2.2 导航结构

```
顶部导航：首页 | 我的档案 | 培训 | 知识库 | 技能 | 活水市场 | 问卷 | OKR | 创新广场
右上角：消息中心 · 待办 · 头像（切换语言 / 退出）
```
（截图位：登录页、我的工作台首屏、顶部导航展开）

### 2.3 我的工作台

工作台展示四类卡片与待办列表：
- 🎯 我的 OKR；📚 待学习；📝 待答题；🚀 活水推荐。
- 待办列表按截止时间排序，点击「前往」直达。

## 3 分模块操作指引

### 3.1 我的档案（C1）

1. 顶部导航进入「我的档案」。
2. 查看工号、组织、岗位、职级、入职日期等。
3. 点击「编辑」，可修改个人可维护字段（如邮箱、工作地等）。
4. 手机号、身份证号显示为脱敏（`138****8888`、`110***********1234`）；如需变更请联系 HR。
（截图位：档案页、编辑弹窗）

### 3.2 我的面试（C1，面试官/候选人）

1. 进入「我的面试」，查看待评价面试列表。
2. 点击某条面试，填写「评分、评价、结论（通过/待定/未通过）」。
3. 提交后该条面试置为「已完成」。
（截图位：面试列表、评价表单）

### 3.3 我的离职申请（C1）

1. 进入「我的离职申请」→「发起申请」。
2. 填写离职类型、申请日期、最后工作日、原因分类。
3. 提交后进入审批流（直属上级→HR），可在列表跟踪状态。
> 注意：提交后不可重复提交；撤回需联系 HR。

### 3.4 培训中心与我的学习（C2）

1. 「培训中心」浏览课程，按分类/方式筛选。
2. 选择课程 →「报名」；若已满则进入「候补」，有空位自动补位并通知。
3. 「我的学习」查看进度，点击「继续学习」断点续学。
（截图位：课程列表、课程详情、报名成功、学习进度页）

### 3.5 考试与证书（C2）

1. 完成课程学习后，在课程详情进入「结业考试」。
2. 提交后立即出分；≥ 及格线（默认 60）通过并生成证书。
3. 未通过可补考 1 次；「我的证书」查看全部证书与有效期。

### 3.6 知识库（C2）

1. 进入「知识库」，按分类浏览或关键词检索。
2. 打开文章阅读，支持目录跳转。
3. 有贡献权限的员工可「投稿」，提交后由管理员审核发布。

### 3.7 我的技能（C3）

1. 进入「我的技能」→「新增技能」。
2. 选择技能标签，填写自评等级（1–5）、使用年限、证据说明。
3. 提交后显示「待认证」；经理/专家认证后显示认证等级。
（截图位：技能列表、技能编辑）

### 3.8 活水市场与申请（C3）

1. 进入「活水市场」，按组织/技能筛选内部岗位。
2. 查看需求详情（技能要求、人数、期望到岗、匹配度）。
3. 点击「投递」，填写申请理由并提交。
4. 在「我的活水申请」跟踪：现部门同意 → 目标部门面试 → HR 审核。
> 注意：试用期员工不可申请；同一时间仅可有一个进行中的申请。

### 3.9 我的问卷（C4）

1. 进入「我的问卷」，选择待填问卷。
2. 匿名问卷顶部有匿名提示，系统不记录你的个人标识。
3. 可「暂存」草稿，全部完成后「提交」（一次性提交，不可修改）。
（截图位：问卷列表、答题页、提交确认）

### 3.10 我的 OKR（C5）

1. 进入「我的 OKR」，选择当前周期。
2. 「新建目标」：填写目标描述，可选择上级目标建立对齐。
3. 为目标添加 KR：选择指标类型、起始值、目标值、权重。
4. 定期「更新进度」：填写当前值、信心指数（高/中/低）、备注。
5. 周期末参与「复盘」，填写自评分与总结。
（截图位：OKR 列表、目标编辑、KR 进度更新、对齐视图）

### 3.11 创新广场（C5）

1. 进入「创新广场」浏览提案，可按分类查看。
2. 「提交提案」：填写标题、分类、内容、团队成员、预期收益、附件。
3. 为他人提案「投票」（打分+评论）；不可为自己投票。
4. 关注提案状态：评审中 → 立项孵化 → 落地。

## 4 常见任务场景

### 场景一：本周要完成一份敬业度问卷

1. 工作台「待答题」卡片或待办列表点击进入。
2. 逐题作答，中途可暂存。
3. 「提交」并确认，页面显示「已完成」。

### 场景二：我想转到公司另一个团队

1. 「活水市场」筛选目标团队岗位。
2. 查看匹配度与技能要求，点击「投递」。
3. 等待现部门负责人确认与目标部门面试。
4. 在「我的活水申请」查看进度与结果。

### 场景三：为新季度制定 OKR

1. 「我的 OKR」选择新周期。
2. 先查看部门目标，再创建个人目标并「对齐」部门目标。
3. 为每个目标添加 2–4 个可量化的 KR。
4. 每周更新进度与信心指数。

### 场景四：报名一门培训课程

1. 「培训中心」找到课程 →「报名」。
2. 到课程开始时间线下签到或线上学习。
3. 完成学习后参加考试，通过即获得证书与学分。

### 场景五：提交一个创新想法

1. 「创新广场」→「提交提案」。
2. 填写完整信息并上传附件，提交。
3. 邀请同事投票支持，关注评审与立项进展。

## 5 FAQ

| 问题 | 解答 |
|---|---|
| 为什么手机号显示为 `138****8888`？ | 出于个人信息保护，PII 默认脱敏；如需修改请联系 HR。 |
| 我修改了手机号为什么不生效？ | 手机号属于受控字段，需 HR 在管理端变更以校验唯一性。 |
| 问卷提交后发现答错了能改吗？ | 不能，问卷为一次性提交；请在提交前仔细核对。 |
| 问卷真的是匿名的吗？ | 是。匿名问卷不存储你的个人标识，且小样本部门结果不会展示。 |
| 课程报名满了还能报吗？ | 可进入候补队列，有人取消时你会自动补位并收到通知。 |
| 考试没通过怎么办？ | 可补考 1 次；仍不通过则该课程计为未通过，需重新报名学习。 |
| 为什么我不能投递活水岗位？ | 可能原因：处于试用期、已有进行中的活水申请、岗位不在你的可见范围。 |
| OKR 可以不对齐吗？ | 个人目标可暂不对齐，但建议对齐上级目标；部门/公司目标必须纳入对齐网络。 |
| 我能给自己喜欢的提案投票吗？ | 可以给他人提案投票，但不能给自己的提案投票。 |
| 忘记密码怎么办？ | 联系系统管理员重置，或使用企业 SSO 登录。 |
| 手机上能用吗？ | 可以，用户端支持响应式与 PWA，可添加到主屏幕。 |
| 我的数据会被谁看到？ | 仅你本人、直属上级（限本部门）与有权限的 HR 可见；跨部门不可见。 |

## 6 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + K` / `Cmd + K` | 全局搜索（知识/课程/提案/功能） |
| `G` 然后 `H` | 回到我的工作台 |
| `G` 然后 `O` | 打开我的 OKR |
| `G` 然后 `M` | 打开活水市场 |
| `G` 然后 `T` | 打开培训中心 |
| `N` | 在当前列表新建（如新建目标/提案） |
| `Esc` | 关闭弹窗/抽屉 |
| `?` | 显示快捷键帮助 |

> 移动端不支持上述快捷键，请使用触控操作。

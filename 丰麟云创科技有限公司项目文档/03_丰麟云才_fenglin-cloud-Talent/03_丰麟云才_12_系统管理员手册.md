## 1 管理端总览

### 1.1 定位

管理端（`/admin/talent`）面向平台运营人员、租户管理员与 HR 管理员，承载**配置、授权、审核、报表定义、治理**类能力；员工日常操作在用户端（`/app/talent`）完成。两端口令与权限域相互独立（`client_type=ADMIN`）。

### 1.2 角色与职责（继承平台基线）

| 角色 | 职责 | 说明 |
|---|---|---|
| 平台超级管理员 | 平台级最高权限 | 运维专用，强制审计 |
| 平台运维 | 租户/套餐/监控/灰度 | 管理端 |
| 租户管理员 | 本租户配置、组织、角色、权限 | 管理端 |
| HR 管理员 | 员工/组织/招聘/培训/活水/问卷/OKR 全流程 | 管理端 |
| 培训管理员 | 课程/班次/考试/知识库 | 管理端 |
| OKR 管理员 | 周期/对齐规则 | 管理端 |
| 安全/审计员 | 审计查看、权限复核 | 管理端 |

### 1.3 管理端导航

```
人才运营概览 | 组织人事 | 招聘管理 | 培训与知识 | 技能与活水 | 敬业度与风险 | OKR 与创新 | 系统设置
```

### 1.4 人才运营概览

首页展示：在编人数、本月入职/离职、在招职位、培训完成率、敬业度与 eNPS、离职风险分布、OKR 达成率、待办审批。

## 2 租户/组织/用户/角色

### 2.1 租户（平台运维）

| 操作 | 说明 |
|---|---|
| 开通租户 | 分配租户 ID（`T{6位}`）、套餐、配额 |
| 套餐/配额 | 席位、存储、开放 API 调用量 |
| 隔离策略 | SaaS 共享库共享模式 + RLS；高合规客户独立库 |
| 密钥初始化 | 为租户生成 CMK/DEK 与租户盐（PII 加密依赖） |

### 2.2 组织管理

1. 「组织人事 → 组织架构」。
2. 支持新增、改名、移动、合并、撤销；维护组织编码（层级点分 `1.2.3`）与负责人。
3. 移动组织将级联重算子树路径；撤销前需满足：无在职员工、无下级、无在招需求。
（截图位：组织树、组织编辑）

### 2.3 用户与员工

| 操作 | 说明 |
|---|---|
| 员工新增/编辑 | 维护档案；手机号、身份证号加密存储，界面脱敏 |
| 批量导入 | 上传 xlsx/csv，支持 dryRun 预校验，返回成功/失败行 |
| 花名册导出 | 默认脱敏；导出明文需专门权限并审计 |
| 账号生命周期 | 入职自动开通、离职自动停用（联动 IAM） |

### 2.4 角色管理

- 角色 = 功能权限集合 + 数据权限范围。
- 支持内置角色与自定义角色；角色变更即时生效。
- 三员分立：系统管理员、安全管理员、审计员职责分离，不可兼任。

## 3 权限与数据权限配置

### 3.1 功能权限（三级）

| 级别 | 示例权限码 |
|---|---|
| 菜单 | `talent:admin:employee:menu` |
| 按钮 | `talent:admin:employee:create` |
| 接口 | `talent:admin:employee:update` |

### 3.2 数据权限（行级）

| 范围 | 说明 |
|---|---|
| 本人 | 仅本人数据 |
| 本部门 | 本部门数据 |
| 本部门及下级 | 含子部门 |
| 指定部门 | 指定若干部门 |
| 全部（本租户） | 全部数据 |

配置路径：「系统设置 → 权限与数据权限」。通过 `data_scope` + SQL 拦截 + RLS 双重生效。

### 3.3 字段权限（列级）

- PII 字段（手机号、身份证号）默认脱敏。
- 明文查看需 `talent:employee:pii:view`；明文导出需 `talent:employee:pii:export`（二次授权 + 审计）。

### 3.4 双端权限域

| 端 | 权限域 |
|---|---|
| 管理端 | `platform:*`、`tenant:*`、`talent:admin:*` |
| 用户端 | `biz:talent:*` |

越端访问将被网关拒绝（403 / `0000002`）。

## 5 流程与审批配置

### 5.1 支持的流程

| 流程 | 节点 | 引擎 |
|---|---|---|
| 招聘需求审批 | 部门负责人 → HRD（超编制）→ HR 复核 | Flowable |
| Offer 审批 | HR → HRD（超带宽特批） | Flowable |
| 异动审批 | 现部门 → 目标部门 → HR | Flowable |
| 活水审批 | 现部门同意 → 目标部门面试 → HR 审核 | Flowable |
| 离职审批 | 直属上级 → HR → 交接 | Flowable |
| 知识审核 | 知识管理员（可多级） | Flowable |
| 提案评审 | ≥3 评审人并行 → 委员会立项 | Flowable |

### 5.2 流程配置要点

1. 「系统设置 → 流程与审批」选择流程模板。
2. 配置审批人：角色/指定人/上级/发起人部门负责人。
3. 配置超时策略：催办（如 48h）、自动通过/驳回（如 7 天）。
4. 配置回调事件与通知渠道（站内信/邮件/企微/飞书）。

（截图位：流程列表、节点配置、审批人设置）

### 5.3 审批操作

审批人在管理端「待办审批」处理；员工可在用户端查看进度。所有审批留痕审计。

## 6 集成与开放平台

### 6.1 中台集成

| 集成 | 配置 |
|---|---|
| IAM | 组织/员工主数据同步、SSO、离职联动 |
| 工作流 | 流程编排与回调 |
| 消息 | 面试通知、问卷触达、预警推送 |
| 文件 | 简历/证书/附件存储与防泄漏 |
| AI（embedded） | 简历解析、人岗匹配、离职预测 |

### 6.2 开放平台

1. 「系统设置 → 集成与开放平台」注册应用，获取 AppKey/AppSecret。
2. 配置授权范围（`talent.employee.read`、`talent.org.read` 等）与配额（QPS/日调用量）。
3. 配置事件订阅：选择事件类型（如 `talent.employee.onboarded`）与回调 URL。
4. 支持沙箱调试与调用量监控。

| 开放接口 | 路径 |
|---|---|
| 令牌 | `/openapi/talent/v1/oauth/token` |
| 员工同步 | `/openapi/talent/v1/employees/sync` |
| 组织同步 | `/openapi/talent/v1/orgs/sync` |
| 事件订阅 | `/openapi/talent/v1/subscriptions` |

### 6.3 事件订阅安全

- 回调签名 `X-FL-Signature`（HMAC-SHA256），接收方须验签。
- 投递失败指数退避重试 6 次，进死信队列；按 `X-FL-Event-Id` 幂等。

## 7 监控与审计

### 7.1 运营监控

管理端「系统设置 → 监控」查看：接口 QPS/RT/错误率、问卷提交速率、批处理状态、开放 API 调用量。

### 7.2 审计日志

| 项 | 说明 |
|---|---|
| 范围 | 员工/组织/招聘/培训/活水/问卷/OKR/权限变更/导出/PII 解密 |
| 内容 | 操作人、时间、IP、对象、前后值、结果 |
| 防篡改 | 哈希链 + WORM；留存 12 个月 |
| 检索 | 按操作人/对象/时间/类型检索 |

### 7.3 安全告警

| 告警 | 触发 |
|---|---|
| 批量 PII 访问 | 短时间大量解密/导出 |
| 异常时段导出 | 非工作时段导出 |
| 跨租户尝试 | 令牌与租户不一致 |
| 匿名问卷组合查询 | 可疑反推查询 |

## 8 备份与安全运维

| 项 | 说明 |
|---|---|
| 备份 | 数据库每日全备+增量、异地容灾（见部署运维手册第 8 章） |
| 密钥轮换 | PII 加密密钥 ≤ 90 天轮换，管理端可查看剩余天数并触发 |
| 权限复核 | 建议季度复核角色与数据权限，清理离岗账号 |
| PII 明文授权 | 审批式授权，最小化授予，全程审计 |
| 剩余信息保护 | 租户停用/销毁时销毁 DEK 使密文不可解 |
| 合规留存 | 审计 ≥ 6 个月（实配 12 个月） |

## 9 故障处理

| 现象 | 排查 | 处置 |
|---|---|---|
| 组织树加载慢/超时 | 检查缓存是否命中、组织节点数 | 预热缓存、联系运维扩容 |
| 员工新增提示 `3001001` | 手机号/身份证已被占用 | 核实是否重复/回流，按业务处理 |
| 招聘需求提交提示 `3001020` | 超编制余额 | 调整编制或走特批 |
| 活水申请提示 `3003005/3003006` | 试用期/存在进行中申请 | 提示员工，按规则处理 |
| 问卷结果不显示某部门 | 样本 < 阈值 | 属正常隐私保护，说明原因 |
| 离职预警未推送 | 数据权限/批处理失败 | 检查批处理日志与账号权限 |
| 审批卡住 | 流程实例异常 | 在流程中心查询实例，必要时人工干预 |
| 导出失败 | 数据量大/权限不足 | 使用异步导出，检查权限与审计 |
| 登录被锁定 | 连续 5 次密码错误 | 等待 10min 或管理员解锁 |
| PII 无法查看 | 缺 `talent:employee:pii:view` | 申请字段权限（审批+审计） |

### 9.1 联系支持

遇到无法处理的问题，请收集：**时间、账号、操作路径、错误码、`X-Request-Id`**，提交至运维值班。

## 1 产品简介

丰麟云法是丰麟云创科技有限公司的合同法务与信息风控平台，口号为"**合同全生命周期可控，核心信息不泄漏**"。作为用户端使用者，您可以在本平台完成：

- **合同全流程**：选择模板 → 起草合同 → 提交审批 → 申请用印 → 电子签署 → 履约跟踪 → 到期处理 → 归档；
- **电子签章**：符合《电子签名法》的实名认证、意愿确认、可信时间戳与签署证据链；
- **内部信息防泄漏**：接收与处置敏感数据外发事件、提交外发放行申请、查看水印与溯源。

| 项 | 说明 |
|---|---|
| 访问地址 | `https://legal.fenglincloud.com/app/legal` |
| 建议浏览器 | Chrome/Edge ≥ 110、Safari ≥ 16、Firefox ≥ 110 |
| 支持终端 | 桌面端为主；移动端支持审批、签署、待办 |
| 面向角色 | 合同管理员、法务专员、用印管理员、普通员工（签署人）、DLP 审计员 |

> 本手册面向**用户端**。管理端配置（模板、印章、DLP 策略等）见《系统管理员手册》。

## 2 登录与工作台

### 2.1 登录

1. 打开 `https://legal.fenglincloud.com/app/legal`；
2. 使用企业统一账号登录（支持 SSO/扫码）；
3. 如开启 MFA，需完成二次验证；
4. 首次登录请确认您的组织与角色。

### 2.2 我的工作台

登录后默认进入**我的工作台**（`/app/legal/workbench`），包含卡片：

| 卡片 | 说明 |
|---|---|
| 待我审批 | 待处理的合同/用印审批 |
| 我起草的 | 我创建的合同及状态 |
| 待我签署 | 待我完成的签署任务 |
| 履约到期提醒 | 临近/逾期的履约与合同到期 |
| 我的 DLP 待处置事件 | 指派给我的敏感外发事件 |
| 到期合同提醒 | T-90/60/30/15/7 提醒 |

点击卡片可直达对应列表。顶部导航包含：工作台、合同、用印、签署、履约、DLP、存证、通知。

## 3 G1 合同管理

### 3.1 起草合同

1. 进入 **合同 → 合同台账**，点击 **起草合同**；
2. 选择合同类型（采购/销售/劳务/保密/租赁/其他）；
3. 选择模板（可选，推荐使用模板）；系统按模板变量生成填充表单；
4. 填写合同名称、相对方、金额、币种、起止日期、归属组织；
5. 在正文/条款区补充或调整条款（红色标识为**必留条款**，不可删除）；
6. 点击 **保存草稿**（生成合同编号 `CT{年份}{6位}`）或 **提交审批**。

> 提示：提交审批前，所有**必填变量**必须填写完整，否则会提示"模板变量未填充"。

### 3.2 相对方管理

- 进入 **合同 → 相对方** 可新增/维护相对方；
- 录入统一社会信用代码会自动查重，重复会提示；
- 相对方联系人手机号按权限脱敏显示；
- 相对方风险等级为**高**时，合同会自动增加法务复核环节。

### 3.3 合同审批

1. 在 **合同台账** 找到合同，点击 **提交审批**（需先选择审批版本）；
2. 系统按金额、类型、组织与相对方风险自动路由审批节点；
3. **作为审批人**：在 **待我审批** 中打开任务，可执行 **通过 / 驳回 / 转办 / 加签** 并填写意见；
4. 审批通过后合同进入 **已通过** 状态，可申请用印。

> 说明：审批记录会绑定审批时的合同版本，确保"审哪个版本就签哪个版本"。

### 3.4 合同版本与条款

- 每次修改正文保存会生成新版本（版本号递增），历史版本不可修改；
- 可在合同详情 **正文条款** Tab 查看版本差异摘要与条款清单。

## 4 G1 用印与签署

### 4.1 用印申请

1. 合同状态为 **已通过** 时，进入合同详情 → **用印** → **申请用印**；
2. 选择印章（电子章/实物章）、份数、用途、用印位置；
3. 提交后进入用印审批流程，可在合同详情查看审批进度。

> 注意：若用印版本与审批版本不一致，会被拒绝（提示"版本不一致"）；印章停用、吊销或证书过期时无法用印。

### 4.2 用印执行

- **作为用印管理员**：审批通过后，在 **用印 → 用印台** 执行用印；
- 电子章：系统调用电子签章服务加盖；
- 实物章：登记用印信息（份数、位置、凭证照片）；
- 用印完成后生成**用印记录**（不可删除），并写入防篡改审计链。

### 4.3 发起与执行签署

1. 在用印完成的合同详情点击 **发起签署**；
2. 维护**签署方**（内部/外部、签署人、签署方式、顺序）；
3. 选择签署方式：**顺序签**（依次签署）或 **并行签**（同时签署）；
4. 设置签署截止时间；
5. **作为签署人**：在 **签署 → 签署中心** 打开任务，阅读合同全文后：
   - 完成 **实名认证**（短信/人脸/证书）；
   - 完成 **意愿确认**（二次验证），确认"签署后具有法律效力且不可撤销"；
   - 点击 **签署**，系统加盖签章并生成可信时间戳；
6. 全部签署方完成后合同变为 **已签署**，并自动生成存证。

> 拒签：如不同意，可选择 **拒签** 并填写原因，合同将回到待处理状态。

## 5 G1 履约、到期与归档

### 5.1 履约跟踪

1. 合同详情 → **履约** → **新增节点**；
2. 选择节点类型（交付/验收/付款/开票/质保/其他），填写计划时间、金额、责任人；
3. 节点到期会自动提醒；逾期节点会标红预警；
4. 完成后上传凭证并标记 **已完成**。

### 5.2 到期提醒与处理

- 系统在到期前 **90/60/30/15/7 天** 分级提醒（站内信 + 邮件）；
- 收到提醒后可在合同详情选择 **续签 / 终止 / 归档**；
- 续签：基于原合同起草新合同；终止：走终止审批；归档：固化快照后转为只读。

### 5.3 合同归档

1. 合同履行完毕或终止后，点击 **归档**；
2. 系统固化归档快照哈希并写入防篡改存储；
3. 归档后合同**只读**，不可修改；如需查看可随时打开并做完整性校验。

### 5.4 检索与导出

- **合同台账**：按类型/状态/组织/相对方/金额/到期日筛选；
- **合同检索**：输入关键词可全文检索名称与条款正文，命中处高亮；
- **导出**：按权限导出（默认脱敏），导出行为会被审计。

## 6 G2 内部信息防泄漏（DLP）

### 6.1 收到外发拦截提示怎么办

当您外发文件被拦截时，说明该文件被认为是敏感数据：

1. 阅读提示中的**数据密级**与**命中原因**；
2. 如确需外发，点击 **申请放行**，填写用途、外发对象、有效期；
3. 待信息安全管理员审批通过后，在有效期内可进行**同一内容**的外发；
4. 内容发生变化时放行会失效，需重新申请。

### 6.2 外发放行申请

- 进入 **DLP → 放行申请**，填写外发对象、用途、有效期并提交；
- 在 **我的申请** 中查看审批状态；
- 放行凭证有**有效期**，过期后自动失效。

### 6.3 处置 DLP 事件（DLP 审计员/部门安全接口人）

1. 在 **DLP → 事件工作台** 查看指派给您的事件；
2. 打开事件详情，查看涉及用户、通道、文件、命中规则、命中片段（脱敏）与风险分；
3. 执行处置动作：
   - **研判**：分派与初判；**调查**：上传调查证据；
   - **确认泄漏**：填写结论与整改项；
   - **误报**：标记 `FALSE_POSITIVE` 并填写原因；
   - **升级**：升级至安全负责人；
4. 事件有 SLA 时限，超时会自动升级。

### 6.4 水印与溯源

- **明水印**：预览/下载文件时会自动叠加（含用户名、时间、IP），用于威慑；
- **暗水印**：后台嵌入可溯源的标识；
- **溯源**：如发现疑似泄漏文档，进入 **DLP → 水印** 上传文档执行溯源，系统会反查泄漏来源（用户、终端、IP、时间）。

### 6.5 我的外发记录

- 进入 **DLP → 我的外发** 查看本人外发与拦截记录；
- 记录不可删除，用于合规追溯。

## 7 存证与核验

1. 进入合同详情 → **存证** Tab，查看存证编号 `EVD{年份}{6位}` 与内容哈希；
2. 点击 **核验** 可验证合同文档与签署证据是否被篡改；
3. 核验通过显示"有效"；若检测到异常会提示并通知管理员；
4. 如需出证（司法/仲裁用途），点击 **申请出证** 生成出证报告。

## 8 常见问题（FAQ）

| 问题 | 解答 |
|---|---|
| 为什么提交审批被拒？ | 可能是必填变量未填或必留条款缺失，请按提示补全。 |
| 为什么用印被拒？ | 可能合同未通过审批、用印版本与审批版本不一致、印章停用/过期。 |
| 为什么无法签署？ | 需先完成实名认证与意愿确认；顺序签需等待前序签署方完成。 |
| 签署有法律效力吗？ | 有。平台采用实名认证、意愿确认、数字证书、可信时间戳与完整证据链，符合《电子签名法》。 |
| 签署后能修改合同吗？ | 不能。签署后合同数据被固化，任何修改都会被检出。 |
| 为什么外发被拦截？ | 文件命中敏感识别规则，可按提示申请放行。 |
| 放行后为什么又拦截了？ | 放行凭证有有效期，或外发内容已变化（指纹不一致）。 |
| 用印记录能删除吗？ | 不能。用印记录为法定留痕，不可删除。 |
| 看不到签署人手机号/身份证？ | 出于隐私保护默认脱敏，如需查看请联系管理员开通权限。 |
| 合同归档后为什么不能改？ | 归档后合同为只读并已固化哈希，确保不可篡改。 |

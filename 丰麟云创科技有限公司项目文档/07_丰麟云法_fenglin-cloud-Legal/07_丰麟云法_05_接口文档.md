## 1 通用约定

（完整约定引用 FL-HUB-STD-001 第 5 章，本品补充如下。）

- 协议 HTTPS（TLS 1.2+，推荐 1.3）；数据格式 `application/json; charset=UTF-8`；文件 `multipart/form-data`。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1 开始）、`size`（默认 20，最大 200）；响应 `data = { records, total, page, size }`。
- 统一响应体：

```json
{
  "code": "0",
  "message": "success",
  "data": {},
  "requestId": "b1f2c3d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- 请求头：`Authorization`、`X-Tenant-Id`、`X-Client-Type`（ADMIN/PORTAL）、`X-Request-Id`、`Idempotency-Key`、`Accept-Language`。
- 错误码结构 `{域2}{模块2}{序号3}`，域前缀 `70`：

| 错误码 | HTTP | 含义 |
|---|---|---|
| `0000001` | 401 | 未认证或令牌失效（平台通用） |
| `0000002` | 403 | 无权限（功能或数据） |
| `0000003` | 400 | 参数校验失败 |
| `0000004` | 404 | 资源不存在 |
| `0000005` | 409 | 状态冲突（并发/重复提交） |
| `0000006` | 429 | 触发限流 |
| `7000001` | 400 | 云法通用参数错误 |
| `7000002` | 403 | 云法功能无权限 |
| `7001001` | 409 | 合同编号重复 |
| `7001002` | 400 | 合同状态不允许该操作 |
| `7001003` | 400 | 必填项/必留条款缺失 |
| `7001004` | 400 | 模板变量未填充 |
| `7001005` | 400 | 审批链配置不完整 |
| `7001006` | 403 | 印章不可用/已吊销/已过期 |
| `7001007` | 409 | 用印版本与审批版本不一致 |
| `7001008` | 503 | CA/电子签章服务不可用 |
| `7001009` | 409 | 签署证据链校验失败 |
| `7001010` | 403 | 签署方身份核验失败 |
| `7001011` | 409 | 合同已归档不可修改 |
| `7001012` | 409 | 存证/完整性哈希校验失败 |
| `7002001` | 400 | 敏感规则表达式非法 |
| `7002002` | 409 | DLP 策略冲突（优先级/生效时间重叠） |
| `7002003` | 409 | 外发事件重复上报 |
| `7002004` | 400 | 通道未启用 |
| `7002005` | 400 | 白名单规则无效/已过期 |
| `7002006` | 409 | 水印比对不一致 |
| `7002007` | 409 | DLP 审计链路校验失败 |
| `7002008` | 403 | 终端未注册或已离线 |
| `7002009` | 429 | 批量上报超出配额 |
| `7002010` | 403 | 敏感数据外发需审批放行 |

- 限流：默认按租户+接口 QPS 限流（读取 200 QPS、写入 50 QPS、导出/上报 20 QPS、Agent 上报通道 500 QPS），超限返回 `0000006`。

## 2 鉴权与端别

| 项 | 说明 |
|---|---|
| 鉴权 | OAuth2.1/OIDC，JWT（RS256）；`Authorization: Bearer {access_token}` |
| 端别 | `X-Client-Type`：`ADMIN`（管理端）/`PORTAL`（用户端）；须与令牌 `client_type` 一致，否则 `0000002` |
| 租户 | `X-Tenant-Id` 必填，须与令牌 `tenant_id` 一致 |
| 权限 | 功能权限码校验（如 `legal:contract:create`）；数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）行级过滤 |
| 幂等 | 写操作支持 `Idempotency-Key`（24h 有效）；用印/签署/审批/放行类强制 |
| 追踪 | `X-Request-Id`（贯穿全链路）、`X-Trace-Id`（SkyWalking） |
| 签署前二次认证 | 签署执行接口需令牌含 `step_up=true`（由 `/auth/step-up` 提升），否则 `7001010` |

**端别归属原则**：`/api/legal/v1/admin/**` 仅 `ADMIN` 可访问（模板变量、印章、DLP 规则/策略/通道/白名单/终端、报表、配置）；其余 `/api/legal/v1/**` 仅 `PORTAL` 可访问；`/api/legal/v1/internal/**` 仅服务间 mTLS 调用（CA 回调、DLP 上报/决策、链路校验），公网不可达。

## 4 逐接口定义

> 说明：所有接口均须携带第 2 章请求头；`data` 为统一响应体中的数据体。PII 字段返回时默认脱敏。写操作默认支持 `Idempotency-Key`。

### LEGAL-API-001 创建合同模板

- **方法/路径**：`POST /api/legal/v1/contract-templates`；**端别**：PORTAL；**鉴权**：`legal:template:manage`；**幂等**：支持。
- **请求体**：

| 参数 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `name` | string | 是 | 1–200 | 模板名称 |
| `category` | string | 是 | 枚举 | PURCHASE/SALES/LABOR/NDA/LEASE/OTHER |
| `appliedOrgIds` | long[] | 否 | — | 适用组织（空=全租户） |
| `visibleScope` | string | 否 | TENANT/ORG/CUSTOM | 可见范围 |
| `contentRef` | string | 否 | — | 正文文件引用（上传后返回） |

- **响应示例**：

```json
{
  "code": "0",
  "message": "success",
  "data": {
    "id": 1801234567890123456,
    "templateNo": "TPL202600000123",
    "name": "标准采购合同模板",
    "category": "PURCHASE",
    "status": "DRAFT",
    "createdAt": "2026-10-19T08:00:00.000+08:00"
  },
  "requestId": "b1f2c3d4-...",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- **错误码**：`0000003`、`7000002`。**幂等**：相同 `Idempotency-Key` 24h 内返回首次结果。

### LEGAL-API-002 发布模板版本

- **方法/路径**：`POST /api/legal/v1/contract-templates/{id}/versions`；**端别**：PORTAL；**鉴权**：`legal:template:version`；**幂等**：支持。
- **请求体**：`{ "contentRef": "...", "changeSummary": "更新付款条款", "publish": true }`
- **规则**：发布后该版本不可修改；若 `publish=true` 则模板 `status=PUBLISHED` 且 `current_version_id` 指向新版本，`version_no` 自增。
- **响应**：`{ "templateId":..., "versionId":..., "versionNo": 2, "contentHash": "9f8e...", "status": "PUBLISHED" }`
- **错误码**：`0000003`、`0000004`、`7000002`。

### LEGAL-API-003 模板变量配置（管理端）

- **方法/路径**：`PUT /api/legal/v1/admin/contract-templates/{id}/variables`；**端别**：ADMIN；**鉴权**：`tenant:legal:template:variable`；**幂等**：支持。
- **请求体**：`{ "templateVersionId": 18..., "variables": [ { "varKey":"partyA","varLabel":"甲方","dataType":"TEXT","required":true,"defaultValue":"丰麟云创科技有限公司","valueSource":"SYSTEM" }, { "varKey":"amount","varLabel":"合同金额","dataType":"NUMBER","required":true,"valueSource":"CONTRACT_FIELD" } ] }`
- **响应**：`{ "templateVersionId": 18..., "variableCount": 2 }`
- **错误码**：`0000003`、`7000001`。

### LEGAL-API-004 合同起草

- **方法/路径**：`POST /api/legal/v1/contracts`；**端别**：PORTAL；**鉴权**：`legal:contract:create`；**幂等**：支持。
- **请求体**：

| 参数 | 类型 | 必填 | 约束 | 说明 |
|---|---|---|---|---|
| `name` | string | 是 | 1–200 | 合同名称 |
| `category` | string | 是 | 枚举 | 合同类型 |
| `templateVersionId` | long | 否 | — | 来源模板版本（空=空白起草） |
| `partyBId` | long | 是 | — | 相对方 ID |
| `amount` | decimal | 否 | ≥0 | 合同金额 |
| `currency` | string | 否 | CNY/USD/EUR | 币种，默认 CNY |
| `startDate` | date | 否 | — | 生效日 |
| `endDate` | date | 否 | ≥startDate | 到期日 |
| `orgId` | long | 是 | — | 归属组织 |
| `variables` | object | 否 | — | 模板变量取值 |
| `sourceRef` | object | 否 | — | 外部来源（如 `{ "bizType":"CRM_OPPORTUNITY","bizId":... }`） |

- **响应**：`{ "id":..., "contractNo":"CT2026000123", "status":"DRAFT", "currentVersionId":..., "creatorId":... }`
- **错误码**：`0000003`、`7001001`（编号重复，理论不出现）、`7001004`（必填变量缺失）。

### LEGAL-API-005 合同列表/台账

- **方法/路径**：`GET /api/legal/v1/contracts`；**端别**：PORTAL；**鉴权**：`legal:contract:view`。
- **查询参数**：`page`、`size`、`category`、`status`、`orgId`、`partyBId`、`ownerId`、`amountMin`、`amountMax`、`endDateFrom`、`endDateTo`、`keyword`（名称/编号，走 ES）。
- **响应**：分页 `records`，每条含 `id/contractNo/name/category/status/amount/currency/partyBName/ownerId/endDate/signStatus/sealStatus`；数据权限内过滤；金额与相对方联系人按权限脱敏。
- **错误码**：`0000003`、`0000002`。

### LEGAL-API-006 合同详情

- **方法/路径**：`GET /api/legal/v1/contracts/{id}`；**端别**：PORTAL；**鉴权**：`legal:contract:view`。
- **响应**：合同主档 + `currentVersion`（正文摘要 + 哈希）+ `clauses` + `parties` + `signatories` + `approvals` + `sealApplications` + `signRecords` + `evidences` + `performanceNodes` + `attachments`。
- **说明**：正文原文经文件服务鉴权后返回带短期签名的预览地址；签署人 PII 脱敏，需 `legal:sign:pii:view` 且审计后返回明文。
- **错误码**：`0000004`、`0000002`。

### LEGAL-API-007 合同版本保存

- **方法/路径**：`POST /api/legal/v1/contracts/{id}/versions`；**端别**：PORTAL；**鉴权**：`legal:contract:edit`；**幂等**：支持。
- **请求体**：`{ "contentRef": "...", "variableValues": {...}, "changeSummary": "调整违约责任条款" }`
- **规则**：生成新 `version_no`；记录 `diff_digest`；合同状态须为 `DRAFT` 或审批驳回后（非归档/签署中）。
- **响应**：`{ "contractId":..., "versionId":..., "versionNo": 3, "contentHash": "ab12..." }`
- **错误码**：`7001002`（状态不允许）、`7001011`（已归档）。

### LEGAL-API-008 合同条款维护

- **方法/路径**：`PUT /api/legal/v1/contracts/{id}/clauses`；**端别**：PORTAL；**鉴权**：`legal:contract:edit`；**幂等**：支持。
- **请求体**：`{ "contractVersionId": 18..., "clauses": [ { "clauseNo":"3.2","title":"违约责任","content":"...","isMandatory":true,"riskTag":"免责条款","sortNo":32 } ] }`
- **规则**：`isMandatory=true` 的条款不可删除（缺失返回 `7001003`）。
- **响应**：`{ "contractVersionId":..., "clauseCount": 12 }`

## 5 开放 API

### 5.1 通用

- 前缀 `/openapi/legal/v1`，由 `fenglin-openapi-service` 统一网关纳管；
- 鉴权：AppKey/AppSecret（`X-App-Key`）+ HMAC-SHA256 签名（`X-Signature`）+ OAuth2.1 授权码模式；
- 时间戳防重放（`X-Timestamp` + `X-Nonce`，5 分钟窗口）；
- 配额与限流按应用/接口维度配置，超限返回 `0000006`。

### 5.2 对外开放资源

| 资源 | 方法 | 路径 | 说明 |
|---|---|---|---|
| 合同台账 | GET | `/openapi/legal/v1/contracts` | 只读，按授权范围返回脱敏数据 |
| 合同状态 | GET | `/openapi/legal/v1/contracts/{id}/status` | 合同编号/状态/签署进度 |
| 发起签署 | POST | `/openapi/legal/v1/sign/initiate` | 由外部系统发起签署（受限配额） |
| 存证凭证 | GET | `/openapi/legal/v1/evidences/{no}` | 存证摘要与核验状态 |
| DLP 事件（只读） | GET | `/openapi/legal/v1/dlp/events` | 按授权租户/时间范围查询 |

### 5.3 签名示例

```
stringToSign = METHOD + "\n" + PATH + "\n" + X-Timestamp + "\n" + X-Nonce + "\n" + sha256(body)
X-Signature = Base64(HMAC-SHA256(appSecret, stringToSign))
```

- 回调地址与应用绑定；投递携带 `X-Event`、`X-Timestamp`、`X-Signature`（HMAC-SHA256）；
- 重试：1min / 5min / 30min 三次；接收方须以 `X-Event-Id` 幂等；
- 连续失败自动告警并可暂停订阅；支持手动重放。

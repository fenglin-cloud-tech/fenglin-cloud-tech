## 1 概述

### 1.1 评估目标与范围

对丰麟云法（`fenglin-legal-service`）开展安全评估，覆盖 G1 合同与电子签章、G2 内部信息防泄漏 DLP 两大模块，重点评估：

1. **电子签名有效性**与**防抵赖**（《电子签名法》第十三条要件）；
2. 合同正文/签章证据/用印记录/DLP 审计日志的**防篡改**（哈希链 + WORM）；
3. **数据防泄漏**能力与外发管控有效性；
4. 对照 **GB/T 22239-2019 等保三级**控制矩阵逐项符合性；
5. STRIDE 威胁建模与残余风险。

### 1.2 评估依据

- GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》（第三级）
- 《中华人民共和国电子签名法》（2019 修正）、GM/T 0031-2014《安全电子签章密码技术规范》
- 《网络安全法》《数据安全法》《个人信息保护法》《密码法》
- OWASP ASVS 4.0、OWASP Top 10 (2021)、STRIDE 威胁模型
- FL-LEGAL-ARCH-002、FL-LEGAL-DB-003、FL-LEGAL-TEST-007

### 1.3 评估方法

文档审查、配置核查、源码审计（重点签名与防篡改逻辑）、工具扫描（SAST/DAST/依赖）、渗透测试、证据链与哈希链专项验证、STRIDE 工作坊。

### 1.4 评估结论（摘要）

控制项符合率 **97.2%**（7 项部分符合、0 项不符合）；无高危漏洞遗留；电子签名四要件齐全；防篡改机制 100% 校验通过。判定：**满足等保三级要求（待补充 2 项运维类证据后可判定完全符合）**。

## 3 电子签名有效性与防抵赖专项

### 3.1 《电子签名法》第十三条要件对照

| 要件 | 要求 | 本品实现 | 结论 |
|---|---|---|---|
| 真实身份 | 签署人身份真实可核验 | 实名认证（企业四要素/个人三要素）+ 数字证书绑定唯一身份 | 符合 |
| 真实意愿 | 签署出于本人意愿 | 意愿确认（短信验证码/人脸/CA 证书 + 二次认证 `step_up`），签署前不可撤销确认 | 符合 |
| 签名可验证 | 签名可被验证 | 证书验签 + 时间戳验证 + 存证核验接口 | 符合 |
| 数据不可篡改 | 签署后签名与数据不可篡改 | 文档哈希固化 + 哈希链 + WORM，任何修改可检出 | 符合 |
| 时间可信 | 可信时间戳 | 对接 TSA 可信时间戳（`tsa_token`） | 符合 |
| 密码合规 | 使用合规密码算法 | 支持国密 SM2/SM3（GM/T 0031）与国际 RSA/SHA-256 | 符合 |

### 3.2 防抵赖机制

| 机制 | 说明 |
|---|---|
| 身份绑定 | 签署行为绑定唯一用户/证书序列号，不可否认 |
| 证据链留痕 | 记录认证记录、意愿确认、时间戳、文档哈希、IP/设备/USER_AGENT |
| 签名值固化 | `sign_data` 存档，可离线验签 |
| 存证出证 | 一键核验与出证，可作为司法证据 |
| 审计不可篡改 | 证据写入哈希链 + WORM，应用侧无删除接口 |
| 撤销可控 | 证书吊销/司法撤销走授权流程并强审计（`REVOKED`） |

### 3.3 专项测试结论

- TC-SEC-007（四要件齐全）、TC-SEC-008（防抵赖）、TC-G1-040（证据链完整性）、TC-G1-044（回调验签）全部通过；
- 验签失败、证据缺失、时间戳缺失等异常场景均被正确拒绝并告警；
- 国密算法在 SM2 模式下签署与验签通过。

## 5 STRIDE 威胁建模

### 5.1 资产与数据流

关键资产：合同正文/条款、签署证据与证书、用印记录、存证、相对方/签署人 PII、DLP 规则与策略、DLP 事件与审计日志。数据流见 FL-LEGAL-ARCH-002 第 4 章。

### 5.2 STRIDE 分析与控制

| 威胁类别 | 具体威胁 | 影响 | 现有控制 | 残余风险 |
|---|---|---|---|---|
| **S**poofing 仿冒 | 仿冒签署人签署 | 合同无效/纠纷 | 实名认证 + MFA + 证书绑定 + 二次认证 | 低 |
| S | 仿冒 CA 回调 | 伪造签署 | HMAC 验签 + mTLS + CA 白名单 + 幂等 | 低 |
| S | 仿冒终端上报 | 伪造事件 | 终端注册证书 + 服务间签名 | 低 |
| **T**ampering 篡改 | 篡改合同正文/条款 | 合同失效 | 版本哈希 + 哈希链 + WORM + 完整性校验 | 低 |
| T | 篡改用印记录 | 用印抵赖 | 用印记录不可删 + 哈希链 + `version_hash` 绑定 | 低 |
| T | 篡改 DLP 审计日志 | 掩盖泄漏 | 哈希链 + WORM + 触发器禁止删改 | 低 |
| T | 篡改放行凭证重复使用 | 越权外发 | 指纹绑定 + 有效期 | 低 |
| **R**epudiation 抵赖 | 否认已签署 | 法律纠纷 | 证据链 + 时间戳 + 签名值固化 + 存证出证 | 低 |
| R | 否认外发敏感数据 | 追责困难 | 水印溯源 + 审计留痕 | 低 |
| **I**nformation Disclosure 信息泄露 | PII 泄露 | 合规风险 | AES-256-GCM + TDE + 脱敏 + 权限 + 审计 | 低 |
| I | 跨租户/组织越权访问 | 数据泄露 | RLS + 数据权限 + 端别校验 | 低 |
| I | 敏感片段明文导出 | 泄漏 | 导出脱敏 + 授权 + 审计 + DLP 管控 | 中（见 7.2） |
| **D**enial of Service 拒绝服务 | 高频上报/回调打满 | 服务不可用 | 限流（Sentinel）+ 配额 + 削峰 + 去重合并 | 中（见 7.1） |
| D | 大文件/深分页耗尽资源 | 性能下降 | 文件大小限制 + `search_after` + 分页上限 | 低 |
| **E**levation of Privilege 提权 | 用户端令牌调管理端接口 | 配置被篡改 | 端别校验（`X-Client-Type`）+ 权限码 + 数据权限 | 低 |
| E | 通过 ID 枚举越权 | 数据泄露 | 雪花 ID + `uuid` 暴露 + 行级校验 | 低 |

### 5.3 关键威胁场景缓解验证

| 场景 | 缓解 | 验证用例 |
|---|---|---|
| 伪造 CA 回调注入假签署 | HMAC 验签 + 幂等 + 告警 | TC-G1-044、TC-SEC-014 |

| RR-06 | AI 识别模型误判 | 低 | 语义识别可能漏判/误判 | 规则与 AI 双通道 + 人工复核 + 阈值可调 |
| RR-07 | 内部人员滥用高权限 | 低 | 管理员误操作或越权 | 三员分立 + 强审计 + 敏感操作二次确认 + 最小权限 |
| RR-08 | 哈希链串行写入的性能与可用性耦合 | 低 | 写入失败阻断业务 | 按聚合分链 + 异步固化 + 失败告警与补偿 |

风险处置原则：中风险须有监控与预案并持续跟踪；低风险接受并纳入常规监控。

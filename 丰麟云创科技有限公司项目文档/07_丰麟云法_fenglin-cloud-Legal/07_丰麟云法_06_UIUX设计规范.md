## 1 设计原则

1. **合规可信**：法务与风控场景强调权威感与可信感，关键操作（用印、签署、放行）须有"确认—留痕—可追溯"的视觉与交互表达。
2. **双端一致、归属清晰**：管理与用户两端共用同一套令牌与组件基础，但信息密度、导航结构与操作重心按端别差异化。
3. **数据安全可视化**：敏感级别、水印、拦截、密级以统一色板与标识呈现，用户一眼可辨。
4. **效率优先**：合同与事件处理为高频操作，列表支持批量、筛选、快捷操作；详情页信息分层，减少跳转。
5. **防误操作**：不可逆动作（用印、归档、放行、吊销）二次确认 + 原因填写 + 审计提示。
6. **响应式**：桌面优先（合同编辑器），移动端保证审批、签署、待办等轻操作可用。

## 4 组件规范

（基础组件继承 FL-HUB-STD-001 第 8 章；以下为云法业务组件。）

| 组件 | 说明 | 关键交互 |
|---|---|---|
| 密级标签 `LevelTag` | 展示数据密级（图标+文字+底色） | 悬浮显示分级依据 |
| 合同状态标签 `ContractStatusTag` | 合同/签署/用印状态 | 颜色按状态映射；点击筛选 |
| 审批流时间轴 `ApprovalTimeline` | 审批节点与意见 | 展示审批人、时间、意见、动作 |
| 签署进度条 `SignProgress` | 签署方签署进度 | 顺序签展示当前激活节点；点击查看详情 |
| 存证核验卡 `EvidenceCard` | 存证编号 + 哈希 + 核验按钮 | 一键核验，显示结果与时间 |
| 哈希展示 `HashText` | 等宽字体 + 复制 + 前缀缩略 | 悬浮显示完整哈希 |
| 文件指纹展示 `FingerprintBadge` | 指纹前缀 + 匹配来源 | 悬浮显示比对信息 |
| 外发事件卡 `DlpEventCard` | 事件摘要（通道/级别/动作） | 展开查看命中片段（脱敏） |
| 水印预览 `WatermarkPreview` | 明水印叠加预览 | 切换明/暗水印示意 |
| 放行凭证 `ReleaseTicket` | 放行对象/有效期 | 到期倒计时，过期置灰 |
| 敏感片段高亮 `SnippetHighlight` | 命中片段标注 | 脱敏显示，需权限看原文 |
| 相对方选择器 `PartySelector` | 检索/新建相对方 | 支持模糊检索 + 新建 |
| 变量填充表单 `VariableForm` | 按模板变量动态生成 | 必填校验，取值来源提示 |
| 条款编辑器 `ClauseEditor` | 结构化条款增删改 | 必留条款禁删，风险标签提示 |

交互统一：

- 加载：按钮 loading + 骨架屏；长任务（导入/导出）用"任务中心"异步展示进度；
- 空态：插画 + 文案 + 主操作；
- 错误：行内校验（表单）/ 全局消息（操作失败）/ 页面级错误（500）；
- 不可逆操作：二次确认弹窗 + 原因必填 + 提示"该操作将写入审计且不可撤销"。

## 5 管理端设计规范

- 导航：法务总览、合同配置（模板/字段/字典/提醒）、印章与证书、CA 服务商、DLP 策略（规则/策略/通道/白名单）、DLP 监控（终端/事件审计）、审计报表。
- 首页（法务总览 `Dashboard`）卡片：合同总量与状态分布、待审批队列、用印待办、印章/证书到期预警、DLP 事件趋势、拦截/放行/误报率、TOP 风险通道与人员。
- 配置类页面：左侧配置分类 + 右侧表单/列表；保存前实时校验（如正则合法性、策略冲突 `7002002`）。
- DLP 策略配置采用"条件构建器"（数据级别 + 组织/角色 + 通道 + 动作），可视化生成，避免手填 JSON。
- 审计与报表：默认近 30 天，支持维度切换与导出（导出走异步任务 + 脱敏 + 审计）。
- 危险操作（吊销印章、删除策略、关闭通道）须二次确认 + 原因 + 告警提示。
- 权限提示：无权限的入口按数据权限隐藏或置灰并说明原因。

## 6 用户端设计规范

- 导航：工作台、合同（台账/起草/我参与的）、用印（申请/用印台）、签署（签署中心）、履约、DLP（事件/放行/水印/我的外发）、存证。
- 工作台 `Workbench` 卡片：待我审批、我起草的、待我签署、履约到期提醒、我的 DLP 待处置事件、到期合同提醒。
- 合同起草：左侧模板选择 + 变量填充，右侧实时预览；变量未填即时提示（提交前强校验）。
- 用印：申请表单含合同版本选择、印章选择、份数、用途、位置；提交后展示审批进度。
- 签署中心：签署任务列表；签署页展示合同全文 + 签署位置 + 身份核验 + 意愿确认（二次认证）流程；签署完成展示存证编号与凭证。
- DLP 事件处置：事件卡片式列表，按风险分与 SLA 排序；处置表单含结论与整改项；误报标记需原因。
- 移动端：审批、签署、待办以卡片流呈现；签署支持移动端意愿确认（短信/人脸）。
- 脱敏与权限：无 `legal:sign:pii:view` 时 PII 脱敏展示，并提供"申请查看"入口。

| 维度 | 管理端 `/admin/legal` | 用户端 `/app/legal` |

## 9 可访问性与响应式

### 9.1 可访问性（对齐 WCAG 2.1 AA）

- 文本对比度 ≥ 4.5:1；聚焦态可见（2px 品牌色描边）；
- 所有交互元素可键盘操作（Tab 顺序合理），弹窗聚焦陷阱与 Esc 关闭；
- 图标按钮具备 `aria-label`；表格首列复选同 `Enter` 操作；
- 不只以颜色传达信息（密级/状态均含图标 + 文字）；
- 尊重 `prefers-reduced-motion`，降级动画。

### 9.2 响应式

| 断点 | 管理端 | 用户端 |
|---|---|---|
| ≥1440 | 多列看板 | 多列卡片 |
| 1200–1439 | 标准两栏 | 标准两栏 |
| 992–1199 | 侧边栏折叠 | 侧边栏折叠 |
| 768–991 | 表格横向滚动/卡片化 | 列表卡片化 |
| <768 | 审批/监控简版可用 | 审批/签署/待办卡片流，点击区 ≥44×44px |

移动端优先保障：待办审批、合同签署、事件处置、到期提醒四类轻操作。

### 10.3 空态与错误态

- 空态：插画（合同/盾牌/水印主题）+ 说明 + 主操作按钮；
- 加载失败：错误插画 + "重试"按钮 + 错误码（如 `7001008`）；
- 部分失败（批量）：汇总条 + 失败明细可下载；
- 网络断开：顶部横幅"网络异常，请稍后重试"，保留本地草稿。

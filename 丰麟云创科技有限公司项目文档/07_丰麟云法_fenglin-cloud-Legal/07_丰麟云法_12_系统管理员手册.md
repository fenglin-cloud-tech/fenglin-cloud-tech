## 1 手册说明

本手册面向**管理端**使用者：平台运维、租户管理员、法务业务管理员、信息安全管理员。管理端地址：`https://legal.fenglincloud.com/admin/legal`，采用与用户端一致的登录方式，权限域为 `platform:*` 与 `tenant:*`。

| 项 | 说明 |
|---|---|
| 端别 | 管理端（`X-Client-Type: ADMIN`） |
| 主要职责 | 配置、授权、审核策略、印章管理、DLP 策略、终端管理、监控审计 |
| 双端隔离 | 管理端与用户端严格分离，权限域、路由、前端工程互不串用 |

> 合同起草/审批/用印申请/签署等业务操作为**用户端**功能，见《用户操作手册》。

## 2 登录与管理总览

### 2.1 登录与安全

1. 访问 `/admin/legal` 并使用管理员账号登录（强制 MFA）；
2. 平台超管与租户管理员权限严格区分，遵循**三员分立**（系统管理/审计管理/安全管理）；
3. 敏感操作（吊销印章、删除策略、关闭通道、导出审计）需二次确认并记录审计。

### 2.2 法务总览 Dashboard

管理端默认首页提供：

| 卡片 | 内容 |
|---|---|
| 合同概览 | 合同总量、状态分布、金额分布 |
| 审批队列 | 待审批合同/用印统计与超时预警 |
| 印章与证书 | 印章数量、证书到期预警（≤30 天） |
| DLP 监控 | 外发事件趋势、拦截/放行/误报率 |
| TOP 风险 | 高风险通道、TOP 风险人员与文件 |
| 系统健康 | 服务可用性、接口 P95、任务执行状态 |

### 2.3 导航结构

法务总览 · 合同配置（模板/字段/字典/提醒）· 印章与证书 · CA 服务商 · DLP 策略（规则/策略/通道/白名单）· DLP 监控（终端/事件审计）· 审计报表 · 租户与权限。

## 3 合同模板与字段配置

### 3.1 模板配置（合同配置 → 模板）

1. 新建模板，填写名称、分类（采购/销售/劳务/保密/租赁/其他）、适用组织与可见范围；
2. 上传模板正文；
3. 配置**变量**（`PUT /admin/contract-templates/{id}/variables`）：变量键、显示名、类型（文本/数字/日期/下拉/相对方）、是否必填、默认值、取值来源（手工/合同字段/系统/外部）；
4. 发布版本：发布后该版本不可修改，修改需发布新版本（版本号递增）。

### 3.2 字段权限配置（合同配置 → 字段）

- 配置敏感字段的**脱敏**与**可见角色**，例如将 `signerMobile` 设为脱敏且仅 `LEGAL_ADMIN` 可见明文；
- 保存后立即生效，变更写入审计。

### 3.3 字典配置（合同配置 → 字典）

- 维护合同类型、履约节点类型、终止类型等字典项（`PUT /admin/config/dictionary`）。

### 3.4 到期提醒配置（合同配置 → 提醒）

- 配置提醒天数（默认 T-90/60/30/15/7）、触达渠道（站内信/邮件/短信）、接收人（负责人/合同管理员）；
- 是否启用履约逾期提醒。

## 4 印章与证书管理

### 4.1 新增印章（印章与证书 → 新增）

1. 填写印章名称、类型（电子章/实物章）、绑定主体；
2. 电子章需填写证书序列号、算法（SM2/RSA）、有效期、CA 服务商、保管人；
3. 保存后印章状态为 `ACTIVE`；证书私钥由 KMS 托管，管理端不持有私钥。

### 4.2 证书到期与吊销

- 列表支持按 `expiringInDays` 查询临近到期证书（建议 ≤30 天预警）；
- 吊销：`POST /admin/seals/{id}/revoke`，需二次确认并强审计；
- 印章停用/吊销后，用印申请将被拒绝（`7001006`）。

### 4.3 用印监督

- 管理端可查看用印记录（只读，不可删除）；
- 关注异常用印（非审批版本、高频用印、非工作时段）。

## 5 CA 服务商配置

### 5.1 配置服务商

1. 进入 **CA 服务商** → **新增/编辑**；
2. 填写编码（FADADA/ESIGN/CFCA/SELF_BUILT）、接入地址、AppId、密钥引用（`secretRef`，经 KMS）、算法、优先级；
3. 保存并执行**连通性探测**，返回 `connectivity: OK` 表示可用。

### 5.2 多服务商与灰度

- 支持配置多个服务商并设置优先级，签署时可切换；
- 建议先启用 1 个服务商并完成签署验证，再启用多服务商；
- 服务商不可用时，签署任务自动排队重试（指数退避），超限转人工并告警。

### 5.3 回调与安全

- 配置回调地址白名单与验签密钥；
- 回调启用验签（`legal.sign.callback.verify=true`），验签失败拒绝并告警。

## 6 DLP 规则、策略与通道配置

### 6.1 敏感识别规则（DLP 策略 → 规则）

| 规则类型 | 说明 |
|---|---|
| KEYWORD/REGEX | 关键字/正则（身份证、银行卡、手机号等） |
| FINGERPRINT | 文件指纹/文档相似度（阈值可配） |
| MODEL | 语义识别（经 `fenglin-ai-service`，置信度阈值可配） |
| CLASSIFICATION | 分类分级标签 |

- 规则有**优先级**（数值小者优先）与**数据级别**；
- 创建后可用**规则测试**（`/sensitive-rules/test`）用样本验证命中；
- 非法正则会返回 `7002001`。

### 6.2 DLP 策略（DLP 策略 → 策略）

1. 新增策略，配置：数据级别 + 适用组织/角色 + 通道 + **动作**（告警/审计/拦截/审批放行/加密/加水印）+ 优先级 + 生效时间；
2. 动作优先级：BLOCK > APPROVE > ENCRYPT > WATERMARK > WARN > AUDIT > ALLOW；
3. 保存前系统校验**策略冲突**（同级别+通道+时间重叠+同优先级），冲突返回 `7002002`；
4. 保存后策略版本递增并失效缓存，实时决策立即生效。

> 建议：策略先在**告警模式**运行观察 1–2 周，评估误报后再切换为拦截，避免影响业务。

### 6.3 通道管控（DLP 策略 → 通道）

- 支持通道：USB、打印、剪贴板、截屏、网盘、邮件、IM、Web 上传；
- 可逐通道启停并设置默认动作；
- 通道关闭时该通道不拦截（按策略或默认），未启用返回 `7002004`。

## 7 DLP 白名单与终端管理

### 7.1 白名单（DLP 策略 → 白名单）

1. 新增白名单：名称、通道、匹配类型（组织/角色/用户/文件/URL）、匹配值、数据级别、依据、生效期；
2. 白名单须经审批（记录审批），**有效期必填**，到期自动失效并通知复核；
3. 命中白名单不拦截但**留审计**；无审批的白名单将被拒绝（`7002005`）。

### 7.2 终端管理（DLP 监控 → 终端）

- 查看受管终端列表：终端编号、主机名（脱敏）、系统、绑定用户、Agent 版本、已下发策略版本、最近心跳、状态；
- 终端离线（心跳 >5min）或未注册时，按策略阻断敏感外发（`7002008`）；
- 关注**终端覆盖率**与**离线率**，覆盖率不足存在泄漏盲区；
- 违规终端可置 `BLOCKED`（需人工解封）。

## 8 审计与报表

### 8.1 审计查询

- **合同审计**：审批、用印、签署、归档等关键操作留痕；
- **DLP 审计**（`GET /admin/dlp/audit-logs`）：规则/策略/通道/白名单变更、决策、水印、事件处置、放行；
- 审计数据经**哈希链 + WORM**保护，应用侧无删除接口；留存 12 个月（合同与签署证据长期）。

### 8.2 审计链校验

- `POST /admin/dlp/audit-logs/verify`：校验哈希链完整性；
- 发现断链返回 `7002007` 并自动告警；
- 定期（每日）执行校验并将结果纳入巡检记录。

### 8.3 报表

| 报表 | 内容 |
|---|---|
| 合同统计报表 | 按组织/类型/状态/月份统计数量与金额 |
| DLP 风险报表 | 按组织/通道/级别/人员的外发趋势、拦截率、放行率、误报率 |
| 签章合规报表 | 实名覆盖率、意愿确认覆盖率、证据完整率、时间戳覆盖率 |

- 报表支持时间范围与维度切换，可导出（脱敏 + 审计）；
- 报表数据每日定时推送。

## 9 租户、组织与权限

### 9.1 租户与配额

- 平台运维可管理租户、套餐与配额（应用、用户数、事件上报配额、存储）；
- 跨租户访问仅平台运营端且强审计。

### 9.2 组织与数据权限

- 维护组织树；用户归属组织决定数据权限范围（本人/本部门/本部门及下级/指定/全部）；
- 合同与 DLP 事件按组织隔离。

### 9.3 角色与权限

| 角色 | 端 | 主要权限域 |
|---|---|---|
| 租户管理员 | 管理端 | `tenant:legal:*` |
| 法务业务管理员 | 管理端 | 模板/印章/提醒/字段/DLP 配置 |
| 信息安全管理员 | 管理端 | DLP 规则/策略/通道/白名单/终端 |
| 合同管理员 | 用户端 | `legal:contract:*` |
| 法务专员 | 用户端 | 审批/会签 |
| 用印管理员 | 用户端 | 用印执行 |
| DLP 审计员 | 用户端 | 事件处置/审计/溯源 |

- 权限遵循**最小权限**；查看 PII 明文需专用权限码并审计；
- 人员离职触发权限回收与持有任务转办（联动 IAM）。

## 10 系统运维与监控

### 10.1 监控看板

- 服务可用性（目标 ≥99.99%）、接口 P95（≤300ms）、错误率（≤0.1%）；
- DLP 决策 P95（≤300ms）、事件上报积压、消费延迟（≤5s）；
- 哈希链写入成功率、完整性校验结果、CA 调用失败率、终端在线率。

### 10.2 定时任务

| 任务 | 频率 | 说明 |
|---|---|---|
| `legalExpiryReminderJob` | 每日 08:00 | 到期提醒（T-90/60/30/15/7） |
| `legalIntegrityVerifyJob` | 每日 02:00 | 合同/证据哈希链完整性校验 |
| `legalDlpAuditVerifyJob` | 每日 03:00 | DLP 审计链校验 |
| `legalSearchReconcileJob` | 每小时 | ES 与数据库对账 |
| `legalArchiveJob` | 每月 | 数据归档与分区维护 |

任务异常需在 XXL-Job 控制台检查执行记录并重跑。

### 10.3 日常巡检

- **每日**：健康检查、错误日志、Kafka 积压、哈希链校验、CA 连通性、证书到期；
- **每周**：慢查询、容量趋势、终端在线率、DLP 误报率、备份完整性；
- **每月**：分区维护、归档执行、策略复盘、权限复核。

### 10.4 配置变更管理

- 所有配置变更（策略/规则/印章/CA）均记录审计，支持追溯变更人与时间；
- 重大变更前评估影响范围（策略可先告警模式），并在变更窗口执行；
- 变更失败或异常立即回滚配置版本。

### 10.5 应急处理要点

| 事件 | 处置 |
|---|---|
| 完整性告警 | 立即冻结受影响对象，核对 WORM，启动应急与法务介入 |
| DLP 拦截失效 | 按默认策略阻断敏感通道，排查决策链路 |
| CA 大面积不可用 | 切换备用服务商，签署排队重试，公告 |
| 高频上报异常 | 触发限流与终端隔离，排查异常终端 |
| 服务不可用 | 切换双活，扩容，通知平台运维 |

详见《部署运维手册》第 11 章。

## 11 常见问题（FAQ）

| 问题 | 解答 |
|---|---|
| 合同提交审批报"变量未填充"？ | 检查模板必填变量配置与合同变量快照。 |
| 用印报"版本不一致"？ | 用印版本须等于审批终态版本，请核对后重新申请。 |
| 用印报"印章不可用"？ | 检查印章状态（启用/停用/吊销/过期）与证书有效期。 |
| 签署任务一直未完成？ | 检查 CA 服务连通性与回调；顺序签需前序完成。 |
| 策略保存报"冲突"？ | 存在同级别+通道+时间重叠+同优先级的策略，调整优先级或时间。 |
| 白名单为何失效？ | 白名单有有效期，到期自动失效，需重新审批复核。 |
| 为什么有些终端不生效？ | 终端离线或未注册，需检查 Agent 心跳与覆盖率。 |
| 审计日志能否删除？ | 不能。审计日志哈希链 + WORM 保护，任何删改可检出。 |
| 如何确认数据未被篡改？ | 使用完整性校验/审计链校验接口，或每日巡检结果。 |
| 能否导出审计数据？ | 可以，但需权限且脱敏，导出行为记入审计。 |

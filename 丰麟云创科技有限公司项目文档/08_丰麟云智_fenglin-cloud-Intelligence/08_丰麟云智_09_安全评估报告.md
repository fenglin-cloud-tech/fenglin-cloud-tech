## 1 评估范围

### 1.1 资产范围

| 资产 | 说明 |
|---|---|
| 门户 | 用户端 `/app/intelligence`、管理端 `/admin/intelligence` |
| 接口 | `/api/intelligence/v1/**`、能力嵌入契约 `/internal/**`、开放 API `/openapi/intelligence/v1` |
| 服务 | `fenglin-intelligence-service` 及依赖（ES/Milvus/ClickHouse/Redis/Kafka/MinIO） |
| 数据 | 知识文档与分块、向量、会话消息、BI 数据集/指标/看板、洞察结果、**数据源凭据**、**模型 API Key**、用量计量 |
| 双模式 | `standalone`（门户暴露）与 `embedded`（仅内部契约） |

### 1.2 重点评估项

1. **数据源凭据保护**：连接凭据与模型 Key 的加密、访问与轮换；
2. **模型数据出境与合规**：敏感数据投喂、出境评估、生成内容合规；
3. **检索越权**：权限感知检索、文档 ACL/密级、跨租户隔离；
4. **LLM 提示注入与输出合规**：注入防护、输出内容安全、脱敏与标识。

### 1.3 评估方法

- 控制矩阵对照（等保三级）；STRIDE 威胁建模；SAST/DAST/SCA 扫描；渗透测试（越权/注入/SSRF/敏感信息）；LLM 红队用例集（注入 ≥ 100、输出合规 ≥ 50）。

## 2 等保三级控制矩阵逐项对照

| 控制类别 | 控制项 | 本品措施 | 结论 |
|---|---|---|---|
| 身份鉴别 | 双因子/强口令/登录失败锁定 | 复用 IAM：MFA、口令复杂度、5 次锁定、会话 30min 超时；服务间 mTLS+服务令牌 | 符合 |
| 访问控制 | 最小权限、职责分离 | RBAC+ABAC+数据权限；三员分立（系统/安全/审计管理员）；能力授权按宿主最小化 | 符合 |
| 安全审计 | 全量审计、防篡改 | 检索/问答/洞察/授权/计量全链路审计，哈希链+WORM，留存 ≥ 6 个月（建议 12 个月） | 符合 |
| 入侵防范 | 边界防护、攻击检测 | WAF/IDS/IPS；Sentinel 限流；候选注入防护；定期漏洞扫描 | 符合 |
| 恶意代码防范 | 主机/应用防护 | HIDS、镜像扫描、依赖 SCA；上传文档病毒扫描 | 符合 |
| 数据完整性 | 传输/存储完整性 | TLS1.3、mTLS、HMAC；向量/索引对账；计量不可篡改 | 符合 |
| 数据保密性 | 传输/存储加密 | 传输 TLS；**数据源凭据/模型Key AES-256-GCM**；PII 加密；DB TDE；KMS 轮换 ≤ 90 天 | 符合 |
| 数据备份恢复 | 本地+异地备份、演练 | 每日全备+增量、异地容灾、季度演练；索引可重建 | 符合 |
| 剩余信息保护 | 数据擦除 | 会话/缓存剩余信息清理；向量删除同步；介质销毁流程 | 符合 |
| 个人信息保护 | 最小必要、脱敏、同意 | PII 最小采集、脱敏展示、授权访问、审计；不投喂公有云模型 | 符合 |
| 安全管理 | 制度、机构、人员、建设、运维 | 安全管理制度、三员分立、应急预案、供应商合规准入 | 符合 |

**重点补充对照**：

| 重点项 | 控制措施 | 结论 |
|---|---|---|
| 数据源凭据 | AES-256-GCM 密文存储（`credential_cipher`），仅存指纹 `credential_hash`；接口不回显明文；KMS 托管、轮换；访问最小化+审计 | 符合 |
| 模型数据出境 | 数据分级；涉密/敏感数据**禁止投喂公有云模型**；出境前合规评估；支持私有化/本地模型；供应商准入合规审查 | 符合 |
| 检索越权 | 权限过滤在召回阶段强制注入（ES/Milvus filter）+ 重排后复核 + 预览二次校验；跨租户 100% 拒绝 | 符合 |
| 提示注入 | 输入护栏检测（指令覆盖/越狱/越权指令）；最小权限执行；工具调用白名单；注入拦截率 ≥ 98% | 符合 |
| 输出合规 | 输出护栏（敏感信息/违规内容拦截、PII 脱敏、内容标识与水印）；生成内容可追溯 | 符合 |

## 3 威胁建模（STRIDE）

| 威胁 | 场景 | 现有控制 | 风险 | 处置 |
|---|---|---|---|---|
| Spoofing 仿冒 | 伪造用户令牌访问检索/问答 | JWT(RS256)+签名校验+MFA；服务令牌+mTLS | 中 | 已缓解；密钥轮换 |
| Spoofing 仿冒 | 伪造宿主产品调用 `/internal/**` | mTLS 双向证书 + `X-Caller-Product` 校验 | 中 | 已缓解；证书吊销 |
| Tampering 篡改 | 篡改检索结果/权限过滤器 | 过滤器服务端生成、不可由前端传入；审计哈希链 | 低 | 已缓解 |
| Tampering 篡改 | 篡改计量数据 | 计量不可 UPDATE/DELETE、对账校验 | 低 | 已缓解 |
| Repudiation 抵赖 | 否认发起检索/问答/洞察 | 全链路审计 + `X-On-Behalf-Of` 溯源 + WORM | 低 | 已缓解 |
| Info Disclosure 泄漏 | **检索越权**获取无权文档 | 权限感知检索 + 密级 + ACL + 跨租户拒绝 | 高 | 已缓解（重点验证） |
| Info Disclosure 泄漏 | **数据源凭据/模型Key** 泄漏 | AES-256-GCM + KMS + 不回显 + 最小权限 | 高 | 已缓解（重点验证） |
| Info Disclosure 泄漏 | **模型数据出境**泄密 | 数据分级 + 禁止投喂 + 出境评估 + 私有化模型 | 高 | 已缓解/持续监控 |
| Info Disclosure 泄漏 | 缓存/日志残留敏感信息 | 脱敏存储、TTL 清理、剩余信息清除 | 中 | 已缓解 |
| DoS 拒绝服务 | 大查询/NL2SQL 拖垮 DB | 查询限时限行、资源组隔离、Sentinel 限流 | 中 | 已缓解 |
| DoS 拒绝服务 | LLM 成本攻击 | 配额、限流、模型分级、成本告警 | 中 | 已缓解 |
| EoP 提权 | **提示注入**诱导越权/调用工具 | 输入护栏、工具白名单、最小权限、人工确认节点 | 高 | 已缓解（重点验证） |
| EoP 提权 | 能力授权绕过（embedded） | 授权校验前置、调用方身份绑定、审计 | 高 | 已缓解 |

## 5 加固措施

### 5.1 数据源凭据与模型 Key

1. 凭据/Key 一律 AES-256-GCM 加密存储，配套指纹用于去重，禁止明文与明文唯一索引；
2. KMS 托管密钥，版本化与轮换（≤ 90 天），凭据轮换走审计；
3. 接口与日志不回显明文；仅授权角色可配置；解密范围限内存、用后即清。

### 5.2 模型数据出境与合规

1. 数据分级（公开/内部/秘密/机密）与模型投喂策略绑定：秘密及以上禁止投喂公有云；
2. 出境场景执行合规评估与供应商准入；优先私有化/本地模型；
3. 生成内容标识、可追溯（记录模型、提示词版本、引用）；
4. 用户告知与同意；不得用于违法/侵权用途。

### 5.3 检索越权防护

1. 权限过滤器服务端生成并注入 ES/Milvus 查询，前端不可传；
2. 召回、重排、预览三处校验；跨租户默认拒绝；
3. 越权请求返回 403 且不暴露资源存在性；全程审计。

### 5.4 提示注入与输出合规

1. 输入护栏：指令覆盖、角色越狱、越权指令、敏感词检测；命中拦截并记录；
2. 执行最小权限：工具白名单、参数校验、危险操作人工确认；
3. 输出护栏：敏感信息/违规内容拦截、PII 脱敏、内容水印；
4. 红队用例集回归（≥ 100 注入 + ≥ 50 合规）。

### 5.5 通用加固

- 全链路 TLS1.3 + mTLS；Sentinel 限流熔断；WAF/IDS；
- 审计哈希链 + WORM，留存 ≥ 6 个月；
- 会话/缓存剩余信息清理；上传文档病毒扫描；
- 三员分立与最小权限；SCA/SAST/DAST 纳入流水线门禁。

## 6 合规结论

1. **等保三级**：11 类控制项逐项对照**全部符合**，重点项（数据源凭据、模型数据出境、检索越权、提示注入与输出合规）措施完备。
2. **数据合规**：满足《数据安全法》《个人信息保护法》最小必要、脱敏、可审计要求；模型数据处理符合出境评估要求。
3. **生成式 AI 合规**：符合《生成式人工智能服务管理暂行办法》——内容安全、标识、可追溯、用户权益保障。
4. **漏洞**：高危漏洞 0；中危已修复/缓解并复测通过。
5. **结论**：本品具备通过等保三级测评的条件，可上线交付。

## 7 残余风险

| 编号 | 残余风险 | 等级 | 影响 | 缓解与监控 | 接受方 |
|---|---|---|---|---|---|
| RR-01 | 第三方 LLM 供应商内容安全依赖其能力 | 中 | 偶发不当输出 | 输出双护栏 + 供应商 SLA + 抽检；必要时切私有化模型 | 产品/安全组 |
| RR-02 | 提示注入攻防持续对抗 | 中 | 新型注入可能绕过 | 红队周期回归、规则库更新、最小权限兜底 | 安全组 |
| RR-03 | 模型幻觉导致事实偏差 | 中 | 答案可信度 | 强制引用溯源、置信度提示、无命中不编造、反馈闭环 | 产品组 |
| RR-04 | 向量/索引与主数据短时不一致 | 低 | 极短窗口检索缺漏 | 事件驱动 + 补偿任务 + 对账监控 | 研发组 |
| RR-05 | 内部人员越权配置数据权限 | 低 | 数据可见范围扩大 | 三员分立、变更审计、定期权限复核 | 审计/安全组 |
| RR-06 | 数据出境政策变化 | 低 | 合规适配 | 政策跟踪、出境清单维护、私有化预案 | 合规组 |

**残余风险等级**：均为中/低，处于组织可接受范围，纳入持续监控清单，季度复评。

## 2 H1 企业级知识搜索引擎

### 2.1 功能清单

| 编号 | 功能 | 说明 | 端别 |
|---|---|---|---|
| H1-F01 | 连接器管理 | 配置本地文件/对象存储/云文档/数据库/HTTP/业务系统的接入连接器 | 管理端 |
| H1-F02 | 同步任务 | 全量/增量/CDC 同步调度与监控 | 管理端 |
| H1-F03 | 文档解析 | 正文、标题层级、表格、图片 OCR 解析 | 系统 |
| H1-F04 | 智能分块 | 语义/固定窗口/标题层级分块，参数可配 | 系统 |

### 2.2 角色权限与双端归属

| 功能 | 用户端 | 管理端 | 权限码 |
|---|---|---|---|
| 检索/预览/图谱查询 | 业务用户、分析师、只读 | — | `ai:search:query`、`ai:search:view`、`ai:kg:query` |
| 连接器/同步配置 | — | 知识管理员、智能业务管理员 | `tenant:ai:source:manage` |
| 入库审核 | — | 知识管理员 | `tenant:ai:kb:review` |
| 图谱维护 | — | 知识管理员 | `tenant:ai:kg:manage` |
| 检索分析 | — | 智能业务管理员 | `tenant:ai:search:analytics` |

**双端归属原则**：配置、授权、审核、分析归**管理端**（`/admin/intelligence/knowledge/**`）；检索、预览、图谱查询归**用户端**（`/app/intelligence/search`）。

### 2.3 业务规则

1. **编号规则**：知识库 `AIKB{yyyyMM}{6位}`；文档沿用来源标识+校验和去重。
2. **密级规则**：文档密级 1 公开/2 内部/3 秘密/4 机密；用户密级 ≤ 文档密级方可召回与预览。
3. **审核规则**：`review_status=APPROVED` 且 `index_status=INDEXED` 后方可被检索；敏感文档（密级 ≥ 3）强制审核。
4. **检索规则**：混合权重默认全文 0.4 + 向量 0.6，可配；Top-K 默认 20，Rerank 后返回 10；无命中时返回空并建议放宽条件。
5. **一致性规则**：分块 ID 全局唯一，PG 为权威源，ES/向量库为派生，事件驱动最终一致。
6. **权限叠加规则**：知识库可见范围 ∩ 数据权限范围 ∩ 文档 ACL ∩ 密级，任一不满足即不召回。
7. **审计规则**：检索、预览、图谱查询、审核均写审计日志，保留 ≥ 6 个月。

### 2.4 状态机（索引任务）

```
        创建任务
           │
      ┌────▼─────┐  解析失败(可重试)
      │ PENDING  │─────────────┐
      └────┬─────┘             │
           │ 开始              │
      ┌────▼─────┐             │
      │ PARSING  │─────────────┤
      └────┬─────┘             │
           │ 解析成功          │
      ┌────▼─────┐             │
      │ CHUNKING │─────────────┤
      └────┬─────┘             │
           │ 分块完成          │
      ┌────▼──────┐            │
      │ EMBEDDING │────────────┤
      └────┬──────┘            │
           │ 向量生成          │
      ┌────▼─────┐             │
      │ INDEXING │─────────────┤
      └────┬─────┘             │
           │ 写入完成          │ 重试超限/永久失败
      ┌────▼──────┐      ┌─────▼────┐
      │ SUCCEEDED │      │  FAILED  │
      └───────────┘      └──────────┘
```

- 触发：文档审核通过（自动）、手工重建（管理端）、增量同步事件。
- 幂等：同一文档同版本任务唯一（幂等键 `document_id+version`）。
- 重试：最多 3 次，指数退避；失败写入 `error_msg` 并告警。
- 断点续传：`INDEXING` 阶段按分块批次续传。

### 2.5 工作流：知识入库审核（BPMN）

**流程标识**：`aiKnowledgeReview`（Flowable，BPMN 2.0）

```
[开始] → (提交入库申请) → <网关:密级判断>
     ├─ 密级 ≤ 2 且非敏感 → [自动通过] → [发布并触发索引] → [结束]
     └─ 密级 ≥ 3 或标记敏感 → [知识管理员审核]
                                ├─ 通过 → [发布并触发索引] → [通知提交人] → [结束]
                                └─ 驳回(附理由) → [通知提交人] → [结束]
```

**节点说明**：

| 节点 | 类型 | 参与角色 | 说明 |
|---|---|---|---|
| 提交入库申请 | 用户任务 | 业务用户/知识管理员 | 选择知识库、上传/关联文档、设定密级与标签 |
| 密级判断 | 排他网关 | 系统 | 按密级与敏感标记路由 |
| 自动通过 | 服务任务 | 系统 | 低密级文档直接通过 |
| 知识管理员审核 | 用户任务 | 知识管理员 | 内容合规、密级核验、重复检查 |
| 发布并触发索引 | 服务任务 | 系统 | 置 `APPROVED` 并发起 `ai_index_task` |
| 通知 | 服务任务 | 消息服务 | 站内信/邮件通知 |

**异常边界**：审核超时（默认 3 个工作日）自动提醒；驳回必须附理由；审核期间文档不可检索。

### 2.6 异常与边界

| 场景 | 处理 |
|---|---|
| 连接器不可达 | 同步任务失败并告警，保留上次成功快照，不删除已有索引 |
| 解析加密/损坏文档 | 标记解析失败，记录原因，跳过该文档不阻断批次 |
| 嵌入服务限流 | 排队重试（退避），必要时降级为仅全文索引并标记 |
| 向量库写失败 | 事务补偿重试，保证 PG 与索引最终一致 |
| 检索超时 | 返回已获得的部分结果并提示；记录慢查询 |
| 越权访问预览 | 返回 403 并审计；不泄漏文档是否存在 |
| 大文档（>100MB） | 分片处理，超限拒绝并提示拆分 |

### 2.7 验收标准

| 编号 | 验收项 | 标准 |
|---|---|---|
| AC-H1-01 | 多源接入 | ≥ 6 类数据源，成功率 ≥ 99%，增量延迟 ≤ 5min |
| AC-H1-02 | 混合检索 | P95 ≤ 300ms；NDCG@10 较单一检索提升 ≥ 8% |
| AC-H1-03 | 权限感知 | 越权召回 0；越权预览 100% 拦截并审计 |
| AC-H1-04 | 图谱 | 实体/关系抽取准确率 ≥ 85% |
| AC-H1-05 | 审核流 | 审核通过后 ≤ 5min 可检索；驳回附理由 |

### 2.8 与标杆产品差异点

对比滴普科技 DEEPEXI：

1. **双模式交付**：DEEPEXI 以独立平台交付；本模块额外支持 `embedded` 能力嵌入，作为中台向 7 款业务产品输出检索能力；
2. **权限感知原生内置**：将数据权限、文档 ACL、密级、租户边界统一为 Filter DSL，检索阶段强制过滤，区别于外挂式权限；
3. **多租户 SaaS 与私有化一致**：同一代码，向量集合可物理隔离或逻辑过滤；
4. **知识图谱与检索融合**：图谱作为检索结果的关联推荐与路径发现，而非独立产品。

### 3.2 角色权限与双端归属

| 功能 | 用户端 | 管理端 | 权限码 |
|---|---|---|---|
| 对话/写作/总结/翻译 | 业务用户、分析师 | — | `ai:chat:use`、`ai:writing:use`、`ai:summarize:use`、`ai:translate:use` |

| 用量统计 | — | 智能业务管理员 | `tenant:ai:usage:view` |

### 3.3 业务规则

1. **上下文规则**：默认 8 轮或 8K token 窗口，超限摘要压缩；会话级隔离，不跨会话记忆。
2. **RAG 规则**：先检索后生成；引用必须来自召回分块；"仅依据知识库"模式下无命中须明确告知，不得编造。
3. **引用规则**：引用展示文档名+分块片段+定位链接；链接访问再次校验权限。
4. **护栏规则**：输入侧检测提示注入（指令覆盖/角色越狱/越权指令/敏感词）；输出侧检测敏感信息与违规内容；命中按策略拦截/脱敏/告警。
5. **模型路由规则**：按任务类型与成本策略路由；供应商不可用时自动切换备用；超配额拒绝或降级。
6. **隐私规则**：个人知识仅本人可见；敏感数据不投喂公有云模型（按数据等级策略）。
7. **版本规则**：提示词/Agent 按版本管理，支持灰度与回滚；运行记录留存版本号。

### 3.4 状态机（Agent 执行）

```
        创建执行
           │
      ┌────▼─────┐
      │ PENDING  │
      └────┬─────┘
           │ 调度
      ┌────▼─────┐   人工确认节点
      │ RUNNING  │◄─────────────┐
      └────┬─────┘              │
           │ 到达人工确认节点     │ 用户确认/补充
      ┌────▼────────────┐       │
      │ WAITING_CONFIRM │───────┘
      └────┬────────────┘
           │ 完成全部步骤      │ 用户取消
      ┌────▼──────┐      ┌────▼──────┐
      │ SUCCEEDED │      │ CANCELLED │
      └───────────┘      └───────────┘
           ▲
           │ 步骤失败且不可恢复
      ┌────┴─────┐
      │  FAILED  │
      └──────────┘
```

- 最大步数 `max_steps`（默认 20）防死循环；超限置 `FAILED`。
- 每步记录 `steps` 轨迹（输入/输出/工具/耗时）支持回放。
- 幂等：`Idempotency-Key` + `agent_id+input_hash`。

### 3.5 工作流：RAG 问答与 Agent 编排

**RAG 问答流程（BPMN 说明，`aiRagQa`）**：

```
[开始:用户提问] → [输入护栏检查] → <网关:是否拦截>
      ├─ 拦截 → [返回安全提示] → [结束]
      └─ 放行 → [计算权限过滤器] → [混合检索(ES+向量)] → [RRF融合+Rerank Top-K]
                 → <网关:是否有命中>
                    ├─ 无命中 → [明确告知并建议] → [结束]
                    └─ 有命中 → [组装Prompt(含引用)] → [LLM流式生成] → [输出护栏/脱敏]
                                → [标注引用] → [落库] → [结束]
```

**Agent 编排流程（`aiAgentRun`）**：

```
[开始] → [加载 Agent 定义(版本)] → [执行节点循环]
   节点类型：
     - LLM 节点：调用模型生成
     - 检索节点：调用 H1 混合检索（权限感知）
     - 工具节点：调用内部能力契约/开放 API
     - 条件节点：按表达式分支
     - 循环节点：按集合迭代
     - 人工确认节点：暂停等待用户确认
   → <网关:是否达到终止条件>
       ├─ 是 → [汇总输出] → [结束]
       └─ 否 → 继续下一节点（步数+1，超限转 FAILED）
```

### 3.6 异常与边界

| 场景 | 处理 |
|---|---|
| LLM 超时/不可用 | 切换备用模型；全部不可用则降级为"仅检索结果+模板回复" |
| 提示注入命中 | 拦截并记录，返回安全提示，不执行越权指令 |
| 输出含敏感信息 | 脱敏或拦截，记录护栏命中 |
| 上下文超长 | 摘要压缩或截断，提示用户 |
| 引用权限失效 | 引用不可点击，提示"内容权限已变更" |
| Agent 工具失败 | 按节点策略重试/跳过/终止；记录失败步骤 |
| 配额耗尽 | 拒绝并提示，或降级至低阶模型（按策略） |

### 3.7 验收标准

| 编号 | 验收项 | 标准 |
|---|---|---|
| AC-H2-01 | RAG 引用 | 引用可定位、可访问，准确率 ≥ 95% |
| AC-H2-02 | 性能 | TTFT ≤ 2s，输出 ≥ 25 token/s，并发 ≥ 200 |
| AC-H2-03 | Agent | 可编排、可中断、可回放，轨迹完整 |
| AC-H2-04 | 安全 | 注入拦截率 ≥ 98%，敏感输出脱敏 100% |
| AC-H2-05 | 无命中 | 明确告知且不编造（人工抽检 100% 合规） |

### 3.8 与标杆产品差异点

对比微软 Copilot：

1. **企业权限感知的 RAG**：引用与检索均受企业数据权限与密级约束，答案不越权，区别于面向个人生产力的 Copilot；
2. **双模式输出**：可作为能力嵌入 7 款业务产品（如云销的销售助手、云协的会议助手），而非单一助手形态；
3. **可私有化与国产模型**：支持私有化部署与国产/本地模型，满足数据不出境合规；
4. **编排与提示词治理**：企业级提示词版本、灰度、A/B 与 Agent 编排统一管理；
5. **输出合规护栏**：内置输入输出内容安全与提示注入防护，符合生成式 AI 服务合规要求。

### 4.3 业务规则

1. **编号规则**：数据集 `AIDS{yyyyMM}{6位}`；看板 `AIDB{yyyyMM}{6位}`。
2. **指标口径唯一**：同名指标唯一口径，派生指标须基于已发布原子指标；指标变更走审批并升版本，历史看板记录引用版本。
3. **数据权限规则**：查询先应用数据范围（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）与行级过滤，再做列级隐藏；嵌入模式按宿主上下文（`X-On-Behalf-Of`）解析权限。
4. **洞察规则**：异动检测基于同环比、趋势斜率、突变点（3σ/Z-score）、异常点；结论须附证据数据与置信度；准确率以业务认可抽检计。
5. **归因规则**：对指标异动按维度计算贡献度，输出主因维度与占比；算法可配（贡献度/AKM）。
6. **加速规则**：大屏优先抽取模式（ClickHouse/Doris 预聚合），直连模式限时限行。
7. **订阅规则**：订阅频次可配，避免打扰；推送含权限校验（接收人须有对应数据权限）。

### 4.4 状态机（洞察任务）

```
        创建任务
           │
      ┌────▼─────┐  调度(CRON/事件/手工)
      │ PENDING  │
      └────┬─────┘
           │ 触发
      ┌────▼─────┐
      │ RUNNING  │
      └────┬─────┘
           ├─ 成功 → ┌───────────┐
           │         │ SUCCEEDED │ → 生成 InsightResult → (可选)归因 → 订阅推送
           │         └───────────┘
           └─ 失败 → ┌────────┐
                     │ FAILED │ → 告警（可重试）
                     └────────┘

      任意状态 → [DISABLED]（管理端停用）
```

- 触发类型：`CRON`（XXL-Job 调度）、`EVENT`（指标阈值/数据更新事件）、`MANUAL`（用户手动）。
- 幂等：同一任务同周期仅执行一次（`task_id+period`）。
- 失败重试：最多 2 次，失败告警不影响其他任务。

### 4.5 工作流：洞察生成（BPMN）

**流程标识**：`aiInsightGenerate`

```
[开始:触发] → [读取洞察任务配置] → [解析指标/维度(语义层)] → [执行聚合查询(权限过滤)]
   → [异动检测(同环比/突变/异常点)] → <网关:是否存在异动>
        ├─ 无 → [记录无异常] → [结束]
        └─ 有 → [归因分析(维度下钻+贡献度)] → [LLM生成洞察结论+建议]
                 → [落库 InsightResult/Attribution] → <网关:是否配置订阅>
                       ├─ 是 → [推送订阅人(权限校验)] → [结束]
                       └─ 否 → [结束]
```

**节点说明**：

| 节点 | 类型 | 说明 |
|---|---|---|
| 触发 | 事件 | CRON/事件/手工 |
| 聚合查询 | 服务任务 | 经语义层生成查询，注入权限过滤 |
| 异动检测 | 服务任务 | 规则引擎（阈值/统计） |
| 归因分析 | 服务任务 | 算法引擎（贡献度/AKM） |
| LLM 生成结论 | 服务任务 | 模型网关，输出结论+建议+置信度 |
| 订阅推送 | 服务任务 | 消息服务，接收人权限校验 |

**异常边界**：查询超时降级为抽样或直连；LLM 不可用时输出纯规则结论（无自然语言）；订阅推送失败重试 3 次并记录。

### 4.6 异常与边界

| 场景 | 处理 |
|---|---|
| 数据源断连 | 查询失败，看板显示错误态与上次缓存，告警 |
| 大查询超时 | 超时降级（抽样/预聚合）并提示 |
| 指标口径冲突 | 拒绝发布并提示冲突指标 |
| 行列权限越权 | 返回 403 并审计；过滤后数据为空则返回空态 |
| 洞察任务堆积 | 队列限流与优先级调度 |
| NL2SQL 歧义 | 澄清追问；无法解析则建议改用筛选 |
| 导出敏感列 | 列级权限拦截或脱敏 |

| 编号 | 验收项 | 标准 |

### 4.8 与标杆产品差异点

对比帆软 FineBI：

1. **自动洞察原生**：内置异动检测+归因+自然语言结论，而非仅可视化；
2. **语义层与 Copilot 融合**：指标口径统一供看板、NL2SQL、洞察复用，问答与 BI 同源；
3. **双模式输出**：可作为 BI 能力嵌入其他产品（如云财经营看板、云销业绩看板）；
4. **权限感知问数**：NL2SQL 执行前做权限与安全校验，问数不越权；
5. **多租户与嵌入计量**：按宿主产品计量 BI 能力调用。

## 5 双模式下的模块行为

| 维度 | standalone | embedded |
|---|---|---|
| 门户 | H1 检索门户、H2 Copilot 工作台、H3 看板中心；管理端全套配置 | 无独立门户；能力经宿主产品界面内嵌 |
| 调用入口 | `/api/intelligence/v1/**` + `/openapi` | `/internal/**`（mTLS + 服务令牌 + `X-On-Behalf-Of`） |
| 权限来源 | 本租户用户 JWT + 数据权限 | 宿主传递用户上下文，同源解析数据权限（`ai_data_permission`） |
| 授权控制 | 套餐/席位 | `ai_capability_grant`（宿主×能力开关+配额） |
| 计费计量 | 席位 + 调用量（`ai_usage_metering` mode=STANDALONE） | 能力调用计量计入宿主（mode=EMBEDDED） |
| 降级 | 面向用户提示并降级 | 返回标准降级响应，不阻断宿主主流程 |
| 知识库 | 独立租户知识库 | 可复用宿主知识库或独立知识库 |

三种模块在两种模式下功能逻辑一致，差异仅在暴露面、鉴权、授权与计量，体现"同一套代码双模式"。

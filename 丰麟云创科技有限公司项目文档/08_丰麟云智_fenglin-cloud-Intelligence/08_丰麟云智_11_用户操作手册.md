## 1 快速开始

丰麟云智（品牌口号：**搜得到、问得清、看得远的企业智能大脑**）用户端提供三大能力：

- **搜得到（H1 知识搜索）**：统一检索企业多源知识，支持关键词与自然语言、全文+向量混合、权限感知；
- **问得清（H2 AI Copilot）**：基于企业知识的多轮问答、写作、总结、翻译，答案有引用、可溯源；
- **看得远（H3 BI 与洞察）**：自助取数、看板查看、自动洞察与归因分析。

三步上手：

1. 打开 `https://intelligence.fenglincloud.com/app/intelligence`，用企业账号登录；
2. 在顶部搜索框输入问题或关键词，或进入「AI Copilot」直接提问；
3. 点击结果/引用查看原文；进入「看板中心」查看经营数据与洞察。

> 提示：**双模式差异**——若您是从其他产品（如丰麟云销、云协）内嵌使用智能能力，则无需登录云智门户，功能在该产品内以"智能助手/智能检索"形态提供；本手册描述的是**独立产品模式（standalone）**下的完整用户端门户。

### 2.1 登录

1. 访问入口 → 跳转统一身份（IAM）→ 输入账号口令 → 必要时 MFA 二次验证；

## 3 分模块操作指引

### 3.1 知识搜索（H1）

**场景**：查找制度、方案、合同条款等企业知识。

操作步骤（截图位：`[图1 知识搜索页面]`）：

1. 进入「知识搜索」，在搜索框输入关键词（如"差旅报销标准"）或一句自然语言问题；
2. 选择检索范围（知识库）与排序方式（相关性/时间）；
3. 系统默认使用**混合检索**（全文+语义），结果按相关性排序并高亮关键词；
4. 点击「预览」在抽屉中查看原文定位（高亮所在段落/页码）；
5. 点击「引用」复制带来源的引用文本。

**说明**：

- 结果只包含**您有权访问**的文档；若某文档不可见，不会出现在结果中（即使标题匹配）；
- 密级高于您权限的文档同样不可检索与预览；
- 无结果时可尝试放宽知识范围或使用更通用的关键词。

### 3.2 知识图谱（H1）

操作步骤（截图位：`[图2 知识图谱页面]`）：

1. 输入实体名（如"丰麟云智"）检索实体；
2. 画布展示该实体的关联实体与关系，可拖拽/缩放/展开；
3. 点击节点查看详情与来源文档；右侧「关联推荐」给出相关文档与实体。

### 3.3 AI Copilot 问答（H2）

**场景**：就企业知识提问、获取带引用的答案。

操作步骤（截图位：`[图3 AI Copilot 页面]`）：

1. 进入「AI Copilot」，点击「新会话」；
2. 在顶部选择知识范围（勾选知识库）与会话类型（RAG / 普通对话）；
3. 输入问题（如"公司差旅标准是多少？"），点击发送；
4. 答案流式生成，末尾展示**引用列表**（文档名+分块+页码）；点击引用跳转原文（再次校验权限）；
5. 对答案点赞/点踩/纠错，帮助改进。

**建议**：

- 需要严谨依据时，开启「仅依据知识库作答」；若知识库无相关内容，系统会明确告知而不会编造；
- 上下文过长时系统会自动压缩，长会话可新建会话；
- 会话可重命名、置顶、归档。

### 3.4 写作 / 总结 / 翻译（H2）

操作步骤（截图位：`[图4 文本工具页面]`）：

1. 进入「文本工具」，选择功能页签（写作/总结/翻译）；
2. 选择模板（如周报、邮件、公文）或粘贴文本；
3. 设置参数（语气/长度/目标语言/术语表）；
4. 点击生成，可续写、改写、扩写、润色，支持多版本对比；
5. 复制或导出结果。

### 3.5 Agent（H2）

操作步骤（截图位：`[图5 Agent 运行页面]`）：

1. 进入「Agent」，选择已发布的 Agent（如"会议纪要助手"）；
2. 填写输入（如选择会议、客户）；
3. 点击运行，右侧时间线展示每步执行（检索/生成/工具调用）；
4. 若出现"待确认"节点，确认或补充信息后继续；
5. 完成可查看结果与执行回放。

### 3.6 自助取数与数据集（H3）

操作步骤（截图位：`[图6 数据集页面]`）：

1. 进入「数据集」，点击新建；
2. 选择数据源 → 拖拽字段或编写 SQL → 定义维度/度量与计算字段；
3. 预览数据，保存为数据集（可设抽取加速）；
4. 数据集可被看板、问数、洞察复用。

### 3.7 看板（H3）

操作步骤（截图位：`[图7 看板中心页面]`）：

1. 进入「看板中心」，打开看板；
2. 使用顶部参数/筛选器调整维度（如时间、区域）；
3. 图表支持联动与钻取（点击图表下钻到明细）；
4. 可导出（PNG/PDF/Excel/CSV）或分享（受权限控制）。

### 3.8 自动洞察与归因（H3）

操作步骤（截图位：`[图8 自动洞察页面]`）：

1. 进入「自动洞察」，选择任务与时间范围；
2. 查看洞察卡：异常类型、结论、建议、置信度与归因占比；
3. 点击「查看证据」查看支撑数据，点击「归因详情」查看维度贡献度；
4. 点击「订阅」配置推送（站内信/邮件/Webhook）与频次。

### 3.9 自然语言问数（H3）

操作步骤（截图位：`[图9 问数页面]`）：

1. 进入「自然语言问数」，输入问题（如"9 月各区域 GMV 是多少"）；
2. 系统返回图表 + 文字结论；
3. 若问题有歧义，系统会追问澄清；可继续追问（如"只看华东"）；
4. 结果受您的数据权限约束（仅可见范围内的数据）。

## 4 常见任务场景

### 场景一：快速找到某项制度

1. 顶部搜索框输入"年假天数" → 回车；
2. 结果第一条即《假期管理制度》，点击「预览」定位到"年假"段落；
3. 点击「引用」粘贴到邮件中。

### 场景二：让 AI 总结一份长文档

1. 进入「文本工具」→「总结」；
2. 上传/粘贴文档 → 选择"要点列表" → 生成；
3. 复制要点，或用「AI Copilot」追问细节（系统基于同一知识库作答）。

### 场景三：查看本月经营并定位下滑原因

1. 进入「看板中心」打开「月度经营看板」；
2. 发现 GMV 下滑 → 进入「自动洞察」查看结论与建议；
3. 点击「归因详情」确认主因渠道（如"线上渠道 62%"）；
4. 订阅该洞察，后续自动推送。

### 场景四：用一句话问数据

1. 进入「自然语言问数」，问"上月各渠道成交额排名"；
2. 得到图表与结论；追问"只看线上渠道近 6 个月趋势"。

### 场景五：在宿主产品内使用智能能力（embedded 模式）

若您使用云销/云协等产品内嵌的智能助手：

1. 在宿主产品界面打开"智能助手/智能检索"（无需登录云智门户）；
2. 提问或检索，能力由云智以中台服务提供；
3. 权限与数据范围沿用宿主产品的登录上下文；计量计入宿主产品，无需您单独付费。

## 5 FAQ

| 问题 | 解答 |
|---|---|
| 为什么检索不到某文档？ | 可能超出您的数据权限或文档密级；请联系知识管理员确认可见范围 |
| AI 答案会不会编造？ | 采用 RAG，答案基于检索到的知识并标注引用；开启"仅依据知识库"时无命中会明确告知，不编造 |
| 引用链接打不开？ | 引用同样受权限控制；若您的权限已变更，链接将不可访问 |
| 为什么有时回答较慢？ | 首次生成需检索+推理；系统会在依赖降级时提示，并支持"停止"重试 |
| 为什么答案被拦截？ | 输入或输出触发了内容安全护栏；请调整提问方式，勿尝试指示 AI 越权或输出敏感信息 |
| 我的提问会被记录吗？ | 会记录检索/问答审计用于安全与优化，个人隐私信息脱敏存储，详见安全策略 |
| 数据是实时的吗？ | 看板按配置刷新（抽取/直连）；洞察按任务周期生成，可在洞察卡查看生成时间 |
| 我看不到某些列或数据？ | 受列级/行级数据权限约束，属正常现象，请联系数据管家调整权限 |

## 6 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl/Cmd + K` | 唤起全局搜索 |
| `Enter` | 发送消息 / 执行搜索 |
| `Shift + Enter` | 输入换行 |
| `Esc` | 关闭抽屉/弹窗；停止生成 |
| `Ctrl/Cmd + Shift + N` | 新建会话 |
| `↑ / ↓` | 在联想建议中导航 |
| `Alt + 1..4` | 切换主模块（工作台/搜索/Copilot/看板） |

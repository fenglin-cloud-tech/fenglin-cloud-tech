## 1 通用约定

（完整约定引用 FL-HUB-STD-001 第 5 章，本品补充如下。）

- 协议 HTTPS（TLS 1.2+，推荐 1.3）；内部服务间 mTLS；数据格式 `application/json; charset=UTF-8`。
- 流式接口（对话/问答）使用 `Content-Type: text/event-stream`（SSE）。
- 时间：ISO-8601（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`），存储 UTC。
- 分页：`page`（从 1 开始）、`size`（默认 20，最大 200）；响应 `data = { records, total, page, size }`。
- 统一响应体：

```json
{
  "code": "0",
  "message": "success",
  "data": {},
  "requestId": "b1f2c3d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "timestamp": "2026-10-19T08:00:00.000+08:00"
}
```

- 请求头：`Authorization`、`X-Tenant-Id`、`X-Client-Type`（ADMIN/PORTAL）、`X-Request-Id`、`Idempotency-Key`、`Accept-Language`。
- 错误码结构 `{域2}{模块2}{序号3}`，域前缀 `80`：

| 错误码 | HTTP | 含义 |
|---|---|---|
| `0000001` | 401 | 未认证或令牌失效（平台通用） |
| `0000002` | 403 | 无权限（功能或数据） |
| `0000003` | 400 | 参数校验失败 |
| `0000004` | 404 | 资源不存在 |
| `0000005` | 409 | 状态冲突 |
| `0000006` | 429 | 触发限流 |
| `0000007` | 500 | 系统内部错误 |
| `8000001` | 400 | 云智通用参数错误 |
| `8000002` | 403 | 云智功能无权限 |
| `8000003` | 403 | 租户配额/许可不足 |
| `8001001` | 404 | 知识库不存在 |
| `8001002` | 400 | 数据源连接失败 |
| `8001003` | 400 | 文档解析失败 |
| `8001004` | 409 | 索引任务冲突 |
| `8001005` | 403 | 检索越权（文档不可见） |
| `8001006` | 400 | 检索参数非法（TopK/权重） |
| `8001007` | 409 | 入库审核状态冲突 |

- 限流：默认按租户+接口 QPS（检索 200、对话并发 50、写入 50、导出 5、索引任务 10），超限 `0000006`。

## 2 鉴权与端别

| 项 | 说明 |
|---|---|
| 鉴权（门户） | OAuth2.1/OIDC，JWT（RS256）；`Authorization: Bearer {access_token}` |
| 鉴权（嵌入） | mTLS + 服务令牌；`X-Caller-Product`、`X-On-Behalf-Of`（用户代理） |
| 端别 | `X-Client-Type`：`ADMIN`/`PORTAL`；须与令牌 `client_type` 一致，否则 `0000002` |
| 租户 | `X-Tenant-Id` 必填，须与令牌一致 |
| 权限 | 功能权限码 + 数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）+ 文档 ACL/密级 |
| 幂等 | 写操作支持 `Idempotency-Key`（24h）；索引/洞察/计量类强制 |
| 追踪 | `X-Request-Id`、`X-Trace-Id` |

**端别归属**：`/api/intelligence/v1/admin/**` 仅 ADMIN；其余业务路径仅 PORTAL；`/internal/**` 仅服务间（mTLS）。

### 4.1 H1 知识检索

#### AI-API-101 创建数据源
- `POST /api/intelligence/v1/admin/data-sources`｜ADMIN｜权限 `tenant:ai:source:manage`｜幂等 支持｜限流 50 QPS
- 请求体：

| 参数 | 类型 | 必填 | 约束 |
|---|---|---|---|
| `name` | string | 是 | ≤128 |
| `category` | string | 是 | `FILE`/`OBJECT_STORAGE`/`CLOUD_DOC`/`DB`/`HTTP`/`APP` |
| `connectorType` | string | 是 | 如 `postgresql`/`minio`/`feishu` |
| `endpoint` | string | 否 | ≤512 |
| `config` | object | 否 | 连接器配置（不含凭据） |
| `credential` | object | 否 | 凭据（服务端 AES-256-GCM 加密存储） |
| `syncMode` | string | 是 | `FULL`/`INCREMENT`/`CDC` |
| `syncCron` | string | 否 | cron 表达式 |

- 响应：`{ "code":"0","data":{"id":9001,"uuid":"...","code":"AIDS202610000001","status":"ENABLED"} }`
- 错误码：`8000003`（配额不足）、`8000001`（参数非法）
- 幂等：`Idempotency-Key`；重复提交返回首次结果。

| 开放接口 | 方法 | 路径 | 说明 |

- 签名：`signature = HMAC-SHA256(AppSecret, method+path+timestamp+nonce+bodyHash)`。

## 7 事件与 Webhook

| 事件 | Topic | 触发 | 载荷要点 |
|---|---|---|---|
| 文档已索引 | `ai.document.indexed` | 索引成功 | `documentId, kbId, chunkCount` |
| 索引失败 | `ai.index.failed` | 索引失败 | `documentId, taskId, errorMsg` |
| 洞察已生成 | `ai.insight.generated` | 洞察完成 | `taskId, metricId, conclusion, confidence` |
| Agent 已执行 | `ai.agent.executed` | 执行结束 | `agentId, executionId, status` |
| 用量阈值 | `ai.usage.threshold_reached` | 达配额阈值 | `hostProduct, capability, used, quota` |

- Webhook 投递：签名验签（HMAC-SHA256）、重试（最多 5 次，指数退避）、幂等（`eventId`）。

## 8 版本与兼容

1. 版本采用 URL 段（`/v1`）；重大不兼容变更升 `v2`，旧版本保留 ≥ 12 个月。
2. 字段新增向后兼容；字段废弃先标记 `deprecated` 并给迁移期 ≥ 6 个月。
3. 流式协议（SSE）事件类型（`delta`/`citation`/`done`/`error`）为兼容契约，新增事件不影响旧客户端。
4. 能力嵌入契约（`/internal/**`）变更须同步 7 款宿主产品并回归；双模式切换不改变契约。

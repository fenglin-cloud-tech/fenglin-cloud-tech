## 1 设计令牌

严格复用 FL-HUB-STD-001 第 9.1 节令牌，用户端与管理端共用。

### 1.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fl-color-primary` | `#1F5EFF` | 主色（丰麟蓝）：主按钮、链接、选中态 |
| `--fl-color-primary-hover` | `#3D78FF` | 主色悬停 |
| `--fl-color-success` | `#16A34A` | 成功、健康指标 |
| `--fl-color-warning` | `#F59E0B` | 警告、洞察预警 |
| `--fl-color-danger` | `#DC2626` | 危险、异常异动 |
| `--fl-color-info` | `#64748B` | 信息、次要标注 |
| `--fl-color-text-primary` | `#1E293B` | 主文本（答案正文、标题） |
| `--fl-color-text-secondary` | `#64748B` | 次文本（引用来源、辅助说明） |
| `--fl-color-bg` | `#F5F7FA` | 页面背景 |
| `--fl-color-surface` | `#FFFFFF` | 卡片/容器（对话气泡、图表卡） |
| `--fl-color-border` | `#E2E8F0` | 边框/分割线 |

**语义扩展（本品）**：AI 生成中状态用主色微渐变骨架；引用高亮底色取主色 8% 透明度；洞察"上升/下降"分别用 success/danger 的 12% 背景 + 实色文字，保证对比度 ≥ 4.5:1。

### 1.2 字体/圆角/间距/阴影

| 令牌 | 值 |
|---|---|
| `--fl-font-family` | `"PingFang SC","Microsoft YaHei",-apple-system,"Segoe UI",Roboto,sans-serif` |
| `--fl-font-size-xs/sm/base/lg/xl` | `12/13/14/16/20px` |
| `--fl-radius-sm/md/lg` | `4/8/12px` |
| `--fl-space-xs/sm/md/lg/xl` | `4/8/16/24/32px` |
| `--fl-shadow-sm/md` | `0 1px 2px rgba(0,0,0,.05)` / `0 4px 16px rgba(0,0,0,.08)` |

**AI 场景补充**：答案正文 `16px/1.7`；代码块等宽字体 `"JetBrains Mono",Consolas,monospace`；对话气泡最大宽度 `min(760px, 78%)`。

### 1.3 双端差异

| 维度 | 管理端（`/admin/intelligence`） | 用户端（`/app/intelligence`） |
|---|---|---|
| 布局骨架 | 左侧菜单 + 顶部面包屑 + 内容区（信息密集） | 顶部导航 + 卡片式工作台（任务导向） |
| 默认首页 | 智能运营概览：索引健康、审核待办、用量、模型状态 | 智能工作台：全局搜索框、最近会话、我的看板、洞察速览 |
| 表格密度 | `size=small`（紧凑） | `size=default`（舒适） |
| 组件库 | Element Plus | 自研 Portal 组件（同 Token） |
| 配色倾向 | 中性 + 主色强调数据 | 主色 + 场景化插画 |

## 5 交互流程

### 5.1 检索 → 预览 → 引用

```
输入关键词/自然语言 → 联想建议 → 回车检索 → 结果高亮列表
  → 点击"预览" → 权限校验 → 抽屉展示原文定位（受密级约束）
  → 点击"引用"→ 复制带来源的引用文本 → 记录点击（分析回流）
```

### 5.2 Copilot 问答

```
选择知识范围 → 输入问题 → 流式生成（骨架+停止） → 引用卡渲染
  → 点击引用跳转原文（二次权限） → 点赞/点踩/纠错 → 反馈回流
```

### 5.3 自助取数与看板

```
选择数据源 → 建数据集（拖字段/写SQL） → 预览 → 保存
  → 新建看板 → 拖入图表 → 配置维度度量 → 联动/钻取 → 发布 → 分享/订阅
```

### 5.4 洞察任务

```
选择目标（看板/指标） → 配置触发（定时/事件） → 配置规则（同环比/阈值/异常）
  → 保存并试运行 → 查看洞察卡 → 配置订阅 → 推送接收
```

### 5.5 双模式能力授权（管理端）

```
查看当前模式 → （embedded）打开能力授权矩阵 → 勾选宿主×能力
  → 配置配额（QPS/Token） → 保存（幂等） → 宿主产品即生效 → 计量大盘核对
```

## 6 响应式

| 断点 | 管理端 | 用户端 |
|---|---|---|
| ≥1440 | 左菜单固定 + 内容 12 栅格 | 顶部导航 + 内容 12 栅格 |
| 1200 | 左菜单可折叠 | 内容 8 栅格 |
| 992 | 左菜单抽屉 | 卡片 2 列 |
| 768 | 表格横向滚动 | 卡片 1 列，看板垂直堆叠 |
| <768 | 仅核心操作，表单全屏 | 单列，底部输入框固定，最小点击区 44×44px |

- BI 大屏：支持 1920×1080 / 3840×2160，等比缩放，字号自适应，超出右边距安全区 ≥ 24px。
- 移动端：Copilot 输入框吸底；看板支持手势缩放。

## 7 状态规范

| 状态 | 表现 |
|---|---|
| 加载（检索/问答） | 骨架屏；流式生成显示光标与停止按钮 |
| 加载（看板） | 图表骨架 + 数值占位 |
| 空态 | 图示 + 引导（如"未找到相关内容，试试放宽知识范围"） |
| 错误 | 错误码 + 重试按钮 + 联系支持 |
| 无权限 | 明确提示"无访问权限"（不暴露资源存在性），提供申请入口 |
| 降级态 | 顶部提示条"当前为降级模式：仅检索结果/模型不可用"，说明影响与恢复预期 |
| 成功反馈 | Toast/Message（保存、发布、订阅成功） |
| 护栏拦截 | 输入/输出拦截横幅，说明原因，不展示违规内容 |

## 8 可访问性

1. 对比度 ≥ 4.5:1（正文）、≥ 3:1（大字/图形），洞察涨跌色与文字并用避免仅靠颜色传达。
2. 全键盘可达：搜索框、结果列表、对话发送、看板图表均可键盘操作；焦点样式清晰（主色描边 2px）。
3. 语义化与读屏：图表提供数据表替代（`aria-label` + 隐藏数据表）；引用卡可读屏朗读来源。
4. 动效：尊重 `prefers-reduced-motion`，关闭流式动画与非必要过渡。
5. 国际化：文案外置 i18n，默认 `zh-CN`，预留 `en-US`；数字/日期按区域格式化。
6. 无障碍错误提示：表单错误通过 `aria-live` 播报。

## 1 设计原则

1. **多租户隔离**：所有业务表含 `tenant_id`，启用 PostgreSQL Row Level Security（RLS），跨租户默认拒绝。
2. **公共字段强制**：每表含 `id/tenant_id/created_by/created_at/updated_by/updated_at/deleted/version`（见 2.2）。
3. **逻辑删除**：`deleted`（0 正常/1 删除）；`version` 乐观锁。
4. **主键策略**：高并发写用雪花 ID（`bigint`），对外暴露用 `uuid` 列（`varchar(36)`）作为外部标识；本文将 `uuid` 明确列出。
5. **三条存储对齐**：分块是检索/引用的最小单元，`ai_document_chunk.id` 与 ES 文档 `_id`、向量主键一致，保证一致性回溯。
6. **敏感数据加密**：数据源连接凭据、模型 API Key 等采用 AES-256-GCM 加密，配套 `{field}_hash`（SHA-256+租户盐）。
7. **命名规范**：表名小写下划线，前缀 `ai_`；字段小写下划线；索引 `idx_`、唯一索引 `uk_`、外键式约束 `fk_`（逻辑外键）。
8. **迁移管控**：全部 DDL/DML 通过 Flyway `V{版本}__{描述}.sql` 提交，禁止手工改库。

## 2 逻辑模型（ER）

### 2.1 核心实体关系（文字 ER）

```
知识库 KnowledgeBase 1 ── N 文档 Document 1 ── N 文档分块 DocumentChunk ── 1 向量索引元数据 VectorIndexMeta
知识库 KnowledgeBase 1 ── N 知识库ACL KnowledgeAcl
数据源 DataSource 1 ── 1 数据源凭据 DataSourceCredential
知识库 1 ── N 索引任务 IndexTask
文档分块 N ── N 图谱实体 KGEntity（通过实体抽取） ；KGEntity N ── N KGRelation
会话 Conversation 1 ── N 消息 Message 1 ── N 引用 Citation
提示词模板 PromptTemplate 1 ── N Agent定义 AgentDefinition 1 ── N Agent执行记录 AgentExecution
模型供应商 ModelProvider 1 ── N 用量计量 UsageMetering
指标定义 MetricDefinition 1 ── N 数据集 Dataset 1 ── N 数据集字段 DatasetField
数据集 Dataset 1 ── N 看板 Dashboard 1 ── N 图表 Chart
数据集/指标 1 ── N 洞察任务 InsightTask 1 ── N 洞察结果 InsightResult 1 ── N 归因分析 AttributionAnalysis
能力授权 CapabilityGrant（宿主产品 × 能力）
数据权限 DataPermission（主体 × 资源 × 范围）
检索日志 SearchLog（行为分析）
问答反馈 QaFeedback
```

### 2.2 公共字段（所有表强制）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `id` | `bigint` | PK，雪花 ID | 主键 |
| `uuid` | `varchar(36)` | NOT NULL, UNIQUE | 对外暴露标识 |
| `tenant_id` | `bigint` | NOT NULL | 租户 ID（RLS 键） |
| `host_product` | `varchar(32)` | NULL | 宿主产品码（embedded 模式溯源，如 `crm`/`collab`） |
| `created_by` | `bigint` | NOT NULL | 创建人 |
| `created_at` | `timestamptz` | NOT NULL DEFAULT now() | 创建时间（UTC） |
| `updated_by` | `bigint` | NULL | 更新人 |
| `updated_at` | `timestamptz` | NULL | 更新时间（UTC） |
| `deleted` | `smallint` | NOT NULL DEFAULT 0 | 0 正常/1 删除 |
| `version` | `int` | NOT NULL DEFAULT 0 | 乐观锁 |

> 下文各表字段字典中「公共字段」一行即代表上表 10 个字段全部存在；`host_product` 仅在 embedded 相关表强约束。

## 6 约束与 RLS

### 6.1 约束

- 主键：`id` 雪花 ID；`uuid` 唯一。
- 唯一约束：见索引设计中 `uk_*`。
- 逻辑外键（应用层保障）：`document_id`、`knowledge_base_id`、`dataset_id` 等。
- 检查约束：`sec_level BETWEEN 1 AND 4`；`deleted IN (0,1)`；`progress BETWEEN 0 AND 100`。

### 6.2 RLS 策略

对全部 `ai_*` 业务表启用 RLS，示例：

```sql
-- 开启行级安全
ALTER TABLE ai_document ENABLE ROW LEVEL SECURITY;

-- 租户隔离策略（会话变量由连接池按请求设置）
CREATE POLICY p_ai_document_tenant ON ai_document
  USING (tenant_id = current_setting('app.tenant_id')::bigint);

-- 跨租户仅平台运营端（platform:*）放行
CREATE POLICY p_ai_document_platform ON ai_document
  USING (current_setting('app.is_platform', true) = 'true');

-- 密级与知识库 ACL 的应用层过滤在检索 DSL 中执行（见 FL-AI-ARCH-002 5.3）
```

- 会话变量：`app.tenant_id`、`app.user_id`、`app.is_platform`，由数据访问层在获取连接时设置。
- 平台运营端跨租户查询强制审计（写 `fenglin-audit-service`）。

## 7 敏感字段加密

| 表.字段 | 加密 | 算法 | 配套哈希 | 脱敏展示 |
|---|---|---|---|---|
| `ai_data_source_credential.credential_cipher` | 是 | AES-256-GCM | `credential_hash`（SHA-256+租户盐） | 仅显示指纹 |
| `ai_model_provider.api_key_cipher` | 是 | AES-256-GCM | `api_key_hash` | 仅显示 `sk-****` |
| `ai_search_log.query_text` | 条件 | 应用层脱敏 | — | 含 PII 时脱敏存储 |
| `ai_message.content` | 条件 | 应用层脱敏 | — | 输出护栏脱敏后存储 |

- 密钥由 KMS 管理，版本号存 `key_version`，支持轮换（≤ 90 天）。
- 加解密通过自定义 MyBatis `TypeHandler` 透明实现，业务代码不感知。
- 禁止在明文字段上建唯一索引；去重/检索一律使用 `{field}_hash`。

## 1 管理端总览

### 1.1 管理端定位

管理端（`/admin/intelligence`）面向平台运维、租户管理员与业务管理员，归口**配置、授权、审核、报表定义、租户治理、监控审计**能力。用户端（`/app/intelligence`）归口日常业务操作。

| 导航项 | 路由 | 归口 |

### 1.3 双模式管理差异（重要）

| 能力 | standalone | embedded |
|---|---|---|
| 门户配置 | 启用门户、独立登录/门户/计费 | 关闭门户；配置宿主产品服务证书与能力授权 |
| 能力授权 | 以套餐/席位控制 | 以「能力授权矩阵」（宿主×能力）控制开关与配额 |
| 计量计费 | 席位+调用量独立账单 | 计量计入宿主产品账单，需对账 |
| 模型/护栏 | 全量可配 | 同左；可约定宿主不可见的策略 |
| 知识库 | 独立租户知识库 | 可复用宿主知识库或独立知识库 |

## 2 租户 / 组织 / 用户 / 角色

### 2.1 租户管理（平台运维）

- 租户开通：由 `fenglin-tenant-service` 统一管理；本产品按租户初始化知识库、默认模型与配额；
- 套餐与配额：设置席位、检索 QPS、Token 月配额、索引容量、BI 数据集/看板数；
- 双模式：设置本租户的 `intelligence.mode`（SaaS 通常 standalone；嵌入场景 embedded）。

### 2.2 组织与用户

- 组织：继承 IAM 组织树（多层级，编码层级点分如 `1.2.3`）；
- 用户：继承 IAM 用户与岗位；离职联动：账号停用后其个人知识、会话保留策略按合规配置处理；
- 数据范围：用户/角色的数据权限决定可检索与可见数据。

### 2.3 角色（本品基线）

| 角色 | 端 | 说明 |
|---|---|---|
| 租户管理员 | 管理端 | 本租户配置、权限、双模式与授权 |
| 智能业务管理员 | 管理端 | 知识库/提示词/Agent/模型/护栏/检索分析 |
| 知识管理员 | 管理端 | 知识库、数据源、文档入库审核、知识图谱 |
| 数据管家 | 管理端 | BI 数据源、指标口径、数据权限、看板治理 |
| 数据分析师 | 用户端 | 取数、看板制作、洞察任务 |
| 业务用户 | 用户端 | 检索、问答、查看 |
| 只读/访客 | 用户端 | 受限查看 |

角色配置路径：管理端 → 角色与权限 → 选择角色 → 勾选功能权限码（`ai:*`/`tenant:ai:*`）→ 保存。

## 3 权限与数据权限配置

### 3.1 功能权限

- 权限码规则 `{域}:{模块}:{操作}`，如 `ai:search:query`、`tenant:ai:kb:review`；
- 管理端权限前缀 `tenant:ai:*`，用户端前缀 `ai:*`；
- 通过角色绑定权限码，接口与菜单双重校验。

### 3.2 数据权限

配置路径：管理端 → 数据权限（`/admin/intelligence/bi/data-permissions`）。

| 维度 | 取值 | 说明 |
|---|---|---|
| 数据范围 | SELF / DEPT / DEPT_AND_CHILD / CUSTOM / ALL | 行级可见范围 |
| 资源类型 | KB / DATASET / DASHBOARD / METRIC | 生效对象 |
| 行级过滤 | 表达式（如 `dept_id in (...)`） | 注入查询 |
| 列级隐藏 | 字段列表 | 敏感列隐藏/脱敏 |

**配置示例**（`AI-API-203`）：

```json
{
  "items": [
    {"subjectType":"ROLE","subjectId":77,"resourceType":"DATASET","resourceId":5001,
     "dataScope":"DEPT_AND_CHILD","columnHidden":"cost,profit"}
  ]
}
```

### 3.3 知识库 ACL 与密级

配置路径：知识库管理 → 选择知识库 → ACL/密级。

- 主体（用户/角色/部门/全部）+ 权限（READ/WRITE/ADMIN）+ 最大可见密级；
- 密级：1 公开 / 2 内部 / 3 秘密 / 4 机密；用户可见密级 ≤ 文档密级方可召回；
- 修改 ACL 需记审计；建议按月复核。

### 3.4 能力授权（embedded 模式）

配置路径：双模式与能力授权 → 能力授权矩阵。

- 勾选宿主产品 × 能力（SEARCH/RAG/WRITING/SUMMARY/TRANSLATE/AGENT/DATASET/DASHBOARD/INSIGHT）；
- 设置配额（QPS、月度 Token）与计费模式（CALL/TOKEN）；
- 未授权调用返回 `8004001`；变更即时生效并审计。

## 4 参数与字典

### 4.1 关键参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `intelligence.mode` | standalone | 双模式开关（修改需重启/校验） |
| `search.fulltext-weight` / `vector-weight` | 0.4 / 0.6 | 混合检索权重 |
| `search.top-k` / `rerank-top-n` | 20 / 10 | 召回与重排数 |
| `rag.context-max-tokens` | 8000 | 上下文窗口 |
| `rag.only-kb` | false | 仅依据知识库 |
| `llm.ttft-timeout-ms` | 2000 | 首字超时 |
| `guardrail.input.prompt-injection` | BLOCK | 注入拦截策略 |
| `guardrail.output.pii-masking` | MASK | 输出脱敏 |
| `bi.mode` / `bi.query-timeout-ms` / `bi.row-limit` | ACCELERATE / 15000 / 100000 | BI 查询策略 |
| `metering.enabled` | true | 计量开关 |

修改路径：参数管理（配置中心同步）→ 发布 → 生效（部分需滚动重启）。

### 4.2 字典

| 字典 | 用途 |
|---|---|
| 密级字典 | 1 公开/2 内部/3 秘密/4 机密 |
| 数据源类别 | FILE/OBJECT_STORAGE/CLOUD_DOC/DB/HTTP/APP |
| 索引任务状态 | PENDING/PARSING/CHUNKING/EMBEDDING/INDEXING/SUCCEEDED/FAILED |
| 洞察异动类型 | UP/DOWN/SPIKE/OUTLIER/TREND |

| 能力码 | SEARCH/RAG/WRITING/SUMMARY/TRANSLATE/AGENT/DATASET/DASHBOARD/INSIGHT |
| 错误码域 | 云智前缀 80 |

维护路径：字典管理 → 新增/编辑 → 保存（全局缓存刷新）。

## 5 流程与审批配置

### 5.1 知识入库审核流程（`aiKnowledgeReview`）

- 引擎：Flowable（BPMN 2.0）；
- 触发：文档提交（低密级自动通过，密级 ≥ 3 或敏感强制审核）；
- 节点：提交 → 密级判断网关 → （自动通过 | 知识管理员审核 → 通过/驳回）→ 发布并触发索引 → 通知；
- 配置路径：流程管理 → 知识入库审核 → 配置审核人/超时提醒（默认 3 个工作日）。

### 5.2 指标审批流程

- 指标新建/变更（口径、公式）走审批：数据管家提交 → 智能业务管理员审批 → 发布并升版本；
- 变更须记录血缘影响面（引用该指标的数据集/看板/洞察）。

### 5.3 流程运维

- 查看流程实例、任务、历史（Flowable Admin）；
- 支持催办、转办、终止；关键操作审计。

## 6 集成与开放平台

### 6.1 与云枢中台集成

| 中台 | 集成 |
|---|---|
| IAM/租户 | 鉴权、组织、角色、数据范围、租户隔离 |
| 文件服务 | 文档上传/预览/水印 |
| 工作流 | 入库审核、指标审批 |
| 消息服务 | 洞察订阅、预警推送（站内信/邮件/Webhook） |
| 审计服务 | 全链路审计 |
| 开放平台 | 开放 API 注册、密钥、配额、沙箱 |

### 6.2 能力嵌入（embedded）集成

宿主产品接入步骤：

1. 在管理端「能力授权矩阵」为宿主产品开启所需能力并设配额；
2. 为宿主产品签发服务证书（mTLS）与服务令牌；
3. 宿主调用 `/internal/v1/capabilities` 拉取可用能力；
4. 宿主以 `X-Caller-Product`、`X-Tenant-Id`、`X-On-Behalf-Of` 调用能力契约；
5. 在「计量大盘」核对调用与计量，定期与宿主账单对账。

### 6.3 开放 API

- 在开放平台注册应用，获取 AppKey/AppSecret（HMAC-SHA256）；
- 配置可访问的开放接口与知识库/数据集范围、QPS 配额；
- 订阅事件 Webhook（`ai.document.indexed`、`ai.insight.generated` 等），配置签名与重试。

## 7 监控与审计

### 7.1 监控（`/admin/intelligence/monitor`）

| 看板 | 指标 |
|---|---|
| 检索健康 | QPS、P95/P99、缓存命中、零结果率 |
| LLM 网关 | TTFT、TPOT、成功率、供应商、降级次数 |
| 索引流水线 | 吞吐、积压、失败率 |
| BI 性能 | 看板 P95、CH 慢查询、连接数 |
| 向量库 | 查询延迟、CPU、集合规模 |
| 双模式 | 模式一致性、能力授权拒绝率、计量丢失率 |

告警配置：阈值 → 通道（企业微信/飞书/邮件/短信）→ 分级（P0/P1/P2）。

### 7.2 审计（`/admin/intelligence/monitor` → 审计追溯）

- 审计范围：检索、预览、问答、洞察、授权、模型配置、计量、双模式变更；
- 审计内容：主体、动作、对象、结果、时间、`requestId`、宿主溯源（embedded）；
- 防篡改：哈希链 + WORM 存储；留存 ≥ 6 个月（建议 12 个月）；
- 查询接口：`AI-API-908`（按宿主/能力/用户/时间追溯）。

## 8 备份与安全运维

### 8.1 备份

| 对象 | 策略 | RPO/RTO |
|---|---|---|
| PostgreSQL | 每日全备 + WAL 归档（PITR）+ 异地 | RPO ≤ 5min / RTO ≤ 30min |
| ES / Milvus / ClickHouse | 快照 + 可重建 | 索引重建约 13 小时 |
| MinIO | 版本化 + 异地复制 | RPO ≤ 15min |
| 配置中心 | Nacos 版本化 | 秒级 |

### 8.2 安全运维

- 密钥/凭据：KMS 托管，轮换 ≤ 90 天；数据源凭据与模型 Key 加密存储、不回显；
- 护栏策略：定期复核输入输出策略，回归红队用例集；
- 数据出境：敏感数据禁止投喂公有云模型，出境前合规评估；
- 权限复核：按月复核角色、数据权限、知识库 ACL、能力授权；
- 漏洞管理：SCA/SAST/DAST 纳入流水线，高危立即修复；
- 三员分立：系统/安全/审计管理员职责分离。

## 9 故障处理

| 故障 | 现象 | 处理 |
|---|---|---|
| 检索延迟飙升 | P95 > 400ms | 检查 ES/Milvus 负载 → 扩容/降级（关重排/缩 Top-K）→ 启用缓存 |
| LLM 不可用 | 问答失败/超时 | 切换备用供应商 → 启用本地模型 → 降级仅检索 |
| 向量库故障 | 语义检索失败 | 降级全文检索；修复后重建集合 |
| 索引积压 | 任务排队增长 | 提升调度并发/优先级、扩容嵌入实例 |
| 审核积压 | 待办堆积 | 增派审核人、配置超时提醒 |
| BI 大屏超时 | 看板加载失败 | 切抽取模式、CH 预聚合、限流 |
| 洞察任务失败 | 无洞察结果 | 查看任务日志（查询超时/LLM 不可用）→ 重试/降级规则结论 |
| 越权/安全告警 | 拦截激增 | 封禁可疑主体 → 审计追溯 → 复核权限 → 上报安全组 |
| 计量异常 | 账单不一致 | 对账核查 → 幂等补偿 → 修正 |
| 双模式配置漂移 | 行为不一致 | 执行一致性校验（`AI-API-907`）→ 回滚配置 → 重启校验 |
| 门户 502/504 | 网关异常 | 检查网关与后端副本、Ingress、证书 |

**升级路径**：P0（不可用/泄漏/越权）15 分钟响应并升级；P1 30 分钟响应、2 小时恢复；P2/P3 工作日处理。

## 1 快速开始

### 1.1 三步上手

1. **登录**：访问 `https://service.fenglincloud.com/app/service`，使用企业账号登录（支持 SSO / 企微 / 飞书 / 钉钉扫码），首次登录完成 MFA 绑定。
2. **认识工作台**：进入「我的工作台」，查看我的工单、流程待办、消息与快捷入口。
3. **完成第一个动作**：点击右上角「＋ 新建工单」提交一条服务请求，或从「服务目录」选择服务项直接申请。

### 1.2 运行环境

| 项 | 要求 |
|---|---|
| 浏览器 | Chrome/Edge ≥ 110、Safari ≥ 16、Firefox ≥ 110 |
| 屏幕 | 支持 1440/1200/992/768 断点；移动端最小点击区 44×44px |
| 网络 | 建议 4G 及以上；页面首屏内网 ≤1s、4G ≤2s |
| 移动端 | 支持 PWA 安装与消息推送；复杂设计器建议桌面端 |

### 1.3 角色与可见范围

| 角色 | 主要可见范围 |
|---|---|
| 员工 | 本人提单与服务目录申请（SELF） |
| 服务台受理员 | 待受理/本组工单、分派与处置（DEPT/DEPT_AND_CHILD） |
| IT 支持工程师 | 本人处理工单、问题/变更、资产 |
| 知识库编辑 | 知识撰写、审核、发布 |
| 应用搭建者 | 本人应用的设计、发布、运行（应用级 + 数据权限） |
| RPA 开发/运维 | 机器人、自动化编排、调度、任务 |
| 流程分析师 | 事件日志、挖掘模型、自动化候选 |
| 只读用户 | 授权范围内查看，无写操作 |

## 2 登录与导航（用户端）

### 2.1 登录

1. 打开用户端地址 → 选择登录方式（账号密码 / 企业 SSO / 扫码）；
2. 输入企业账号与口令（需满足复杂度策略）；
3. 首次登录或异地登录需完成 MFA 二次验证；
4. 连续 5 次失败将锁定 15 分钟；空闲 30 分钟会话自动超时，需重新登录。

### 2.3 通用操作约定

- **新建**：多数列表页右上角提供「＋ 新建」；
- **筛选**：筛选条件可折叠、可保存为常用视图，条件同步到地址栏便于分享；
- **批量**：列表首列勾选后出现批量操作条（分派、升级、挂起等）；
- **导出**：导出为异步任务，完成后在消息中心下载；导出文件带水印与审计编号；
- **脱敏**：手机号默认显示 `138****8888`，查看明文需相应权限且记录审计；
- **二次确认**：关闭、撤销、发布、冻结、删除等关键操作需确认；
- **幂等提示**：提交按钮在响应前锁定，重复点击不会重复提交。

## 3 分模块操作指引

### 3.1 F1 员工服务与 IT 支持

#### 3.1.1 自助提单（员工）

1. 进入「服务台 → 自助提单」，点击「＋ 新建工单」；
2. 选择服务目录项（如"设备申请""账号开通""软件安装"）或直接选择问题类型；选择目录项后，下方表单会自动切换为该服务项绑定的申请表；
3. 填写标题、描述、影响范围与紧急程度；标题输入框失焦时系统会**自动推荐相关知识**（命中则提示"先自助解决"，但不阻断提交）；
4. 需要时可上传附件、关联资产；
5. 点击「提交工单」，系统生成工单编号 `SVC{年月}{6位}` 并跳转工单详情。

【截图位：自助提单页与知识推荐提示】

#### 3.1.2 查看我的工单与进度

1. 「服务台 → 我的工单」查看本人提单状态；
2. 每条工单展示 **SLA 计时条**（正常蓝色 / 临期黄色 / 违约红色）与剩余时间；
3. 打开工单详情可查看沟通记录、流转记录、附件、关联知识；
4. 支持在详情页追加回复、上传补充附件。

#### 3.1.3 服务目录申请（员工）

1. 「服务台 → 服务目录」，按分类浏览可用服务项；
2. 打开服务项查看说明、预计时限、所需材料；
3. 点击「申请」，填写申请表并提交；
4. 若该服务项需审批，提交后状态为"审批中"；审批通过后自动转为工单进入处理。

【截图位：服务目录与申请表单】

#### 3.1.4 服务台受理与处置（受理员/工程师）

1. 「服务台 → 服务台工作台」，切换页签：待受理 / 我的工单 / 本组 / SLA 临期；
2. **认领**：点击行内「认领」将工单分派给自己；或按规则由系统自动分派；
3. **处理**：点击「开始处理」，工单进入"处理中"；
4. **挂起**：需要用户反馈或第三方介入时点「挂起」（SLA 计时暂停），恢复后续计；
5. **升级**：问题严重或超时点「升级」，系统按升级矩阵通知上级或调整优先级；
6. **解决**：填写解决方案并点「解决」，可勾选「沉淀为知识」；工单将在 24 小时后自动关闭并向提单人发放满意度问卷；
7. **转派/协办**：可将工单转派给其他工程师或邀请协办。

【截图位：服务台工作台与工单详情抽屉】

#### 3.1.5 知识库（全部 / 知识库编辑）

1. 「知识库 → 知识检索」输入关键词全文检索（支持中文分词），返回高亮片段；
2. 打开文章可查看正文、版本、有用性比例；底部可点「有用 / 没用」反馈；
3. 知识库编辑可进入「知识编辑」撰写文章，设置分类与可见范围，提交审核或发布；
4. 工单解决时可一键把解决方案沉淀为知识。

#### 3.1.6 满意度评价（员工）

1. 工单关闭后，系统自动发放满意度问卷（站内信/邮件）；
2. 评价为 1–5 星 + 标签 + 留言；
3. 工单只能评价一次；评分低于 2 星会自动生成回访任务。

#### 3.1.7 问题、变更与资产（工程师）

- **问题**：把重复工单聚合为"问题"，记录根因、临时措施、已知错误；问题详情可查看关联工单；
- **变更**：提交配置/上线变更请求，填写计划与回滚预案，走审批流；变更完成后自动回写关联工单并通知；
- **资产**：查询 IT 资产，办理借用/归还；资产到期会按配置提前提醒。

### 3.2 F2 低代码/零代码

#### 3.2.1 创建应用（搭建者）

1. 进入「低代码 → 应用清单」，点击「＋ 新建应用」；
2. 填写名称、图标、描述、负责人、可见范围；可选择从模板创建（如"入职办理""设备申请""用章申请"）；
3. 创建后应用编码为 `{租户码}-APP-{4位}`，初始状态为"草稿"。

#### 3.2.2 表单设计器

1. 进入应用 → 「表单」，拖拽左侧组件到画布（布局、文本、数字、日期、下拉、附件、人员、部门、关联数据等）；
2. 选中字段在右侧配置属性：标签、是否必填、校验规则、默认值、计算公式、字段权限（可编辑/只读/隐藏）；
3. 配置**联动显隐**（满足条件显示/隐藏字段）；
4. 点击「预览」查看效果；点击「保存草稿」保存并生成版本。

【截图位：表单设计器三段式界面】

#### 3.2.3 流程设计器

1. 进入应用 → 「流程」，拖拽节点：开始/结束、审批节点（会签/或签/依次）、条件网关、并行网关、抄送、服务任务、定时边界事件；
2. 为审批节点配置处理人（发起人/角色/部门/指定人/表单人员字段）；
3. 为服务任务配置调用（API/Webhook/脚本）；
4. 点击「校验」检查流程完整性（缺开始/结束节点会报错）；点击「模拟」填入变量查看执行路径。

#### 3.2.4 数据模型设计

1. 进入应用 → 「数据模型」，定义实体、字段、类型、约束、索引与关联关系（1:1 / 1:N / N:N）；
2. 修改模型时点「差异预览」查看变更；点「兼容性校验」检查破坏性变更（被表单/流程引用会阻止保存）。

#### 3.2.5 页面搭建

1. 进入应用 → 「页面」，拖拽组件（列表、表单、看板、图表、详情、仪表盘、筛选器）；
2. 绑定数据源（数据模型/流程任务/外部 API）；外部 API 需在白名单内；
3. 配置可见范围与移动端自适应。

#### 3.2.6 应用权限与发布

1. 「应用权限」配置应用级、页面级、字段级权限；数据权限由管理员在管理端配置；
2. 「应用发布」：发布到**预发**无需审批；发布到**生产**需管理员审批；
3. 发布生成不可变快照，支持灰度与一键回滚。

#### 3.2.7 运行时使用（授权用户）

1. 通过应用入口填报表单、发起流程；
2. 「我的流程任务」查看待办，点开办理（同意/驳回/转办），可填写意见；
3. 应用被管理员冻结时，运行时会提示"应用已冻结"。

【截图位：运行时表单与我的流程任务】

#### 3.2.8 脚本与扩展（高级）

1. 在服务任务或计算字段中使用受限脚本（JS）；
2. 脚本在沙箱运行（无网络、无文件系统、超时 ≤3 秒）；
3. 保存时自动安全扫描，高风险脚本禁止发布。

### 3.3 F3 流程挖掘与 RPA

#### 3.3.1 事件日志管理（流程分析师）

1. 「挖掘 → 事件日志管理」，可批量导入（csv/xlsx）或对接实时接入；
2. 导入后查看接受/拒绝统计，可下载错误清单；
3. 日志字段：`case_id / activity / event_time / resource / source_system`。

#### 3.3.2 挖掘分析

1. 「挖掘 → 挖掘分析」，选择数据源与时间范围，点「模型发现」；系统生成流程网络图（节点频次=大小，耗时为热力色）；
2. 点「一致性检查」对比设计流程，查看跳步骤/返工/绕行/多余分布；
3. 点「瓶颈分析」查看耗时最长的活动与优化建议；
4. 查看「资源负荷」了解各资源的工作量与耗时；
5. 在「自动化候选」查看高重复、规则性强、人工耗时的活动，点「生成自动化候选」创建编排草稿。

【截图位：挖掘分析画布与瓶颈列表】

#### 3.3.3 机器人管理（RPA 运维）

1. 「RPA → 机器人管理」，查看机器人状态（在线/忙/离线/停用）、心跳、并发与成功率；
2. 点击「注册机器人」，填写名称、类型（有人值守/无人值守）、主机、能力与并发上限；
3. 凭据由管理员在管理端配置，此处仅可选择绑定的凭据，**不显示明文**。

#### 3.3.4 自动化编排（RPA 开发）

1. 「RPA → 自动化编排」，从草稿或新建开始；
2. 拖拽节点：打开应用、输入、读取表格、调用 API、条件、循环、人工审批；
3. 配置参数、错误处理（重试/退避/超限转人工）与**目标系统白名单**；
4. 点「校验」检查节点可达性与白名单；通过后「发布」。

#### 3.3.5 调度与任务中心

1. 「RPA → 调度计划」创建计划（定时 CRON / 事件触发 / 队列 / 手动），配置参数、机器人选择、超时与重试；
2. 也可在「任务中心」手动触发任务或批量调度（单批支持数百任务）；
3. 「任务中心」按状态查看：队列/运行中/待人工/已完成/失败；点击详情查看执行节点时间线与截图；
4. 失败任务可点「重投」；转为"待人工"的任务需人工处理后重投。

【截图位：任务中心与任务详情时间线】

#### 3.3.6 服务与自动化报表

- 「报表 → 服务报表」：工单量趋势、SLA 达成率、满意度、工程师工作量；
- 「报表 → 自动化效能」：任务成功率、平均耗时、节省人时、失败 TOP、机器人利用率。

## 4 常见任务场景

### 4.1 员工自助服务闭环

```
登录 → 自助提单（标题失焦先看知识推荐）→ 提交工单 → 查看进度(SLA计时)
 → 与工程师沟通 → 工程师解决 → 24h 自动关闭 → 满意度评价
```

### 4.2 服务台受理闭环（受理员）

```
工作台待受理 → 认领/分派 → 开始处理 → (需信息)挂起 → 恢复
 → 解决(沉淀知识) → 自动关闭发放问卷
```

### 4.3 低代码应用交付闭环（搭建者）

```
创建应用 → 表单设计 → 流程设计 → 数据模型 → 页面搭建 → 权限配置
 → 发布预发(免审批) → 验证 → 发布生产(管理端审批) → 运行时上线
```

### 4.4 从挖掘到自动化闭环（分析师+RPA 运维）

```
导入事件日志 → 模型发现 → 一致性检查 → 瓶颈分析 → 自动化候选
 → 生成编排草稿 → 编排设计(白名单) → 发布 → 调度计划 → 任务执行 → 效能看板
```

### 4.5 机器人任务排障（RPA 运维）

```
任务中心查看失败任务 → 打开详情看节点时间线与截图 → 定位错误码
 → (可重试)等待自动重试 / (不可重试)修复后人工重投
 → 若目标系统不可达 → 联系系统负责人 → 恢复后重投
```

## 5 FAQ

| 问题 | 解答 |
|---|---|
| 登录提示"未认证或令牌失效"怎么办？ | 会话空闲 30 分钟会自动超时，请重新登录；若仍失败请联系管理员核对账号状态。 |
| 提单时提示"请先自助解决"是什么意思？ | 系统根据标题推荐了相关度高（≥80%）的知识；你可先查看，也可忽略提示继续提交。 |
| 为什么手机号显示为 `138****8888`？ | PII 字段默认脱敏展示；查看明文需相应权限且会记录审计。 |
| 工单提交后没有重复生成？ | 提单为幂等操作，重复点击或重复请求只生成一条工单。 |
| 工单一直"处理中"没动静？ | 打开详情查看流转记录；若已挂起（等待用户或第三方）请及时补充信息。 |
| SLA 计时为什么暂停了？ | 工单挂起时 SLA 计时暂停，恢复后继续；非工作时段不计入工时。 |
| 目录项申请后为什么还没生成工单？ | 该服务项需审批，审批通过后才会生成工单；可在"我的工单"查看状态。 |
| 表单设计保存报错？ | 可能是必填或校验配置问题；错误会就地提示，修正后重试。 |
| 发布到生产为什么需要审批？ | 生产环境变更需管理员审批（合规与安全校验）；预发环境免审批。 |
| 应用运行时提示"已冻结"？ | 应用被管理员临时冻结，请联系管理员了解原因。 |
| 脚本保存被拒绝？ | 脚本安全扫描发现高风险（如网络访问、文件系统），请按扫描详情修改。 |
| 流程任务看不到待办？ | 请确认你在该节点处理人范围内；角色/部门变更后以服务端实时校验为准。 |
| 机器人任务一直"待人工"？ | 重试已耗尽或遇到不可重试错误，请打开详情定位原因并人工处理后重投。 |
| 为什么没有看到凭据明文？ | 凭据由 KMS 加密保管，界面与接口均不回显明文，执行时通过一次性临时令牌换取。 |
| 自动化任务提示"目标系统不在白名单"？ | 该访问被安全策略拦截，请联系管理员将目标系统加入白名单。 |
| 挖掘分析提示"数据量不足"？ | 事件日志样本过少无法建模，请导入更多数据或放宽时间范围。 |
| 导出的文件在哪里下载？ | 导出为异步任务，完成后在"消息中心"下载；文件带水印与审计编号。 |
| 移动端可以使用全部功能吗？ | 支持响应式与 PWA；复杂设计器建议在桌面端操作。 |
| 忘记密码怎么办？ | 通过企业 SSO 重置或联系管理员重置；连续 5 次失败将锁定 15 分钟。 |

## 6 快捷键

| 快捷键 | 功能 | 生效范围 |
|---|---|---|
| `Ctrl/Cmd + K` | 全局搜索（工单/知识/应用/任务） | 全站 |
| `N` | 快捷新建（新工单/新应用/新任务） | 列表页 |
| `Ctrl/Cmd + S` | 保存（表单/设计器/编排） | 编辑页 |
| `Ctrl/Cmd + Enter` | 提交/发布 | 提交类表单 |
| `Esc` | 关闭抽屉/弹窗 | 全站 |
| `G` 然后 `D` | 跳转我的工作台 | 全站 |
| `G` 然后 `T` | 跳转我的工单 | 全站 |
| `G` 然后 `L` | 跳转低代码应用清单 | 全站 |
| `G` 然后 `R` | 跳转 RPA 任务中心 | 全站 |
| `←/→` | 设计器画布内微移选中节点 | 表单/流程设计器 |
| `?` | 打开快捷键帮助 | 全站 |

> 快捷键支持全键盘操作，焦点样式清晰；输入框内不触发全局快捷键。

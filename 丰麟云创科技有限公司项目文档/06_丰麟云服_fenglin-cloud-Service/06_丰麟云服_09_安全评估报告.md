## 1 评估范围

### 1.1 评估对象

| 类别 | 范围 |
|---|---|
| 应用 | `fenglin-service-service`（F1/F2/F3 全部接口与双端页面）；机器人执行端 `fenglin-service-rpa-agent`（客户侧） |
| 接口 | `/api/service/v1/**`（76 个）、能力契约 `/lowcode-engine/v1/**`、回调 `/internal/**`、开放 API `/openapi/service/v1`、事件 Webhook |

## 2 等保三级控制矩阵逐项对照

> 结论列：✔ 满足；△ 部分满足（见加固）；✘ 不满足。

### 2.1 安全物理环境 / 安全通信网络

| 控制项 | 三级要求 | 云服实现 | 结论 |
|---|---|---|---|
| 通信传输保密性 | 密码技术保证通信保密 | 客户端↔网关 TLS 1.2+（推荐 1.3）；微服务/执行端 mTLS；KMS 签发与轮换 | ✔ |
| 通信传输完整性 | 保证通信完整性 | TLS 记录层校验；回调/Webhook HMAC-SHA256 签名 | ✔ |
| 网络架构 | 划分安全区域与边界防护 | K8s NetworkPolicy 隔离；网关统一入口；`/internal/**` 仅 mTLS 可达；执行端独立网段 | ✔ |
| 网络访问控制 | 最小权限控制网络访问 | 数据库/中间件仅应用网段；管理端口禁公网；RPA 目标系统白名单 | ✔ |

### 2.2 安全区域边界

| 控制项 | 三级要求 | 云服实现 | 结论 |
|---|---|---|---|
| 边界防护 | 非授权设备不得接入 | WAF + 网关白名单 + K8s 网络策略 + 执行端准入凭证 | ✔ |
| 访问控制 | 边界源/目的/端口控制 | 网关端别策略（ADMIN/PORTAL）；Sentinel 按租户+接口限流；自动化访问白名单 | ✔ |
| 入侵防范 | 检测并阻断已知攻击 | IDS/IPS + WAF（SQLi/XSS/命令注入）；依赖 SCA 阻断高危 | ✔ |
| 恶意代码防范 | 边界恶意代码检测 | 上传文件病毒扫描 + 类型/大小白名单；脚本静态扫描 | ✔ |
| 安全审计 | 边界审计与告警 | 网关访问日志 + 异常流量与越权告警（Alertmanager） | ✔ |

### 2.3 安全计算环境

| 控制项 | 三级要求 | 云服实现 | 结论 |
|---|---|---|---|
| 身份鉴别-唯一标识 | 用户标识唯一 | 中台 IAM 统一账号（员工工号唯一）；机器人独立设备身份 | ✔ |
| 身份鉴别-复杂度与周期 | 口令复杂度、定期更换 | 口令复杂度策略 + 90 天到期提醒 | ✔ |
| 身份鉴别-MFA | 双因子鉴别 | 登录 MFA；管理端高风险操作（凭据配置、发布审批、跨租户）二次验证 | ✔ |
| 身份鉴别-失败锁定 | 登录失败处理 | 连续 5 次失败锁定 15 分钟；会话空闲 30min 超时 | ✔ |
| 访问控制-最小权限 | 授予最小权限 | RBAC 权限码 + 数据权限（SELF/DEPT/DEPT_AND_CHILD/CUSTOM/ALL）+ 字段权限 + 应用级权限 | ✔ |
| 访问控制-职责分离 | 关键操作分离 | 申请人≠审批人；发布/编排设计≠审批/治理；三员分立 | ✔ |
| 访问控制-默认拒绝 | 默认拒绝未授权 | 无权限码默认拒绝；跨租户默认拒绝（RLS）；白名单外系统拒绝（`6008002`） | ✔ |
| 安全审计-全覆盖 | 覆盖重要用户与操作 | 登录、权限变更、配置变更（SLA/目录/白名单/凭据）、发布审批、凭据换取/使用、PII 查看、导出全覆盖 | ✔ |
| 安全审计-防篡改 | 审计记录防删改 | 写 `fenglin-audit-service`（哈希链 + WORM）；应用侧无删除接口 | ✔ |
| 安全审计-留存 | 留存 ≥ 6 个月 | 操作审计 12 个月，任务日志默认 365 天，安全日志 ≥ 6 个月 | ✔ |
| 入侵防范-最小安装 | 仅安装必要组件 | 基础镜像最小化；无多余端口/服务 | ✔ |
| 入侵防范-漏洞修补 | 及时修补 | 镜像扫描 + 依赖 SCA + 发布流水线阻断高危 | ✔ |
| 恶意代码-主机防护 | 主机恶意代码防范 | HIDS + 镜像扫描 + 运行时防护（执行端同样纳管） | ✔ |
| 可信验证 | 关键设备/程序可信验证 | 镜像签名校验（cosign）+ ArgoCD 基线校验 | △（私有化需开启可信根，见 R-01） |
| 数据完整性 | 传输/存储完整性 | TLS、HMAC、数据库约束与业务校验（状态机、幂等、乐观锁） | ✔ |
| 数据保密性 | 传输/存储加密 | PII AES-256-GCM；TDE；RPA 凭据 KMS 加密；密钥轮换 ≤90 天 | ✔ |
| 数据备份恢复 | 本地/异地备份与演练 | 每日全备 + WAL 归档、异地容灾、季度演练（RPO 2.4min / RTO 18min） | ✔ |
| 剩余信息保护 | 存储/内存剩余信息清除 | 逻辑删除 + 物理清理；凭据临时令牌内存一次性；日志脱敏 | △（内存级清零依赖运行时，见 R-02） |
| 个人信息保护 | 最小必要/脱敏/授权/审计 | 手机号加密存储 + `phone_hash` 检索；展示脱敏；查看明文需权限并审计 | ✔ |

## 3 威胁建模（STRIDE）

| 威胁类别 | 场景 | 资产 | 攻击面 | 缓解措施 | 残余等级 |
|---|---|---|---|---|---|
| **S**poofing | 伪造令牌访问接口 | 全部接口 | 网关、JWT | JWT RS256 校验；`X-Client-Type` 与令牌 `client_type` 一致；`X-Tenant-Id` 一致；MFA | 低 |
| **S**poofing | 伪造机器人执行端领取任务/回调 | 任务、凭据 | 内部接口 | 执行端 mTLS + 注册凭证；回调幂等键；凭据临时令牌 | 低 |
| **S**poofing | Webhook 伪造回调 | 事件订阅 | 开放 API | HMAC-SHA256 签名 + 时间戳防重放 + `eventId` 幂等 | 低 |
| **T**ampering | 篡改工单状态/流转日志 | 工单、日志 | 业务接口 | 服务端状态机校验；非法迁移 `6001002`；审计留痕 | 低 |
| **T**ampering | 篡改低代码应用定义/发布快照 | 应用、快照 | 设计器/发布 | 发布快照不可变；生产变更需审批；权限码控制 | 低 |
| **T**ampering | 篡改审计日志 | 审计 | 审计库 | 哈希链 + WORM；应用仅追加；篡改告警 | 低 |
| **R**epudiation | 否认审批/发布/调度操作 | 审批、发布、任务 | 业务操作 | 操作人 + 时间戳 + 客户端信息审计；审批意见不可删改 | 低 |
| **I**nformation Disclosure | 越权读取他人/他部门工单 | 工单 | 查询接口 | RLS + 数据权限 SQL 拦截；状态/范围双重校验（`6001004`） | 低 |
| **I**nformation Disclosure | PII 明文泄漏 | 手机号 | 库/接口/日志/导出 | AES-256-GCM 存储；展示/导出/日志脱敏；明文查看审计 | 低 |
| **I**nformation Disclosure | **RPA 凭据窃取** | 目标系统凭据 | 执行端/接口 | KMS 加密保管；接口不回显明文；一次性临时令牌 TTL ≤60s；全链路审计脱敏 | 低 |
| **I**nformation Disclosure | 挖掘事件日志泄漏 | 事件日志 | 接入/报表 | 接入鉴权 + 幂等；日志脱敏；可见范围控制 | 低 |
| **D**enial of Service | 高频提单/调度打满 | 服务/DB/执行端 | 全部接口 | 网关限流（读 200/写 50/批量 5 QPS）；Sentinel 熔断；批量调度分批 + 机器人并发上限；HPA | 中（见 R-04） |
| **D**enial of Service | 脚本死循环耗尽执行资源 | 沙箱 | 脚本执行 | 沙箱超时 ≤3s、内存 ≤64MB、无网络/文件、白名单 API | 低 |
| **E**levation of Privilege | 普通用户调用管理端配置接口 | 配置接口 | ADMIN 前缀 | 端别强校验；权限码校验；仅 ADMIN 令牌可达 | 低 |
| **E**levation of Privilege | **脚本沙箱逃逸提权** | 宿主/数据 | 沙箱 | 沙箱隔离 + 静态扫描阻断高危；无网络/文件/反射受限；越权调用返回 `6004004` | 低 |
| **E**levation of Privilege | **自动化越权访问系统** | 外部系统 | 编排执行 | 白名单双重校验（调度+执行）；越界 `6008002` 并告警 | 低 |
| **E**levation of Privilege | 搭建者越权发布生产 | 应用 | 发布接口 | 生产发布需管理端审批（`tenant:service:app:approve`）；快照不可变 | 低 |

## 6 加固措施

| 类别 | 加固项 | 措施 |
|---|---|---|
| 传输 | 全链路加密 | 强制 TLS 1.2+（推荐 1.3）；HSTS；内部/执行端 mTLS；禁弱套件 |
| 存储 | 加密与密钥 | PII AES-256-GCM + TDE；RPA 凭据 KMS 托管；轮换 ≤90 天；`{field}_hash` 替代明文索引 |
| 访问 | 最小权限 | RBAC + 数据权限 + 字段权限 + 应用权限；跨租户默认拒绝；白名单最小化 |
| 认证 | 强认证 | MFA；5 次失败锁定；会话 30min 超时；令牌短期 + 刷新轮换；执行端设备身份 |
| 审计 | 不可篡改与留存 | 哈希链 + WORM；留存 12 个月；凭据/发布/白名单/PII 强制审计 |
| 脚本 | 沙箱与扫描 | 网络/文件禁用 + 资源限制 + API 白名单 + 静态扫描阻断高危 |
| 自动化 | 白名单与配额 | 白名单双重校验；机器人并发上限；批量分批下发；越界告警 |
| 输入输出 | 校验与编码 | 参数白名单；统一异常码；输出编码防 XSS；文件类型/大小白名单 + 病毒扫描 |
| 依赖 | 供应链安全 | 镜像签名 + SCA + 镜像扫描；无高危进入发布 |
| 运行时 | 防护与隔离 | HIDS + 容器最小权限（非 root、只读根文件系统）+ NetworkPolicy |
| 剩余信息 | 清理 | 逻辑删除 + 物理清理；临时令牌一次性；日志/缓存/截图脱敏 |
| 合规 | 个人信息保护 | 最小必要；告知同意；脱敏展示；授权访问；可审计；支持删除（逻辑删除 + 清理） |

## 7 合规结论

1. 对照 GB/T 22239-2019 三级基本要求与 FL-HUB-STD-001 第 8 章控制矩阵，丰麟云服 **11 类控制域核心项全部满足，2 项部分满足**（可信验证、剩余信息保护的内存级清零），已列入加固计划；
2. OWASP Top 10（2021）逐项测试未发现高危可利用漏洞；中低危发现项已全部修复；
3. **重点专项全部通过**：脚本沙箱（28 项逃逸全部被拦）、RPA 凭据保管（无明文泄漏、临时令牌可控）、自动化越权（白名单越界全部被拦）；
4. 越权（水平/垂直）、PII 泄漏、注入、并发滥用等专项测试全部通过；
5. 容灾演练 RPO 2.4min、RTO 18min，备份恢复有效；
6. **合规结论：达到网络安全等级保护三级要求，可提交测评**；无高危漏洞遗留（与 AC-12 一致）。

| 编号 | 残余风险 | 等级 | 说明 | 缓解与跟踪 |
|---|---|---|---|---|
| R-01 | 可信验证依赖部署环境可信根 | 低 | 私有化客户若未开启可信根，镜像签名校验降级 | 私有化交付清单强制开启；交付验收项 |

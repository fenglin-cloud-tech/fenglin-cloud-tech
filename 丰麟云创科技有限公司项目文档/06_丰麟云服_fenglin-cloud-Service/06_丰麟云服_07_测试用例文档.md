## 1 测试范围与策略

### 1.1 测试范围

| 层次 | 范围 |
|---|---|
| 功能 | F1 员工服务与 IT 支持、F2 低代码/零代码、F3 流程挖掘与 RPA 全部 FR（SRS 第 3 章） |
| 接口 | `/api/service/v1/**`（76 个）、能力契约 8 项、回调契约 4 项、开放 API 6 项、事件 16 类 |
| 页面 | 用户端 32 页、管理端 20 页（UIUX 第 3 章） |
| 非功能 | 性能、安全、可靠性、兼容性（SRS 第 4 章） |
| 集成 | 中台 `fenglin-lowcode-service` / `workflow-service` / `ai-service` / `message` / `file` / `audit` / `search` / `report` / `openapi` |

### 1.2 测试策略

| 方法 | 说明 |
|---|---|
| 单元测试 | 领域规则（SLA 计时、状态机、分派策略、重试策略）覆盖率 ≥ 70% |
| 接口测试 | 全接口正向 + 参数/权限/异常/幂等用例 |
| 集成测试 | 低代码引擎能力契约、工作流回调、RPA 执行端回调、消息与审计链路 |
| 状态机测试 | 工单/流程实例/流程任务/机器人任务全状态迁移（含非法迁移） |
| 性能测试 | 工单并发创建 300TPS、流程实例流转 200TPS、RPA 批量调度 500 任务 ≤10s |
| 安全测试 | 越权、PII、脚本沙箱、RPA 凭据、自动化白名单、开放 API 签名 |
| 兼容测试 | 浏览器、移动端、开放 API 版本、模板导入 |
| 回归测试 | 核心链路回归组 R1–R8 |

### 1.3 测试环境

dev / test / staging（staging 用于性能与安全测试，规格同生产 1:2 缩比）；数据基线：1 租户、2 部门、1 员工、5 线索迁移数据（云服自建：3 处理组、4 目录项、5 SLA 策略、6 知识文章、2 应用、3 机器人）。

## 5 缺陷分级

| 级别 | 定义 | 示例 | 处理时限 |
|---|---|---|---|
| S1 致命 | 服务不可用、数据丢失/错乱、安全越权可致泄漏、金额/权限类严重错误 | 工单重复生成、跨租户数据可见、凭据明文回显 | 立即，24h 内修复 |
| S2 严重 | 核心功能不可用或结果错误、性能严重不达标、SLA 计时错误 | SLA 计时不准确、发布快照可篡改、任务重试失效 | 2 个工作日内 |
| S3 一般 | 非核心功能异常、体验问题、边界场景缺陷 | 提示文案错误、次要筛选失效 | 5 个工作日内 |
| S4 轻微 | 文案/样式/易用性建议 | 空态文案、间距 | 版本计划内 |

**缺陷流转**：新建 → 指派 → 修复 → 验证 → 关闭；S1/S2 必须回归并补充用例；缺陷率与收敛曲线纳入测试报告。

**通过标准**：S1/S2 全部关闭；S3 关闭率 ≥95%；S4 登记并排期；核心链路用例 100% 通过；性能与安全关键用例全部达标。
